Kwai Keye-VL 기술 보고서
Multimodal Reinforcement Learning
108
Kwai Keye Team, Biao Yang, Bin Wen, Changyi Liu, Chenglong Chu, Chengru Song, Chongling Rao, Chuan Yi, Da Li, Dunju Zang, Fan Yang, Guorui Zhou, Hao Peng, Haojie Ding, Jiaming Huang, Jiangxia Cao, Jiankang Chen, Jingyun Hua, Jin Ouyang, Kaibing Chen, Kaiyu Jiang, Kaiyu Tang
Jul 2

핵심 요약

1. Kwai Keye-VL은 동적이고 정보 밀집한 단편 영상을 이해하는 데 뛰어난 성능을 발휘하는 80억 개 파라미터의 다중 모달 기초 모델이며, 이는 6000억 토큰을 넘는 대규모 고품질 데이터셋과 혁신적인 훈련 레시피에 기반합니다. 2. 훈련 레시피에는 시각-언어 정렬을 위한 4단계의 사전 훈련 과정이 포함되어 있고, 이어서 기초 기능 강화를 위한 첫 번째 사후 훈련 단계와 고급 추론을 위한 두 번째 단계가 있습니다. 특히, 두 번째 단계에서는 "추론", "비추론", "자동 추론", "이미지와 함께 추론", 고품질 비디오 데이터를 포함하는 5가지 모드의 "콜드 스타트" 데이터 혼합이 중요한 혁신입니다. 3. Keye-VL은 공개 비디오 벤치마크에서 최고 수준의 결과를 달성하며 일반 이미지 기반 작업에서도 경쟁력을 유지합니다. 또한, 우리는 실제 단편 영상 시나리오에 적합한 새로운 벤치마크 KC-MMBench를 개발하고 공개했으며, Keye-VL은 큰 장점을 보여줍니다.

Abstract

다중 모달 대형 언어 모델(MLLMs)은 정적 이미지에서 놀라운 성능을 보이지만, 현재의 디지턀 랜드스케이프에서 주요한 매체인 동적이고 정보 밀집형 단편 영상을 이해하는 데 한계가 있습니다. 이러한 간극을 메우기 위해, 저희는 Kwai Keye-VL을 소개합니다. 이는 80억 개 파라미터의 다중 모달 기초 모델로, 우수한 단편 영상 이해 성능을 발휘하면서도 견고한 일반적인 비전-언어 능력을 유지합니다.

LongAnimation: Long Animation Generation with Dynamic Global-Local Memory

다이내믹 글로벌-로컬 메모리를 활용한 롱 애니메이션 생성(LongAnimation: Long Animation Generation with Dynamic Global-Local Memory)
Computer Vision
67
Nan Chen, Mengqi Huang, Yihao Meng, Zhendong Mao
Jul 2

핵심 요약

1. 기존 연구들이 지역적 정보에만 의존하여 장기적인 색상 일관성을 유지하지 못하는 문제를 해결하기 위해 LongAnimation 프레임워크를 제안하였다. 2. LongAnimation은 다이내믹 글로벌-로컬 메모리를 활용하여 현재 생성과 관련된 글로벌 색상 일관 특징을 동적으로 추출하여 색상 일관성을 개선한다. 3. 실험 결과는 LongAnimation이 단기와 장기 애니메이션에서 색상 일관성을 효과적으로 유지하는 데 성공했음을 입증하며, 이는 오픈 도메인 애니메이션 컬러화 작업에 중요한 기여를 한다.

Abstract

애니메이션 컬러화는 실제 애니메이션 산업 제작의 중요 부분이다. 긴 애니메이션 컬러화는 높은 노동 비용을 요구한다. 따라서 비디오 생성 모델을 기반으로 하는 자동화된 긴 애니메이션 컬러화는 중요한 연구 가치가 있다. 기존 연구들은 단기 컬러화에 제한되어 있다. 이러한 연구들은 지역적 패러다임을 채택하여 중첩된 특징을 융합하여 지역 세그먼트 간의 부드러운 전환을 달성한다. 그러나 지역적 패러다임은 글로벌 정보를 무시하여 장기적인 색상 일관성을 유지하지 못한다. 본 연구에서는 이상적인 장기적인 색상 일관성은 현재 생성과 관련이 있는 글로벌 색상 일관 특징을 동적으로 추출하는 다이내믹 글로벌-로컬 패러다임을 통해 달성할 수 있다고 주장한다. 구체적으로, 우리는 SketchDiT, Dynamic Global-Local Memory (DGLM), Color Consistency Reward를 주로 포함하는 새로운 LongAnimation 프레임워크를 제안한다. SketchDiT는 DGLM 모듈을 지원하기 위해 혼합 참조 기능을 캡처한다. DGLM 모듈은 긴 비디오 이해 모델을 채택하여 글로벌 역사적 특징을 동적으로 압축하고 현재 생성 특징과 적응적으로 융합한다. 색상 일관성을 개선하기 위해 Color Consistency Reward를 도입한다. 추론 중에는 비디오 세그먼트 전환을 부드럽게 하는 색상 일관성 융합을 제안한다. 짧은 기간(14프레임)과 장기(평균 500프레임) 애니메이션 두 가지에 대한 방대한 실험은 LongAnimation이 오픈 도메인 애니메이션 컬러화 작업의 단기와 장기 색상 일관성을 유지하는 데 효과적임을 보여준다. 코드는 https://cn-makers.github.io/long_animation_web/에서 확인할 수 있다.

LLM Reinforcement Learning
62
Kuan Li, Zhongwang Zhang, Huifeng Yin, Liwen Zhang, Litu Ou, Jialong Wu, Wenbiao Yin, Baixuan Li, Zhengwei Tao, Xinyu Wang, Weizhou Shen, Junkai Zhang, Dingchu Zhang, Xixi Wu, Yong Jiang, Ming Yan, Pengjun Xie, Fei Huang, Jingren Zhou
Jul 3

핵심 요약

1. LLM 훈련에서 초인적 추론 능력이 중요한데, WebSailor는 오픈 소스 모델에서 부재한 정교한 추론 패턴을 도입하여 극단적 불확실성을 줄이는 능력을 훈련시키는 방법론이다. 2. WebSailor의 접근 방식은 새로운 고불확실성 작업 생성, 구조화된 샘플링 및 정보 난해화, RFT 콜드 스타트, 그리고 'DUPO'라는 강화학습 알고리즘을 활용하여 나타난다. 3. WebSailor는 복잡한 정보 탐색 작업에서 오픈 소스 에이전트들을 앞선 성과로 이끄는데, 이를 통해 전용 에이전트의 성능과 능력 갭을 줄이는 것에 성공한다.

Abstract

인간의 인지적 한계를 넘어서는 것은 LLM(대규모 언어 모델) 훈련에서 중요한 최전선을 대표한다. DeepResearch와 같은 전용 에이전트 시스템은 BrowseComp와 같은 매우 복잡한 정보 탐색 벤치마크에서 초인적인 능력을 보여주어 이전에는 불가능했던 성취를 이루었다. 이들의 성공은 오픈 소스 모델에 없는 정교한 추론 패턴에 달려있음을 주장한다: 방대한 정보 영역을 탐색할 때 극단적 불확실성을 체계적으로 줄일 수 있는 능력. 이 통찰력을 바탕으로 이 중요한 능력을 심어주기 위한 완전한 후 훈련 방법론인 WebSailor를 소개한다. 저희의 접근 방식은 새로운 고불확실성 작업을 생성하기 위해 구조화된 샘플링과 정보 난해화, RFT 콜드 스타트, 효율적인 에이전트 강화학습 훈련 알고리즘인 'Duplicating Sampling Policy Optimization (DUPO)'을 포함한다. 이 통합된 파이프라인을 통해 WebSailor는 복잡한 정보탐색 작업에서 오픈 소스 에이전트들을 크게 앞선 성과를 보여주며, 전용 에이전트의 성능에 필적하여 능력 차이를 좁힌다.

Abstract

본 연구에서는 객체, 카메라, 배경을 재구성하여 새로운 장면을 합성하는 생성적 시각 합성 프레임워크인 BlenderFusion을 제안합니다. 이는 레이어링-편집-합성 파이프라인을 따릅니다. 시각적 입력을 편집 가능한 3D 엔티티로 분할하고 변환하는 과정(레이어링), Blender에서 3D-기반 제어로 편집하는 과정(편집), 생성적 컴포지터를 사용하여 일관된 장면으로 퓨징하는 과정(합성). 저희의 생성적 컴포지터는 사전 훈련된 확산 모델을 확장하여 원본(소스) 및 편집된(타겟) 장면을 병렬로 처리합니다. 두 가지 주요 훈련 전략인 소스 마스킹(배경 교체와 같은 유연한 수정 가능)과 시뮬레이션 객체 지터링(객체 및 카메라에 대한 분리된 제어 용이화)을 사용하여 비디오 프레임으로 미세 조정됩니다. BlenderFusion은 복합적인 합성 장면 편집 작업에서 이전 방법들을 현격히 능가합니다.

Abstract

본 보고서에서는 멀티모달 이해, 텍스트-이미지 생성, 이미지 편집 기능을 통합한 30억 개 파라미터의 Ovis-U1을 소개합니다. Ovis-U1은 OpenCompass 멀티모달 학술 벤치마크에서 69.6의 점수를 기록하여 Ristretto-3B 및 SAIL-VL-1.5-2B와 같은 최근 최첨단 모델을 앞섭니다.
