When Instructions Retrieve Trajectories: Diagnosing and Mitigating Generalization Failures in VLA Models

arXiv PDF alphaXiv
VLA relevance 10/10 Robotics (cs.RO)
Hung-Jen Chen, Yu-Hsun Hou, Yan-Hong Chen, Yan-Fu Chen, Binghua Cai, Min Sun, Chun-Yi Lee PDF 전문 1차 66점
π0.5·GR00T-N1.7 같은 VLA가 language와 vision 둘 다에 반응하면서도 이를 결합해 올바른 행동을 선택하지 못하는 instruction-action binding 실패를, 행동 분석과 internal state 개입으로 규명함. 같은 instruction이 scene에 따라 다른 action을 요구하는 counterfactual demonstration과 paired loss로 학습하는 Equivariant Counterfactual Training(ECT)을 제안해 LIBERO-PRO position-swap 성공률을 36%에서 59%로, 실로봇 unseen-position 성공률을 8%에서 88%로 올림.
Core Innovation & Methodology
- VLA 실패를 nuisance(행동 불변 perturbation)와 counterfactual(행동 요구 변경 perturbation)로 구분하고, 둘 다에 강건해 보이는 aggregate robustness score가 instruction-action binding 실패를 가릴 수 있음을 지적함 - 381개 targeted probe에서 실패 rollout의 69%가 source task나 다른 demonstrated task를 그대로 재현하는 retrieval-like 행동임을 human labeling(inter-annotator κ=0.78)으로 확인함 - flow matching objective를 분석해, demonstration의 narrow conditional action support 하에서는 instruction-keyed lookup 해와 grounded 해가 수학적으로 구분되지 않음을 보임 - ECT를 제안함: 같은 instruction·다른 scene·다른 요구 action의 five-tuple 쌍을 구성하는 ECT data와, 두 counterpart의 imitation loss를 한 업데이트에서 같이 최적화하는 ECT loss로 구성됨 - internal state 개입(prefix-KV readout으로 모델 내부 KV cache에서 현재 실행 중인 task 표현을 교체)으로 행동이 바뀌는지 확인해, VLA가 실행 task를 internal state에 인코딩함을 mechanistic하게 보임
Novelty vs. Prior Works
- 가장 가까운 prior work인 CAG(Fang et al., 2026)는 inference 시점에 language conditioning을 강화하는데, ECT는 학습 데이터의 supervision 구조(conditional action support 부족) 자체를 고친다는 점에서 본질적으로 다름 - RoCoDA·MimicGen과 scene 변환 mechanism은 유사하지만, instruction-action binding 진단에서 역으로 필요한 counterfactual 쌍을 설계했다는 problem formulation의 novelty가 있음 - prefix-KV readout과 closed-loop intervention으로 실행 task가 internal state에 인코딩되어 교체 시 행동이 바뀐다는 mechanistic 증거를 제시한 점은 기존 counterfactual augmentation 연구에 없던 기여임
Benchmark Results
- LIBERO-PRO 4개 suite 모두에서 official π0.5·GR00T-N1.7 checkpoint가 nuisance cell 대비 counterfactual cell(Swap, Task)에서 최소 42pt 낮은 성공률을 보임 - Frozen-LM 조건(3 seed 평균)에서 ECT data+loss가 π0.5 mean Swap 성공률을 36%에서 59%로, mean Task를 21%에서 28%로 올림 - CALVIN ABC→D에서 추가 demonstration 없이 ECT loss만으로 5-task 연속 완료율(LH-5)이 58%에서 76%로 상승함 - 실로봇 UR5e에서 400 demonstration 고정 예산 하에 unseen-position 성공이 Standard 3/40에서 ECT data 30/40, ECT data+loss 35/40으로 증가함(task 종류는 본문에서 확인 불가) - demonstration을 25%에서 100%로 늘려도 Swap·Task는 ID 대비 항상 34pt 이상 낮게 유지되어, 단순 demonstration 수 증가로는 해결되지 않음을 보임
누리랩 연구와의 연결
- instruction-action binding 진단 틀은 누리랩의 VLA failure detection/diagnosis 연구에 바로 적용 가능함 — rollout이 familiar하지만 틀린 trajectory를 재현하는지 readout으로 검출하는 모듈 설계에 참고할 수 있음 - prefix-KV 교체로 action을 교정하는 test-time intervention 결과는 실패 감지 후 internal state를 고쳐 복구하는 test-time recovery 메커니즘의 proof-of-concept으로 쓸 수 있음 - ECT data 구성 방식(같은 instruction·다른 scene, replay controller로 action-valid 확보)은 robot memory·counterfactual augmentation 파이프라인에 바로 이식 가능함

BIND: Binding 3D Robot Actions to 2D Image Features

arXiv PDF alphaXiv
Manipulation relevance 9/10 Robotics (cs.RO)
Cameron Smith, Arsh Tangri, Vitor Guizilini, Yue Wang, Zubair Irshad, Sergey Zakharov PDF 전문 1차 68점
BIND는 3D action 후보를 camera geometry로 2D image feature에 투영해 결합하는 action head를 제안해, global feature pooling 기반 정책보다 data efficiency와 out-of-distribution robustness를 크게 높임. 실로봇에서 단 5개 demo로 near-perfect 성공을 달성하고, camera viewpoint·object position이 크게 바뀌어도 global-regression baseline이 완전히 실패하는 조건에서 성능을 유지함.
Core Innovation & Methodology
- 기존 global-regression 정책(ACT, Diffusion Policy, π0)은 CLS token 등 하나의 global feature vector에서 MLP로 action을 직접 regression해, action-feature 간 projective relationship을 데모만으로 학습해야 하는 구조임 - BIND는 end effector 후보 위치들을 3D volume으로 discretize하고, 각 후보를 camera pose·intrinsics로 매 camera view의 image feature map에 투영해 feature를 bilinear sampling함 - 후보 position과 투영된 image feature를 concat해 작은 MLP로 classification score를 매기고 cross-entropy로 학습하며, inference는 argmax로 위치를 선택함 - rotation·gripper는 선택된 위치의 feature를 teacher forcing(학습)/argmax(추론)로 인덱싱해 별도 MLP로 전체 chunk를 예측하고, image encoder(DINOv3)는 freeze하지 않고 head와 end-to-end fine-tuning함
Novelty vs. Prior Works
- PerAct·C2F-ARM·GNFactor 같은 voxel-categorical head와 유사하게 action을 3D 위치 classification으로 보지만, 이들은 voxel화된 RGB-D fusion에 의존해 free-space voxel에는 feature가 없고 sparse keyframe만 예측하는 반면, BIND는 free-space 후보도 projection으로 feature를 받아 dense-in-time chunk를 예측함 - RVT·RVT-2는 point cloud를 가상 view로 재렌더링해 2D heatmap을 예측한 뒤 멀티뷰 triangulation으로 3D를 복원하는데, BIND는 방향을 반대로 해 3D candidate를 2D로 내려 투영하므로 depth sensor, 재렌더링, triangulation이 모두 불필요함 - 핵심 아이디어는 action-feature 관계를 camera geometry라는 closed-form 식으로 explicit하게 제공한다는 것으로, 새로운 representation learning이 아니라 기존 2D encoder에 기하학적 inductive bias를 주입한 조합이라 architecture 자체의 참신성은 제한적이나 실용적 효과가 큼
Benchmark Results
- 실로봇 cup pick-and-place에서 5개 demo만으로 BIND는 progress 100(10/10 성공)을 달성한 반면, ACT는 모든 data 규모에서 36% 이하, Motion Tracks는 31% 이하에 머묾 - OOD object position(학습은 테이블 왼쪽 절반, 평가는 오른쪽 절반)에서 BIND는 progress 63점(63/100)을 유지하는데 ACT와 Motion Tracks는 0으로 완전히 붕괴함 - OOD camera viewpoint(3개 미학습 시점 평균)에서 BIND는 79점, ACT는 1점, Motion Tracks는 4점에 그침 - LIBERO Spatial/Object suite에서 BIND는 92.0%/94.0%(평균 93.0%)로 OpenVLA(86.6%), SpatialVLA(89.1%)보다 높고 π0(97.8%), GR00T N1.7(97.6%) 등 대형 pretrained 모델에는 못 미침 - RoboTwin 5개 task 평균 성공률 77.8%로 point cloud 기반 ManiFlow-3D(61.9%)보다 높음. teapot·cup stacking·spill cleanup·fold towel 등 long-horizon dexterous task는 30~40개 demo 기준 단일 실험이고, 코드·모델 공개 여부는 본문에서 확인 불가
누리랩 연구와의 연결
- action head 설계에서 camera geometry를 explicit prior로 주는 아이디어는 누리랩 manipulation·VLA 정책을 실로봇에 이식할 때 OOD robustness를 높이는 가벼운 대안으로 바로 시도해볼 만함 - object-centric 3DGS나 scene graph 연구와 결합해, 3D candidate volume을 scene representation에서 직접 뽑아 action head에 연결하는 방식으로 확장 가능함 - failure detection/recovery 관점에서 image-bound feature 점수를 action 품질의 uncertainty signal로 재활용해 test-time verifier를 만드는 아이디어로 이어질 수 있음

PRICE the Action Chunks: Physical Relational Credit Assignment for Embodied Reinforcement Learning

arXiv PDF alphaXiv
RL relevance 9/10 Robotics (cs.RO)
Yangang Zou, Jiajun Lu, Weitao Zhou, Haibao Yu, Bozhou Zhang, Jiawei Wang, Honglong Tian, Minglei Li 외 1명 PDF 전문 1차 64점
Outcome 기반 RL로 VLA를 post-training할 때 trajectory 전체에 같은 advantage를 주는 문제를, 같은 물리적 상황에 도달한 다른 rollout들의 성공 여부를 서로의 참조로 삼아 action chunk 단위 credit으로 바꾸는 PRICE를 제안함. 추가 evaluator 없이 cross-trajectory physical relational graph와 confidence gating만으로 LIBERO·RoboTwin 2.0·실로봇에서 outcome-based baseline 대비 성공률과 학습 속도를 모두 개선함.
Core Innovation & Methodology
- 긴 horizon manipulation에서 outcome-based GRPO가 모든 action chunk에 같은 trajectory-level advantage를 주는 문제를 지적하고, 같은 물리적 situation에 도달한 rollout들의 terminal outcome을 서로의 참조로 쓴다는 insight를 제안함. - visual·proprioceptive descriptor로 chunk 경계를 node로 clustering한 physical relational graph를 만들어 현재 round와 과거 round의 outcome을 pooling해 node별 success potential을 추정함. - 두 endpoint의 potential 차이를 Hoeffding 부등식 기반 confidence interval로 gating해, 불확실한 credit은 버리고 신뢰할 수 있는 credit만 GRPO advantage에 더함. - oracle potential 변화가 terminal-success objective의 gradient와 일치함을 이론적으로 보이고(Theorem 1), finite-sample 상황에서 credit 방향이 틀릴 확률의 bound를 제시함.
Novelty vs. Prior Works
- 가장 가까운 evaluator 기반 접근(VLA-RL, TGRPO, SRPO, world-model 기반 Feat2Go 등)은 학습된 reward·value model이나 world model, task-specific progress label이 필요한데, PRICE는 추가 evaluator 없이 rollout들 간의 물리적 대응만으로 credit을 뽑는다는 점이 본질적 차이임. - agentic RL의 cross-trajectory credit assignment(RUDDER, graph 기반 agentic credit 등)를 embodied 영역으로 옮기면서, 연속적 visual·proprioceptive 관측에서 같은 물리적 상황을 정의하는 node matching 설계가 추가 기여임. - 다만 node matching이 cosine similarity threshold 기반 clustering이라 viewpoint·appearance 변화에 취약할 수 있고, 저자도 이를 한계로 명시함. 이 부분은 새로운 representation이라기보다 기존 clustering 기법을 그대로 적용한 수준에 가까움.
Benchmark Results
- LIBERO 4개 suite 평균에서 one-shot SFT initialization 48.9%에서 PRICE 적용 시 99.0%로 50.1pp 개선되어, evaluator 기반 SOTA인 SRPO(99.2%)와 거의 동등함. - RoboTwin 2.0 6개 task 평균에서 SFT 31.9%에서 90.0%로 58.1pp 개선되어, world-model 기반 Feat2Go(88.8%)·RLinf-VLA(84.5%)·SimpleVLA-RL(71.3%)보다 각각 1.2, 5.5, 18.7pp 높음. - 실로봇(HiFi-UMI) 2개 task에서 offline adaptation 방식인 PRICE-AWR(advantage-weighted regression 기반)이 macro-average 61.25%로 GRPO-AWR(같은 방식에 GRPO credit을 적용)보다 13.75pp 높음, 다만 rollout 60개만 쓴 소규모 실험임. - ablation에서 historical evidence를 빼면 평균 성공률이 98.3%에서 94.0%로 거의 GRPO 수준(93.9%)까지 떨어지고, confidence gate를 빼면 96.9%로 낮아져 두 구성요소 모두 필요함이 확인됨. - 독립적 Monte Carlo continuation test에서 gating 후 retained credit의 방향 정확도가 97.5%(gating 전 77.2%)로 높아져 credit이 실제 local progress와 일치함을 보임.
누리랩 연구와의 연결
- failure detection/recovery, credit assignment 주제와 직접 연결됨. 같은 물리적 상황에 도달한 rollout을 서로의 참조로 삼는다는 아이디어는 실패 원인 진단, 즉 어느 chunk가 실패를 유발했는지 찾는 데도 그대로 적용 가능함. - test-time optimization·RL 주제에서 outcome-only label로 fine-grained credit을 뽑는 틀은 evaluator 학습 비용 없이 다른 embodied RL 세팅에도 이식 가능함. - robot memory 관점에서, round를 넘어 누적되는 node summary(historical evidence)는 과거 경험을 재사용하는 memory 구조로 볼 수 있어 관련 연구와 연결 지어볼 만함.

Beyond the Remembered World: Predictive 4D Belief for Persistent Navigation in Evolving Worlds

arXiv PDF alphaXiv
Navigation relevance 9/10 Artificial Intelligence (cs.AI)
Mingjian Gao, Zhaocheng Li, Haoyang Huang, Wenqiao Zhang, Yingjie Niu, Hao Zhou, Chao Li, Juncheng Li 외 2명 PDF 전문 1차 68점
EvolvingNav는 과거 관측 이후에도 계속 변화하는 환경에서 target 위치를 추론하기 위해 persistence-relocation belief와 event-driven predict-observe-replan filter를 결합한 navigation agent를 제안함. 54개 scene·803,680개 task로 구성된 새 벤치마크 EvoWorld-Bench와 실로봇 LYNX M20 실험에서 기존 structured memory·predictive baseline 대비 탐색 성공률과 효율을 크게 올림.
Core Innovation & Methodology
- Evolving-World Navigation이라는 새 문제를 정의함: target이 query 이전뿐 아니라 navigation 도중에도 보이지 않는 사이 이동할 수 있는 상황에서 agent가 도착 시점의 상태를 예측하고 belief를 갱신해야 함 - P4D-Nav는 timestamped 3D object history를 Transformer로 인코딩해, target이 마지막 관측 위치에 머무는 persistence와 다른 후보로 옮기는 relocation을 분리해 확률을 배정하고, 알려지지 않은 위치(unknown)에도 확률 질량을 남겨둠 - event-driven filter가 belief를 현재 시점으로 propagate하고, 각 후보의 도착 예정 시간(ETA)에 맞춰 occupancy를 forecast한 뒤 RGB-D evidence로 belief를 갱신함 - negative observation은 calibrated visibility-conditioned detection probability로 soft하게 반영하고 동일 evidence 재사용을 방지함 - frozen zero-shot vision-language controller(GPT-5.6-Luna)가 memory·prediction·inspection·exploration·navigation tool을 호출해 belief 기반으로 행동을 선택하고 replan함
Novelty vs. Prior Works
- PredictiveGraphs가 future object-receptacle state를 예측하고 top-k navigation을 하는 가장 가까운 선행연구이나, EvolvingNav는 candidate별 도착 시간을 고려한 arrival-time filtering과 time-valid evidence round, candidate reopening을 추가해 navigation 도중의 hidden evolution까지 다룬다는 점이 다름 - Transit-Aware Planning은 이동 가능한 target을 다루지만 irregular observation history와 visibility 조건부 evidence를 결합하지 않음. EvolvingNav는 이 세 요소(irregular history, arrival-time별 후보 occupancy, visibility 조건부 negative evidence)를 하나의 loop로 묶은 것이 formulation 측면의 기여임 - belief 구조(persistence-relocation factorization) 자체는 상태를 last-seen·다른 후보·unknown 세 갈래로 나누는 필터링 설계로, 완전히 새로운 패러다임이라기보다 기존 predictive memory 연구의 구성요소를 navigation loop에 통합한 것에 가까움
Benchmark Results
- EvoWorld-Bench(54개 scene, 803,680개 task)에서 First-Inspection SR이 DynaMem 45.33%에서 EvolvingNav 61.32%로, Search SR이 71.94%에서 86.18%로 상승함 - FindingDory에서 HL-SR(고수준 목표 성공률) 53.22%로 비교 대상 중 최고치를 기록했으나 HL-SPL(고수준 목표 경로 효율)은 38.83%로 FindingDory Agent(40.92%)에는 못 미침 - N4(실행 중 target이 이동하는 online-dynamic) 설정에서 PredictiveGraphs 대비 Dynamic SR +18.4점, Online Recovery SR +22.0점, excess distance -4.8m, revisit 성공 +13.7점 개선됨 - paired world 비교에서 routine world는 Last Seen 대비 SR +22.36점이지만 random world에서는 +6.93점에 그쳐, 학습 가능한 시간 패턴이 있을 때 이득이 가장 큼 - ablation에서 predictive belief를 제거하면 First-Inspection SR이 62.17%에서 12.51%로 급락하고 evidence update를 제거하면 Search SR이 42.02점 하락함. 실로봇은 LYNX M20 64회 매칭 trial에서 First-Inspection SR 17.2%→34.4%, Search SR 26.6%→48.4%로 개선됨(X30·Lite3는 32-trial transfer subset)
누리랩 연구와의 연결
- 시간에 따라 변하는 world에서 belief를 유지·갱신하는 구조는 누리랩의 robot memory·failure detection 연구에서 기억이 틀렸을 가능성을 명시적으로 모델링하는 참고 사례로 쓸 수 있음 - persistence-relocation factorization과 visibility 조건부 negative evidence 처리는 object-centric 3DGS·scene graph에 시간 축을 추가해 scene graph가 낡아지는 문제를 다루는 연구로 확장 가능함 - 후보별 도착 시간에 맞춰 belief를 forecast해 행동을 고르는 방식은 long-horizon manipulation의 test-time replanning이나 counterfactual reasoning(현재 안 보이는 물체 위치 추론) 연구와 직접 연결됨

EWAM: Emergent Depth-Wise Specialization in a Unified Embodied Model -- From Semantic Understanding through Visual Foresight to Action

arXiv PDF alphaXiv

Core Innovation & Methodology
- soft pneumatic robot과 vision-based tactile sensor(gel)를 모두 MPM particle로 표현하고 3DGS 렌더링을 결합한 단일 시뮬레이터를 제안함. 기존 연구는 둘을 분리 모델링함 - CAD mesh에서 particle을 샘플링하고 로봇은 crop 이미지 1장, tactile gel은 indentation 이미지 1장만으로 vision-based real-to-sim calibration을 수행함 - 전체 MPM 연산 대신 residual torque MLP(action network)와 indentation 매핑 UNet(perception network)이라는 surrogate 모델로 각각 5배, 3000배 속도를 높임 - real demonstration을 웜스타트로 쓰는 CEM 기반 MPC가 tactile 접촉 영역 신호를 guidance로 사용해 시뮬레이션에서 demonstration을 증강함
Novelty vs. Prior Works

Function beyond Form: Functional Correspondence for Cross-Embodiment Dexterous Grasp Generation

arXiv PDF alphaXiv
Manipulation relevance 9/10 Robotics (cs.RO)
Bolin Zou, Wenlong Dong, Mu Ai, Chao Tang, Aoxiang Gu, Lipeng Chen, Hong Zhang PDF 전문 1차 64점
손마다 다른 손가락 부위를 grasping 역할 기준으로 공통 기능 부위(wrist·metacarpal·proximal·middle·distal·tip)에 매핑하고 canonical local frame으로 정렬한 뒤, 그 위에서 diffusion model로 grasp를 생성하는 FunCo-Grasp를 제안함. 추가 데이터나 fine-tuning 없이 미지의 손 4종에서 시뮬레이션 평균 74.02%, 실로봇 미지의 손 2종에서 76.00% 성공률을 보임.
Core Innovation & Methodology
- Functional Part Alignment(FPA)로 서로 다른 손의 물리적 link를 grasping 역할에 따라 공유된 기능 부위(wrist/metacarpal/proximal/middle/distal/tip)로 매핑함. - Canonical Frame Alignment(CFA)로 각 기능 부위를 forward·closing·lateral 축을 가진 canonical local frame으로 표현해 손 간 좌표계를 통일함. - MAF graph encoder가 이 정렬된 hand graph에서 node/edge feature를 만들고, diffusion model이 object patch feature를 조건으로 기능 부위들의 목표 배치를 생성한 뒤 inverse kinematics로 실행 가능한 joint configuration으로 변환함. - 미지의 손 적용에는 URDF·기구학 모델과 1회성 functional annotation만 필요하며 target-hand grasp data, fine-tuning, learned retargeting이 불필요함.
Novelty vs. Prior Works
- 가장 가까운 interaction-centric 선행연구(D(R,O)Grasp, T(R,O)Grasp)는 hand-specific link나 local frame으로 interaction을 정의해 구조가 다른 손 사이 대응이 모호했는데, FunCo-Grasp는 기능적 역할 기준의 명시적 대응을 도입함. - morphology-alignment 계열인 UniMorphGrasp은 joint slot을 canonical하게 매핑하는 수준인 반면, FunCo-Grasp는 part 단위로 inter-part·hand-object interaction 전체를 정렬함. - 다만 이는 기존 hand-centric/object-centric/interaction-centric 분류 안에서 interaction-centric 표현을 정교화한 확장이라, 완전히 새로운 problem formulation이라기보다 점진적 novelty에 가까움.
Benchmark Results
- Seen hands(Shadow/Allegro/Barrett) 평균 성공률 92.40%로 baseline T(R,O)Grasp 91.07%, D(R,O)Grasp 85.33%보다 높음(시뮬레이션, CMapDataset 48 train/10 held-out objects). - Unseen hands(ApexHand/XHand/LeapHand/Robotiq-3F) 평균 74.02%로 CEDex 66.50%, D(R,O)Grasp 38.13%, T(R,O)Grasp 11.95% 대비 크게 앞섬. - 실로봇(ApexHand·Revo2, 둘 다 unseen, UR5 플랫폼, 물체 10종×10회)에서 전체 76.00%(84/100, 68/100) 성공. - Ablation에서 FPA 제거 시 unseen 성공률 74.02%→33.90%, CFA 제거 시 19.40%, 둘 다 제거 시 0.95%로 급락해 두 alignment의 기여가 뚜렷함. - Grasp 생성 효율은 0.16초/grasp로 T(R,O)Grasp(0.21초)·D(R,O)Grasp(0.75초)보다 빠르나, 생성 diversity는 0.293rad로 baseline(0.401~0.535rad)보다 낮다는 한계를 저자도 명시함.
누리랩 연구와의 연결
- functional correspondence 개념은 손뿐 아니라 object affordance나 scene graph에서 서로 다른 object instance 간 기능적 대응을 정의하는 데에도 적용할 여지가 있음. - canonical frame 기반 표현은 failure detection에서 어느 기능 부위에서 실패가 발생했는지를 진단하는 단위로 재사용할 수 있음. - diffusion 기반 grasp 생성에 test-time optimization을 결합해 미지의 손 적응을 샘플링 단계에서 더 정교화하는 후속 연구로 확장 가능함.

오늘의 핵심 연구 트렌드 종합

  • VLA의 instruction-action binding 실패 진단 — Equivariant Counterfactual Training과 ReGuide가 VLA가 language·vision에는 반응하면서도 둘을 결합해 올바른 action을 못 고르는 binding 실패를 서로 다른 각도(counterfactual training vs. training-free rebinding)에서 공략함. 둘 다 LIBERO position-swap을 testbed로 쓰고 실로봇에서 큰 폭(각각 8%→88%, 최대 75.0%p)의 개선을 보임.
  • world model의 planning 유효 범위를 직접 측정하는 흐름 — The Planning Limits of Latent World Models가 plannable range가 5~10 step에 불과함을 수치로 입증했고, RoboCoach는 그 한계를 world model 상상 rollout으로 실패 subtask를 진단해 우회하고, EWAM은 world model과 VLA를 한 transformer로 통합해 다른 방식으로 접근함.
  • action representation에 geometry·structure prior를 명시적으로 주는 흐름 — BIND는 3D action 후보를 camera geometry로 2D feature에 투영해 OOD robustness를 얻고, FunCo-Grasp는 손 구조를 canonical frame으로 정렬해 cross-embodiment 일반화를 얻음. 둘 다 추가 학습 없이 structural prior로 문제를 해결함.
  • 4D·시간 축을 더한 scene representation — ChronoGraph와 EvolvingNav는 각각 affordance 기반 action-conditioned scene graph와 persistence-relocation belief로, 관측 사이 변하는 환경의 과거·미래 상태를 명시적으로 추적함.
  • outcome-only label에서 fine-grained credit·verification을 뽑는 흐름 — PRICE는 action chunk 단위 credit을, Looking Back to Move Forward는 temporal energy-based verifier를 추가 evaluator 없이 뽑아냄.
  • 정밀 language grounding 전용 모델·표현 — GroundingPI와 Text-to-3D Policy는 범용 VLM·video backbone의 grounding 약점을 지적하고 각각 전용 grounding foundation model, fine-grained token-level alignment로 해결함.
