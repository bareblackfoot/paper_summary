TAPVid-MV: A Benchmark for Tracking Any Point in 3D Across Multiple Views

arXiv PDF alphaXiv
3D Vision Point Tracking Benchmark relevance 5/10 Computer Vision and Pattern Recognition (cs.CV)
Skanda Koppula, Frano Rajic, Abdullah Faiz Ur Rahman, Yi Yang, Ignacio Rocco, Jeet Thakwani, Rishabh Kabra, Andrew Zisserman 외 4명 PDF 전문 1차 57점
여러 대의 움직이는 카메라에서 동일 물리적 점의 장기 3D 궤적을 추적하는 새로운 벤치마크 TAPVid-MV를 제안함. 284개 시퀀스·1,142개 카메라 뷰·109,769개 3D 궤적으로 구성되며, 30개 이상 baseline을 reconstruction 품질과 함께 평가해 현재 병목이 tracker가 아니라 dynamic scene의 geometry 복원임을 밝힘.
Core Innovation & Methodology
- 문제설정: 기존 point tracking benchmark는 단일 비디오이거나 고정 rig의 static multi-camera만 다뤄, 카메라가 독립적으로 움직이는 다중 뷰 환경에서 장기 3D 궤적을 추적하는 태스크(multi-view TAP-3D)를 처음 정의함. query는 한 카메라의 한 프레임에만 주어지고 다른 뷰의 대응점은 제공하지 않음 - 데이터 구축: DROID(로봇 조작), EgoExo4D, Harmony4D, PACE, Hi4D, Waymo, 자체 제작 synthetic generator Perpetua 등 7개 subset에서 depth·LiDAR·SLAM/SfM·human mesh·posed object mesh 등 데이터셋별 보조 modality로 3D track을 만들고 전 시퀀스를 사람이 시각 검증함 - 평가 설계: query view(Q)·non-query view(N)·world space(W) 3개 좌표계로 나눠 채점해, monocular tracking 오류·cross-view correspondence 오류·global registration 오류를 분리 진단함 - reconstruction과 tracking을 동일 데이터에서 함께 측정해, 3D tracking 오차가 correspondence 오류인지 geometry 오류인지 구분함(모든 point tracker를 공통 VGGT-Ω reconstruction 위에서 비교)
Novelty vs. Prior Works
- 가장 가까운 prior work인 TAPVid-3D(단일 뷰)와 MVTracker·LAPA(고정 rig, known calibration)와 달리, 카메라가 독립적으로 움직이는 실세계 환경에서 2개 초과 뷰를 다루는 첫 벤치마크임(논문 Table 2 비교 기준) - 새로운 추적 알고리즘 제안은 없는 벤치마크·데이터셋 논문이지만, reconstruction과 tracking을 같은 데이터로 동시 측정해 오차 원인을 분리하는 평가 방법론 자체가 novelty이며 기존 벤치마크는 이 분리를 제공하지 못함 - MV-TAP과 달리 모든 뷰에 query가 주어진다고 가정하지 않고 한 뷰의 pixel만 query로 제공해, 실제 활용 조건에 더 가까운 태스크 정의를 채택함
Benchmark Results
- 30개 이상 baseline 중 최고 성능은 lifted monocular tracker TAPIP3D로, 공유 VGGT-Ω reconstruction 기준 world-space accuracy(δ³D_W) 22.8(7개 subset 평균)에 그쳐 어떤 방법도 태스크를 풀지 못함 - multi-view 3D tracker MVTracker의 non-query-view accuracy(δ³D_N)는 20.8로 최고지만 monocular TAPIP3D의 20.6과 사실상 동률이며, query-view accuracy는 오히려 TAPIP3D(27.1)가 MVTracker(24.0)보다 높아 기존 multi-view tracker가 monocular 대비 일관된 우위를 보이지 못함 - joint multi-view 모델 OmniX는 δ³D_W 10.3, Hi4D에서는 0.4까지 하락하며, 이는 tracking head가 아니라 자체 geometry 복원 실패 때문임(Hi4D extrinsics error 9.2 vs VGGT-Ω의 55.8) - geometry 병목 증거: SpatialTrackerV2 가중치를 고정한 채 자체 reconstruction을 공유 VGGT-Ω reconstruction으로 교체만 해도 query-view accuracy가 11.8에서 23.5로 거의 2배 상승함 - driving(Waymo)·밀접 인간 상호작용(Hi4D) subset은 모든 방법이 각각 δ³D_W 6.6, 5.9 이하로 특히 취약하며, ground-truth depth를 줘도 TAPIP3D의 DROID 성능 상한이 40.3에 그쳐 완벽한 geometry만으로는 문제가 해결되지 않음을 보임
누리랩 연구와의 연결
- 'tracking 오차가 실은 geometry 오차에서 온다'는 진단은 object-centric 3DGS·scene representation 연구에서 reconstruction 품질을 tracking·correspondence 품질과 분리해 검증해야 한다는 방법론적 시사점을 줌 - DROID 기반 robot manipulation subset(5,371 episode, metric 3D trajectory)은 manipulation policy의 object·gripper tracking 평가나 world model 학습 데이터로 바로 활용 가능함 - 추가 뷰가 query view 자체의 reconstruction도 개선시킨다는 결과(Fig. 4)는 active perception·next-best-view 연구에서 multi-view 정보가 단일 뷰 추정치까지 개선한다는 근거로 인용할 만함

Recursive Value Learning for Long-Horizon Offline Goal-Conditioned RL

arXiv PDF alphaXiv
RL relevance 7/10 Machine Learning (cs.LG)
Hyeonseong Jeon, Youngwoon Lee PDF 전문 1차 62점
offline goal-conditioned RL에서 긴 horizon일수록 value bootstrap 오류가 누적되는 문제를, trajectory segment를 균형 이진 트리로 재귀 분할해 leaf에서 root 순서로 학습하는 DCRL로 해결함. bootstrap depth를 선형에서 로그로 줄여 OGBench 최장 horizon task에서 이전 최고 평균 점수 55를 64로 끌어올림.
Core Innovation & Methodology
- trajectory segment (s_i, s_j)를 중점 k=(i+j)/2에서 재귀적으로 이등분해 균형 이진 트리를 만들고, leaf(single-step, V=γ)부터 root까지 child-to-parent 순서로만 value를 학습함 - max 기반 selection 없이 exact factorization V_τ(s,g)=V_τ(s,w)·V_τ(w,g)로 parent value를 계산해, 관측된 route만 쓰고 noisy 후보 중 optimistic 선택으로 인한 error 증폭을 피함 - in-trajectory behavior value만으로는 최적 경로를 못 찾으므로, globally relabel된 goal에 대한 n-step propagation objective(upper-expectile loss)를 별도로 병행해 cross-trajectory 최단 경로를 구성함 - 여러 root segment를 slot에 나눠 leaf-to-root 순서를 유지하면서 배치 내 다양한 horizon을 섞는 parallel slot scheduling으로 학습 효율을 확보함
Novelty vs. Prior Works
- 가장 가까운 prior work인 TRL(Transitive RL, ICLR 2026)은 매 업데이트마다 독립적으로 무작위 subgoal을 뽑아 학습 순서가 없는 반면, DCRL은 트리를 명시적으로 구성하고 child를 parent보다 먼저 학습하는 순서를 강제함. 이 순서 제약이 핵심 차별점이며 저자는 이를 이론적으로(worst-case bootstrap depth: TD-n Θ(H/n), TRL-n Θ(H), DCRL-n Θ(log(H/n))) 증명함 - TDP(Sub-goal tree dynamic programming)와 달리 top-down greedy subgoal 선택 대신 고정된 midpoint를 쓰고 bottom-up으로 학습해 overestimation을 피함. random split을 쓰는 ablation(DCRL w/ random split)이 성능은 유지하면서 throughput만 낮아진다는 결과로 '재귀적 순서'가 '균형 이진 분할'보다 본질적임을 확인함 - 다만 quasimetric/triangle-inequality 기반 GCRL이라는 큰 틀 자체는 QRL, TMD, TDP, TRL 등 기존 계열을 따르고 있어, 새로운 problem formulation이라기보다는 기존 계열 내에서 학습 순서(scheduling)를 새롭게 설계한 기여로 보는 것이 정확함
Benchmark Results
- OGBench 최장 horizon 5개 task 평균 점수: DCRL 64로 이전 최고(SHARSA, hierarchical) 55를 능가, flat method 중 cube-octuple에서 유일하게 0이 아닌 점수(5±1)를 달성함 - humanoidmaze-giant에서 93±3, puzzle-4x5 100±0, puzzle-4x6 87±5로 대부분 baseline 대비 큰 폭 우위. 단 cube-quadruple(37±4)은 SHARSA(74±2)에 못 미쳐 hierarchical 방법이 여전히 우세한 영역이 있음을 저자가 명시 - standard-horizon OGBench(10 state + 10 pixel envs) aggregate score: state 68(2위 TRL 55), pixel 56(2위 TRL 36)로 모든 baseline 대비 우위임 - CALVIN(state): 4개 subtask 연속 완료율 DCRL 8% vs 최고 hierarchical baseline(HIQL) 3%, 모든 flat baseline 0%. pixel-CALVIN도 유사 경향이나 절대 성공률은 낮음(4개 subtask 1%) - ablation(standard-horizon state aggregate 기준): recursion 제거 시 성공률 68→39, propagation 제거 시 68→45, max-based backup으로 교체 시 68→62로 각 구성요소가 모두 필요함을 확인. combination-lock 환경에서 DCRL-n의 Q-error가 horizon 256~2048 구간에서 거의 평평한 반면 TD-n·TRL-n은 급격히 증가함
누리랩 연구와의 연결
- robot manipulation의 long-horizon offline RL/IL 세팅에서 goal-conditioned policy를 학습할 때 DCRL의 재귀적 value scheduling을 도입하면 skill chaining·long-horizon planning 연구에 직접 적용 가능함 - exact route factorization과 propagation을 분리하는 division of labor 아이디어는 test-time optimization 연구에서 '관측된 경로 기반 신뢰값'과 '탐색적 propagation'을 분리 평가하는 설계로 참고할 만함 - deterministic dynamics 가정이 한계로 명시됐으므로, VLA의 stochastic manipulation 환경에 확장하려면 factorization을 expectation 기반으로 완화하는 후속 연구가 필요하며 이는 world model과 결합한 counterfactual reasoning 연구 주제로 이어질 수 있음

Spatially Aware World Action Model via Geometric Latent Diffusion

arXiv PDF alphaXiv
World Model 3D-Aware Manipulation relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Javier Alejandro Lopetegui Gonzalez, Paul Pacaud, Cordelia Schmid PDF 전문 1차 74점
pretrained video diffusion 기반 WAM(world action model)에 metric depth를 별도 latent frame으로 주입해 3D 정보를 활용하는 SA-WAM을 제안함. RoboCasa와 LIBERO-Plus에서 SOTA를 달성하고 실제 UR5 실험의 randomized 환경에서 특히 큰 강건성 향상을 보임.
Core Innovation & Methodology
- Cosmos-Predict2 기반 pretrained video DiT를 그대로 재사용하면서 depth를 RGB와 동일한 frozen VAE tokenizer로 인코딩해 latent 시퀀스에 추가 프레임으로 삽입함. 3D 전용 encoder를 새로 학습하지 않음. - unbounded metric depth를 log-scale nonlinear normalization으로 [-1,1] tokenizer 입력 범위에 매핑함. near-field에 해상도를 더 배분해 조작 정밀도가 중요한 영역을 우선 보존함. - action, proprioception, RGB, depth를 하나의 DiT latent sequence 안에서 EDM objective로 공동 denoising함. modality별 별도 head나 loss 없이 단일 backbone으로 학습함. - future depth 예측 오차와 policy rollout 성공 사이의 상관관계를 정량 분석해, world model prediction quality가 failure 진단 신호로 쓰일 수 있음을 보임.
Novelty vs. Prior Works
- 동일 latent-frame injection 틀을 쓰는 Cosmos-Policy에 depth modality를 추가한 확장 연구로, representation이나 학습 objective 자체의 근본적 변화는 아님. - log-scale depth normalization 자체는 DepthFM, DMD 등 기존 monocular depth 추정 문헌의 원리를 WAM에 그대로 전이 적용한 것으로 기법 자체의 novelty는 낮음. - 3D-VLA, SpatialVLA, PointVLA 등 기존 3D-aware VLA는 정책에 3D를 결합했지만, WAM(공동 video-action 생성) 구조에 dense depth를 frozen tokenizer 그대로 결합한 것은 이 논문이 처음으로, world model 계열 내에서는 실질적 novelty가 있음.
Benchmark Results
- RoboCasa 24-task, 50 demo/task 기준 76.6% 성공률로 동일 예산 Cosmos-Policy(67.1%) 대비 +9.5점. 300~1000 demo를 쓰는 GR00T+World2Act(72.6%), FLARE(71.3%)도 능가함. - LIBERO-Plus zero-shot(7축 perturbation) weighted avg 86.6%로 π0.5(84.6%) 대비 +2.0점, Cosmos-Policy(81.4%) 대비 +5.2점 앞섬. - depth normalization ablation(8-task subset): log 방식이 policy success 61.7%로 최고, linear 대비 +5.2점, inverse 대비 +2.2점. metric reconstruction 오차도 log가 overall AbsRel 0.63%로 최저임. - 실제 UR5 4개 조작 카테고리: clean 환경에서 90.0% vs Cosmos-Policy 75.0%, π0 21.3%. randomized 환경에서는 SA-WAM 77.5% 유지, Cosmos-Policy 48.8%, π0 11.3%로 격차가 더 커짐. - pick-and-place task에서 future depth 예측 오차 기반 failure 탐지가 AUC≈0.88, 80% 탐지율 @ 13% false-alarm rate를 기록함. 단 이 분석은 PnP task 부분집합에 한정됨.
누리랩 연구와의 연결
- log-depth latent-frame injection 방식은 저비용으로 world model에 기하 정보를 결합하는 방법론으로, 누리랩의 object-centric 3DGS/scene graph 연구에 참고할 수 있음. - future depth 예측 오차와 rollout 성공의 상관관계(AUC 0.88)는 failure detection·test-time monitoring 신호로 바로 응용 가능함. - WAM+3D 결합이 distractor·randomized 환경에서 강건성을 크게 높인다는 결과는 누리랩의 test-time robustness/generalization 연구 방향과 직접 연결됨.

ZETA: A Controlled Study of Zero-Shot Cross-Embodiment VLA Transfer for Tabletop Manipulation

arXiv PDF alphaXiv
VLA (Cross-Embodiment Transfer) relevance 9/10 Robotics (cs.RO)
Mi Yan, Wenhao Zhang, Zhiqi Zhang, Yu Peng, Tangxinyu Wang, Lingfei Zhai, Jiayi Su, Shengliang Deng 외 9명 PDF 전문 1차 58점
ZETA는 VLA의 zero-shot cross-embodiment transfer를 target robot이 사전학습에도 전혀 없는 strict 설정과 사전학습에는 있지만 downstream task에서 빠진 pretrain-exposed 설정으로 명확히 나누고, 512개 procedurally generated Franka 임베디먼트 풀을 이용한 통제 실험으로 표현·다양성·co-training·노출 비율 4가지 요인의 효과를 정량화함. sim 6,300 rollout과 real-world 검증을 통해 EEF 중심 local state-action 표현이 sim 평균 약 15%p·real-world 약 34%p, source diversity가 약 18%p, co-training이 약 7%p 개선을 가져오고, target 데이터 5%만 섞어도 성능 격차가 크게 줄어든다는 것을 보임.
Core Innovation & Methodology
- strict zero-shot transfer(target embodiment가 사전학습·post-train 전 과정에서 부재)와 pretrain-exposed zero-shot transfer(사전학습에는 등장하나 downstream task는 부재)를 명시적으로 구분하고, Octo·π0.7·OpenVLA 등 기존 'zero-shot' 주장 논문을 이 분류로 재정리함(Table 1) - appearance-only/gripper-only/arm-only/full-embodiment 4개 shift 카테고리와 7개 held-out target embodiment로 구성된 controlled benchmark를 sim과 real-world 양쪽에 구축하고, task·환경·카메라·데이터 양을 고정한 채 embodiment만 변화시킴 - 4개 연구질문(state-action representation, source embodiment diversity, auxiliary co-training, target-embodiment exposure)을 π0.5 기반 단일 백본에서 factorize된 통제 변인으로 검증함 - 512개의 procedurally generated Franka-style source embodiment pool과 고정/가변 예산 두 가지 조건을 모두 사용해 source diversity와 data budget을 분리해서 분석함
Novelty vs. Prior Works

  • world action model이 test-time planning의 기본 단위로 자리잡음 — World-Coherent Decoding, Spatially Aware World Action Model, SolarWM이 모두 pretrained video diffusion 기반 WAM(world action model)을 공통 백본으로 삼음. WCD는 reward 없이 모델 내부 신호로 rollout을 고르고, SA-WAM은 depth latent를 추가로 주입해 성능을 올림.
  • cross-embodiment/OOD 일반화를 정량 분해하는 통제 실험 논문이 늘어남 — ZETA는 표현·데이터 다양성·co-training·노출 비율 4개 요인의 효과를 정량 분해해 다양성 자체가 가장 큰 개선 요인임을 보임. BEV-Forcing 기반 driving VLA는 반대로 학습 embodiment 다양성이 늘수록 BEV-Forcing이라는 개별 기법의 효과가 줄어든다는 것을 보임.
  • long-horizon credit assignment를 abstraction 단위로 해결하려는 흐름 — SPACE는 LLM agent의 action을 skill 경계 supervision으로 chunk하고, DCRL은 offline GCRL(goal-conditioned RL)의 value bootstrap을 이진 트리로 재귀 분할함. 도메인은 다르지만 "매 스텝 단위 credit assignment의 오류 누적"이라는 같은 문제를 다른 계층에서 공략함.
  • 저비용 event trigger로 고비용 reasoning 빈도를 줄이는 시스템 설계 — LookStep은 VLN에서 관찰을 memory에 남길지를 모델이 판단하게 하고, HINT는 manipulation pattern이 바뀔 때만 VLM을 다시 부름. 둘 다 지연시간을 3배 이상 줄이면서 성능은 유지·개선함.
  • 자기비판적 controlled study·negative result 공개가 하나의 장르로 보임 — Modeling What Changes는 제안 기법의 실익이 사실상 no-op 수준임을 스스로 밝히고, rollout vs closed-loop 상관성 연구는 rollout horizon보다 측정 보정 빈도가 핵심 변수임을 보임. SOTA 경쟁보다 가설 검증에 무게를 둔 논문이 늘어남.
  • 3D 인프라 논문(벤치마크·서베이)이 로봇 인식 하부구조를 재정의 — TAPVid-MV는 다중 뷰 3D point tracking 병목이 tracker가 아니라 dynamic geometry 복원에 있음을 밝혔고, action-grounded reasoning 서베이는 자율주행 reasoning 표현을 4개 축으로 정리함.

유망 연구 방향 및 프로젝트 제안

verifier-free test-time WAM 신호를 실패 탐지로 확장 - research question: WCD가 쓰는 flow surprisal(생성된 미래 영상의 velocity field 발산을 누적한 불확실성 신호)이 rollout 실패를 사전에 예측하는 failure detection 신호로도 쓰이는가. - 접근·novelty: reward/verifier 없이 얻은 self-verifying 신호를 재계획 트리거가 아니라 recovery 트리거(재계획 vs memory 질의 vs human 개입 분기)로 재해석함. - 왜 지금·경쟁 prior works: WCD가 Franka 실로봇에서 신호의 유효성을 이미 검증했지만 failure detection·recovery로는 확장하지 않음. - risk·target venue: WCD 자체도 Horizon-3(3단계를 잇는 긴 sub-task 세팅) 밖 일반화가 제한적이라 신호의 안정성 확인이 먼저 필요함. target: CoRL.

dexterous manipulation의 single-demo generalization을 object-centric 3DGS 표현과 결합 - research question: DemoMimic의 local contact geometry 조건화가 3DGS 기반 object-centric 표현으로 대체되면 unseen object shape에 대한 일반화가 더 늘어나는가. - 접근·novelty: 현재 mesh/point 기반 contact geometry를 gaussian primitive 단위 표현으로 바꿔 물체 형상 변화에 더 강건한 residual RL reward를 설계함. - 왜 지금·경쟁 prior works: DemoMimic이 16개 물체·4개 task에서 71% 실성공률로 이미 강력한 baseline을 세워, 표현만 바꿔 비교 실험하기 좋은 시점임. - risk·target venue: contact geometry를 3DGS로 바꿀 때 실시간 렌더링 비용이 residual RL 학습 루프에 병목이 될 수 있음. target: CoRL.

cross-embodiment diversity 분해 방법론을 실패 복구 데이터로 확장 - research question: ZETA가 밝힌 "source diversity가 co-training보다 효과 크다"는 결론이 실패 복구 정책 학습에도 성립하는가. - 접근·novelty: ZETA의 procedurally-generated embodiment pool 대신 procedurally-generated failure scenario pool을 구성해 동일한 factorize 실험(표현/다양성/co-training/노출 비율)을 반복함. - 왜 지금·경쟁 prior works: ZETA는 512개 embodiment·6,300 rollout 규모의 통제 실험 설계를 이미 공개해 재사용 가능함. - risk·target venue: ZETA는 tabletop manipulation에 한정되고 real-world 검증 규모가 작아, 실패 시나리오로 옮겨도 규모의 한계가 이어질 수 있음. target: CoRL/RSS.

event-driven re-reasoning trigger를 robot memory 공통 모듈로 일반화 - research question: LookStep(VLN)과 HINT(manipulation)가 각자 도메인에서 설계한 "언제 다시 생각할지" 판단 기준을 하나의 memory-conditioned trigger로 통합할 수 있는가. - 접근·novelty: 두 논문의 trigger 신호(관찰 novelty vs manipulation pattern 전환)를 공통 latent state-change 신호로 추상화해 VLN·manipulation 모두에 적용 가능한 memory 모듈을 설계함. - 왜 지금·경쟁 prior works: LookStep은 GPU 메모리를 44.3GB→19.7GB, HINT는 보조 추론 지연을 445ms→57ms로 줄여 event trigger의 실효성이 두 도메인에서 독립적으로 입증됨. - risk·target venue: 두 trigger 신호의 스케일이 달라(언어 태그 vs manipulation phase) 공통 표현을 만드는 것 자체가 별도 연구가 될 수 있음. target: ICRA/CoRL.

recursive value learning을 long-horizon manipulation skill chaining으로 이전 - research question: DCRL의 로그 depth bootstrap이 navigation/maze 중심 OGBench를 넘어 manipulation skill chaining에서도 동일한 이득을 주는가. - 접근·novelty: trajectory segment를 균형 이진 트리로 재귀 분할하는 DCRL의 학습 순서를 skill 단위 offline GCRL로 옮겨 TAMP급 long-horizon manipulation에 적용함. - 왜 지금·경쟁 prior works: DCRL은 이론적 bootstrap depth 증명과 OGBench 최장 horizon 평균 55점을 64점으로 올린 강한 실험 결과를 동시에 갖춘 흔치 않은 논문임. - risk·target venue: DCRL 실험이 전부 non-manipulation domain이고 real-robot 검증이 없어 이전 시 처음부터 실험을 다시 설계해야 함. target: ICLR/CoRL.

오늘 반드시 읽어야 할 논문

  • World-Coherent Decoding — reward/verifier 없이 WAM 내부 신호만으로 test-time에 rollout을 고르는 방식이 실로봇 성공률을 실제로 올림.
  • Spatially Aware World Action Model — video diffusion WAM에 depth latent를 더해 RoboCasa·LIBERO-Plus SOTA와 UR5 실로봇 강건성을 동시에 확보함.
  • One Demonstration, Many Objects (DemoMimic) — 단일 데모로 16개 물체에 일반화되는 dexterous manipulation을 71% 실성공률로 입증함.
  • Recursive Value Learning (DCRL) — offline GCRL의 bootstrap depth를 로그로 줄이는 이론과 실험을 함께 갖춰 오늘 배치 중 가장 완결적임.
  • ZETA — cross-embodiment VLA transfer를 요인별로 분해한 통제 실험 설계 자체가 재사용 가치가 큼.
  • SPACE — LLM agent가 매 스텝 하나의 action만 내다 학습이 무너지는 single-action collapse 문제를 skill 경계 증류로 풀어 long-horizon 효율을 높임.
  • HINT — manipulation pattern 전환 시에만 VLM을 호출하는 구조로 dual-arm 실로봇 성공률과 지연시간을 동시에 개선함.
  • WM-LOCO — world model과 PPO를 공동학습해 humanoid 실로봇의 gap·stepping-stone 통과를 baseline 0%에서 93%대로 끌어올림.
