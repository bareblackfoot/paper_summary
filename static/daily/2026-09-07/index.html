TacPAC: Tactile Prediction and Real-Time Action Correction in World-Action Models for Contact-Rich Manipulation

arXiv PDF alphaXiv
Manipulation Tactile World Model relevance 9/10 Robotics (cs.RO)
Zipei Ma, Xiaofei Wei, Junzhe Jiang, Shunlin Lu, Li Zhang PDF 전문 1차 68점
world-action model이 미래 tactile을 추가 view로 예측해도 실행 중 새로 들어오는 tactile 신호로 이미 계획된 action을 고치지 못한다는 timing mismatch 문제를 지적하고, 계획 당시 예측된 접촉을 attention KV 캐시로 저장해두고 tactile expert가 매 관측마다 이를 대조해 실시간으로 delta action을 계산하는 TacPAC를 제안함. 5개 실제 로봇 contact-rich task에서 평균 성공률을 vision-only base model의 22%에서 64%로 끌어올려 가장 강한 baseline인 T-Rex(48%) 대비 16점 앞섬.
Core Innovation & Methodology
- world-action model(WAM)의 action expert가 예측된 미래 tactile을 조건으로 action chunk를 planning한 뒤, 그 예측(contact)과 planned chunk 자체의 내부 표현을 층별 attention key/value 캐시로 저장함. - 새로 관측되는 tactile 이미지를 매번 이 캐시에 대조하는 tactile expert가 한 번의 forward pass로 아직 실행 안 된 스텝에 대한 delta action을 출력하며, chunk를 재생성하지 않고 20.7배 저렴하게(30.4ms/pass, 32.9Hz) 보정함. - 2단계 학습: Stage 1에서 video·action expert를 flow matching으로 학습해 base WAM을 만들고, Stage 2에서 base 모델을 freeze한 채 tactile expert만 다양한 execution offset(m)에서 ground-truth 액션과의 residual로 학습함. - 비동기 inference로, 보정이 계산되는 동안 로봇은 이미 커밋된 chunk를 계속 실행하고 보정은 아직 실행 안 된 suffix에만(지연 d스텝 이후부터) 반영해 correction으로 인한 급격한 움직임을 방지함.
Novelty vs. Prior Works
- 가장 가까운 prior work인 Dream-Tac(예측만 하고 단일 생성 pass로 chunk를 확정)과 T-Rex(현재 tactile로 반응적으로만 보정하고 예측 대비 대조는 없음) 대비, TacPAC은 예측된 contact을 명시적 reference로 남겨두고 이를 관측과 대조해 보정한다는 점이 본질적 차이임. ablation에서 cache 접근만 제거해도 성공률이 64%에서 47%로 떨어져(-17점) 이 차이가 실제 기여임을 수치로 보여줌. - tactile prediction만 단순 추가하는 방식(future view로 tactile 예측)은 이득의 약 1/3만 회수한다는 사실(22%→37%, 전체는 64%)을 데이터로 규명해, 문제의 원인이 timing mismatch에 있음을 정량적으로 뒷받침함. - 다만 base WAM 아키텍처(Mixture-of-Transformers 기반 video·action expert)는 LingBot-VA 계열을 그대로 채택한 것이라 architecture 자체의 새로움은 제한적이고, 기여는 correction 메커니즘과 caching 전략에 집중됨.
Benchmark Results
- 5개 real-robot task(충전 플러그 삽입, 다중 과일 이송, 감자칩 이송, 빈 병 세우기, 확장카드 삽입) 평균 성공률 64%로 전 baseline 중 최고, 두 번째인 T-Rex(48%) 대비 +16점, vision-only base model(22%) 대비 +42점. - 가장 tight-tolerance인 확장카드 삽입은 tactile world-action model 두 개(Dream-Tac 20%, T-Rex 35%)를 제외한 모든 baseline이 0%인 반면 TacPAC은 45%를 기록함. - component ablation에서 tactile expert 제거 시 37%, tactile prediction 제거(반응형 보정만) 시 33%, cache 접근만 제거 시 47% 대 전체 64% — 예측·보정·cache 세 요소 모두 필수임을 확인함. - damage-sensitive task(감자칩·과일)에서는 예측 기반 baseline Dream-Tac이 우세(85%, 40%)하고 tight-tolerance insertion에서는 반응형 T-Rex가 우세(65%, 35%)한 반면, TacPAC은 양쪽 모두에서 최고(90%/65%, 80%/45%)를 기록해 두 접근의 장점을 통합함. - inference 효율: tactile correction 1회 30.4ms(32.9Hz)로 chunk 재생성(628.6ms) 대비 20.7배 빠르고, correction 계산 중 로봇이 1스텝 이상 진행한 비율은 1.6%에 불과함.
누리랩 연구와의 연결
- 예측 대비 관측을 대조해 실시간 보정하는 구조는 world model 예측이 빗나갈 때 즉각 revise하는 test-time correction 패러다임으로 일반화 가능해, VLA의 실패 감지·복구 연구에 캐시 기반 보정 아이디어를 이식할 수 있음. - tactile 대신 다른 실패 신호(force, 시각적 이상 등)에도 "예측을 캐시해두고 관측과 대조"하는 프레임을 적용하면 manipulation 실패 조기 탐지 모듈로 확장 가능함. - chunk 전체를 재생성하지 않고 단일 pass로 correction하는 설계는 다른 long-horizon VLA/WAM의 test-time optimization·inference-time planning 효율화에 참고할 만함.

Same Trajectory, Contradictory Rewards (ROBORMBENCH): Paraphrase Fragility in Vision Language Reward Models

arXiv PDF alphaXiv
RL relevance 8/10 Robotics (cs.RO)
Wonje Jeung, Sangyeon Yoon, Hyesoo Hong, Yoonjun Cho, Dongjae Jeon, Bumjun Kim, Jean Oh, Youngjae Yu 외 1명 PDF 전문 1차 58점
VLM 기반 robot reward model이 의미상 동일한 instruction의 paraphrase만으로 같은 궤적에 정반대 reward를 줄 수 있음을 보임. 실로봇 궤적 2,390개와 검증된 paraphrase 21,673개로 ROBORMBENCH를 구성해 이를 정량화했고, 범용 VLM은 scale이나 reasoning을 늘려도 이 불안정성이 줄지 않지만 trajectory 기반으로 학습된 전용 reward model은 훨씬 안정적임을 확인함.
Core Innovation & Methodology
- paraphrase invariance를 VLM reward model의 핵심 요건으로 정식화하고, 궤적은 고정한 채 goal description만 바꿔 reward 안정성을 측정하는 evaluation protocol을 설계함 - lexical substitution, syntactic restructuring, action-goal perspective shift 3단계로 언어적 발산도를 높여가며 paraphrase를 생성하고, 3개 LLM(Gemini-3-flash, Claude-Sonnet-4.6, DeepSeek-v3.2) ensemble로 의미 동등성을 필터링함(human 대비 recall 96%) - Score Crossing Rate(SCR, 동일 궤적이 failure급과 success급 예측을 동시에 받는 비율), Flip Rate(FR, 원본 대비 판정 반전 비율), Mean Error(ME)로 robustness와 accuracy를 분리해 측정함 - paraphrase 간 예측 분산을 벌점으로 추가하는 variance reduction training과, 여러 paraphrase 예측을 평균하는 aggregation 두 가지 완화책을 제시함
Novelty vs. Prior Works
- VLM-as-reward 연구(RoboReward, Robometer 등)나 멀티모달 reward benchmark(VL-RewardBench, RewardBench2)는 정확도·선호 판단력 중심이었고 paraphrase에 대한 불변성은 다루지 않았음 — 이 논문은 언어 표면형 취약성이라는 별개의 failure mode를 처음 체계적으로 드러냄 - reward hacking·style bias 연구와 문제의식은 닿아 있지만, 의미가 보존된 rewrite에서도 실패-성공 판정이 뒤집힌다는 점을 지적해 기존 reward robustness 논의보다 더 근본적인 문제를 제기함 - 벤치마크는 기존 RoboRewardBench의 실로봇 궤적·라벨을 그대로 가져와 paraphrase를 덧붙인 구조라 데이터 수집 자체의 새로움은 제한적이고, 기여는 evaluation protocol과 mitigation 실험에 집중됨
Benchmark Results
- AGPS(action-goal perspective shift)에서 Gemini2.5-flash-lite와 Llama4-scout는 SCR 0.607/0.557로 전체 궤적의 절반 이상에서 동일 행동이 성공과 실패로 동시에 판정됨 - GPT-5.1의 SCR은 LS 0.153 → SR 0.204 → AGPS 0.300으로 rewrite가 원문에서 멀어질수록 악화됨. Claude-Sonnet-4.6은 LS에서 SCR 0.051로 가장 안정적이나 ME는 0.999로 정확도는 낮아 robustness와 accuracy가 별개 축임을 보임 - dedicated reward model RR-4B/RR-8B는 AGPS에서도 SCR 0.086~0.114로 모든 범용 VLM보다 낮고 ME도 가장 낮아, trajectory-grounded 학습이 scale보다 robustness에 중요함을 시사함 - Qwen3-vl·Gemma3 계열은 모델을 키워도 SCR이 줄지 않고 오히려 커지며, reasoning을 켜도 SCR이 낮아지지 않고 일부 모델(Qwen3-vl-235B, Gemini3-flash)에서는 더 높아짐 - offline best-of-N(N=20) 선택에서 SCR과 Regret은 Pearson r=0.882로 강하게 상관돼, paraphrase 불안정성이 실제 policy 최적화 방향에도 영향을 줌. - variance reduction training은 Qwen3-VL-4B의 AGPS SCR을 0.200에서 0.057로, ME를 1.020에서 0.372로 낮췄으나 완전히 해소하지 못했고, 모든 instruction이 영어로 한정돼 다국어·code-switching 강건성은 미검증임
누리랩 연구와의 연결
- VLM reward를 test-time verifier나 world model rollout 평가에 쓰는 방향과 직결됨 — reward 대신 goal reasoning이나 subgoal verification에 VLM을 쓸 때도 동일한 paraphrase fragility가 재현될 가능성이 커서 사전 점검이 필요함 - SCR 같은 category-crossing 지표는 failure detection에서 쓰는 VLM 기반 판별기의 신뢰도 평가에도 그대로 적용 가능함 - variance reduction training의 아이디어(같은 의미의 다른 표현에 대한 예측 분산을 벌점화)는 language feedback 기반 학습이나 counterfactual reasoning 모듈의 안정성 확보에 재사용할 수 있음

VLA-Precision: Asymmetric Co-Bootstrapping for Efficient Real-World Online RL of Vision-Language-Action Models

arXiv PDF alphaXiv
VLA (Real-World Online RL) relevance 10/10 Robotics (cs.RO)
Chenyu Su, Zhaolong Shen, Yuan Qian, Chen Qian, Rui Zhang, Feng Yan, Weixing Chen, Fei Zhang 외 3명 PDF 전문 1차 76점
대형 VLA를 실제 로봇에서 online RL로 post-training할 때 생기는 value 오류로 인한 policy drift와 낮은 처리량 문제를, asymmetric co-bootstrapping 알고리즘(ACoB)과 스트리밍 시스템(ACoB-Stream)으로 각각 푼 논문임. 9개 화학실험 조작 task·4개 로봇 embodiment에서 평균 성공률 98.3%(π0.5 대비 +30.5%p)를 달성했고 throughput은 최대 10.9배 개선됨.
Core Innovation & Methodology
- 문제 설정: real-world online RL로 VLA를 post-training할 때 unreliable value 신호로 인한 policy drift, 큰 VLA 연산 overhead로 인한 낮은 throughput이라는 두 병목을 동시에 겨냥함 - ACoB 알고리즘: intervention 기반 행동복제(BC)로 policy를 빠르게 개선해 온라인 경험 질을 동시에 높이고, K개 critic 앙상블의 global TD return propagation과 local preference ranking(교정 행동이 원래 제안보다 낫다고 순위 매김)으로 value를 점진적으로 보정함 - relative-advantage policy improvement: 절대 Q값 대신 K개 critic에서 계산한 pessimistic advantage gap(현재 행동 vs frozen reference·intervention baseline 중 최소값)을 사용해 policy drift를 억제하고, frozen reference로의 regularization을 병행함 - ACoB-Stream 시스템: frozen VLM prefix context 재사용(invariant-state decoupling), 디스크 기반 context buffer·objective별 access, trainable subspace만 동기화(on-demand streaming)로 대형 VLA의 반복 forward·저장·동기화 비용을 줄임
Novelty vs. Prior Works
- HIL-SERL·ConRFT·Robo-Dopamine 같은 기존 real-world VLA RL은 BC 제약으로 policy 분포를 안정화하지만 value 추정 자체는 개선하지 못해 drift에 취약함. ACoB는 critic 쪽에 global TD와 local preference ranking을 결합해 value 신뢰도를 직접 높인다는 점이 다름 - EXPO-FT·RL Token은 VLA 본체에 gradient를 안 통과시키려고 residual·token 보조 정책을 쓰는데, 이는 개선이 별도 policy에 갇혀 task가 늘어도 누적되지 않음. VLA-Precision은 action expert의 LoRA 파라미터를 직접 최적화해 하나의 policy로 개선을 누적한다는 점이 차별점임 - 다만 ensemble critic의 pessimistic advantage, preference ranking, LoRA 파인튜닝, reference regularization 등 구성 요소 자체는 기존 RL·RLHF 기법의 재조합에 가까워 formulation 차원의 근본적 새로움은 제한적임. 오히려 ACoB-Stream 시스템 설계가 더 뚜렷한 실용적 차별점임
Benchmark Results
- 화학실험 9개 task(4개 카테고리: contact-rich/contact-light/contact-free/bimanual), 로봇 4종에서 평균 성공률 98.3%로 π0.5(67.8%), π0(59.4%), Robo-Dopamine(10%), ConRFT(7.8%), HIL-SERL(2.8%) 대비 크게 앞섬 - 평균 학습시간 45.8분/task, episode 길이 27.6초로 π0(32.0s) 대비 1.2배, π0.5(30.0s) 대비 1.1배 빠르고 HIL-SERL/ConRFT/Robo-Dopamine(각 50.4s/45.3s/44.5s) 대비도 빠름 - ACoB-Stream이 throughput·연산효율을 최대 10.9배 개선했다고 보고함(세부 latency 분해 수치는 본문 추출 과정에서 중간 생략되어 확인 불가) - discussion 절 실험에서 step-wise delta action의 실행 horizon He를 3에서 6으로 늘리면 3개 고정밀 삽입 task 평균 자율 성공률이 58.3%→6.7%로 급락하고 상대 action RMSE가 29.3% 증가해, 현재 표현 방식의 장기 실행 한계를 확인함 - ACoB 구성요소별 상세 ablation 수치(critic ranking·BC 개별 기여도 표)는 텍스트 추출 중 중간 생략되어 확인 불가하나, "actor BC가 행동과 경험 질을 빠르게 개선하고 critic preference ranking이 점진적으로 value를 보정해 안정적 policy 개선을 만든다"는 정성적 결론은 본문에 명시됨
누리랩 연구와의 연결
- real-world online RL로 VLA를 demonstration 한계 너머로 개선하는 접근은 test-time optimization·RL 트랙에 바로 참고할 수 있고, pessimistic relative-advantage와 reference regularization 조합은 policy drift 억제가 필요한 failure recovery 학습에도 적용 가능함 - ACoB-Stream의 frozen VLM prefix 재사용·디스크 기반 context buffer 설계는 다른 real-world online RL·test-time adaptation 파이프라인에서 대형 VLA 연산 병목을 줄이는 시스템 패턴으로 참고할 만함 - step-wise vs chunk-wise delta action 표현에 대한 discussion 실험은 long-horizon bimanual manipulation·skill chaining 연구에서 action representation을 고를 때 참고할 실증 근거를 제공함

Linguistic Trajectory Encoding for Efficient Long-Horizon Spatial Memory in Embodied Agents

arXiv PDF alphaXiv
Embodied AI Robot Memory relevance 8/10 Computer Vision and Pattern Recognition (cs.CV)
Tianyidan Xie, Shenyi Wang, Qiang Tang, Mingjie Wang, Zhicheng Qiu, Xuanfu Li, Zhan Xu, Jian Yang 외 2명 PDF 전문 1차 68점
동적 물체의 상태 변화를 며칠 단위 시간 지평에서도 자연어로 질의할 수 있는 memory 표현이 없다는 문제를 지적하고, 물체별로 언어 캡션·희소 3D anchor·시각 anchor를 결합한 Linguistic Trajectory Encoding(LTE)으로 이를 압축 저장하는 방법을 제안함. Spectral-Target Physical Latent Structuring for JEPA-Style World Models

arXiv PDF alphaXiv
World Model relevance 7/10 Machine Learning (cs.LG)
Penghao Zhu, Salvatore Penachio, Kaustav Mukherjee, Aneesh Jonelagadda PDF 전문 1차 60점
JEPA 스타일 world model(LeWM)에서 SIGReg로 collapse를 막아도 latent가 특정 물리 객체 정보를 담지 않는 새로운 실패 모드 physical representation laziness를 정의함. bounding box를 Fourier 변환해 permutation-invariant하게 만든 spectral target으로 latent를 지도학습하는 auxiliary head를 붙여 n-ball 환경에서 planning 성공률을 최대 88.8%p 개선함.
Core Innovation & Methodology
- physical representation laziness라는 새 실패 모드를 정의함: SIGReg가 latent collapse는 막지만 제어 대상 공의 위치 정보는 latent에 담기지 않는 현상을 two-ball 환경에서 Spearman correlation(제어공 ρ=-0.0008)으로 실증함 - 각 object의 oriented bounding box·segmentation mask를 8차원 상태벡터로 만들고, 시각적으로 구분 안 되는 동일 object 집합은 Dirac delta measure의 Fourier transform으로 permutation-invariant하게 symmetrize한 spectral target(y^spec)을 구성함 - 2-layer MLP auxiliary head가 encoder·predictor의 latent에서 이 spectral target을 복원하도록 학습시에만 추가 loss를 부여하고, 추론 시에는 head를 제거해 inference-time 비용이 없음 - 명시적 물리 규칙(충돌 회피 등)이 있는 경우 auxiliary head의 예측을 CEM planning objective에 직접 제약항으로 넣어 rule-aware planning도 가능함을 부록에서 보임
Novelty vs. Prior Works
- 가장 가까운 prior work인 LeWM·VISReg는 representation collapse 방지에만 초점을 맞추는데, 이 논문은 collapse 방지와 물리 정보 보존이 별개 문제임을 명확히 구분한 것이 핵심 novelty임 - depth regularization, PSG-JEPA(proprioception 기반 grounding) 등 유사한 auxiliary supervision 계열 연구와 방향은 같지만, permutation-invariant Fourier symmetrization으로 시각적으로 구분 불가능한 다수 동일 객체를 다루는 부분이 차별점임 - 다만 방법 구성은 bounding box 기반 auxiliary supervision + Fourier feature encoding이라는 비교적 단순한 조합이고, ground-truth bounding box/mask를 시뮬레이터에서 직접 획득해 사용하므로 실환경에서 검증된 기여는 아님. 알고리즘적 신규성은 제한적임
Benchmark Results
- n-ball 환경(H=4) planning 성공률: 제안 기법 1-ball 90.0% vs LeWM 1.2%, 3-ball 72.8% vs 3.2%, 6-ball 65.4% vs 2.7%로 LeWM이 physical representation laziness로 인해 대부분 실패함 - Spearman correlation(제어공 위치): LeWM은 -0.0008~0.017로 사실상 0인데 제안 기법은 0.38~0.49로 크게 개선됨 - laziness가 없는 환경(Push-T, Two Room, OG-Bench Cube)에서는 개선폭이 작음(예: Push-T 성공률 89.2% vs LeWM 86.4%) - 데이터 효율성 ablation: Push-T에서 25만 샘플일 때 최대 1.53배 성공률 개선을 보였으나 1만 샘플처럼 데이터가 극히 적으면 개선 효과가 사라짐(underdetermination) - 부록 실험에서 VISReg와 결합 시 오히려 성능이 저하됨을 이론적으로 분석해 제안 기법이 SIGReg에 특화되어 있음을 인정함. baseline은 LeWM 하나뿐이고 real-world 검증은 없음
누리랩 연구와의 연결
- physical representation laziness 개념은 world model·VLA의 latent representation을 진단하는 프레임워크로 확장 가능해서 누리랩의 world model·object-centric representation 연구에 참고할 수 있음 - permutation-invariant Fourier symmetrization은 다수의 유사 객체를 다루는 3DGS·scene graph 표현에서 object identity 문제를 우회하는 기법으로 응용해볼 수 있음 - auxiliary head를 학습시에만 쓰고 추론시 제거하는 구조는 test-time optimization 연구에서 무료로 얻는 representation 개선 기법으로 실험해볼 가치가 있음

오늘의 핵심 연구 트렌드 종합

  • 추론 비용 없는 학습 시점 보조 지도 — Latent Semantic Scaffolding과 Spectral-Target Physical Latent Structuring이 서로 다른 도메인(VLA policy, JEPA world model)에서 같은 패턴을 독립적으로 씀. 학습 때만 auxiliary head로 reasoning이나 물리 정보를 latent에 강제하고 추론 때는 head를 통째로 버려 비용 없이 이득만 남김.
  • 실패를 측정 가능한 대상으로 만드는 벤치마크 러시 — LIBERO-RECOVER, RoboSPA, ROBORMBENCH가 모두 새 방법이 아니라 실패 유형을 세분화한 진단 도구임. 표준 벤치마크에서 90%대인 VLA가 실제 실패 상태·긴 절차·paraphrase 앞에서 50%p 이상 무너진다는 사실을 수치로 확정함.
  • 예측을 캐시해두고 관측과 대조하는 실시간 보정 — TacPAC이 계획 시점의 예측 접촉을 KV 캐시로 남겨 실행 중 tactile 관측과 대조해 보정하고, Bimanual Handover도 tactile history로 release 시점을 직접 학습함. 두 논문 모두 "재계획 없이 진행 중인 chunk만 미세 수정"하는 동일한 설계를 씀.
  • 로봇 메모리의 언어화 — Linguistic Trajectory Encoding과 CFAM이 각각 물체 이력과 스킬 이력을 압축된 형태로 저장해 장기 기억 문제에 접근함. 각각 언어 캡션+3D anchor(LTE)와 gradient-free capsule(CFAM, 파라미터 업데이트 없이 스킬 이력을 저장하는 단위)를 씀. 둘 다 개별 구성요소는 기존 기법 재조합이지만 memory representation의 problem framing 자체가 기여임.
  • World model latent가 실제로 뭘 담고 있는지에 대한 의심 — Spectral-Target이 SIGReg(latent collapse 방지용 정규화 기법)로 collapse를 막아도 물체 위치 정보가 latent에 없는 physical representation laziness를 실증함. TourPhysics는 관찰(카메라 이동)과 개입(물리적 조작)을 명시적으로 분리해야 world model이 신뢰 가능하다고 주장함.
  • VLM 기반 judge·reward의 신뢰성 위기 — ROBORMBENCH가 의미상 동일한 instruction의 표현만 바꿔도 VLM reward model이 같은 궤적에 정반대 판정을 내림을 보임. scale이나 reasoning을 늘려도 해결되지 않고, trajectory 기반 전용 reward model만 안정적이라는 결과는 VLA 평가·verification 전반에 걸린 문제로 볼 수 있음.
