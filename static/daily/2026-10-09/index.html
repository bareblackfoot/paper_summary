REACT: Rolling Denoising and Dual Decoupling for Reactive Robot Control with VLA Models

arXiv PDF alphaXiv
VLA Reactive Robot Control relevance 9/10 Robotics (cs.RO)
Houlong Xiong, Zhenqi Qiu, Zechen Wang, Suohang Zhang, Yiyu Ren, Wanting Xu, Hongfei Niu, Chengyang He 외 3명 PDF 전문 1차 74점
REACT는 action chunk를 처음부터 다시 만들지 않고 staggered timestep을 가진 rolling action buffer를 매 control step마다 한 번의 Euler step으로 갱신함. 여기에 sensing·encoding·denoising·실행을 분리하는 dual decoupling(DD)을 더해 RoboTwin 2.0과 real robot에서 success rate와 smoothness를 함께 개선함.
Core Innovation & Methodology
- rolling denoising: H-step buffer를 K개 블록(길이 S)으로 나누고 블록마다 다른 flow timestep(staircase)을 배정, 매 iteration 전체 버퍼에 한 번의 Euler step만 적용함. - 가장 깨끗한 앞 블록을 실행하고 나머지를 한 칸씩 당긴 뒤 tail에 fresh noise를 채워, 실행되는 블록이 여러 번의 최근 observation으로 refine되게 함. - dual decoupling: 카메라 주기로 뽑은 observation을 VLM worker pool이 비동기 인코딩해 최신 캐시를 유지하고, DiT는 그 캐시만 보고 갱신해 모델 가중치 변경 없이 input/output throughput을 분리 확보함. - matched staircase training: 한 forward pass에서 블록 위치별로 결정적 flow timestep(1/K,...,1)을 동시에 supervise해 inference에서 쓰는 schedule과 학습을 맞춤.
Novelty vs. Prior Works
- rolling buffer로 action을 점진적으로 denoise하는 아이디어 자체는 diffusion forcing, rolling diffusion model, streaming diffusion policy, responsive noise-relaying diffusion policy 등 기존 rolling/streaming diffusion 계열에서 이미 제안됨. REACT의 기여는 이를 VLM+action expert로 구성된 dual-system VLA 구조에 맞춰 재구성하고, VLM 인코딩 지연이라는 VLA 특유 병목을 dual decoupling으로 따로 뗀 점임. - RTC(real-time chunking) 대비 차이는 committed prefix에 새 suffix를 inpainting하는 대신 하나의 rolling buffer를 여러 관측에 걸쳐 점진적으로 refine한다는 점. 이로 인해 RTC가 겪는 action mode switching이 줄어든다고 주장하나, 두 방식의 mode-consistency를 직접 정량 비교한 지표는 본문에서 확인 불가. - 검증은 단일 backbone(π0.5)에서만 이뤄졌고, 다른 dual-system VLA(GR00T N1, X-VLA 등)로의 일반화는 저자도 limitation으로 명시해 cross-model novelty 증거는 아직 없음.
Benchmark Results
- RoboTwin 2.0 7개 task 평균 success(%, Clean/Randomized): REACT가 Async+training-time RTC보다 높음(44.86/19.86 vs 33.29/10.57). DD를 뺀 변형(REACT w/o DD)은 수치 자체는 더 높음(49.71/20.86)이나 real-time 배치에 필요한 throughput을 못 내 실제 배치가 불가함. - real-world 6개 platform-task(ARX X5·Franka R3, 각 30 trial) 평균 success: REACT 64.8% vs Async+RTC 17.7%, full-chunk π0.5(H50E50) 58.7%. 이 success rate 차이는 two-proportion z-test(z=4.44, 4.84, 9.10, 모두 p<1e-5, 각각 clean/randomized simulation·real-world 기준)로 유의함. - trajectory smoothness(성공 episode만의 mean jerk, 통계 유의성 검정 없음)는 REACT가 Async+RTC보다 낮음(simulation 1219.0<2022.2, ARX X5 90.1<284.1, Franka 28.6<31.6). - specialized task: Pour Rice(ARX X5) success REACT 63% vs Async+RTC 0%, π0.5 H50E50 3%; Reaction Game(Franka R3) latency REACT 734ms vs Async+RTC 747ms, human teleop 705ms. - 학습 효율 ablation: staircase training이 π0.5 baseline의 30k-step 성능(59.3%)을 15k step에 도달시킴. 단, 모든 수치는 단일 backbone(π0.5)·evaluation-rollout 기준이며 코드·모델 공개 여부는 본문에서 확인 불가(프로젝트 페이지만 언급).
누리랩 연구와의 연결
- rolling buffer의 staggered timestep 설계는 누리랩 test-time optimization/inference-time planning 연구에 참고 가능 — world model rollout이나 실로봇 test-time replanning에 유사한 staircase schedule을 적용할 수 있음. - dual decoupling의 sensing-VLM-denoising-execution 분리 구조는 failure detection·recovery에서 observation 갱신과 recovery policy 실행을 분리하는 설계에 응용 가능. - Pour Rice·Reaction Game 같은 specialized dynamic task 설계는 manipulation의 reactivity를 평가하는 프로토콜(연속 상태변화 대응 vs 순간 이벤트 반응)로 참고할 만함.

Self-Supervised Keyframe Discovery for Horizon-Invariant Behavior Cloning

arXiv PDF alphaXiv
Manipulation relevance 9/10 Artificial Intelligence (cs.AI)
Prabin Kumar Rath, Omkar Patil, Nakul Gopalan PDF 전문 1차 78점
과거 관찰을 무작위로 마스킹한 proxy policy는 신경망의 simplicity bias로 keyframe 기반 예측에 쏠림. 이 쏠림(예측 오차)을 reward로 써서 RL로 keyframe selector를 self-supervised로 학습하고, 이렇게 고른 keyframe(mnemonics)을 조건으로 쓰는 BC policy는 학습 horizon보다 수십~수만 배 긴 horizon에서도 성능 저하 없이 동작함.
Core Innovation & Methodology
- non-Markovian BC를 keyframe discovery와 keyframe 조건 BC 두 단계로 분리하는 problem formulation을 제안함. - proxy policy를 무작위 마스킹된 과거 관찰 버퍼(masked-sampling)로 학습시켜, 신경망의 simplicity bias를 이용해 keyframe 기반 가설을 background 기반 가설보다 선호하게 만듦(Kolmogorov complexity 기반 이론, Theorem 1·Proposition 1). - 학습이 끝난 proxy의 negative log-likelihood 손실을 reward로 써서 PPO로 selector policy를 학습함. reward는 action 불확실성(surprise) 계수로 가중한 로그 형태임. - keyframe이 action 정보의 대부분을 담고 unique하다는 task-structure 가정 하에, infinite horizon에서 keyframe이 buffer에서 eviction 없이 유지됨을 증명함(Theorem 2). 이 keyframe과 현재 관찰을 조건으로 BC policy를 학습함.
Novelty vs. Prior Works
- 가장 가까운 prior work는 수동 keyframe annotation·VLM 기반 선택과 ELMUR 같은 explicit memory architecture임. KM은 annotation 없이 self-supervised로 keyframe을 찾는다는 점에서 차별화됨. - RL 기반 keyframe selection을 쓴 선행연구가 있으나 grid world·MuJoCo 수준에서만 검증됐고, 저자는 KM이 로봇 manipulation·real robot까지 확장한 첫 self-supervised keyframe 식별 방법이라고 주장함(related work 기준 저자 claim). - novelty의 핵심은 masked-sampling으로 simplicity bias를 유도해 self-supervised reward를 얻는 학습 트릭임. 다만 이론은 keyframe이 sparse하고 unique하다는 가정에 강하게 의존하며, 저자도 복잡한 manipulation에서는 이 가정이 엄밀히 성립하지 않을 수 있다고 인정함.
Benchmark Results
- synthetic·grid domain(Add, Scattered Copy, T-Maze, MiniGrid-Memory, LTMB-Hallway)에서 KM은 100% SR(또는 최저 MSE)을 달성하고 학습 horizon보다 최대 10^5~10^6배 긴 horizon까지 성능 저하 없이 유지됨. LSTM(BPTT/TBPTT), Decision Transformer, Decision-Mamba, Transformer-XL, ELMUR 등 7개 baseline은 학습 범위 밖에서 붕괴함. - sim 기반 memory-intensive manipulation benchmark MIKASA-Robo(32 tasks 중 23 tasks로 비교)에서 가장 강한 baseline ELMUR 대비 평균 절대 SR +13.9%p 개선함. 본문은 23개 개별 task 중 21개에서 ELMUR보다 우수하다고 적음. - Figure 4는 task를 일부 그룹화해 17개 bar로 보여줘 위 21개 집계와 방식이 다름(서로 모순은 아니나 혼동 가능). - RememberColor3-ΔT 실험(sim)에서 학습 시 ΔT=15였고, KM은 테스트에서 ΔT=250까지 늘려도 성공률(약 70%)을 유지함. 반면 ELMUR는 ΔT=35에서 붕괴, PTP는 ΔT=75부터 서서히 저하됨. - real robot(RememberColor2 task, VR teleoperation 데모 30개, 20 trial) 실험에서 KM은 학습 시 delay(약 5초)의 20배 긴 delay에서도 평균 80% SR을 유지함. 단 real robot 검증은 이 1개 task에 한정됨. - memory가 불필요한 Robomimic Lift/Can/Square에서는 diffusion policy baseline과 성능이 동등함(KM 1.00/0.98/0.85, DP 0.99/0.95/0.80). keyframe 조건화가 Markovian task에서 성능을 떨어뜨리지 않음을 보임.
누리랩 연구와의 연결
- robot memory 축에 바로 연결됨. failure detection·recovery에서 "과거 관찰 중 어떤 것이 실패 원인 진단에 결정적인지"를 고르는 데 KM의 masked-sampling 기반 self-supervised reward 트릭을 재사용할 수 있음. - keyframe selector가 추론 시에도 online으로 동작해 context buffer를 갱신하는 구조라, test-time optimization에서 VLA policy의 working memory를 줄이는 방향으로 응용 가능함. - object-centric 3DGS·scene graph와 결합해 "keyframe 관찰" 대신 "결정에 필요한 object/scene node"를 self-supervised로 고르는 확장이 가능함(본 논문에는 없는 제안임).

UNITAS: A 3D-Native World Action Model for Embodied Manipulation

arXiv PDF alphaXiv
World Model relevance 10/10 Robotics (cs.RO)
Ruixiang Wang, Yongyi Su, Wenlve Zhou, Bo Yue, Hengyan Liu, Dekun Lu, Yuxin Tian, Yihan Fang 외 9명 PDF 전문 1차 78점
UNITAS는 로봇 그리퍼와 사람 손을 3D point trajectory로 표현하는 action flow와 그에 따른 scene flow를 하나의 metric 3D frame에서 공동 생성하는 world action model임. 1.7B 파라미터로 LIBERO 99.8% success rate와 RoboTwin action-conditioned scene prediction에서 PointWorld 대비 최대 49% 낮은 displacement error를 보임.
Core Innovation & Methodology
- 관측·행동·장면변화를 이미지가 아니라 공유 metric 3D frame에 정렬함. 로봇 그리퍼·사람 손 motion을 action flow(3D point trajectory)로, 장면 반응을 scene flow로 표현해 embodiment 간 공통 representation을 만듦. - depth 유무와 무관하게 visual token을 world frame에 위치시키는 world-aligned 3D positional embedding을 씀. depth 없을 때는 카메라 ray 위 64개 후보 depth에 대한 attention 기반 weighted sum으로 위치를 추정함. - 서로 다른 frame rate·길이의 trajectory를 physical time(초 단위)으로 정렬해 point trajectory 하나를 하나의 token으로 인코딩하는 physical-time trajectory tokenizer를 제안함. - point dynamics expert(action/scene flow 담당)와 action expert(end-effector 명령 담당)를 Mixture-of-Transformers로 결합함. causal attention mask로 policy 전용 추론 시 future flow branch를 skip하게 설계함.
Novelty vs. Prior Works
- point flow를 cross-embodiment action representation으로 쓰는 아이디어 자체는 General Flow·Track2Act·Flow-as-cross-domain-interface 계열의 기존 연구이고, scene flow 예측도 PointWorld가 이미 다룸. - 본질적 차이는 PointWorld가 외부에서 주어진 robot motion에 조건화해 scene flow만 예측하는 반면, UNITAS는 instruction으로부터 action flow까지 생성해 policy와 world model을 하나의 interface로 묶은 것임. - world-aligned PE와 physical-time tokenizer는 구현이 깔끔하지만, 새로운 learning paradigm이라기보다는 기존 3D point tracking·flow 기반 action 표현과 MoT 아키텍처를 결합한 종합에 가까움.
Benchmark Results
- LIBERO 평균 success rate 99.8%로 비교 baseline 중 최고치임(pretrain 없이도 99.5%). sim-only 벤치마크임. - RoboTwin 2.0 50개 bimanual task(task당 100 episode)에서 Clean 92.94%, Randomized 93.04%로 Fast-WAM(6B)·Motus(8B)보다 적은 1.7B 파라미터로 상회함. - VLABench에서 success rate 56.2%로 π0.5의 48.1% 대비 상회함. LIBERO-Plus 전체 조건에서도 89.1%로 최고치를 보여 camera·robot-state perturbation에 강함. - action-conditioned scene prediction(RoboTwin held-out rollout, 시뮬레이터 ground truth 사용)에서 Moving ADE 0.427cm, Static ADE 0.043cm로 PointWorld(0.656cm, 0.084cm) 대비 각각 약 35%, 49% 감소함. - 실로봇 2개 task(Organize Books, Pack the Ball), task당 20회 시행에서 각각 90%, 80% 성공률로 π0.5(75%, 55%)·Fast-WAM(65%, 60%)을 상회함. task 수가 2개로 제한적임. - ablation(LIBERO-Plus, pretrain 없음, 10,030 episode)에서 3D positional embedding 제거 시 overall 85.74%→81.35%, action-flow history token 제거 시 75.92%로 하락. 모든 구성요소 제거 시 67.58%까지 떨어짐.
누리랩 연구와의 연결
- action flow와 scene flow의 불일치를 test-time monitoring 신호로 써서 failure detection에 적용할 수 있음. 생성된 action flow 실행 후 예측 scene flow와 실제 관측 변화를 비교하는 방식임. - 3D-native world model이라 object-centric 3DGS나 scene graph와 결합해, 특정 object의 scene flow만 선택적으로 예측하는 active perception 실험에 연결할 수 있음. - physical-time trajectory tokenizer는 robot memory(과거 trajectory 압축) 용도로 재사용할 여지가 있어 보임. human hand 데이터까지 쓰려면 MANO annotation 수집 비용을 먼저 검토해야 함.

ARC: A Reasoning Recipe for Robot Foundation Models

arXiv PDF alphaXiv
VLA Robot Foundation Model Reasoning relevance 9/10 Robotics (cs.RO)
Gokul Puthumanaillam, Tao Sun, Elie Aljalbout, Moritz Reuss, Zhaoshuo Li, Fabio Ramos, Ankit Goyal, Jenai Xuning Yang PDF 전문 1차 76점
로봇 action chunk마다 원인-효과-행동을 연결하는 action-grounded causal trace(ARC)를 만들고, 이를 기존 VLA(pi0.5)와 WAM(Cosmos3-Nano-Policy, world action model)에 fine-tuning으로 주입하는 방법임. 추가 로봇 데이터나 foundation-scale 재학습 없이 RoboLab-120·MolmoSpaces에서 state of the art를 달성하고 실로봇에서 82.2%p 성공률 향상을 보임.
Core Innovation & Methodology
- action chunk마다 State·Cause·Effect·Action·Avoid·Completion으로 구성된 action-grounded causal trace(ARC)를 reasoning 표현으로 정의함. - 기존 ECoT·subtask 라벨은 action-head attention이 4~6%에 그쳐 모델이 무시하는 shortcut learning임을 attention 분석으로 보임. ARC trace는 41%까지 올라감. - VLM 파이프라인으로 DROID를 재라벨링해 약 75K episode, 1.2M action-aligned frame 규모의 Arc-Trace-DROID를 새 로봇 데이터 수집 없이 자동 생성함. - VLA(pi0.5)는 counterfactual trace에 margin loss를 걸어 trace 무시 shortcut을 막고, WAM(Cosmos3-Nano-Policy)은 reasoner의 next-token loss로 trace를 직접 학습시키는 등 아키텍처별로 다른 fine-tuning 전략을 적용함.
Novelty vs. Prior Works
- ECoT(Zawalski et al. 2024)·pi0.5의 semantic subtask 라벨(Black et al. 2025a) 대비, trace를 '효과를 일으키는 원인'으로 명시적으로 구조화하고 counterfactual loss로 shortcut을 차단한 점이 본질적 차이임. - RT-H(Belkhale et al. 2024)나 steerable VLA(Chen et al. 2026) 같은 선행 action-level language guidance와 달리, 라벨링을 전부 자동화해 기존 데모에서만 trace를 뽑아 scale을 확보함. - 방법론 자체는 CoT형 intermediate reasoning을 로봇 제어에 적용한 것이라 reasoning paradigm의 신규성은 제한적임. 기여의 중심은 '무엇을 reasoning에 넣어야 action과 실제로 연결되는가'라는 representation 설계와 그 실증임.
Benchmark Results
- RoboLab-120(Vague/Default/Specific 세 세팅)에서 pi0.5+ARC, Cosmos3-Nano+ARC가 베이스 대비 각각 최대 +29.8%p, +24.3%p 향상하며 1·2위를 차지함. - MolmoSpaces(9개 task)에서 pi0.5는 17.8%→45.0%(+27.2%p), Cosmos3-Nano는 39.0%→57.6%(+18.6%p)로 새 state of the art를 달성함. - reasoning 전용 benchmark인 RoboLab-Reasoning-50에서 pi0.5 +46.8%p, Cosmos3-Nano +50.0%p로 가장 큰 개선폭을 보임. 단 이 benchmark는 저자 그룹과 밀접한 측에서 만든 것으로 독립 검증은 아님. - 실로봇 28개 task(RoboLab-Reasoning-Hardware)에서 pi0.5+ARC가 9.5%→91.7%(+82.2%p)로 sim 개선이 하드웨어에서도 유지됨. hardware-specific fine-tuning은 하지 않음. - pi0.5+ARC는 Euler step을 10→1로 줄여도 베이스 성능과 동등함(추론 10배 가속). RFL은 후보 미래 viewpoint마다 answerability를 매겨 action value로 쓴다는 점이 다름. - VG-AVS는 answer-correctness reward로 viewpoint adjustment를 직접 regression하는 policy인데, RFL은 모든 후보 모션에 graded target을 주는 candidate-wise value learning이라 미실행 대안까지 supervision에 포함함. - 다만 핵심 요소인 privileged teacher distillation과 answerability metric은 각각 Learning-by-Cheating 계열과 저자 그룹 자신의 선행 연구(Answerability Fields, E3VS-Bench)에서 가져온 조합이라 conceptual leap은 제한적임. 평가 벤치마크인 E3VS-Bench 자체도 이 논문과 저자가 다수 겹쳐 평가의 독립성이 약함.
Benchmark Results
- E3VS-Bench 테스트 377 episode(unseen scene 21개) mean judge score(1~5): RFL 3.05, GPT-5.1 2.81, Gemini 3.0 Flash 2.62, Cosmos3(future-view generation) 2.36, 동일 VLM 직접 제어 2.14, π0.5 imitation 2.15. Collision rate는 RFL이 0.11로 최저임. - 같은 teacher trajectory로 action만 clone한 baseline은 2.47인데, candidate-wise answerability value로 학습한 RFL은 3.05로 더 높음. value supervision이 action imitation보다 효과적임을 시사함. - rendering oracle과 비교하면 RFL은 1-step에서 2.98로 oracle과 동일하지만, 2-step에서는 RFL 3.05 vs oracle 3.19로 0.14 차이가 남음. - answerability가 탐색 성공 신호인지 검증한 validation 231 episode 실험에서 AUROC 0.824로, privileged target IoU(0.719)나 episode length(0.743)보다 높음. - real robot(6-DoF arm, end-effector camera, 질문 3개×방법 3개×trial 10회=90 trial)에서 RFL이 pot 질문 3.80, oven 질문 3.00으로 최고 평균을 기록했고 base VLM은 세 질문 모두 1.40에 머묾. 단 text를 읽어야 하는 blue-package 질문은 GPT-5.1(2.60)이 RFL(2.20)보다 높았음.
누리랩 연구와의 연결
- test-time optimization/inference-time planning 관점에서, 렌더링 없이 privileged teacher의 lookahead를 distill하는 레시피는 failure detection·recovery policy 학습에도 적용 가능함. 3DGS로 counterfactual rendering 후 VLM으로 '복구 가능성'을 scoring해 distill하는 식임. - object-centric 3DGS·scene graph 연구와 연결됨. RFL의 teacher는 3DGS를 counterfactual rendering 도구로만 쓰는데, scene graph나 object-centric representation을 결합하면 answerability target을 더 compositional하게 줄 수 있을 것으로 보임. - stopping 결정이 여전히 base VLM에 맡겨져 있다는 한계(oracle gap 대부분이 stopping에서 발생)는 누리랩의 failure detection 연구와 바로 연결됨. '언제 멈출지'를 별도 value로 학습하는 확장이 유망함.

오늘의 핵심 연구 트렌드 종합

  • world model을 policy 선택·학습의 기준으로 씀 — UNITAS, World-Model Policy Arbiter 등이 world model을 예측기가 아닌 policy 선택·학습·post-training의 기준(scorer)으로 씀.
  • frozen policy를 재학습하지 않고 test-time에만 손을 댐 — SpatialHarness, World-Model Policy Arbiter 등은 policy 가중치를 그대로 두고 observation·conditioning·policy 선택만 test-time에 조정해 성능을 올림.
  • 실패를 측정 가능한 state component로 분해해 원인을 찾음 — Observation-Space Shift 진단과 HWAM은 추상적 실패 대신 어떤 object·joint·state 성분이 틀렸는지를 먼저 분리해냄.
  • human video를 robot action target으로 직접 전환함 — VioLA는 human·robot motion encoder를 같은 latent space에 공유시킴. 이 덕분에 human 비중 93.2% 데이터만으로 humanoid policy를 학습함.
  • 고정 카메라 가정을 깨고 viewpoint를 policy 입력의 변수로 다룸 — VersaCamVLA와 Rendering-Free Lookahead는 카메라 개수·포즈·모션 선택을 policy design space에 넣음.
  • VLA inference 구조를 rolling/비동기 방식으로 재조직함 — REACT는 action chunk를 처음부터 다시 만들지 않고 staggered timestep rolling buffer로 observation freshness와 chunk coherence를 동시에 확보함.

유망 연구 방향 및 프로젝트 제안

object-centric 3DGS로 action-execution gap을 조기 탐지하는 test-time failure detector - research question: VLA가 action chunk를 실행하는 동안 실제 scene 변화가 예측과 어긋나는 지점을 object 단위로 분해하면 실패를 더 일찍 잡아낼 수 있는가. - 접근·novelty: UNITAS의 action flow/scene flow 불일치 신호, HWAM의 action-execution gap 측정, Observation-Space Shift 진단의 성분별 teleport-oracle ablation을 object-centric 3DGS 노드 단위로 결합함. - 왜 지금·경쟁 prior works: 오늘 세 논문이 각각 '실행 결과와 예측의 불일치'를 실패 신호로 쓰지만 object 단위로 분해한 연구는 없음. Observation-Space Shift 진단은 privileged simulator teleport에 의존해 real-robot 확장이 안 됨. - risk·target venue: object tracking 오차가 누적되면 false alarm이 늘어남. real-robot failure injection 실험이 필수. target: CoRL/RSS.

frozen VLA policy bank를 위한 world-model arbitration + capability-aware trigger 결합 - research question: 여러 이질적 VLA·skill policy를 pool로 두고 world model scoring과 실시간 capability latent를 같이 써서 test-time에 policy와 observation 조합을 함께 고를 수 있는가. - 접근·novelty: World-Model Policy Arbiter의 policy arbitration을 뼈대로 하고, CAPABLE의 label-free capability inference로 전환 시점을 보강하고 SpatialHarness의 test-time scaffolding으로 observation까지 같이 조정함. - 왜 지금·경쟁 prior works: World-Model Policy Arbiter는 state-based sim(OGBench)만 검증했고 pixel 기반 real-robot 확장은 저자도 future work로 남김. - risk·target venue: world model scoring 오차 누적과 실시간 연산 비용이 리스크. target: CoRL.

미래 조건화 신호의 신뢰도를 3DGS counterfactual rendering으로 사전 추정하는 reliability gate - research question: future video나 subgoal 같은 조건화 신호가 틀렸을 때를 실행 전에 3DGS 기반 counterfactual rollout으로 탐지해 fallback할 수 있는가. - 접근·novelty: RAFC의 reliability gate(고정 시간축 오프셋 blend)를 DreamTrue식 counterfactual action 생성으로 대체하고, Rendering-Free Lookahead처럼 학습 시에만 3DGS로 렌더링해 distill하고 추론 시엔 렌더링 없이 평가하게 만듦. - 왜 지금·경쟁 prior works: RAFC는 고정된 시간축 오프셋 3개만 blend하고 counterfactual world model은 쓰지 않음. - risk·target venue: 3DGS 렌더링 비용이 real-time 제약과 충돌할 수 있음. target: RSS/CoRL.

human-to-robot latent motion 공유에 tactile perception을 결합한 manipulation VLA - research question: hand latent controller에 tactile feedback을 추가하면 VioLA가 보고한 grasp retention 실패(옷 놓침, 병 넘어짐)가 줄어드는가. - 접근·novelty: VioLA의 human·robot 공유 latent motion space에 contact force 정보를 추가해 vision-only hand decoder의 한계를 보완함. - 왜 지금·경쟁 prior works: VioLA는 저자 스스로 hand decoder에 contact-force feedback이 없다는 한계를 명시함. - risk·target venue: tactile sensor 하드웨어 의존과 sim-to-real gap이 리스크. target: CoRL/RSS.

stopping을 별도 학습된 value로 분리하는 active-perception failure detector - research question: '언제 멈출지'를 base VLM 판단 대신 별도 학습된 value function으로 분리하면 oracle과의 격차를 더 줄일 수 있는가. - 접근·novelty: Rendering-Free Lookahead가 밝힌 stopping gap(oracle gap 대부분이 stopping에서 발생)을 CAPABLE의 online capability latent로 보완해 stopping을 별도 head로 학습함. - 왜 지금·경쟁 prior works: Rendering-Free Lookahead는 motion selection만 distill하고 stopping 결정은 여전히 base VLM에 위임함. - risk·target venue: stopping label 수집 비용이 변수. target: ICRA/CoRL.
