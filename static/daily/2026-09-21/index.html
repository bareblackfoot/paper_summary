PSR: Predictive Sensorimotor Representation Learning for Contact-Rich Manipulation

arXiv PDF alphaXiv
VLA Manipulation (force-aware contact-rich manipulation) relevance 9/10 Robotics (cs.RO)
Shengbao Li, Peng Xu, Chao Tang, Hao Wei, Jiaheng Wang, Hong Yin, Jiangtao Chen, Jinxuan Zhu 외 3명 PDF 전문 1차 68점
F/T·joint effort·관절 변위를 미리 예측하도록 pretraining한 sensorimotor representation hierarchy를 VLA의 action expert에 여러 depth로 주입하는 PSR-VLA를 제안함. 6개 실제 로봇 contact-rich task에서 π0.5·ForceVLA·ForceVLA2 대비 19.2~30.0pp 높은 성공률(91.7%)을 보임.
Core Innovation & Methodology
- 기존 force-aware VLA는 F/T를 정책 입력으로 수동 조건화만 함. PSR은 미래 F/T·joint effort·종단 관절 변위를 예측하는 pretraining objective로 이를 대체함(Stage 1, action-unconditioned). - 6-layer multimodal Transformer의 매 layer 출력을 hierarchy Z=[z1...z6]로 보존함. 얕은 층은 modality 독립 처리, 중간층은 attention bottleneck cross-modal fusion, 깊은 층은 fused representation임. - 중간층 visual/F-T stream에는 4-expert Top-2 MoE를 적용해 이질적 접촉 패턴을 분리 학습함. - Stage 2에서 z1~z6를 18-layer action expert의 3,6,9,12,15,18번 layer에 gated cross-attention으로 depth 정렬해 주입, π0.5 기반 PSR-VLA를 만듦.
Novelty vs. Prior Works
- ForceVLA/ForceVLA2는 F/T를 reactive conditioning이나 hybrid force-position control target으로 쓰는데, PSR은 F/T·joint effort·종단 변위를 하나의 predictive representation objective로 묶은 게 핵심 차이임. - CoT-VLA·JEPA-VLA·DreamTacVLA·UniTacVLA는 시각 또는 tactile 미래만 예측하는데, PSR은 외부 접촉 반응과 내부 구동 부하, 결과 상태 변화를 함께 예측 대상으로 삼음. - 다만 구성 요소(RPT식 예측 pretraining, attention bottleneck fusion, MoE routing, depth-aligned injection) 자체는 기존 기법의 조합이라 새 paradigm보다는 정교한 엔지니어링 조합에 가까움.
Benchmark Results
- 6개 실제 로봇 task(hard 2·medium 2·easy 2), task당 20 trial 총 120 trial, 단일 embodiment(Rainbow Robotics RB-Y1)에서만 검증했고 sim 실험은 없음. - PSR-VLA 110/120(91.7%)로 π0.5 74/120(61.7%), ForceVLA-π0.5 83/120(69.2%), ForceVLA2-π0.5(short-horizon pathway만 이식한 변형) 87/120(72.5%) 대비 +30.0/+22.5/+19.2pp임. baseline은 원 코드가 아니라 저자가 π0.5 backbone으로 재구현한 버전임. - ablation(water-hose/2-hole plug 2개 task, offline 100 episode): Stage-1 pretraining 제거 시 실제 성공률 95%/95%에서 70%/55%로 하락함. - depth 정렬을 뒤집으면 65%/60%, 모든 층에 z6만 공유하면 70%/75%로 하락해 representation 다양성과 정렬 순서 모두 효과 있음을 보임. output 1곳만 조건화하면 50%/55%로 더 떨어짐. - PSR-VLA 단독 재현 4회 109.5±2.5/120, water-hose stress test 442/450(98.2%)은 baseline 비교 없는 자체 결과임. 코드·모델 공개 여부는 본문에서 확인 불가함.
누리랩 연구와의 연결
- PSR의 예측 hierarchy를 failure detection에 그대로 쓸 수 있음: 예측된 F/T·effort와 실측값의 괴리를 anomaly signal로 쓰면 contact 이상을 사전에 탐지하는 recovery trigger가 됨. - 현재는 Stage 1 pretraining 후 Stage 2에서 prediction loss를 끊는데, test-time optimization 관점에서 배포 중에도 predictive loss를 켜 두고 온라인 적응하는 방향으로 확장할 여지가 있음. - FAWAM·Dream-Tac 등 force/tactile-conditioned world model 계열과 PSR의 representation-level 예측을 비교하면, world model 기반 planning과 representation 기반 action 증강의 차이를 정리하는 연구로 이어질 수 있음.

Skel-WAM: A Hand-Skeleton-Conditioned World Action Model for Human-to-Robot Manipulation Transfer

arXiv PDF alphaXiv
World Model Manipulation (Human-to-Robot Transfer) relevance 9/10 Robotics (cs.RO)
Zetao Cai, Yaping Li, Yiqun Wang, Xinyu Zhan, Yuyin Yang, Haoxiang Ma, Kailin Li, Tao Lu 외 3명 PDF 전문 1차 63점
인간 영상과 로봇 시연을 손-골격(hand-skeleton)이라는 공통 인터페이스로 정렬해 world action model Skel-WAM을 학습시킴. 21개 keypoint 기반 시각 overlay와 2.5D keypoint로 사람-로봇 동작을 같은 공간에 투영하고, 로봇 action label 없이 인간 영상만으로 로봇이 못 본 task variation의 성공률을 38.89%에서 86.11%로 올림.
Core Innovation & Methodology
- 사람과 로봇 두 손을 21-keypoint 공통 토폴로지로 표현하는 unified hand-skeleton motion interface를 씀. 장면에 그려 넣는 skeleton overlay(시각 정렬)와 정규화 좌표+깊이로 된 구조화 2.5D keypoint(운동학 정렬)를 같이 씀. - Video Expert(Wan2.2-TI2V-5B 초기화)와 Keypoint Expert로 구성된 Mixture-of-Transformers(MoT)가 방향성 있는 attention mask로 미래 overlay 영상과 미래 keypoint 궤적을 동시에 예측함. - 로봇 데이터로만 학습하는 별도의 causal Action Expert가 위 예측을 저수준 로봇 action으로 디코딩함. 이 분리 구조 덕분에 인간 영상은 action label 없이 MoT의 dynamics만 supervise함. - 학습은 사람+로봇 데이터로 MoT를 2:1 비율로 80k step cotrain한 뒤, 로봇 데이터만으로 Action Expert를 50k step 학습하는 2단계 방식이고 전 과정 flow matching objective를 씀.
Novelty vs. Prior Works
- 손 골격을 사람-로봇 공유 표현으로 쓰는 아이디어 자체는 DexWM(MANO keypoint displacement), Ego-Pi(finger-skeleton overlay를 로봇 action space로 매핑), OSCAR(2D skeleton 조건 world model) 등 선행 연구가 이미 다룸. 완전히 새로운 표현은 아님. - 차별점은 overlay(시각)와 2.5D keypoint(운동학)를 동시에 쓰고 dynamics 학습과 action 디코딩을 분리해, 인간 영상이 action label 없이도 shared dynamics만 supervise하도록 만든 조합임. - LDA-cotrain(사람 wrist pose·MANO를 로봇 end-effector pose로 직접 retarget)이 30.56% SR에 그친 반면 Skel-WAM cotrain은 86.11%로, 직접 pose retargeting보다 공유 skeleton 공간 정렬이 낫다는 것을 실증적으로 보임. 다만 이는 표현 선택의 효과 검증이지 새 learning paradigm은 아님.
Benchmark Results
- 실제 로봇 4개 bimanual task(Franka Research 3 x2 + RobotEra XHand1, teleoperation 수집, 로봇 전용 학습)에서 평균 SR(success rate) 79.86%/PSR(progress success rate, task 완료도 기준 부분 점수) 89.24%로 가장 강한 baseline인 EgoVLA(57.64%) 대비 22.22pp 앞섬. ACT 12.32%, Fast-WAM 38.89%, LDA 42.01%. - robot-missing task variation(위치·회전·방해물·높이) 4종에서 human-robot cotraining이 SR을 38.89%(no cotrain)에서 86.11%로 47.22pp 올림. keypoint 제거 시 SR 17% 미만, overlay 제거 시 50.00%로 두 표현 모두 필요함. - 시뮬레이션 7개 EgoVLA-Sim task(각 93 episode, 그중 66개는 unseen table/background, 로봇 전용 학습)에서 평균 SR 63.29%/PSR 78.42%로 EgoVLA 대비 8.28pp/13.11pp 앞섬. ablation에서는 keypoint 제거 시 38.40%로 더 크게 떨어져 sim에서는 keypoint 기여가 overlay보다 큼(overlay 제거 시 61.90%). - 실제 로봇 unseen background 실험(로봇 전용 학습)에서 SR 58.33%/PSR 76.04%로 EgoVLA 대비 20.83pp/19.79pp 앞섬. - 실제 로봇 실험은 task당 setting별 6~24 trial로 표본이 작고, 단일 bimanual dexterous-hand 플랫폼에 한정됨. 코드·모델 공개 여부는 본문에서 확인 불가(project page 링크만 제시됨).
누리랩 연구와의 연결
- 로봇 시연에 없는 task variation을 인간 영상으로 채운다는 문제 설정은 실패 유발 조건(위치·회전·방해물 등)을 사전에 커버하는 접근이라, failure detection/recovery보다는 실패를 미리 줄이는 data coverage 확장 아이디어로 참고할 만함. - action label 없이 shared dynamics만 학습하는 분리 구조(MoT cotrain + robot-only action expert)는 다른 저비용 감독 신호(시뮬레이션 rollout, affordance 등)로 VLA를 확장할 때의 설계 참고가 됨. - 21-keypoint 두 손 skeleton을 embodiment-agnostic 중간 표현으로 쓰는 방식은 object-centric 3D/4D representation 연구에서 hand-object interaction을 다룰 때 대체 표현으로 검토해볼 수 있음.

From Pretraining to Proficiency: Real-World Subtask RL for Long-Horizon Manipulation with Minimal Human Intervention

arXiv PDF alphaXiv
Manipulation Real-World RL (VLA fine-tuning) relevance 9/10 Robotics (cs.RO)
Sichang Su, Benjamin Yang, Zhiyun Deng, Boyuan Liang, Yip Fun Yeung, Zelin Wang, Lingfeng Sun PDF 전문 1차 72점
PARTS는 pretrained VLA(π0.5)가 long-horizon task 대부분을 잘 수행하지만 반복 실패하는 소수 bottleneck subtask에만 residual RL을 집중시켜 학습 효율을 높이는 프레임워크임. bottleneck마다 coding agent가 작성한 selector·verifier·reset 프로그램으로 로컬 보상과 에피소드 진행을 자동화해, 사람 개입 없이 real-world RL rollout을 반복하고 success-reweighted retraining으로 재배포함.
Core Innovation & Methodology
- 문제 설정: pretrained VLA가 task 대부분을 수행하지만 소수 bottleneck subtask에서 반복 실패한다고 보고, 전체 task 대신 bottleneck에만 RL을 집중하는 targeted subtask RL을 제안함. - 구조: base VLA(π0.5)는 고정한 채 매 step nominal action chunk를 내고, bottleneck별 residual actor가 coordinate mask와 물리적 bound로 제한된 소수 action 차원만 보정함. - 학습: chunk 단위 TD3+BC로 residual actor-critic을 학습하고, reference dropout으로 actor가 nominal chunk를 그대로 베끼는 것을 막음. - Agentic scaffolding: 사람이 bottleneck별 contract(진입 조건·수정 가능 좌표·성공 기준·reset 방식)를 정의하면 coding agent(논문 표기: Claude Fable 5, GPT-6 Astra)가 policy selector·success verifier·auto-reset 프로그램을 작성함. 이 덕분에 학습 rollout 중 사람의 보정·전환·보상 라벨링이 필요 없음. - success-reweighted retraining: bottleneck별 replay에서 성공 전체와 실패 일부(비율 ρ)를 뽑아 새 네트워크를 재학습·재배포해, sparse reward와 좁은 restaging 분포로 인한 overfit을 완화함.
Novelty vs. Prior Works
- RLT[7]도 VLA를 freeze하고 residual actor-critic을 쓰지만 사람이 지정한 단일 handoff 이후 base로 되돌아가지 않는 구조라, LEGO처럼 bottleneck이 매 브릭마다 반복되는 task는 표현이 안 됨. PARTS는 selector가 base↔residual 전환을 반복 수행함. - DSRL[9]·EXPO-FT[10]는 sparse reward를 full task 단위로만 받아 credit assignment가 어렵고, EXPO-FT는 (본문의 별도 비교에서) backbone 자체를 업데이트해 이미 100%였던 cable unplug 성공률을 55%로 퇴화시킴(PARTS 자체의 cable 성공률 50%→95%와는 다른 비교 기준). - RL 알고리즘 자체(TD3+BC, chunk-level actor-critic, offline retraining[37])는 기존 기법의 재조합이고 bottleneck 식별은 여전히 사람이 함. 이 논문의 novelty는 사람이 준 contract를 coding agent가 실행 가능한 local supervision(selector/verifier/reset)으로 변환하는 시스템 설계에 있고, RL 알고리즘 신규성은 제한적임.
Benchmark Results
- earbud insertion(bimanual YAM) 전체 성공률 10%→40%(PARTS), base policy 대비 4배. 두 insertion bottleneck(RL1, RL2)은 각각 20~35%p 개선됨. task당 20 episode 평가. - LEGO sorting(YAM)은 progress score(10개 브릭 중 분류 비율)만 보고 — SFT 54%→PARTS 82%, RL rollout 17분만 사용. DSRL(44.5%)·EXPO-FT(48%)·RLT(50%)는 SFT보다 낮거나 비슷해 baseline이 개선을 전혀 못 함. - cable unplug&plug(single-arm Franka FR3) 성공률 50%→95%, RL rollout 29분. - 동일 rollout budget 비교(matched budget)에서 최고 baseline 대비 PARTS가 earbud 25%p(15%→40%, matched-budget 최고 baseline 기준이며 base policy의 10%와는 다른 비교임), cable 25%p(70%→95%) 앞섬. abstract의 "25% 이상" 표현은 percentage point 기준으로 보임. - ablation(earbud RL1/RL2에만 적용): success-reweighted retraining 제거 시 binary 성공률 40%→25%로 하락 — retraining이 핵심 메커니즘임. 평가는 3개 task·2개 real-robot 플랫폼뿐이고 sim 실험은 없음. 코드·모델 공개 여부는 본문에서 확인 불가(project page 링크만 존재). 참고로 abstract의 "YAM 32%→61%" 수치는 earbud 이진 성공률과 LEGO progress score를 단순 평균한 값으로, 서로 다른 두 지표를 섞은 값임.
누리랩 연구와의 연결
- failure detection/recovery 관점에서, "실패가 소수 bottleneck에 집중된다"는 관찰과 국소 수정 전략은 누리랩의 failure diagnosis·recovery 연구에 바로 붙일 수 있는 formulation임. - test-time optimization 관점에서, pretrained policy를 얼리고 소수 구간에만 online 학습을 거는 구조는 test-time adaptation 파이프라인 설계에 참고할 만함. - coding agent가 사람의 contract를 selector/verifier/reset 코드로 변환하는 부분은 VLM 기반 scene understanding·semantic mapping과 결합해 bottleneck 식별 자체를 자동화하는 후속 연구로 확장 가능함.

GALA: Geometry-Aware Latent Action Modeling for Vision-Language-Action Model Pretraining across Embodiments

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Yichen Liu, Puzhen Yuan, Xiang Zhu, Yanjiang Guo, Jianyu Chen PDF 전문 1차 71점
image 기반 latent action model에 end-effector의 3D point cloud transition을 더해 손가락 단위 articulation까지 잡아내는 GALA를 제안함. 사람 손·dexterous hand 2종·gripper 총 4종 embodiment를 point cloud 기반 공유 latent(UEMR)로 묶어 VLA를 pretrain해서 multi-embodiment co-training 기준 RoboCasa GR-1 68.3%, 실물 XHand 4 task 평균 75.5% 성공률을 냄.
Core Innovation & Methodology
- image latent action(RGB transition)만으로는 미세한 손가락 움직임을 놓친다는 문제를 짚고, wrist/root 중심 point cloud(N=1024)로 표현한 end-effector geometry transition을 별도 latent로 추가함. - UEMR 세 가지 설계로 embodiment 간 공유 가능한 geometric latent를 만듦: 좌우 손을 하나의 latent로 묶는 unified bimanual latent, start-goal pair에 동일한 3D 변환을 주는 pair-consistent augmentation, forward/backward 양방향으로 transition을 학습하는 bidirectional learning. - 구조는 frozen DINOv2+SigLIP(visual)과 frozen Point Transformer V3(geometry)를 shared spatiotemporal transformer로 융합하고, 각각 EMA-VQ codebook으로 양자화함. geometric decoder는 시작 geometry 조건부로 goal point cloud를 Chamfer distance로 복원함. - 2단계 VLA co-training은 GR00T 아키텍처에 visual/geometric bridge token을 붙여 latent를 autoregressive 예측(CE loss)하고, shared DiT + embodiment별 action head로 각 embodiment의 native action space를 그대로 유지함(공통 action space로 강제 변환하지 않음).
Novelty vs. Prior Works
- point cloud 기반 cross-embodiment geometric latent action 자체는 새 문제가 아님. LAD, OPFA, XL-VLA, METIS 등 2025~2026 동시기 연구가 같은 방향을 다룸. GALA의 차별점은 joint·keypoint correspondence 없이 순수 point cloud transition만으로 latent를 공유하는 것과 UEMR 세 설계임. - novelty는 새 패러다임 제시보다는 기존 아이디어(point 기반 LAM + visual/geometric dual latent supervision)의 조합·정교화에 가까움. 다만 같은 학습 데이터·아키텍처 조건에서 OPFA·METIS를 직접 baseline으로 놓고 이겨서 실증적 우위는 확인됨. - 각 embodiment의 native action space를 유지하고 shared DiT + embodiment별 head로만 연결하는 선택은 XL-VLA류의 unify 접근과 다른 설계 판단이며, 이 부분이 UEMR과 함께 논문의 실질적 기여로 보임.

Benchmark Results
- 실로봇 4개 task(peg insertion, chip handling, cap unscrewing, board wiping), task당 20 trial(총 80 trial)에서 평균 성공률 95.0%임 (전 task 최고 성공률 달성). - fine-tuned π0.5 58.75%, FiLM-fusion TacVLA 71.25%, concat-and-gating TacVLA 72.5%, ACT 13.75% 대비 각각 36.25%p, 23.75%p, 22.5%p, 81.25%p 높음. - ablation: tactile 없음 58.75% → concat 68.75% → 단방향 cross-attn 80.00% → +forecasting 81.25% → 양방향 cross-attn+forecasting(최종) 95.00%로 단계적으로 상승함. - tactile forecasting 자체 정확도는 held-out set에서 정규화 tactile space 기준 MAE 6.48×10⁻³로 보고됨 (절대적 해석 기준은 본문에서 확인 불가). - 저조도 환경 80.0%·시각적 혼잡 환경 81.25%로 baseline 대비 성능 저하폭이 가장 작음. 단 전부 real robot 단일 embodiment·task 4개·데모 280개 규모이며 코드·모델 공개 여부는 본문에서 확인 불가.
누리랩 연구와의 연결
- tactile forecasting은 접촉 상태에 대한 짧은 horizon world model로 볼 수 있어서 world model·failure detection 연구와 바로 연결됨. 미래 접촉 상태 예측이 어긋나는 순간을 실패 징후로 활용하는 방향을 검토할 만함. - ground-truth-to-prediction curriculum은 학습 중 예측 오차에 점진적으로 노출시키는 방식이라, test-time optimization/adaptation 연구에서 참고할 만한 학습-추론 격차 완화 기법임. - 단일 센서·단일 embodiment 한계는 일반화 문제로 확장할 여지가 있음. 여러 tactile 센서·그리퍼에 걸친 forecasting 일반화를 manipulation generalization 연구와 연결할 수 있음.

오늘의 핵심 연구 트렌드 종합

  • 미래 상태를 예측하는 objective를 도입한 논문이 modality별로 동시다발적으로 나타남 — PSR(F/T·joint effort), SkelWAM(skeleton state), ME-Dex 1.0·ForeTac-VLA(tactile), CARF(progress score) 다섯 편 모두 미래 상태를 예측하는 objective를 독립적으로 씀. 이 예측-실측 오차를 failure 신호로 쓸 수 있다는 아이디어는 각 논문이 직접 검증한 것이 아니라 리뷰가 제안한 확장임.
  • 저차원 기하 표현을 canonical interface로 써서 cross-embodiment·human-to-robot 전이를 푸는 계열이 자리잡음 — skeleton/keypoint 기반의 SkelWAM(robot-to-robot)·Skel-WAM(human-to-robot), point cloud 기반의 GALA가 같은 날 나옴. embodiment 차이를 흡수하는 저차원 기하 표현이라는 같은 답을 서로 다른 방식으로 씀.
  • VLA backbone은 얼리고 경량 모듈만 온라인/실시간으로 학습시키는 test-time 보정이 늘어남 — Catch Me If You Can(마지막 denoising step만 재추정), Sandwich-Residuals(predictor 입출력단 residual)가 공통적으로 backbone 재학습 없이 소수 파라미터만 건드림.
  • task 전체가 아니라 실패가 몰리는 소수 subtask·영역에만 개입을 국소화 — PARTS(bottleneck subtask에만 residual RL), FOCAL-VLA(subtask-relevant 영역에만 geometry distillation)가 같은 문제의식(전체 재학습은 비효율)을 공유함.
  • 물리엔진 없이 단일 스캔·이미지에서 조작 시연을 합성하는 data engine이 두 편 등장 — GaussianFactory(비디오 스캔+contact model)는 IL 데이터를, DEXTERA(단일 이미지+VR teleop)는 IL·RL 데이터를 각각 3DGS 기반 real-to-sim 파이프라인으로 확보함.

유망 연구 방향 및 프로젝트 제안

modality 통합 failure attribution — 예측-실측 오차를 모아 실패 원인을 귀속하는 진단 모델 - research question: tactile·F/T·skeleton·geometry 각각의 예측-실측 오차 신호를 하나로 모으면, 어느 modality의 오차가 실제 실패를 유발했는지 구분할 수 있는가. - 접근·novelty: 오늘 나온 다섯 편(PSR, SkelWAM, ME-Dex, ForeTac-VLA, CARF)은 각자 한 modality의 미래 상태를 예측하는 objective만 씀. 이 예측 신호를 실패 판정에 직접 쓰는 논문은 아직 없으므로, 예측-실측 오차를 counterfactual reasoning으로 통합해 "이 오차를 제거했으면 실패가 안 났을까"를 판정하는 attribution head를 새로 설계함. - 왜 지금·경쟁 prior works: 다섯 편이 미래 예측이라는 같은 objective를 독립적으로 냈다는 것 자체가 이 표현이 무르익었다는 신호임. 단순 앙상블로 가면 novelty가 약해지므로 attribution 자체를 formulation으로 잡아야 함. - risk·target venue: 여러 modality를 동시에 갖춘 실로봇 세팅을 새로 구축해야 해서 실험 비용이 큼. CoRL/RSS 타겟.

object-centric 3DGS를 canonical embodiment interface로 쓰는 world-action model - research question: skeleton/point cloud 대신 object-centric 3DGS를 human-to-robot·cross-embodiment의 공유 표현으로 쓰면 occlusion·contact geometry를 더 잘 보존해 전이 성능이 오르는가. - 접근·novelty: SkelWAM·Skel-WAM·GALA는 모두 저차원 keypoint/point cloud로 embodiment를 정렬함. GALA는 recommendation에서 이미 3DGS 확장을 언급함 — object 표면 전체를 canonical latent로 삼는 쪽으로 한 단계 더 감. - 왜 지금·경쟁 prior works: 같은 날 skeleton 계열 3편이 동시에 나온 것은 이 방향이 이미 경쟁이 붙었다는 뜻. 3DGS로 차별화하지 않으면 후발 논문이 됨. - risk·target venue: 3DGS 재구성의 실시간성 확보가 관건. sim 검증만으로는 부족하고 real robot deployment까지 필요함. CoRL.

test-time predictor-freeze + 경량 residual을 world model과 VLA에 동시에 적용하는 통합 test-time optimization 파이프라인 - research question: world model adaptation(Sandwich-Residuals)과 VLA action 보정(Catch Me If You Can)에 쓰인 "backbone 고정 + 경량 모듈만 학습" 패턴을 하나의 파이프라인으로 묶어, world model 오차 신호로 VLA residual을 같이 트리거할 수 있는가. - 접근·novelty: 두 논문은 서로 독립된 모듈(world model residual, action feedback module)을 따로 학습함. 이들을 공유 오차 신호 하나로 연결하면 "언제 재계획할지"와 "어떻게 action을 보정할지"를 한 루프로 처리하는 test-time optimization/inference-time planning formulation이 됨. - 왜 지금·경쟁 prior works: Catch Me If You Can 저자도 predictive world model과의 결합을 future work로 언급함 — 아직 아무도 실제로 붙이지 않음. - risk·target venue: 두 모듈을 동시에 온라인 학습시키면 안정성 확보가 어려움. 우선 sim에서 루프 안정성을 검증한 뒤 real robot으로 확장. CoRL/ICRA.

subtask 단위 실패 진단·개입 국소화를 failure recovery로 확장 - research question: PARTS·FOCAL-VLA가 쓴 "전체 task 대신 bottleneck subtask에만 개입"하는 전략을, 학습이 아니라 실행 중 실패 recovery에 적용하면 재시도 비용을 얼마나 줄일 수 있는가. - 접근·novelty: PARTS는 학습 단계에서 bottleneck을 미리 찾아 RL을 집중시킴. 이를 실행 중 실시간으로 "지금 실패가 어느 subtask에서 났는가"를 판정하는 detector로 뒤집으면, recovery를 처음부터 재시작하지 않고 해당 subtask만 재실행하는 정책이 됨. - 왜 지금·경쟁 prior works: long-horizon manipulation에서 recovery는 대부분 처음부터 재시도하는 방식뿐임. subtask-localized recovery를 다룬 논문은 아직 드묾. - risk·target venue: subtask 경계 정의 자체가 도메인마다 달라 일반화가 어려움. CoRL.
