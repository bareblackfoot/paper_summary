Latent evolving World Action Model

arXiv PDF alphaXiv
World Model VLA Manipulation relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Xueji Fang, Boqiang Duan, Hua Wu, Jingdong Wang, Guo-Jun Qi PDF 전문 1차 65점
VAE와 video diffusion backbone 대신 frozen I-JEPA embedding 위에서 action 생성과 미래 상태 예측을 한 predictor로 같이 학습하는 LeWAM을 제안함. 0.4B 파라미터, embodied pretraining 없이 RoboTwin 2.0 평균 성공률 92.28%로 기존 대형 VLA·WAM과 맞먹거나 앞서고 real robot에서도 검증함.
Core Innovation & Methodology
- VDM 기반 WAM은 observation을 VAE로 압축한 뒤 video diffusion backbone으로 특징을 뽑는데, 이 압축이 action 예측에 필요한 정보를 잃는다는 것을 이론적으로 보임 (action relevance gap, VAE posterior mean의 spectral compression) - 대안으로 frozen I-JEPA embedding을 관측 표현으로 그대로 쓰고, action denoising(flow matching)과 미래 embedding 예측(world modeling)을 구조화된 attention mask로 하나의 predictor에서 같이 학습하는 LeWAM을 제안함. 추론 시에는 future query와 demonstrated action을 빼서 action만 생성하므로 video diffusion backbone이 필요 없음 - AdaFuse: JEPA encoder의 여러 layer 표현을 feature dimension별로 다른 가중치로 합쳐 씀. 단일 layer보다 depth·segmentation probing 성능이 좋아짐 - DemoDPO: online RL이나 사람 피드백 없이, frozen reference policy가 뽑은 후보 action들을 demonstration과의 MSE로 승/패로 나눠 offline DPO로 policy를 재조정함. imitation learning이 demonstration은 맞히지만 좋은 action과 나쁜 action을 구분 못 한다는 문제를 겨냥함
Novelty vs. Prior Works
- 가장 가까운 LaWAM(DINOv3 기반 latent action + 별도 world model + subgoal 조건 action expert)과 VLA-JEPA(V-JEPA2를 world model supervision에만 쓰고 action은 VLM 표현에서 생성)와 달리, LeWAM은 JEPA embedding을 action 생성의 직접 입력이자 미래 예측 타겟 둘 다로 쓰고 단일 predictor로 학습함. 추론 시 future prediction을 완전히 제거해 별도 subgoal decode 단계가 없음 - encoder 비교 자체의 기여도 있음. 기존 연구는 VAE·SigLIP·DINOv3·V-JEPA2 등을 서로 다른 setting에서 봤거나 VLA feature에 추가하는 형태였는데, 이 논문은 동일 action predictor·학습 레시피로 통제 비교함 - DemoDPO는 Diffusion-DPO/Flow-DPO를 offline demonstration 기반 랭킹으로 재구성한 것이라 알고리즘 자체의 이론적 참신성은 제한적임. preference label을 사람·reward 없이 demonstration MSE로 대체한 실용적 조합에 가까움
Benchmark Results
- RoboTwin 2.0 50 task 평균 성공률 92.28%(clean 93.14%, randomized 91.42%), trainable parameter 0.4B로 π0.5(3B), Fast-WAM(6B), LingBot-VA(5B), LaWAM(1.7B) 대비 비슷하거나 근소 우위 - encoder 비교(같은 action predictor 기준)에서 Wan2.2 VAE 10.81%로 최저, I-JEPA-Huge 86.17%로 최고, AdaFuse 추가 시 86.88% - ablation: Action Only 86.17% → future embedding direct prediction 87.02%(flow matching 방식은 86.21%로 더 낮음) → future embedding 예측 위에 AdaFuse 추가 시 90.69% → +DemoDPO(최종 LeWAM) 92.28%로 단계적 개선 - DemoDPO는 8개 도전적 task subset에서 73.31% → 76.63%로 개선했고, 같은 step 수만큼 추가 supervised 학습만 하면 73.25%로 오히려 소폭 하락해 개선이 단순 추가 학습 효과가 아님을 확인함 - real-world 3 task(블록 쌓기, 수건 접기, 꽃 꽂기)에서 task progress 84.9%/60.7%/53.0%로 π0.5·LingBot-VLA-v2·FastWAM보다 높음. 단 task 3개, rollout 50회 규모이고 완결 success rate가 아니라 milestone 기반 progress 지표라 일반화 검증 범위는 제한적임
누리랩 연구와의 연결
- video diffusion backbone 없이 frozen self-supervised encoder 표현 공간에서 action과 future state를 함께 예측하는 구조는, 누리랩 world model·failure detection 연구에서 무거운 video generation 없이 쓰는 저비용 dynamics 예측 module로 재사용 가능함 - DemoDPO처럼 demonstration MSE만으로 candidate action을 랭킹해 offline preference를 만드는 방식은, online RL 없이 test-time에 여러 후보 action을 sampling·재순위화하는 failure recovery/inference-time optimization 아이디어로 확장 가능함 - I-JEPA가 VAE·SigLIP보다 depth·segmentation 정보를 더 잘 노출한다는 probing 결과는, object-centric 3D representation을 쓰는 누리랩 연구에서 policy backbone 선택 근거로 활용 가능함

InternW0: A Foundational Physical World Model for Efficient Real-World Interactions

arXiv PDF alphaXiv
World Model relevance 9/10 Robotics (cs.RO)
Jisong Cai, Yao Mu, Ganlin Yang, Zhe Cao, Zhangzheng Tu, Xing Gao, Kailin Li, Xinyu Zhan 외 18명 PDF 전문 1차 68점
InternW0는 video expert(느림)와 action expert(빠름)를 비대칭 구조로 분리하고, 매 action chunk마다 관측 기반으로 cached video context만 국소 수정해 재사용함. 이 방식으로 world-action model의 추론 속도를 Fast-WAM 대비 3배 이상 높였고, LIBERO·RoboTwin 2.0 시뮬레이션은 물론 MOF(금속-유기 골격체) 합성·정량 pipetting 같은 실제 과학 실험 조작까지 검증해 로봇 조작을 넘어선 적용 범위를 보여줌.
Core Innovation & Methodology
- mixture-of-transformers 기반으로 future video prediction을 맡는 video expert(느림)와 robot control을 맡는 action expert(빠름)를 비대칭으로 분리해 flow matching으로 joint 학습함 - 매 action chunk마다 video plan을 다시 생성하지 않고, layerwise chunk K/V editor가 최신 관측으로 cached video context를 국소적으로만 수정해 재사용함(observation-conditioned context routing) - action expert에 force/tactile 이력을 조건으로 넣고 미래 action과 6차원 wrench(힘 3축+모멘트 3축)를 함께 예측하는 contact-aware post-training으로 접촉이 중요한 조작을 지원함 - embodiment별 soft prompt와 37차원 통합 action/state 인터페이스로 real-robot 4종·simulation 2종·egocentric video 1종, 총 7개 데이터셋·25개 domain을 하나의 backbone으로 학습함
Novelty vs. Prior Works
- video context routing 메커니즘은 논문이 스스로 AHA-WAM 설계를 따른다고 밝히고, embodiment별 soft prompt도 X-VLA 설계를 차용함 → architecture 자체의 신규성은 제한적임 - 신규성은 주로 스케일과 도메인 확장에 있음: 실험실 wet-lab 조작(MOF 합성, 정량 pipetting)까지 다루는 275시간 EgoLab egocentric 데이터셋과 과학 실험 workflow 적용은 기존 WAM 논문들이 다루지 않은 영역임 - video/action expert 분리로 추론 속도를 크게 높인 점은 실용적 기여이나, 개념적으로는 기존 dual-system VLA(π0.5 계열)의 비동기 처리 아이디어를 world-action model 맥락으로 확장한 것에 가까움
Benchmark Results
- LIBERO 전체 40 task 평균 success rate 98.6%로 LingBot-VA(98.5%), Fast-WAM(97.6%) 대비 각각 0.1%p, 1.0%p 앞섬 - RoboTwin 2.0-Full(50 task, in-domain) 평균 93.12%로 최고 성능 ABot-M0.5(94.10%)보다 0.98%p 낮고, Fast-WAM(91.83%) 대비는 1.29%p 높음 - RoboTwin 2.0-Clean2Random(clean 학습→randomized 평가로 out-of-domain generalization 측정) 평균 75.60%로 비교 대상 중 1위, 2위 GigaBrain-0.7(67.3%)을 8.3%p 앞섬 - 추론 속도 16.47Hz(60.73ms)로 Fast-WAM(5.26Hz, 190ms) 대비 3.13배, Motus(0.54Hz, 1866ms) 대비 약 30배 빠름 - 실로봇 실험(Make Sandwich, Pick Industrial Parts, Sort Tubes, MOF 15단계 합성, 정량 pipetting 5단계)에서 π0.5·Fast-WAM 대비 success rate가 대체로 높게 보고되나, 해당 수치는 표지 그래프에서 추출한 값이라 방법-수치 정확한 대응은 본문에서 확인 불가함. ablation 세부 결과와 limitation 논의도 제공된 텍스트가 중간에서 생략되어 확인 불가함
누리랩 연구와의 연결
- force/tactile 조건화와 미래 wrench 예측을 결합한 contact-aware post-training은 접촉 실패를 사전에 예측하는 신호로 failure detection·recovery 연구에 참고할 만함 - video expert는 느리게, action expert는 빠르게 돌리는 비대칭 구조와 chunk K/V editor는 world model rollout 비용을 줄이는 test-time optimization 설계 참고 사례로 쓸 수 있음 - 특정 도메인(실험실) egocentric video로 action-free video 학습을 얹는 EgoLab 방식은 데이터가 부족한 특정 산업 조작 도메인에 적용해볼 만한 데이터 전략임

Memory That Changes Action Is Not Memory That Guides It: Counterfactual Auditing of History-Conditioned Robot Policies

arXiv PDF alphaXiv
Robot Memory Evaluation relevance 10/10 Robotics (cs.RO)
Jiajie Zhang, Yankai Xiang, Changhao Chen PDF 전문 1차 58점
action이 바뀌어도 그것이 올바른 branch 선택이라는 보장은 아님을 보이는 counterfactual 평가 프로토콜 CMA(Counterfactual Memory Audit)를 제안함. Mem-0와 BridgeVLA++를 시뮬레이션과 양팔 로봇 실험에서 감사한 결과, action은 바뀌지만 올바른 목표를 고르지 못하는 사례를 다수 확인함.
Core Innovation & Methodology
- 두 개의 task-consistent 과거가 서로 다른 memory를 만들면서도 동일한 현재 입력으로 수렴하는 상황을 구성해, perceptual aliasing 조건에서 memory가 결정에 실제로 쓰였는지를 감사하는 문제로 formulation함 - frozen policy를 memory state만 바꿔 동일 action seed로 두 번 쿼리하고, 저장된 action을 policy에 노출되지 않는 evaluator-only world 두 개에서 각각 채점하는 교차 설계를 씀 - 평가를 sensitivity(S, action 변화 여부), signed faithfulness(F, warranted branch 선택 여부), matched-world value(U1, 물리적 진행도), reliability(모든 방향·시드에서 일관되게 정답인 pair 비율) 네 단계로 분리함 - native rollout에서 history bank를 교체하거나 4096바이트 anchor만 복원하는 개입을 추가해, 구성된 audit 밖의 closed-loop 영향력도 별도로 검증함
Novelty vs. Prior Works
- 가장 가까운 선행연구 Chameleon은 stored trace를 유지·교체·제거하며 counterfactual choice accuracy까지만 봄. CMA는 완전한 lawful native history를 교체하고 current packet의 정확한 동일성을 검증한 뒤 matched-world physical value와 pair 단위 bidirectional reliability를 추가해, discrete choice가 다른 physical value를 감출 수 있다는 점과 평균 성능이 개별 pair 실패를 감출 수 있다는 점 두 가지 빈틈을 메움 - TFP는 action variation 확인에서 멈추고 TRACE는 routing path consistency만 봄. CMA는 이보다 한 단계 더 나아가 reliability 검증까지 포함함 - 다만 새로운 policy나 memory architecture를 제안하지 않고 기존 두 정책(Mem-0, BridgeVLA++)에 대한 평가 프로토콜만 제공하므로, 알고리즘적 novelty보다는 evaluation methodology 기여로 한정됨
Benchmark Results
- Mem-0 Put Back: 64쌍 모두 action change가 일어나지만 fully reliable pair는 20/64에 불과함. correct-choice rate 0.729, signed faithfulness F=0.529, matched-world value U1=0.185이지만 absolute regret 0.442로 평균적 이득과 신뢰성이 분리됨 - later Swap: 24쌍 모두 action이 바뀌지만 F=0, pcorrect=0.5로 branch 선택은 무작위 수준이고 fully reliable pair는 0/24임 - native event에서 opposite-target history로 교체하면 official success가 BridgeVLA++·Mem-0 모두 0/48로 떨어지지만, 48/48 continuation이 donor target으로 이동해 closed-loop redirection이 확인됨 - 4096바이트 anchor만 복원해도 injected bank fault 이후 success가 6/36에서 20/36으로 회복함(+38.9 point, [27.8, 50.0]). full rebuild(20/36)와 동일한 회복 수준임 - 양팔 로봇(PiPER) 실험: Put Back 32회 실행 중 target correct 6/32, full success 4/32, memory-consistent direction 16/32에 그쳐 시뮬레이션과 같은 분리 현상이 재현됨. 이 수치는 조작자 라벨 기반이고 독립 blind annotation은 아님
누리랩 연구와의 연결
- robot memory·failure detection 연구에 바로 적용 가능한 진단 도구임. memory-augmented VLA나 recovery policy를 낼 때 CMA 방식으로 memory가 실제로 결정을 바꿨는지 사전 검증에 쓸 수 있음 - counterfactual/causal reasoning 축과 직접 연결됨. 두 개의 lawful history를 교차시켜 동일 현재에서 평가하는 설계는 우리 lab의 counterfactual reasoning 문제 정의에 참고할 실험 설계 패턴임 - memory bank 결함 발생 시 protected anchor만 복원해 성능을 회복하는 아이디어는 test-time failure recovery 연구에서 policy가 아니라 memory 저장 구조 설계 원칙으로 가져올 수 있음

Watch, Recall, Act: Always-On Robots in Concurrent Embodied Streams

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Ding Yi, Peiwen Sun, Chenchu Rong, Jianan Wang, Xili Dai, Xiangyu Yue, Xi Lin PDF 전문 1차 62점
항상 켜져 있는 dual-arm 로봇이 먼 미래 신호를 지켜보고(watch) 자기 과거 행동을 기억하고(recall) 실행하는(act) 문제를 하나의 π0.5 backbone에 perception trigger gate, embodied-state head, 압축 self-history memory 세 모듈을 얹어 푼 논문임. 직접 구축한 dual-arm 스트리밍 벤치마크에서 combined-task 성공률(EAS) 45%로 최강 baseline인 SwitchVLA의 28%를 앞섬.
Core Innovation & Methodology
- watch(먼 미래 standing guard 감지)·recall(자기 과거 행동 참조)·act(dual-arm 동시 실행)를 하나의 문제로 묶어 always-on dual-arm streaming을 새로 formulation함. - 새 네트워크나 planner를 만들지 않고 pretrained π0.5 backbone 하나에 경량 module 세 개(perception trigger gate, embodied-state head, 압축 self-action memory)를 붙여 각각을 context token으로 주입하는 구조임. - 핵심은 agent-causal self-history임: 어느 arm이 무엇을, 언제 했는지 기록해 두 팔의 동시 기록이 섞이지 않게 하고 "왼팔이 넣은 것" 같은 self-referential recall을 가능하게 함. - 세 module이 asynchronous하게 context를 갱신해 perception·memory 갱신이 action 실행을 막지 않음(Dispider의 non-blocking skeleton을 계승), 이 설계가 dual-arm concurrency를 가능하게 하는 핵심임.
Novelty vs. Prior Works
- MemoryVLA(perceptual-cognitive memory)·SwitchVLA(mid-task switching)·RoboStream(causal spatio-temporal graph memory)는 각각 always-on·proactive·retrospective·interruptible·concurrent 다섯 축 중 일부만 만족함(Table 1). ARMS는 다섯 축을 모두 만족한다고 주장하나 개별 메커니즘(trigger gate는 Dispider, memory 압축은 MemoryVLA)은 기존 것을 그대로 가져온 것임. - 새로운 학습 알고리즘이나 architecture가 아니라 기존 module들의 통합과 agent-causal 라벨(어느 arm, 언제)이라는 새 supervision 신호가 novelty의 핵심이며, 저자 스스로도 "integration, not a new network or planner"라고 명시함. - 즉 novelty는 problem formulation(다섯 축 동시 충족)과 dataset construction(구축 스크립트가 곧 오라클이 되어 추가 annotation 없이 라벨 생성)에 있고, module 각각의 기술적 기여는 제한적임.

- RoboCasa 성공률은 Policy-Only 43.8% → FLARE 53.2% → AWM-VLA(full) 58.9%로, FLARE 대비 +5.7%p, Policy-Only 대비 +15.1%p 개선됨. - 휴머노이드 tabletop에서도 AWM-VLA 52.6% vs FLARE 47.5%, novel object 48.3% vs FLARE 40.6%, novel instruction 46.1% vs FLARE 37.9%로 5~8%p대 일관된 개선을 보임. - 초록의 '최대 21% 개선' 주장은 Table 1 수치로 정확히 재현되지 않음 — 본문에서 확인되는 가장 큰 격차는 Diffusion Policy 대비 RoboCasa +29.7%p, UWM(pixel world model) 대비 novel instruction +26.9%p임. - ablation에서 object-centric alignment를 제거하면 RoboCasa는 58.9→56.4로, rater 선호도는 83.1%→71.5%로 크게 떨어져 해석가능성 개선이 주로 object 정렬에서 나옴을 보임(rater 평가는 사람 5명, N=5 기준이라 표본이 작음). - MGDA 대신 고정 가중치(λ=0.2)를 쓰면 RoboCasa 58.9→57.2, novel object 48.3→46.8로 하락함.
누리랩 연구와의 연결
- object-centric future prediction을 rationale로 바로 쓰는 방식은 failure detection/recovery 연구에 붙일 수 있음 — 예상한 object 변화가 실제로 일어나지 않는 것을 실패 신호로 쓰는 test-time monitoring으로 확장 가능함. - MGDA 기반 multi-objective balancing은 우리 VLA world model 프로젝트에서 auxiliary loss 가중치를 수동 튜닝하는 대신 쓸 수 있는 일반적 도구로 참고할 만함. - 다만 이 논문은 RoboCasa·휴머노이드 시뮬레이션에 한정되고 real-robot 검증이 본문에서 확인되지 않으므로, 우리 연구에서 실로봇 검증을 먼저 채우면 차별점이 됨.

InfiNoVA: Infinite Novel View Augmentation for Viewpoint Invariant Robot Policies

arXiv PDF alphaXiv
VLA relevance 8/10 Robotics (cs.RO)
Sai Puneeth Reddy Gottam, Elmar Rueckert, Vedant Dave PDF 전문 1차 62점
동기화된 5대 카메라 데모를 timestep마다 3D Gaussian Splatting으로 재구성해 새 카메라 시점 이미지를 렌더링하고 원래 상태-액션 라벨을 그대로 붙여 VLA 학습 데이터를 늘리는 방법임. 4개 실물 매니퓰레이션 task에서 미학습 시점 성공률을 VISTA 대비 5.4배, 5대 카메라 전체 학습 대비 1.7배 높였음.
Core Innovation & Methodology
- InfiNoVA는 5대 동기화 카메라로 찍은 매니퓰레이션 데모를 매 timestep마다 InstantSplat++로 3D Gaussian Splatting 재구성해 time-varying 장면 표현을 만듦. - 재구성한 장면에서 방위각 [-π/2, π/2], 반경 0.6~1.2m, 고도 0~π/2 범위로 가상 카메라를 샘플링해 timestep당 최대 15개 새 시점을 렌더링함. - 렌더링된 관측은 원본 데모와 같은 물리적 상태이므로 언어 지시와 액션 라벨을 그대로 재사용해 relabeling 없이 D_train = D ∪ D_nv를 구성함. - SmolVLA 정책에서 wrist 카메라는 그대로 두고 2개의 third-person 카메라만 합성 시점으로 교체해 학습하며, 데모당 최대 100개 가상 episode를 만들어 task당 7,000 episode로 확장함.
Novelty vs. Prior Works
- 가장 가까운 baseline인 VISTA는 단일 이미지 diffusion 기반 NVS로 시점을 늘리지만 미관측 영역을 데이터셋 수준 prior로 채워 task 간 콘텐츠가 섞이는 hallucination이 생김 (Pick-and-Place에 Stack task 스펀지가 등장하는 사례 등). - InfiNoVA는 다중 시점에서 재구성한 명시적 3D Gaussian 표현에서 렌더링해 이런 task-critical hallucination을 줄이는 것이 핵심 차별점이지만, InstantSplat++ 재구성과 feed-forward Gaussian Splatting 자체는 기존 기법을 그대로 가져온 것이라 표현이나 학습 패러다임 차원의 새로움은 아님. - Yang et al.(RSS 2025)도 Gaussian Splatting으로 시점·외형 증강을 했지만 장면 분해와 정렬이 필요했던 반면, InfiNoVA는 장면 전체를 통째로 재구성해 별도 편집 단계를 없앤 것이 차이점임. 다만 이 역시 응용 단의 개선이지 새로운 problem formulation은 아님.
Benchmark Results
- novel-view 렌더링 품질(4 task 400 샘플)에서 PSNR 16.65, SSIM 0.841, LPIPS 0.388로 Hunyuan3D/DepthSplat/GLD/VISTA 대비 전 지표 최고이며, 상위 3개 baseline 대비 PSNR 4.3~25.5%, SSIM 2.6~11.7% 개선, LPIPS 15.5~25.0% 감소함. - 렌더링 시간은 episode당 평균 437초로 VISTA(1575초) 대비 3.6배, GLD(36204초) 대비 82.8배 빠름. - temporal consistency에서 FeaCD 0.915, ReStraV-Δθ 3.49도로 VISTA 대비 각각 7.0%, 51.3% 개선됨. - 정책 평가(4 task, 100 rollout)에서 미학습 랜덤 시점 평균 성공률이 Baseline(Random) 7.5%, VISTA-Aug 7.5%인 반면 InfiNoVA는 40.5%로 5.4배 높음. 원 시점 고정 학습인 Baseline(Reference) 65.3% 대비로는 손실의 약 57%를 회복함. - ablation(Pick-and-Place, 100 rollout)에서 단일 시점 학습은 랜덤 시점 6%, 5대 카메라 전체 학습은 24%인데 InfiNoVA는 40%로, 물리적 카메라를 늘리는 것보다 밀도 높은 가상 시점 증강이 1.7배 더 효과적임을 보임.
누리랩 연구와의 연결
- object-centric 3DGS로 로봇 데모를 time-varying 장면으로 재구성하는 파이프라인은 실패 진단·recovery 연구에서 재현(replay) 기반 counterfactual 시점 생성에 그대로 응용 가능함. - viewpoint 증강이 VLA의 spurious camera correlation을 줄인다는 결과는 test-time에 여러 가상 시점 관측을 앙상블해 policy 신뢰도를 추정하는 failure detection 아이디어로 연결됨. - InstantSplat++ 기반 pose-free 재구성은 카메라 calibration 없이 동작하므로, tabletop rig에서 demo 수가 부족한 manipulation 프로젝트에 바로 이식 가능함.

오늘의 핵심 연구 트렌드 종합

  • World-action model의 비대칭·경량 실행 — InternW0, LiMA, NowWAM(Beyond Future Prediction) 세 편 모두 느린 미래 예측과 빠른 동작 실행을 분리하거나, 미래 예측 자체가 필요한지 되물음. video diffusion backbone을 걷어내고 real-time 제약 안에서 world model을 돌리는 방향으로 수렴함.
  • video diffusion backbone 없는 world model — LeWAM는 frozen I-JEPA embedding으로, PointCast는 point-set 상태로, Generalizable Robotic Insertion은 TD-MPC2 implicit world model로 각각 무거운 video generation 없이 world model을 구성함.
  • robot memory가 만드는 연구와 감사(audit)하는 연구가 같은 날 등장 — MemBodied는 고정크기 associative memory 구조를, Watch, Recall, Act는 agent-causal self-history를, CMA는 memory가 실제로 결정을 바꿨는지 감사하는 프로토콜을 제안함. memory를 만드는 쪽과 검증하는 쪽이 분리된 채 같이 성숙하고 있음.
  • 개입(intervention)을 constraint·trigger로 재정식화 — BEE는 사람 correction을 차원별 신뢰도 있는 constraint로, TANDEM은 TAMP 실패 구간을 사람이 임시로 채워 넣는 placeholder 동작(magic operator)으로, Talk2Escape는 kinematic 실패 신호를 대화 트리거로 바꿈. "언제 개입할지"와 "개입을 어떻게 반영할지"를 분리해서 다루는 것이 공통 패턴임.
  • 통념을 대규모 통제 실험으로 반증하는 논문 — The Gaussian Is Enough은 flow-matching prior가 LBM 파인튜닝에 효과 없음을, NowWAM(Beyond Future Prediction)은 미래 예측이 world-action model 성능의 핵심 요인이 아님을 통계적으로 보임. 둘 다 새 방법이 아니라 가정 자체를 겨냥함.
  • 3D reconstruction을 데이터 증강으로 쓰는 흐름 지속 — InfiNoVA는 timestep마다 3DGS로 재구성해 새 시점을 렌더링하고, relabeling 없이 학습 데이터를 늘림.

유망 연구 방향 및 프로젝트 제안

Memory read 신뢰도를 test-time에 실시간 추정하는 monitor - research question: history-conditioned policy가 배포 중 memory를 실제로 의사결정에 썼는지, 그 판단이 맞는 branch를 골랐는지를 rollout 중간에 감지할 수 있는가. - 접근·novelty: CMA가 제안한 offline counterfactual audit(두 개의 lawful 과거를 교차시켜 사후 채점)을 배포 중 매 스텝 계산 가능한 lightweight proxy로 압축함. 두 과거를 실제로 재현하지 않고 memory read의 attention 분포나 associative state 변화량만으로 신뢰도를 근사하는 방식을 목표로 함. - 왜 지금·경쟁 prior work: CMA는 offline 사후분석만 제안하고, MemBodied는 memory 구조 개선에만 집중함. memory reliability를 실시간 실패 신호로 쓰는 연구는 없음. - risk·target venue: proxy 지표와 실제 action 실패 간 상관이 task마다 다를 위험이 큼. 실로봇 검증 없이는 신뢰도 논문으로만 읽힐 수 있어 real-robot failure case를 먼저 확보해야 함. CoRL/RSS.

Encoder representation divergence를 실패 조기 경보로 쓰는 diagnosis - research question: fine-tuning 성능을 prior보다 encoder 학습이 지배한다는 결과를 거꾸로 이용해, 배포 중 encoder embedding이 학습 분포에서 벗어나는 정도로 정책 실패를 미리 예측할 수 있는가. - 접근·novelty: The Gaussian Is Enough이 학습 단계 진단용으로만 쓴 LogME(사전학습 특징의 전이 적합도를 라벨 없이 추정하는 지표) 기반 training-free introspection을 test-time monitoring으로 옮김. action head가 아니라 encoder representation을 실패 원인으로 분리해서 보는 관점이 기존 failure detection 연구와 다름. - 왜 지금·경쟁 prior work: 해당 논문은 이 결과를 파인튜닝 품질 진단에만 씀. 배포 단계 실패 예측으로 확장한 사례는 확인되지 않음. - risk·target venue: embedding divergence가 distribution shift와 실제 task 실패를 항상 같이 예측하지 못할 위험이 있음. 여러 실패 유형(occlusion, 목표 오인식 등)별로 구분되는지 먼저 확인해야 함. CoRL.

Sampling-based MPC 기반 world model에 active perception 결합 - research question: Generalizable Robotic Insertion이 남긴 한계인 큰 socket에서의 시각적 occlusion 문제를, 카메라 시점을 능동적으로 바꿔 기하학적 불확실성을 줄이는 방식으로 풀 수 있는가. - 접근·novelty: implicit world model(TD-MPC2)의 latent uncertainty를 NBV(next-best-view) 목적함수로 바로 쓰는 방식. object CAD 없이 raw visual 정보만으로 동작한다는 원 논문의 장점을 유지한 채 active perception을 얹음. - 왜 지금·경쟁 prior work: 논문이 스스로 Fabrica류 촬영 위치 조정을 참고문헌으로만 언급하고 직접 다루지 않음. world model uncertainty와 NBV를 명시적으로 연결한 삽입 조작 연구는 확인되지 않음. - risk·target venue: 추가 시점 이동이 조작 속도를 늦출 위험, 실시간성과의 trade-off를 실험으로 보여야 함. ICRA/IROS.

Object-centric future prediction을 failure trigger로 쓰는 통합 프레임워크 - research question: AWM-VLA의 object 단위 미래 예측과 Talk2Escape의 kinematic trigger를 결합해, "예상한 object 변화가 실제로 일어나지 않음"을 manipulation의 실패 신호로 formalize할 수 있는가. - 접근·novelty: 두 논문 모두 서로 다른 도메인(manipulation vs. navigation)에서 독립적으로 trigger 설계를 했음. object-centric 예측 오차를 trigger 조건으로 통일하면 도메인 무관한 failure detection 신호를 만들 수 있음. - 왜 지금·경쟁 prior work: AWM-VLA는 rationale 생성에, Talk2Escape는 kinematic 신호에만 머무름. object 예측 오차 자체를 trigger로 쓰는 논문은 확인되지 않음. - risk·target venue: object segmentation·tracking 오차가 trigger의 false positive를 늘릴 위험. real-robot 검증이 두 원 논문 모두 제한적이라 이 부분을 채우는 것이 차별점임. CoRL.

오늘 반드시 읽어야 할 논문

  • Latent evolving World Action Model — video diffusion backbone 없이 frozen I-JEPA 위에서 action과 미래를 함께 학습해 대형 VLA와 맞먹는 성공률을 냄.
  • InternW0 — video/action expert 비대칭 분리로 world-action model 추론 속도를 3배 이상 높이고 로봇 조작을 넘어 과학 실험까지 검증함.
  • Memory That Changes Action Is Not Memory That Guides It (CMA) — memory가 action을 바꿔도 옳은 선택인지는 별개라는 것을 보이는 counterfactual 감사 프로토콜임.
  • Watch, Recall, Act — always-on dual-arm 로봇에 self-history memory를 붙여 watch·recall·act를 하나의 문제로 formulation함.
  • LiMA — 느린 world model과 빠른 diffusion 보정기를 Schrödinger bridge로 연결해 지연을 줄이면서 dexterous manipulation 성공률을 높임.
  • BEE — 사람의 correction을 imitation target이 아니라 차원별 신뢰도 있는 constraint로 재정식화한 online RL임.
  • The Gaussian Is Enough — flow-matching prior가 LBM 파인튜닝에 통계적으로 무의미하고 encoder 학습이 지배 요인임을 대규모로 실증함.
  • Generalizable Robotic Insertion with World Models — model-based RL 하나로 최대 90개 조립 과제를 학습해 미지 물체에 zero-shot 일반화됨을 보임.
