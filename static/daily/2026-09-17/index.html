GroundingVLN: Reasoning and Acting with Grounding for Vision-Language Navigation

arXiv PDF alphaXiv
Navigation relevance 9/10 Robotics (cs.RO)
Kailing Li, Yu Han, Tianwen Qian, Yuqian Fu, Jingyu Gong, Jiangming Shi, Xiaoling Wang PDF 전문 1차 66점
VLM 기반 VLN에서 reasoning이 시각 근거에 anchoring되지 않고 고수준 결정이 정밀한 spatial goal로 이어지지 않는 두 gap을, visual grounding을 reasoning과 action 사이 공유 인터페이스로 써서 메우는 GroundingVLN을 제안함. R2R-CE SR 69.9%, RxR-CE SR 75.1%로 SOTA를 달성했고, 학습 데이터는 최강 baseline 대비 0.9% 수준만 사용함.
Core Innovation & Methodology
- reasoning과 action 사이 두 개의 결합된 gap(추론이 시각 근거에 안 묶임, 고수준 결정에 정밀한 spatial goal이 없음)을 지적하고 visual grounding을 두 층 사이 공유 인터페이스로 사용함 - structured CoT를 history recall, current perception, progress estimation, future planning 4단계로 나누고, 각 단계에서 / 태그로 근거를 이미지 좌표에 바인딩함. 이전에 등장한 entity는 3D world marker와 SAM3 재투영으로 시점이 바뀌어도 identity를 유지함 - 고수준 VLM이 MOVE/TURN/STOP을 예측하고, MOVE는 현재 subtask에 정렬된 progress-aligned pixel goal을 함께 예측함. 이 goal은 RTAB-Map 기반 online map에 back-project되어 A* planner가 primitive action으로 변환함 - 학습은 2단계: GroundingCOTVLN-188K(21K trajectory, 188K sample)로 SFT 후, GEAR(Grounded and Execution-aware RL)로 GRPO 강화학습. GEAR는 route consistency·semantic progress·물리적 실행가능성(장애물 회피)을 반영한 2D reward map을 사용함
Novelty vs. Prior Works
- 기존 텍스트/latent CoT 기반 VLN(AwareVLN, FantasyVLN)은 추론이 시각 근거에 검증 가능하게 묶이지 않았고, DualVLN은 pixel goal을 쓰지만 latent VLM feature로 diffusion executor를 조건화함. GroundingVLN은 추론 단계마다 좌표를 명시 삽입하고 pixel goal을 subtask 경계에 정렬시킨다는 점에서 두 축 모두 다름 - reasoning-with-grounding 자체는 ViGoRL, Thinking with Visual Grounding 등 최근 멀티모달 reasoning 흐름의 연장선이며, 이 논문의 기여는 이를 시점이 계속 바뀌는 navigation 상황에 맞춰 temporal identity alignment로 확장한 것에 가까움. 완전히 새로운 패러다임이라기보다 기존 아이디어의 결합·확장임 - 데이터 효율성(188K vs ABot-N0의 21.9M, 0.9%)과 cross-dataset transfer(R2R→RxR SR 59.9%, 최강 baseline 대비 +20.1%p)가 가장 강한 실증 증거이며, grounding 인터페이스가 표면적 패턴이 아니라 전이 가능한 표현을 학습했음을 시사함
Benchmark Results
- R2R-CE val-unseen SR 69.9%, RxR-CE val-unseen SR 75.1%로 ABot-N0·AwareVLN·DualVLN·NavFoM 등 전체 baseline 대비 최고이며, ABot-N0(21.9M 샘플) 대비 SR +3.5%p(R2R)/+5.8%p(RxR)를 학습 데이터 0.9%만으로 달성함 - R2R만 학습 후 RxR-CE로 zero-shot transfer 시 SR 59.9%/SPL 48.2%로 최강 baseline AwareVLN(SR 39.8%) 대비 +20.1%p/+12.2%p - ablation(Table 3): GEAR 제거 시 SR 69.9→57.2%(-12.7%p, 최대 하락), / 제거 시 66.1%(-3.8%p), temporal alignment 제거 시 62.2%, 2D pixel-distance reward로 대체 시 66.2% - execution-aware reward map이 단순 좌표 거리 reward보다 중요함을 시사 - 수작업 100 episode grounding 분석: SFT 대비 SFT+GEAR가 F1 70.9→83.1%로 상승했고, grounding이 맞을 때 action accuracy 96.4% vs 틀릴 때 48.1%로 grounding 정확도와 navigation 성공이 강하게 연관됨 - 평가는 전부 Habitat 시뮬레이션(Matterport3D 기반 R2R-CE/RxR-CE)이며 실로봇 실험 없음. low-level planner가 RGB-D 깊이와 온라인 SLAM에 의존해 depth 센서 없는 플랫폼 배포는 제한됨(저자가 limitation으로 명시)
누리랩 연구와의 연결
- pixel goal로 reasoning과 action을 잇는 구조는 manipulation VLA에도 적용 가능함. action을 직접 예측하는 대신 '어디를 봐야 하는가'를 좌표로 지정하고 별도 planner/controller가 실행하게 하면 failure recovery 시 재계획 지점을 명시적으로 만들 수 있음 - 기반 temporal identity 유지(3D marker+SAM3 재투영)는 robot memory와 object-centric 3DGS 연구에서 시점이 바뀌어도 같은 물체를 다시 지시하는 문제와 직접 연결되며, manipulation의 long-horizon task용 memory 모듈 설계에 참고할 만함 - GEAR의 execution-aware reward map(장애물·실행가능성 반영)은 test-time/inference-time planning 연구에서 단순 목표 거리 대신 '실행 가능성'을 reward에 넣는 방식으로 일반화할 수 있고, counterfactual reasoning(다른 pixel goal이었다면 실행 가능했을지)과 연결 지어볼 만함

LEAP: Learning Emergent Active Perception for Quadruped Navigation

arXiv PDF alphaXiv
Active Perception Navigation (RL) relevance 8/10 Robotics (cs.RO)
Ü. Bora Gökbakan, Stéphane Caron, Philippe Souères PDF 전문 1차 62점
LEAP는 능동적 시선 제어에 별도 보상(coverage, curiosity 등)을 전혀 넣지 않고, 시선과 무관하게 인코딩되는 egocentric belief map 표현과 지형 커리큘럼만으로 quadruped 내비게이션 정책이 시선 제어를 스스로 학습하도록 함. held-out 지형에서 92.7% 성공률로 스크립트 방식(sweep) 74.2%, 수동 지각(passive) 34.5%를 크게 앞섰고 ground-truth oracle(97.3%)과는 4.6점 차이로 근접함.
Core Innovation & Methodology
- 목표 위치를 시각적으로 발견해야 하는 hazardous-terrain goal-oriented navigation을 POMDP로 정식화하고, 보상함수에 시선 관련 항을 전혀 넣지 않음 — reward는 cost-to-go 기반 progress shaping과 성공/추락/시간 페널티로만 구성됨 - 하나의 Transformer 정책이 body twist와 pan-tilt 카메라 명령을 동시에 출력하며, sparse attention mask로 actor(비특권 정보)와 critic(특권 지형 정보)을 한 네트워크 안에서 비대칭적으로 분리함 - depth 이미지를 시선과 무관하게 인코딩되는 egocentric belief map(fine/coarse 두 스케일, 높이 평균·분산·ray-hit count·goal-hit count·visitation trail 5채널)으로 통합해, 새로운 시선이 만드는 분포 밖 관측 문제를 원천적으로 없앰 - spawn-distance curriculum으로 목표까지 거리를 난이도로 삼아 점진적으로 어려운 지형을 학습시켜, 정면 시선만으로는 위험을 파악할 수 없는 상황에서 과제 압력만으로 시선 제어가 창발하도록 유도함
Novelty vs. Prior Works
- 기존 능동 지각 연구(curiosity bonus, coverage objective, reconstruction loss 기반)는 지각 자체에 별도 proxy 목적함수를 부여하는데, LEAP는 시선에 대한 보상 항을 아예 제거하고 task reward만으로 시선이 창발함을 보여 문제 설정 자체가 다름 - 가장 가까운 선행연구인 Eye, Robot(BC-RL 기반 manipulation 카메라 제어)과 비교해, LEAP는 조작이 아닌 내비게이션 과제이고 지각(RL)과 조작(모방학습)을 분리하지 않고 하나의 정책이 body와 camera를 동시에 명령한다는 점에서 구조가 다름 - gaze-invariant belief map은 로봇 elevation mapping의 확장이라 표현 자체는 새롭지 않지만, 이를 능동 시선 정책의 학습 안정화 장치로 쓴 것이 핵심 기여이며, 검증은 시뮬레이션 procedural terrain 5종 안에서만 이뤄짐
Benchmark Results
- held-out 지형(procedural terrain 5종, unseen layout 100개×4 episode×5 seed)에서 Active(LEAP) 평균 92.7%, Sweep(스크립트 sinusoidal 스캔) 74.2%, Passive(고정 시선) 34.5%, GT oracle 97.3% - 지형별 Passive는 pillars에서 Active와 거의 동률(97.7% 대 98.8%)이지만 crests(2.5%)·islands(5.8%)에서는 붕괴함 — 정면 시선으로는 아래쪽 위험을 볼 수 없기 때문 - MuJoCo 기반 Go2 quadruped full-body sim2sim 전이에서도 성능 순서(GT>Active>Sweep>Passive, 평균 94%>92%>79%>38%)가 유지됨. 다만 절대 수치는 planar 시뮬레이션과 embodiment·평가 규모가 달라 직접 비교는 어려움 - time cost·success bonus 항이 학습된 정책에 유의미한 영향을 주지 않았다고 각주로 보고하나 구체 수치는 본문에서 확인 불가함 - 검증은 전량 시뮬레이션(procedural heightmap, MuJoCo)에서만 이뤄졌고 실로봇 검증은 없음. depth 렌더러가 2.5D heightmap 기반이라 overhang을 표현하지 못하는 한계가 있음(저자 명시)
누리랩 연구와의 연결
- 시선 관련 보상 없이 task reward만으로 능동 지각이 창발한다는 결과는 우리 랩의 active perception/NBV(next-best-view) 연구에서 재관측 시점을 별도 보상 없이 policy가 스스로 결정하게 만드는 설계에 참고할 만함 - gaze-invariant belief map(시선과 무관하게 동일하게 인코딩되는 표현) 아이디어는 manipulation에서 viewpoint를 바꿔가며 촬영하는 active perception 정책의 관측 분포 이탈 문제를 줄이는 표현 설계로 이식 가능함 - 정보가 이미 충분하면 시선 제어를 게을리한다는 GT oracle의 관찰(vestigial gaze)은 world model 기반 test-time exploration에서 불확실성이 낮을 때 탐색을 줄이는 판단 로직 설계의 근거로 쓸 수 있음

PointZero: 3D Point Track Completion for Learning Transferable 3D Dynamics

arXiv PDF alphaXiv
World Model relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Bardienus P. Duisterhof, Kaifeng Zhang, Adam Hung, Bowen Wen, Stan Birchfield, Yunzhu Li, Deva Ramanan, Jeffrey Ichnowski PDF 전문 1차 62점
단일 RGB-D 이미지와 소수의 부분 3D point track만 주어졌을 때 관측된 모든 점의 미래 3D track을 완성하는 3D point track completion을 로봇 action label 없는 pretraining objective로 제안함. 이 objective로 사전학습한 PointZero는 action-conditioned dynamics 예측과 imitation learning으로 fine-tuning했을 때 PGND, 3PoinTr 등 기존 방법 대비 우수하거나 동등한 성능을 냄.
Core Innovation & Methodology
- 3D point track completion을 robot-free pretraining objective로 정식화함. RGB-D 관측과 1~3개의 sparse partial 3D trajectory를 조건으로 관측된 모든 점의 미래 track(T=10 프레임)을 예측하게 학습해, action label 없는 웹 비디오 데이터도 학습 pool에 넣을 수 있게 함 - 아키텍처는 Perceiver-IO로 DINOv2 시각 feature를 압축하고, point/action/visual 토큰을 key-value로 삼는 diffusion transformer(DiT) 하나로 처리함. flow matching과 JiT(원본 pixel space에서 직접 노이즈를 제거하는 방식) 스타일 x-prediction 두 objective를 비교함 - deformable, articulated, rigid object를 아우르는 2.9M frame 규모 synthetic dataset을 새로 구축해 학습에 사용하고 공개함 - post-training으로 (1) partial point track 조건을 robot end-effector pose 조건으로 바꿔 scene-specific action-conditioned dynamics를 예측하고, (2) action head를 붙여 imitation learning에 적용하는 두 다운스트림 레시피를 제시함
Novelty vs. Prior Works
- 가장 가까운 선행연구는 PGND, GBND, ParticleFormer 같은 scene-specific dynamics model과 task-specific point track prediction을 pretraining으로 쓰는 3PoinTr, 그리고 concurrent work인 PointWorld임. PointWorld는 scalable 3D dynamics를 다루지만 calibrated real robot interaction data가 필요한 반면, PointZero는 point track만으로 조건화해 robot annotation을 요구하지 않는다는 점이 본질적 차이임 - 방법론 자체는 새로운 learning paradigm이라기보다 기존 요소(Perceiver-IO, DiT, flow matching)의 조합이고, novelty는 주로 3D point track completion을 pretext task로 쓴다는 problem formulation에 있음 - 3PoinTr은 task-specific point track prediction을 쓰는 반면 PointZero는 임의의 sparse partial track 조건에서 dense track을 완성하는 범용 objective로 확장했다는 점이 차이나, 본문에서 두 아키텍처의 직접 비교는 imitation learning 실험에 한정됨
Benchmark Results
- 자체 synthetic held-out set(약 3.2만 scene)에서 PointZero 모든 변형이 GBND, ParticleFormer, PGND, PTv3 대비 deformable/articulated/rigid 전 카테고리 전 지표에서 우세함. rigid object MDE가 PointZero-FM-oracle 19.91cm 대 PGND 67.58cm로 차이가 큼 - PGND benchmark(6개 scene, 로봇 end-effector 조건)에서 사전학습 후 fine-tuning한 PointZero-FT가 6개 중 4개 scene에서 PGND를 능가함. 무작위 초기화한 PointZero-Scratch는 대부분 PGND보다 열세여서 사전학습이 성능의 핵심임을 보여줌 - imitation learning 실험(task당 20개 라벨 demo와 100개 actionless video)에서 시뮬레이션 3개, 실로봇 4개 총 7개 task 중 6개에서 3PoinTr, DP3, Diffusion Policy, ATM 대비 최고 또는 공동 최고 성공률을 냄. 실로봇 Paper task만 70.0%로 3PoinTr(90.0%)에 못 미침 - ablation에서 downstream track supervision을 쓸 때 pretraining은 평균 성공률을 80.5%에서 88.2%로 올림. 안 쓸 때는 74.1%에서 80.0%로 올려, pretraining objective 자체의 기여를 분리해 확인함 - 실로봇 zero-shot 일반화(학습에 없던 real-world object 14종, 124회 상호작용)에서 12개 지표 중 11개에서 baseline을 능가하나 rigid object MSE는 PTv3가 더 나음
누리랩 연구와의 연결
- robot-free 3D dynamics prior라는 개념은 world model 사전학습에서 action label 병목을 없애는 방향이라, test-time optimization 연구에서 무거운 사전학습 prior로 붙여 쓸 수 있음 - PointZero가 예측한 미래 3D track과 실제 실행 후 관측된 track의 divergence를 failure detection 신호로 쓸 수 있음. predicted track이 크게 빗나가는 시점을 실패 조짐으로 해석하는 방향임 - point track completion을 object-centric 3DGS의 dynamic Gaussian 궤적 예측과 결합하면 appearance까지 포함한 fine-grained 3D dynamics 표현으로 확장할 수 있음. 단 이 논문은 point 위치만 다루고 appearance나 topology 변화는 다루지 않음

Causal-History Test-Time Scaling for Failure Recovery in Autoregressive World-Action Models

arXiv PDF alphaXiv
World Model relevance 9/10 Robotics (cs.RO)
Lin Li, Long Chen, Kwunhang, Wong, Jiaming Lei, Song Jin, Shucheng Du, Chuhan Zhang 외 5명 PDF 전문 1차 68점
자기회귀 world-action model에서 실행 실패가 causal KV cache에 남아 이후 예측을 계속 오염시키는 문제를, 학습 없이 언제·어디서·어떤 history로 되돌릴지 결정하는 test-time scaling 프레임워크(FARE)로 해결함. LingBot-VA 위에 적용해 RoboTwin2.0과 실로봇 SO-101 양쪽에서 성공률을 일관되게 끌어올림.
Core Innovation & Methodology

- Physics-IQ Verified(66개 물리 실험, 396개 비디오)에서 45.5%로 비교 대상 17개 모델 중 1위, Cosmos3-Super-Image2Video(42.7%) 대비 2.8퍼센트포인트 우위 - 저자가 직접 재현한 비교 대상은 LingBot-Video뿐이고 나머지 16개 모델 점수는 2026년 9월 16일 벤치마크 스냅샷 공개 값을 그대로 인용함 — 동일 조건 재현 비교가 아니라 공개 리더보드 비교임 - caption ablation으로 백본 간 물리 중심 캡션의 효과를 보였다고 서술하나, 구체 수치는 제공된 텍스트가 실험 결과 중반에서 잘려 확인 불가함 - IA2V의 정량적 rollout 성능, 4-step distillation 이후 화질·일관성 저하 정도, 실로봇 검증 여부는 제공된 텍스트에서 확인 불가함(본문 중간 분량 생략) - 학습은 물리 특화 1만 시간과 일반 도메인 1만 시간 코퍼스를 70/30→40/60→20/80 비율로 단계적으로 조정하는 커리큘럼을 썼다는 것이 저자 주장이며, 이 커리큘럼 자체의 효과를 분리한 ablation 수치는 확인 가능한 본문 범위에 없음

FIERCE: From Generalist Robot Policies to Fast Specialists via Progress-Failure Feedback

arXiv PDF alphaXiv
RL relevance 9/10 Robotics (cs.RO)
Runjia Tan, Yuang Tu, Yujie Yan, Lan Yu, Xuesong Tian, Chen Lv PDF 전문 1차 62점
generalist robot policy로 초기화한 컴팩트 specialist를 소량의 실제 상호작용만으로 강화학습 정제하는 FIERCE를 제안함. progress(진행도)와 failure(실패 위험)를 동시에 예측하는 evaluator로 shaping reward와 risk penalty를 만들고, 이를 이용한 강화학습이 실로봇 두 개 contact-rich task에서 sparse reward나 failure penalty 제거 조건보다 높은 성공률을 냄.
Core Innovation & Methodology
- generalist policy(VLA 등)로 초기화한 compact specialist를 real-world interaction만으로 강화학습 정제하는 프레임워크를 제안함. 정제 과정에서 generalist에 추가 action query를 하지 않고 target task 전용 시뮬레이터나 수작업 dense reward도 요구하지 않음 - observation-language representation(Cosmos 3 Edge 인코더)을 공유하는 progress head와 action-conditioned latent predictor를 두고, latent predictor의 과거·현재 예측을 causal sequence head에 넣어 failure 위험을 추정하는 통합 evaluator를 설계함 - evaluator는 progress/preference label, action-synchronized 데이터, terminal outcome으로 범용 학습한 뒤 target task rollout으로 LoRA(low-rank adaptation) 기반 adaptation과 calibration을 거침. 고정된 evaluator snapshot이 progress shaping과 failure-risk penalty를 제공하고 evaluator와 policy는 번갈아 갱신됨 - reward는 discounted potential-difference 형태의 progress shaping 항, failure-risk penalty 항, 독립 검증된 terminal outcome 항을 결합하고, SAC(soft actor-critic) 기반 RLPD(reinforcement learning with prior data)로 policy를 학습함
Novelty vs. Prior Works
- 가장 가까운 선행연구는 progress/preference feedback을 다루는 Robometer와 action-conditioned latent로 실패를 탐지하는 Foresight임. FIERCE는 이 둘을 하나의 evaluator 아키텍처로 결합한 것이 핵심이나, 각 head의 학습 방식은 두 선행연구의 supervision 원리를 그대로 재사용함 - 아키텍처가 Cosmos 3 Edge 인코더, Robometer의 progress/preference supervision, Foresight 스타일 failure head, RLPD-SAC를 조합한 구성이라 새로운 representation이나 paradigm이라기보다 기존 모듈의 통합에 가까움. 저자도 parameter sharing의 효과를 독립 학습된 두 모델과 분리하지 않았다고 명시함 - failure risk를 shaping reward의 penalty 항으로 쓰는 설정 자체는 FARL(world model과 risk penalty를 결합한 선행 risk-aware RL 방법) 등과 유사하고, 차별점은 failure penalty가 실제로 학습에 도움이 되는지를 같은 아키텍처 안에서 ablation(β=0)으로 분리 검증했다는 점임. novelty가 제한적임을 저자 스스로 여러 차례 명시함
Benchmark Results
- VLABench 3개 held-out task split의 failure discrimination에서 FIERCE의 rollout AUROC(실패 판별력 지표) 0.822로 Foresight-Transformer(0.807), FAIL-Detect(0.577) 대비 우세하나 balanced accuracy는 0.648 대 Foresight 0.637로 격차가 작음 - 실로봇 peg-in-hole/cup stack 2개 task, seed 1개(seed=7) 조건에서 FIERCE(full)가 평균 92% 성공, Robometer 기반 RL 83%, failure penalty 제거(β=0) 85%로 FIERCE가 가장 높음. 다만 single-seed 결과이며 통계적 유의성은 확인되지 않았다고 저자가 직접 명시함 - component ablation에서 failure penalty 제거 시 N80(80% 성공 도달까지 필요한 rollout 수)이 peg-in-hole 185에서 270으로, cup stack 147에서 206으로 늘어 학습 효율이 떨어짐 - 배포 시 지연시간은 FIERCE 21.923ms로 BC-only 21.743ms와 거의 같음. evaluator와 generalist를 제거한 compact specialist만 남기므로 추론 비용 증가가 없다는 뜻이지, failure feedback이 추론을 빠르게 한다는 근거는 아님 - 모든 결과가 seed 1개짜리 single-run이고, sim(LIBERO·ManiSkill3) 및 실로봇 실험의 시행 횟수·집계 방식이 불충분하게 문서화되어 있어 통계적 결론을 내리기 어렵다고 논문이 스스로 여러 번 지적함
누리랩 연구와의 연결
- failure detection·diagnosis 연구와 직결됨. observed-progress head와 action-conditioned failure head를 분리해 학습하는 구조는 무엇이 실패인지와 왜 실패할 것 같은지를 나누는 설계 참고가 될 수 있음 - generalist to specialist 정제 파이프라인은 test-time optimization 연구와 연결됨. deployment에서 generalist와 evaluator를 모두 제거하고 compact policy만 남기는 방식은, test-time에 무거운 world model을 계속 돌리는 접근과 대비되는 선택지로 참고할 만함 - potential-based progress term과 failure risk term을 분리해 결합한 reward 설계(식 6)는 counterfactual reasoning 연구에서 진행은 됐지만 실패 위험이 높아진 행동을 구분하는 penalty 설계에 응용할 수 있음. 단 이 설계는 policy invariance를 깨뜨려 이론적 보장이 없다는 점을 논문도 명시함

오늘의 핵심 연구 트렌드 종합

  • world-action model의 실패·분포 변화 대응 — CSWAM와 Causal-History Test-Time Scaling(FARE) 둘 다 FastWAM·LingBot-VA(observation·action을 하나의 시퀀스로 자기회귀 예측하는 world-action model 계열) 위에서, 재학습 없이 test-time에 OOD 관측이나 실행 실패를 처리하는 방향으로 감. 학습 목표를 바꾸기보다 inference 절차를 바꾸는 쪽이 늘어남.
  • action을 관절·latent 공간이 아니라 명시적 geometry로 표현 — Acting in Meters, GraphPoint, PointZero가 각각 metric pose token, entity graph 기반 point trajectory, 3D point track completion으로 action을 명시적 3D 표현에 묶음. VLA의 암묵적 action 표현 한계를 geometry로 보완하려는 흐름이 뚜렷함.
  • discrete action tokenizer 재설계 — ActionPiece와 M2Tok 모두 FAST·VQ-VLA 계열 tokenizer의 재구성 오차 문제를 지적하고 각각 rank consistency 보존, multi-head multi-codebook으로 대응함. VLA 성능 개선의 병목이 policy architecture보다 action representation 쪽으로 옮겨가는 신호로 보임.
  • failure·progress 신호를 정교하게 나눠 쓰려는 시도 — RAFAIL은 relationship 단위로 OOD를 나눠 실패 탐지 정확도를 높이고, FIERCE는 progress·failure를 동시에 예측해 RL reward shaping의 학습 신호로 씀. 같은 실패 신호를 탐지 정밀화(RAFAIL)와 학습 신호화(FIERCE)라는 다른 목적으로 쓰는 두 갈래가 보임.
  • 비디오·오디오 생성 모델을 물리 정보원으로 재해석 — Dreaming the Sound of Contact는 생성 오디오의 접촉음 크기를 force profile로 변환하고, StrucPhysVideo는 구조화 캡션과 MoE 비디오 생성으로 물리 동역학을 학습함. 생성 모델의 출력을 그대로 쓰지 않고 물리량으로 변환하는 접근이 늘어남.
  • active perception이 explicit 신호 대 emergent 학습으로 갈림 — ActiveScale은 camera pose를 explicit token으로 넣고 대규모 human data로 mid-training하는 반면, LEAP는 별도 보상 없이 belief map 표현과 지형 커리큘럼만으로 시선 제어를 emergent하게 학습시킴. 같은 문제에 상반된 설계 철학이 공존함.

유망 연구 방향 및 프로젝트 제안

ICRA·CoRL, 실로봇 contact-rich task로 검증
