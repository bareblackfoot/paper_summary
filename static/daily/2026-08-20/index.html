GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment Interaction

arXiv PDF alphaXiv
World Model relevance 10/10 Robotics (cs.RO)
Ziyang Cheng, Tianshu Tang, Jinxin Lan, Xinze Chen, Yuhan Gong, Zhichao Liu, Changzhong Wu, Yahao Mao 외 12명 PDF 전문 1차 88점
휴머노이드 whole-body tracker를 action만 내는 반응형 policy가 아니라, 자신의 next state와 next command 분포까지 함께 예측하는 Behavior World Model로 학습시키고, retargeted motion에서 3D terrain을 자동 복원해 환경 상호작용 데이터를 대규모로 만든다. 그 결과 terrain interaction SR 81.3%(최강 baseline의 4.3배), fall recovery 99.3%를 달성했고, 예측된 분포로 implausible command를 온라인에서 감지해 best-effort 동작으로 바꿀 수 있다.
Core Innovation & Methodology
- causal Transformer가 매 control step에서 action, next proprioceptive state, next latent command의 GMM 분포를 동시에 예측하는 Behavior World Model(BWM)을 제안한다. state 예측은 현재 작용 중인 contact dynamics를, command 분포 예측은 환경이 허용하는 behavior 집합을 policy 내부에 내재화시킨다. - retargeted motion의 kinematics만으로 접촉을 검출해 의자·계단·박스 같은 3D terrain primitive를 복원하는 자동 annotation pipeline을 만들었다. 2.5D elevation map(SceneBot)과 달리 진짜 spatial geometry를 생성해, 2000시간 이상의 기존 motion corpus 규모로 terrain-paired 데이터를 구축한다. - 한 step 전에 예측된 GMM에 Mahalanobis-radius gate를 적용해 OOD command를 감지하고, closed-form radial retraction으로 가장 가까운 학습된 behavior로 사영한다. 별도 classifier 없이 O(1)·1ms 미만이며, 안전 반경 R_safe 하나만 runtime에 조절하면 된다. - fallen initialization을 curriculum으로 tracker 학습에 직접 포함시켜, 별도 recovery controller 없이 넘어짐→기립→tracking 복귀를 하나의 policy가 처리한다.
Novelty vs. Prior Works
- 가장 가까운 SceneBot 대비 세 가지가 본질적으로 다르다: 2.5D height field가 아닌 full 3D geometry 복원, per-link contact label 대신 operator가 온라인으로 만들 수 있는 reference window command, 그리고 contact prompt 조건화가 아닌 world model로서의 학습이다. - OOD filtering은 CMP의 single-step reduction 아이디어를 따르되, 보조 module을 따로 학습하는 대신 world model이 이미 예측하는 mixture를 무료로 재사용한다는 점이 차별점이다. - '행동하는 네트워크가 자기 미래를 예측한다'는 joint objective 자체는 world model 문헌에서 새롭지 않지만, 이를 humanoid WBC의 environment interaction과 command robustness가 같은 능력의 양면이라는 formulation으로 연결한 것은 새롭다.
Benchmark Results
- Terrain split: SR 81.3% vs SONIC/HoloMotion-1/Humanoid-GPT 14.0~18.7%(4.3배), MPKPE 93.3mm vs 283~331mm. flat→terrain 이동 시 자체 MPKPE 상승은 22%(76.6→93.3mm)에 그친 반면 baseline은 3~4배 악화됐다. - Fall recovery: 99.3% vs baseline 0.7~5.9%(16.8배), jerk도 1050.6 rad/s³로 최저(baseline 1295~3598)라 hardware 배포 가능한 수준의 부드러운 기립을 보였다. - OOD(물리적으로 불가능한 command): SR 83.1% vs 50.0~70.6%, MPKPE 158.0mm vs 최고 baseline 208.0mm로, command를 버리지 않고 의도에 가장 가까운 동작으로 retraction함을 보였다. - Standard(AMASS): MPKPE 76.6mm·SR 96.3%로 flat-ground에서도 4개 방법 중 최고. 단 root velocity는 211.1mm/s로 HoloMotion-1(121.3)에 뒤지며, 저자는 root-translation masking의 대가로 설명한다. - terrain annotation 인간 audit은 200개 motion에서 92% 정확도. 실제 hardware에서 동일 operator command로 SONIC과 비교 데모, G1→Maker L01 fine-tuning 전이를 보였으나, component ablation과 real-robot 정량 수치는 본문에서 확인 불가(추후 추가 예정으로 명시).
누리랩 연구와의 연결
- policy가 자기 예측 분포로 OOD command를 감지·사영하는 구조는 누리랩의 failure detection·recovery 주제에 직접 연결된다. VLA 하위 controller의 command feasibility filter로 이식해 상위 policy의 무리한 명령을 걸러내는 안전층으로 쓸 수 있다. - motion에서 3D contact geometry를 역추정하는 pipeline은 object-centric 3D representation·scene graph 연구에서 interaction-grounded scene 복원 도구로 활용할 수 있다. - next-state 예측 head의 오차가 커지는 시점을 감지해 replanning이나 recovery를 트리거하는 proactive failure detection으로 확장하면, test-time optimization과 world model을 잇는 후속 연구가 가능하다.

ADEPT: Accelerating Dexterity via Pre-Training and Post-Training using Reinforcement Learning

arXiv PDF alphaXiv
Manipulation relevance 10/10 Robotics (cs.RO)
Jayjun Lee, Jessica Yin, Asif Rana, Nicholas Blauch, Sam Mady, Mohak Bhardwaj, Nima Fazeli, Nathan Ratliff 외 2명 PDF 전문 1차 87점
고자유도 arm-hand 로봇의 dexterity를 task마다 처음부터 배우는 대신, generic object reposing task로 RL pre-training한 뒤 BC distillation·critic warm-up·conservative PPO의 3단계 recipe로 안정적으로 post-training하는 ADEPT를 제안한다. 23-DoF Kuka-Allegro와 29-DoF Flexiv-Sharpa에서 demonstration이나 pose tracker 없이 raw vision·tactile만으로 pick-reorient-insert를 zero-shot sim-to-real로 풀었고, visuo-tactile student가 FMB insertion 8/10을 달성했다.
Core Innovation & Methodology
- 16개 primitive shape의 reposing task에 PPO+ADR+PBT로 8B step pre-training하면, 이 prior가 downstream task의 reposing 구간을 zero-shot으로 해결하고 자연스러운 grasp를 emergent하게 만든다. - naive RL fine-tuning collapse의 원인을 관측 공간 불일치·critic 미보정·과도한 policy drift로 분해하고, BC actor distillation → frozen-actor critic warm-up(20 iter) → conservative PPO(actor LR 1e-5, clip 0.05)의 구조화된 post-training으로 해결한다. - DextrAH 계열의 5D PCA grasp subspace 대신 full joint Cspace geometric fabric을 policy와 로봇 사이에 두어, 23/29-DoF 전체 kinematic dexterity를 노출하면서 collision·joint-limit 안전을 보장하고 sim과 real에서 동일한 low-level controller를 유지한다. - teacher-student distillation에 2단계 curriculum(Stage 1: perception 중심 surrogate task로 encoder 학습, Stage 2: downstream teacher BC)과 8-keypoint pose auxiliary loss를 도입하고, TacMap penetration-depth map + SaTA식 FiLM anchoring으로 5개 fingertip tactile을 sim-to-real로 전달한다.
Novelty vs. Prior Works
- 개별 요소(BC init, critic warm-up, conservative update, geometric fabric, TacMap, DAgger)는 모두 기존 기법이어서 방법론적 novelty는 제한적이며, 기여의 본질은 이들을 조합해 '무엇이 collapse를 막는가'를 통제 ablation으로 규명한 recipe와 시스템 완성도다. - demonstration·pose estimator 없이 raw (visuo-tactile) perception만으로 long-horizon pick-reorient-insert를 sim-to-real RL로 푼 첫 demonstration이라는 주장은 related work 구도상 타당해 보인다. 동시기 Play2Perfect·SimToolReal은 object pose를 입력으로 받는 state-based policy를 실기에 쓴다는 점에서 구분된다. - fabric을 PCA subspace에서 full Cspace로 확장한 것 자체는 자연스러운 일반화지만, 그로 인해 어려워진 학습 문제를 reposing pre-training이 tractable하게 만든다는 연결이 논문의 핵심 논거다.
Benchmark Results
- post-training ablation(5 seed): actor LR 1e-5가 필수 요소로, 1e-3 변형은 BC·warm-up이 있어도 전부 ADR20에서 collapse(0/5)했고 KL penalty(beta=1)로도 구제되지 않았다. critic warm-up은 Train SR +17.6pt, BC는 수렴 시간을 35.2h→19.9h로 단축, tight clip은 효과가 미미했다. - scratch 학습은 대부분의 seed가 9B step에서 ADR6 이하 정체인 반면, ADEPT는 8B pre-training + task당 3B post-training으로 5/5 seed가 ADR50에 도달했다. pre-training 비용은 downstream task 전체에 amortize된다. - 실기 zero-shot: visuo-tactile Flexiv-Sharpa가 FMB square/round 8/10 vs vision-only 3/10으로 tactile이 결정적 — vision-only는 grasp 성공 여부를 몰라 재파지를 반복하는 실패 양상을 보였다. vision Kuka-Allegro는 star 5/10, square/round 3/10, dish placement 6/10. - 단일 stage distillation은 실기에서 0/10으로 완전 실패해, 2단계 curriculum이 sim-to-real 전이의 필수 요소임을 보였다. - 실행 속도 5~10s/trial로 FMB parallel-jaw pipeline(20~70s, 외부 fixture 의존) 대비 2~14배 빠르며, pre-trained teacher는 unseen 물체(VisDex 152개)에서 SR 0.77로 in-distribution(0.73)과 동등 이상의 일반화를 보였다.
누리랩 연구와의 연결
- reposing pre-training + 구조화된 post-training은 누리랩 manipulation·RL 연구에서 skill prior 재사용의 구체적 레시피로 바로 참고할 수 있다. 특히 critic warm-up과 낮은 actor LR가 collapse를 막는다는 ablation은 VLA fine-tuning의 안정화에도 시사점이 있다. - vision-only student의 실패가 'grasp 성공 여부를 모르는' 인지 불확실성에서 온다는 분석은 tactile perception과 failure detection을 잇는 고리로, contact confidence 기반 failure detection·recovery 설계에 활용할 수 있다. - full Cspace geometric fabric은 안전 제약을 유지하면서 탐색 공간을 넓히는 action interface로, dexterous RL 실험 인프라에 도입을 검토할 만하다.

Reinforced Planning with Latent World Models

arXiv PDF alphaXiv
World Model relevance 9/10 Machine Learning (cs.LG)
Armin Sommer, Jannik Schilling PDF 전문 1차 87점
pretrained latent world model 위에서 plan을 개선하는 search rule 자체를 신경망으로 학습하는 Reinforced Planning(RP1)을 제안한다 — critic이 latent L2 거리 대신 temporal cost-to-go를 배우고, planner는 (현재 plan, terminal value, gradient)만 받아 residual update를 반복한다. CEM/MPPI의 9,000회 대비 1,000배 적은 9회 world-model rollout으로 세 domain 전부에서 최고 성능을 냈고, 50개 동시 planner 상황에서 67배 빠르다.
Core Innovation & Methodology
- hand-designed optimizer(CEM/MPPI/Adam) 대신 F(a_k, v_k, g_k)→a_{k+1} 형태의 학습된 plan-update rule을 K=8회 weight-tied로 적용하는 residual planner를 제안한다. task 정보가 value와 그 gradient로만 전달되도록 interface를 제한해, state-goal-to-action mapping이 아닌 '개선 규칙' 자체를 배우게 강제한다. - frozen world model rollout을 통해 terminal value를 미분하는 fully offline 학습으로, conventional optimizer를 training target으로도 inference 내부에서도 쓰지 않는다. 어떤 pretrained latent world model(LeWM, PLDM)에도 부착 가능하다. - latent L2 거리 대신 quasimetric MRN critic을 IQL expectile regression + HER로 offline 학습해 temporal reachability를 평가 목적함수로 쓴다. Theorem 1은 예측 정확도만으로는 Euclidean latent geometry가 결정되지 않음(invertible reparameterization으로 goal 거리 순서가 뒤집힘)을 보인다. - planner가 world-model 오류를 exploit하는 문제('grasp-and-miss' hallucination)를 1회 Dyna iteration(실패 rollout으로 world model finetune 후 planner 재학습)으로 완화한다.
Novelty vs. Prior Works
- DMPO는 MPPI update를 유지한 채 수정만 학습하고, L2O-MPC는 고예산 MPPI expert 모방으로 학습하며, IAPO는 next-action 분포만 반복 개선한다. multi-step plan의 update rule을 target optimizer 없이 완전히 학습한 것은 저자 주장대로 이 논문이 처음으로 보이며, related work 정리가 이 구분을 설득력 있게 뒷받침한다. - 'objective(critic)와 search(planner)의 기여 분리' 실험 설계가 깔끔하다 — TwoRoom에서는 objective가 병목(learned critic만 주면 대부분의 planner가 포화), Reacher·Cube에서는 search가 병목임을 분리 입증했다. - Theorem 2(task heterogeneity 하 학습된 planner의 strict advantage)는 저자 스스로 인정하듯 idealized expressivity 결과로, RP1 architecture가 그 rule을 표현하거나 학습이 이를 찾는다는 보장은 없다.
Benchmark Results
- OGBench Cube(no-op floor 56.0/45.3%를 보정한 hard score): RP1이 LeWM h25 75.2 / h100 67.8, PLDM h25 61.1 / h100 58.1로 전 column 최고 — 최강 baseline CEM+value critic(63.6/57.4/31.8/34.1) 대비 PLDM에서 약 2배. rollout은 9회 vs 3,000~9,000회. - TwoRoom: latent L2로는 planner 전반이 저조(CEM 100step 13.3%)하나 learned critic을 주면 대부분 포화 — RP1은 25step 100.0%, 100step 94.2~96.0%. - Reacher tight tolerance(tau=0.05): RP1 88.7(LeWM)/82.0(PLDM)으로 최고, 최강 baseline 대비 LeWM에서 +6.7pt. 낮은 tolerance에서 격차가 벌어져 terminal precision 우위를 시사한다. - 1회 Dyna finetuning으로 Cube hard score +4.2~+19.1pt(h25 rollout만 수집, h100에 그대로 재사용해도 개선). - latency(H200, fp32): 단일 planner 30ms vs CEM 391ms(13배), 50개 동시 79ms vs 5.31s(67배), DMPO 대비 3.0배·L2O-MPC 대비 2.4배 빠름.
누리랩 연구와의 연결
- 누리랩의 test-time optimization·inference-time planning 주제와 직결된다 — manipulation world model이나 VLA 위에 RP1식 learned refiner를 얹으면 CEM 기반 planner의 rollout·latency 병목을 해소해 실시간 closed-loop planning에 접근할 수 있다. - latent 거리와 temporal reachability가 다르다는 Theorem 1과 quasimetric critic은 world model 기반 subgoal 평가·failure detection에서 목적함수 설계의 이론적 근거로 활용할 수 있다. - planner의 world-model exploitation을 실패 rollout 기반 Dyna loop로 고치는 절차는 failure-driven world model 보정이라는 점에서 failure detection·recovery 연구와 자연스럽게 결합할 수 있다.

SPADE: Self-Play in Adaptive Synthetic Executable Environments

arXiv PDF alphaXiv
LLM RL Self-Play Open-Endedness relevance 4/10 Computation and Language (cs.CL)
Bo Liu, Simon Yu, Yiding Jiang, Ao Qu, Andrew Zhao, Zichen Liu, Junsu Kim, Zijian Zhou 외 10명 PDF 전문 1차 81점
하나의 LLM이 Environment Designer와 Reasoning Agent 역할을 번갈아 수행하며, Gym-style reset()/step() Python 코드로 state transition·reward·검증까지 갖춘 완전한 multi-turn 환경을 스스로 작성하고 그 안에서 RL로 학습하는 self-play 프레임워크 SPADE를 제안한다. privileged hint 유무의 성능 격차(hint-based regret)로 designer를 학습 frontier에 맞춰, 30B급에서 최강 fixed-environment baseline 대비 8개 벤치마크 평균 +5.3, ACEBench-Agent +13.9를 달성했다.
Core Innovation & Methodology
- code-as-environment. Environment Designer가 transition function, reward function, verification 코드를 포함한 complete MDP를 Python 클래스로 생성한다. 계산 가능한 MDP는 모두 프로그램으로 표현되므로 hand-designed parameterization에 갇히지 않고, single-turn reasoning과 multi-turn tool use를 하나의 인터페이스로 통합한다. - hint-based regret reward. designer 보상 rD(e) = r̄A(e|hint) − r̄A(e). hint가 있으면 풀리고 없으면 안 풀리는 환경, 즉 agent 능력의 frontier에 있는 학습 가능한 환경에 보상이 집중된다. PAIRED의 minimax regret을 별도 antagonist 없이 hint-equipped agent를 upper-bound policy로 써서 근사하며, Appendix B에서 equilibrium 분석을 제공한다. - corpus grounding + environment memory. 매 라운드 DCLM/MegaScience(games)·Nemotron code corpus(tool use)에서 15k 문서를 샘플해 조건화함으로써 self-play의 mode collapse('invisible leash')를 막고, regret 점수가 붙은 과거 환경 memory로 난이도를 frontier에 유지한다. - 30B 규모 안정 학습 recipe. per-role advantage 정규화, delayed designer update + truncated importance sampling, 비대칭 clipping, floored regret(가중 0.4)과 win-rate 0.4~0.6 band를 겨냥한 flat-top difficulty anchor(가중 0.6) 결합, syntax/실행 검증 게이트 등.
Novelty vs. Prior Works
- SPIRAL·SPICE·AZR·R-Zero 등 기존 LLM self-play는 terminal reward만 있는 단발성 'task'를 생성하지만, SPADE는 상태 전이·보상·검증 코드를 갖춘 full multi-turn MDP를 생성하고 designer 자체를 RL로 학습한다는 점이 본질적 차이다. verifier가 생성 환경 안에 포함되어 designer와 co-evolve한다. - 고전 UED(PAIRED/POET)가 maze 크기 같은 parameterized 공간 안에서 환경을 '선택'하는 것과 달리, unbounded code 공간에서의 open-ended '생성'으로 regret 원리를 확장했다. OMNI-EPIC도 code 환경을 생성하지만 frozen FM judge에 의존하는 반면 SPADE의 designer는 학습된다. - hint-based regret은 저비용 regret 추정으로 참신하나 개념적으로는 PAIRED antagonist의 변형이며, corpus grounding은 SPICE의 원리를 task에서 environment 생성으로 옮긴 것이라 개별 구성요소의 novelty는 조합적이다.

monocular video에서 4D Gaussian Splatting 파라미터를 Riemannian Flow Matching(RFM)으로 생성하고 test-time optimization으로 다듬는 dynamic 4D 재구성 프레임워크 DAV4를 제안한다. 동일 조건 MLP baseline 대비 F-score +0.044를 RFM의 순수 기여로 분리해 주장하지만, 외부 SOTA 비교가 없고 논문 자체의 신뢰성 우려가 크다.
Core Innovation & Methodology
- 4DGS 파라미터가 사는 non-Euclidean manifold(scale은 log-space, rotation은 SO(3) geodesic, opacity는 logit)에서 직접 probability path를 정의하는 RFM prior — Euclidean interpolation + post-hoc projection의 invalid Gaussian 문제를 회피한다 - frozen DINOv2-L + Perceiver로 latent token을 만들고, flow time t와 video time τ에 조건화된 vector field로 coarse-to-fine ODE sampling(10+20 step) 후 rendering gradient guidance TTO(20 step)를 적용한다 - human depth label 없이 rendering·SE(3)-equivariance·optical flow(RAFT)·scale(DA2 median depth를 weak supervision으로 명시) loss로 학습한 self-supervised teacher의 4DGS를 distillation target으로 사용한다 - TTO/pre-training/RFM의 기여를 분리하는 controlled experiment 설계(동일 데이터·구조·TTO의 deterministic MLP baseline)와 multi-hypothesis sampling 기반 uncertainty(NGLL, ECE) 정량화
Novelty vs. Prior Works
- manifold-valued 3DGS/4DGS 파라미터에 Riemannian FM을 적용한 조합은 흥미로우나, flow matching·4DGS·feed-forward GS prior 각각은 기존 연구이며 결합 이상의 conceptual leap은 크지 않다 - 비교군이 자체 구현 4D-GS와 MLP baseline에 한정되고 최신 dynamic reconstruction SOTA(MonST3R, Shape-of-Motion 계열 등)와의 비교가 전무해 상대적 위치를 판단할 수 없다 - 'Depth Anything V4'라는 제목을 쓰지만 저자진(난징우전대)이 원 Depth Anything 시리즈 저자 그룹과 무관해 시리즈 계승으로 보기 어렵고, 실존 여부가 의심되는 인용(Dynamic-Sim ICCV 2023 등)과 'corrected cost analysis' 같은 rebuttal 잔재성 표현이 있어 논문 신뢰성에 심각한 의문이 있다

누리랩 연구와의 연결
- 핵심 아이디어(scale·rotation·opacity manifold 위의 geodesic flow로 invalid Gaussian 없이 파라미터를 생성)는 누리랩의 object-centric 3DGS/4D representation 연구에서 참고할 가치가 있다 — Euclidean FM 대비 invalid 12.3%→0.01% 수치가 유일하게 시사적인 근거다 - 학습된 generative prior + 소수 step의 rendering-guided refinement 구조는 test-time optimization 연구 흐름과 맞닿아 있어 개념 차용이 가능하다 - 다만 인용·데이터셋·baseline의 실존과 재현성이 확인되기 전에는 이 논문의 수치를 인용하거나 baseline으로 삼는 것은 피하는 편이 안전하다

오늘의 핵심 연구 트렌드 종합

  • World model이 시뮬레이터에서 policy의 내부 구조로 이동한다 — GigaBrain-WBC-0.5는 whole-body tracker를 next state·next command 분포까지 예측하는 behavior world model로 학습하고, Reinforced Planning은 월드모델 위에서 plan을 개선하는 search rule 자체를 신경망으로 학습한다. Dream2Reward는 성공 transition field를 dense reward로 쓴다. 월드모델을 "돌려보는 것"이 아니라 policy·planner·reward의 구조적 사전(prior)으로 흡수하는 흐름이 뚜렷하다.
  • 데이터 엔진: 인간 비디오와 generic task가 teleop을 대체한다 — RoboEdit은 인간 조작 영상을 물리적으로 타당한 로봇 상호작용 비디오·3D hand state로 편집해 7개 embodiment 경험을 만들고, ADEPT는 generic object reposing pre-training 후 3단계 post-training recipe로 task별 dexterity를 가속한다. 고비용 teleop 수집 대신 변환·사전학습 기반 데이터 엔진이 표준이 되어가고 있다.
  • Frozen policy 위의 plug-and-play 보정 계층 — GS-VLA는 4M 파라미터 3DGS canonicalizer로 카메라 시점 변화를 학습 시점 canonical view로 되돌려 frozen VLA를 구제한다. 어제의 UniReflex(force reflex)와 같은 계열로, 거대 VLA를 재학습하지 않고 관측·제어 수준 어댑터로 견고성을 확보하는 패러다임이 자리잡고 있다.
  • Agentic RL의 병목이 알고리즘에서 환경·credit 구조로 — SPADE는 LLM이 Gym-style 환경 코드를 스스로 작성하며 self-play로 학습하고, RTPO는 multi-turn RL 불안정의 원인을 turn-level credit assignment로 규명한다. long-horizon 학습의 관건이 reward shaping이 아니라 환경 생성과 credit 구조 설계임이 분명해지고 있다.
  • 평가의 정직성: 숨은 상태를 드러내는 벤치마크 — SoftVTBench는 policy가 못 보는 FEM 변형 상태로 "성공했지만 물체를 망가뜨린" 경우를 잡아내고, LT-Mem은 세션 간 물체 이력 소실(temporal amnesia)을 측정한다. task 성공률 뒤에 숨은 물리적·시간적 상태를 평가 축으로 끌어내는 움직임이 시작됐다.

유망 연구 방향 및 프로젝트 제안

1. 3DGS 기반 관측 정규화 계층의 일반화 — viewpoint를 넘어 embodiment·조명·occlusion으로 - Research question: frozen VLA의 분포 이탈 관측을 어디까지 "학습 분포로 되돌려" 해결할 수 있는가. - 접근·novelty: GS-VLA의 시점 정규화를 object-centric 3DGS로 확장해 조명·부분 가림·gripper 형상 차이까지 canonical 관측으로 재렌더링하는 범용 adapter를 만든다. - 왜 지금: GS-VLA·GroupForward(8/19)로 재료가 모두 공개됐고, frozen VLA 보정 계층은 아직 시점 하나만 다뤄졌다. - 난이도·venue: 중간 — 실로봇 검증 필수. CoRL/ICRA 적합.

2. 성공 transition field 기반 failure detection·recovery - Research question: Dream2Reward의 "성공 latent 변위와의 이탈"을 reward가 아니라 실시간 failure detector로 쓸 수 있는가. - 접근·novelty: 성공 데모의 transition field에서 방향·크기 이탈이 임계값을 넘으면 failure로 진단하고, 이탈 방향의 반대 gradient를 recovery 신호로 활용한다. reward 학습과 failure detection을 하나의 표현으로 통합하는 것이 새롭다. - 왜 지금: Dream2Reward가 표현을 검증했고, 어제의 danger-law 논문이 rare-mode 실패의 이론 틀을 제공한다. - 난이도·venue: 중간 — CoRL/RSS 적합, 누리랩 failure recovery 라인과 직결.

3. Volatility-aware scene-graph memory와 object-centric 3DGS의 결합 - Research question: 물체별 이동성(volatility)을 명시적으로 추정하는 lifelong 3D scene graph가 장기 mobile manipulation을 얼마나 개선하는가. - 접근·novelty: LT-Mem의 Tri-Memory 구조를 scene graph 노드 단위로 재구성하고, 각 노드를 GroupForward식 instance-grouped 3DGS로 표현해 "참조 가능하고 기억되는" 씬을 만든다. - 왜 지금: LT-Mem이 문제(temporal amnesia)와 평가를 정의했지만 표현은 point cloud 수준에 머물렀다. - 난이도·venue: 중상 — multi-session 실환경 데이터 수집 필요. IROS/ICRA → CoRL 확장.

4. Human video → robot experience 파이프라인에 tactile을 추가 - Research question: RGB 인간 영상에서 변환한 로봇 경험에 접촉·변형 정보를 어떻게 보강해 contact-rich task까지 커버하는가. - 접근·novelty: RoboEdit식 video editing에 SoftVTBench의 FEM/tactile 시뮬레이션을 결합해, 시각적으로 편집된 경험에 물리적으로 일관된 tactile 신호를 합성한다. - 왜 지금: 두 논문이 각각 절반(시각 변환, 변형 GT)을 오늘 공개했다. - 난이도·venue: 높음 — 시뮬-실환경 tactile 정합이 관건. CoRL 적합.

5. Turn-level credit assignment를 로봇 skill chaining에 이식 - Research question: RTPO의 역순 최적화·sibling rollout fork가 long-horizon manipulation의 skill 단위 credit assignment에도 유효한가. - 접근·novelty: LLM tool-use turn을 robot skill 실행으로 치환하고, skill boundary state에서 fork한 rollout으로 skill-level advantage를 추정한다. skill chaining RL의 안정화 recipe로 재해석하는 것이 새롭다. - 왜 지금: RTPO가 이론 정리를 제공했고, 로봇 쪽 skill chaining은 여전히 trajectory 단위 reward에 머물러 있다. - 난이도·venue: 중간 — 시뮬레이션 중심으로 시작 가능. NeurIPS/CoRL 적합.

오늘 반드시 읽어야 할 논문

  • GigaBrain-WBC-0.5 — whole-body 제어기를 behavior world model로 학습하는 설계는 누리랩의 world model + policy 통합 라인에 가장 직접적인 참조점이다.
  • ADEPT — dexterous manipulation의 pre-training/post-training recipe가 구체적 수치와 함께 정리돼 있어 manipulation 프로젝트의 학습 전략에 바로 쓸 수 있다.
  • Reinforced Planning with Latent World Models — plan 개선 규칙을 학습한다는 발상은 test-time optimization 연구의 다음 단계를 보여준다.
  • SPADE — 환경을 스스로 작성하는 self-play는 로봇 curriculum 자동 생성으로 확장할 여지가 크다.
  • Dream2Reward — 성공 transition field 표현은 reward·failure detection·recovery를 하나로 묶을 수 있는 도구다.
  • GS-VLA — 3DGS로 frozen VLA의 시점 취약성을 고치는 접근은 object-centric 3DGS 라인과 VLA 라인의 정확한 교차점이다.
  • SoftVTBench — tactile perception과 deformable manipulation 평가의 새 기준으로, 벤치마크 선점 관점에서도 중요하다.
  • LT-Mem — temporal amnesia 문제 설정은 robot memory·scene graph 연구의 빈 자리를 정확히 가리킨다.
