Morphometric Imitation: From Morphology and Contact Aware Hand Retargeting to Sim-to-Real Visuomotor Policy

arXiv PDF alphaXiv
Manipulation relevance 9/10 Robotics (cs.RO)
Tara Sadjadpour, Siming He, C.K. Wolfe, Haozhi Qi, Lea Wilken, S. Shankar Sastry, Claire Tomlin, Jitendra Malik PDF 전문 1차 72점
사람 손-물체 상호작용 영상을 kinematic retargeting, residual RL, visuomotor distillation 세 단계로 로봇 손 policy로 바꾸는 Morphometric Imitation을 제안함. 세 종류 로봇 손, 10개 물체 카테고리에서 baseline 대비 큰 폭의 성능 향상을 보였고 실로봇 300회 시도 중 89.3% 성공했음.
Core Innovation & Methodology
- 사람 hand-object demonstration을 kinematic retargeting → residual RL → visuomotor distillation 세 단계로 로봇 policy까지 변환하는 파이프라인 Morphometric Imitation을 제안함 - 첫 단계 morphometric optimization(MMO)은 MANO hand model을 로봇 morphology에 맞게 손바닥·손가락별로 scale한 Scaled MANO를 만들고, 형태 변형으로 어긋난 hand-object contact를 프레임마다 재최적화해 복원함 - robot pose는 linear blend skinning 원리를 skeleton에 적용한 linear blend retargeting과 IK로 복원하며, 기존 방식과 달리 손목 pose target까지 별도 휴리스틱 없이 dense하게 얻음 - 둘째 단계 residual RL은 MMO reference를 warm start로 써서 object pose tracking과 contact matching을 함께 보상하고, 그 rollout을 ManiFlow 기반 point cloud policy로 distill해 zero-shot sim-to-real을 노림
Novelty vs. Prior Works
- 가장 가까운 prior work인 OmniRetarget(mesh matching)과 Contact PyRoki(fingertip-object proximity) 대비, MMO는 사람 hand model 자체를 로봇 morphology에 맞춰 먼저 최적화한 뒤 contact을 복원하는 순서를 택해 형태 차이로 인한 contact 왜곡을 더 직접적으로 다룸 - residual RL의 object-tracking+contact reward 조합은 Chen et al., Human2Sim2Robot 등 기존 dynamic retargeting 계열과 원리상 유사하며 새 학습 알고리즘은 아니고, distillation도 기존 ManiFlow를 그대로 씀 - 결국 novelty는 kinematic retargeting representation(Scaled MANO+contact matching)에 집중되어 있고, 나머지 두 단계는 기존 구성 요소를 조합해 하나의 완결된 파이프라인으로 검증한 성격이 강함
Benchmark Results
- kinematic retargeting: GRAB dataset 10개 demonstration, 5mm tolerance 기준 MMO가 Dex3/Allegro/Sharpa 세 손 전부 최고 F1이며 가장 강한 baseline 대비 각각 27.8/8.3/10.5 pt 개선함 - contact patch distance도 MMO가 7.5/9.1/9.7mm로 최저이며 baseline(10.7~18.9mm) 대비 크게 낮음 - dynamic retargeting(카테고리당 2048 rollout)에서 MMO reference 사용 시 success rate가 Dex3 82.5%, Allegro 69.9%, Sharpa 91.8%로 가장 강한 baseline(53.2/68.2/56.5%) 대비 최대 35.3 pt 향상됨 - ablation에서 contact reward를 빼면 SR이 82.5→51.2%(Dex3)로, object pose reward까지 빼면 42.5%까지 떨어져 두 reward가 상호 보완적임을 보임 - 실로봇은 Sharpa Wave+KUKA iiwa14 arm, 10개 카테고리 30개 object instance에서 300 trial 중 268회 성공(89.3%)했고, simulation student(93.75%) 대비 4.4 pt 낮음. 코드 공개 여부는 본문에서 확인 불가하고 project page만 언급됨
누리랩 연구와의 연결
- location-aware contact F1·patch distance 지표는 grasp 실패를 contact 단위로 진단하는 metric으로, 누리랩의 failure detection/recovery 연구에 그대로 가져다 쓸 수 있음 - 실로봇 실패가 특정 object 위치(near row)에 몰린 결과는 test-time에 관측만으로 실패 가능성을 미리 판단하는 failure 예측 실험의 단서로 쓸 수 있음 - residual RL이 kinematic reference를 warm start로 쓰는 구조는 world model을 이용해 test-time에 reference trajectory 자체를 온라인 재최적화하는 방향으로 확장할 수 있음

World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Yehang Zhang, Haojian Huang, Yifan Chang, Jianchong Su, Bohan Zhou, Yingjie Xu, Wosong Chen, Tianhao Zhou 외 8명 PDF 전문 1차 65점
VLM이 로봇을 조종할 때 global view 하나만 보고 즉시 행동을 실행하는 대신, contact view로 상호작용 지점을 확대해서 보게 만든 multi-agent harness인 World Action Agent(WAA)를 제안함. action은 실행 전에 rehearsal로 미리 검증함. LIBERO-Pro 평균 75.6% 성공률로 end-to-end VLA와 code-as-policy 계열 baseline을 능가했고, LIBERO에서 학습한 skill을 추가 학습 없이 robosuite에도 그대로 전이시킴.
Core Innovation & Methodology
- VLM이 직접 로봇을 조종하되 '무엇을 보는지'와 '결정이 어떻게 반영되는지'를 바꾸는 visual action workspace를 제안함. VLM 자체는 손대지 않음. - contact view는 scene point cloud와 상호작용 영역을 기반으로 visibility·framing·redundancy·안정성 항을 최적화해서 자동 선정하며, 두 view의 수평 투영을 직교시켜 오차를 두 방향에서 읽게 함(식 2). - action rehearsal은 각 action을 IK+cuRobo motion planning으로 미리 검증하는 editable proposal로 다루고, 필요시 별도 context의 Imagination Agent가 반복 수정함. 실행 가능한 plan만 실제 로봇 동작이 됨. - in-view correction은 contact view 위에서 드래그한 이미지 좌표를 calibration으로 end-effector 변위로 변환해 관찰-교정을 같은 좌표계에서 닫음. 별도로 expert video·human teaching에서 관계형(relational) skill을 진화시키는 Learner-Editor-Reviewer 루프와, harness trace로 소형 VLM(Qwen3.5-9B)을 SFT하는 두 가지 학습 경로도 제공함.
Novelty vs. Prior Works
- 가장 가까운 prior work인 Show-Harness·VIA도 VLM이 시각 인터페이스에서 직접 action을 고르지만, 관찰이 상호작용 중심이 아니고 action이 즉시 실행되며 perception과 action이 다른 좌표계에 있다는 3가지 한계가 있음. WAA는 이 3가지를 각각 contact view·rehearsal·in-view correction으로 정면 대응함. - HAMSTER·ReKep·CaP류는 VLM이 constraint나 code를 간접적으로 생성해 downstream policy/optimizer에 넘기는 구조인 반면, WAA는 VLM이 기본 primitive를 통해 직접 조종하면서도 planner의 feasibility check로 grounding한다는 점에서 본질적으로 다름. - skill 표현 자체는 ASPIRE류의 object별 고정 파라미터(grasp height offset 등)와 달리 relational guidance(관계·접촉·clearance 조건)라서 object instance·layout·viewpoint 간 transfer가 가능하다고 주장하나, 이 relational skill 표현 자체의 novelty는 부분적임 — 기존 언어 기반 절차 지식 아이디어의 확장에 가까움.
Benchmark Results
- LIBERO-Pro 6개 split 평균에서 evolved skills 적용 WAA가 75.6%로 SOTA 달성, 가장 강한 baseline인 ASPIRE(72.0%)를 능가함(전체 split 평균 기준이며 모든 개별 split에서 우세한 것은 아님). skill은 LIBERO-90에서만 진화시키고 LIBERO-Pro 평가 전 고정함(rollout·failure log로 추가 학습 없음). - zero-shot(스킬 없음) WAA는 28.9%로 π0.5(12.8%), OpenVLA(0.0%), 동일 backbone(Gemini 3.7 Flash)의 Show-Harness(6.7%)를 크게 앞섬. Spatial split(centimeter급 배치, zero-shot/evolved skill 순)에서 격차가 가장 큼(WAA 80.0%/73.3% vs ASPIRE 51.0%/60.0%). - Object split(zero-shot/evolved skill 순)에서는 ASPIRE(98.0%, 95.0%)가 WAA(95.0%, 93.3%)보다 여전히 강함 — 전 영역 우위는 아님. - scene point cloud source를 simulator에서 fused RGB-D나 VGGT reconstruction으로 바꿔도 평균 성공률이 71.1%, 68.9%로 각각 4.5·6.7%p만 하락, 두 경우 모두 Spatial split에서는 모든 baseline을 상회함(perception source에 대한 강건성 근거). - robosuite(LIBERO와 다른 scene·object·camera)에서 LIBERO에서 학습한 skill을 추가 학습 없이 적용 시 restacking 성공률이 60.0%에서 100.0%로 상승, 평균 100.0%(CaP-Agent0+RATs skill은 63.3%). - Qwen3.5-9B를 harness trace 1,774개로 LoRA fine-tuning하면 out-of-domain 성공률이 1.7%에서 43.3%, in-domain은 0.0%에서 55.0%로 상승함 — 다만 sub-agent(Imagination·Skill Agent)는 Gemini 3.7 Flash를 그대로 사용해 main policy만 교체한 결과이고 sim-only 평가임.
누리랩 연구와의 연결
- 누리랩의 failure detection/recovery 주제와 직접 연결됨 — rehearsal(실행 전 IK/motion planning 검증)과 human teaching 기반 recovery guidance 추출(Learner가 실패 직전 상태와 human correction을 대조해 회복 절차를 distill) 방식은 자체 failure recovery 연구에 baseline 또는 구성요소로 바로 활용 가능함. - test-time optimization/inference-time planning 맥락에서 Imagination Agent가 별도 context에서 proposal을 반복 수정하는 구조는 world model 기반 test-time rehearsal 연구와 비교 대상이 됨. contact view 선정 objective(식 2)는 active perception/NBV 연구에서 재사용 가능한 정식화임. - object-centric 3DGS·scene graph 연구와는 point cloud 기반 contact view가 아니라 3DGS로 상호작용 중심 view를 렌더링하는 확장 아이디어로 연결 가능함. 다만 이 논문은 sim-only이므로 실로봇 적용 시 calibration·depth noise에 따른 in-view correction 정확도 검증이 선행 과제임.

Aim Short to Reach Far: Your Frozen World Model Can Plan Better Than You Think

arXiv PDF alphaXiv
World Model relevance 9/10 Machine Learning (cs.LG)
Xvyuan Liu, Jianjie Fang, Chen Gao, Yong Li PDF 전문 1차 78점
Frozen LeWM(joint-embedding 기반 world model) 플래너가 goal 이미지까지의 거리만으로 다음 action을 고르면 처음에 목표에서 멀어지는 유용한 첫 걸음을 거부해 목표에 못 이를 수 있음을 증명함. 저자들은 기록된 경로에서 뽑은 중간 target을 향해 같은 frozen model로 action을 채점하는 Anchored Planning을 제안해 추가 학습 없이 Cube·PushT·Reacher·TwoRoom 4개 sim task 전부에서 공개된 LeWM 플래너를 앞섬.
Core Innovation & Methodology
- final-goal distance scoring이 exact dynamics와 전역 최적 short-horizon search에서도 영원히 제자리에 머무는 선택을 고를 수 있음을 Proposition 1로 증명함(곡선 c(s)=(s,s^2) 위에 상태를 두는 반례 구성). - Anchored Planning(AP)은 현재·목표 관측과 시작·끝이 비슷한 기록 segment를 memory에서 검색해, 그 segment의 초기 successor(기본 L=5 step 뒤 관측)를 target으로 삼음. - 남은 offset h=max(L, H-t)를 실행이 진행될수록 줄여가며 검색 범위를 좁히고, 같은 frozen encoder·forward model로 candidate action의 predicted endpoint를 이 target에 채점함. - observation-only memory에서는 CEM(cross-entropy method)으로 action을 직접 합성(AP-CEM)하고, action-labeled memory에서는 검색된 8개 action block 중 하나를 순위로 선택(AP-rank)함 — 두 경우 모두 별도 모델 학습이 없음.
Novelty vs. Prior Works
- SPTM·SoRB·PALMER 같은 observation-graph 검색이나 SAGE·HWM·Hi-LeWM 같은 subgoal generator는 별도 distance/target 모델을 학습시키는 반면, AP는 학습 없이 기록 experience에서 target을 그대로 가져와 씀 — 핵심 차이는 target을 학습하는 대신 검색으로 대체한 것임. - 가장 가까운 baseline인 SAGE의 generator-only variant는 학습된 target을 CEM으로 채점하는 구조로 AP-CEM과 골격이 거의 같지만, AP는 그 target 모델을 아예 없애고 retrieval로 대체한 점이 차별점임. - nearest-neighbor 기반 검색 자체(VINN, PALMER 등)는 새로운 기법이 아니므로, novelty는 새 검색 알고리즘이 아니라 final-goal scoring 실패를 정식화한 Proposition 1과 이를 training-free하게 해결한 조합에 있어 제한적인 편임.
Benchmark Results
- 평가는 MuJoCo 기반 sim task 4개(Cube, PushT, Reacher, TwoRoom)에 한정되고 real-robot 실험은 없으며, task당 128개 paired query(standard start 1개 + perturbed start 2개)로 측정함. - standard start 평균 success: CEM은 final-goal target 9.2%에서 AP-CEM 59.8%로, ranking은 final-goal target 67.0%에서 AP-rank 83.8%로 오름(frozen predictor·action rule은 동일하게 유지). - 원 논문의 goal offset(100~150 action) 구간에서 AP-CEM·AP-rank가 공개된 LeWM 플래너를 모든 task·start 조건에서 앞섬; 예측 block 수는 Cube·PushT·TwoRoom에서 LeWM의 63.4~85.5%, Reacher에서는 126.6~128.1%를 사용함. - ablation: intermediate target을 쓰면 CEM 2 iteration만으로도 final-goal target 30 iteration보다 모든 task에서 나은 성능을 냄. - retrieval span을 고정(h=H)하면 AP-rank 평균 success가 83.8%에서 9.6%로 크게 낮아져 span을 줄여가는 것이 필수임을 보임. - learned target은 held-out successor 예측 오차가 4개 task 모두에서 더 낮지만, CEM control success는 task별로 갈림(Cube·TwoRoom은 learned가, PushT·Reacher는 observed가 우세)해 예측 정확도와 control 성능이 분리됨을 보임. - 코드와 per-episode 결과는 저자 repository에 공개됨.
누리랩 연구와의 연결
- failure detection/recovery와 test-time optimization 관점에서, replanning마다 남은 거리에 맞춰 retrieval span을 줄이는 h=max(L,H-t) 규칙은 실패 후 recovery 단계에서 중간 목표를 다시 잡는 방식으로 바로 적용해볼 수 있음. - world model·robot memory 연구에 붙이면, VLA policy의 test-time inference에서 학습된 subgoal 대신 demonstration memory에서 검색한 anchor를 scoring target으로 쓰는 frozen-world-model 조합을 실로봇 manipulation task로 확장해볼 수 있음. - Proposition 1의 반례(local objective가 전역 경로를 거부하는 상황)는 counterfactual reasoning·long-horizon planning 논의에서 짧은 horizon distance reward가 실패하는 이유를 설명하는 이론적 근거로 인용 가능함.

AD-WM: Action-Discriminative World Models for Counterfactual Model Predictive Control

arXiv PDF alphaXiv
World Model relevance 10/10 Artificial Intelligence (cs.AI)
Jiabin Qiu, Zixuan Chen, Hongye Cao, Jieqi Shi, Jing Huo, Yang Gao PDF 전문 1차 82점
world model이 factual transition 예측 오차만 줄이면 후보 행동들을 잘 구별하지 못한다는 문제를 지적함. residual latent prediction과 predictor 단계 action recovery(inverse dynamics + mutual information(MI) 기반 정규화)를 결합해 counterfactual MPC 성능을 높임. OGBench-Cube hard-start 성공률을 matched LeWM 대비 3.7%에서 52.0%로 올렸고, 실제 Franka pick-and-place 성공률도 42.2%에서 71.1%로 개선했음.
Core Innovation & Methodology
- factual prediction 정확도와 counterfactual action 비교 능력이 별개라는 문제를 제기함. action-independent predictor도 낮은 prediction error를 낼 수 있지만 모든 후보 action에 같은 cost를 부여해 planning에 쓸모없다는 점을 formulation 단계에서 보임. - residual latent prediction: 절대 latent 대신 증분 Δz를 예측하도록 바꿔 action-dependent 변화를 명시적으로 모델링함. - predictor 단계 action recovery 두 가지를 도입함 — (a) 예측된 (z_t, ẑ_t+1)에서 action embedding을 복원하는 inverse dynamics head, (b) Barber-Agakov variational bound로 정당화한 conditional mutual information 기반 normalized recovery. 두 head 모두 model이 생성한 transition에 gradient를 걸어 MPC가 실제로 rollout하는 latent 자체를 제약함. - planning 진단 지표로 whole-bank 순위 상관(CAD)과 별개로 CEM이 실제 쓰는 elite 집합 기준 regret(R_k, R̄_k)을 새로 정의해 factual error·CAD보다 closed-loop 성공률과 더 잘 맞는지 검증함.
Novelty vs. Prior Works
- 가장 가까운 baseline은 LeWM(구조 자체)이고, 개념적으로 가장 가까운 prior work는 Delta-JEPA임. Delta-JEPA는 관측된 latent displacement에서 action을 복원해 action sensitivity를 유도하는 반면, AD-WM은 inverse dynamics와 MI 기반 recovery를 model이 예측한 transition에 적용해 MPC가 직접 쓰는 latent를 제약함 — 적용 대상은 다르지만 'action recovery로 action-aware latent를 만든다'는 방향 자체는 선행 연구(inverse dynamics 계열, Delta-JEPA)와 공유함. - ablation(Table II A)에서 Res+MI만으로도 mean HS(hard-start 성공률) 54.7%로 Inv까지 더한 AD-WM 전체(52.0%)보다 오히려 높게 나옴. - RoboTwin 2.0 10 task(5 task씩 2개 panel) 기준, DeltaWAM+SDM은 Fast-WAM 대비 평균 성공률을 clean 81.3%→85.4%, randomized 75.8%→83.9%로 올림(전체 10 task 합산). - 단 panel (a) 5 task만 보면 SDM을 추가할 때(SDM 없는 DeltaWAM 기준) clean 성능이 86.4%→82.8%로 오히려 떨어지고 randomized만 82.6%→86.6%로 개선되는 trade-off가 있음(Table I·III). - 학습 FLOPs는 세 architecture 모두 Fast-WAM 대비 17.78~23.77% 감소했고, SDM은 one-step 추론에서 latency 36.57%, FLOPs 31.55% 감소시킴 — 단 delta encoder 자체가 추가 비용(학습 3.048 TFLOPs, 추론 0.457 TFLOPs)을 유발해 절감폭을 일부 상쇄한다고 저자가 명시함. - 실로봇 평가는 dual-arm(RealMan RM75-6F) bimanual task 3종, task당 20 trial(총 60 trial)로 규모가 작음 — DeltaWAM 성공률 41.67% vs π0.5 38.33%, Fast-WAM 35.00%이고 normalized progress는 72.14%로 세 방법 중 최고임. - ablation에서 anchor를 없애면 성공률이 32.6/35.2%로 급락해 dense anchor context가 필수적임을 확인함(저자 실험으로 검증됨).
누리랩 연구와의 연결
- Streaming Delta Memory의 KV cache 증분 업데이트 방식은 누리랩의 test-time optimization/inference-time planning 연구에서 world model rollout 비용을 줄이는 아이디어로 참고할 만함. - delta representation이 randomized(시각 교란) 세팅에서 강건성을 높인다는 결과는, failure detection·recovery 연구에서 '무엇이 변했는지'만 추적하는 state representation으로 확장할 여지가 있음. - novelty가 재조합 수준이라 그대로 채택하기보다는, delta stream을 counterfactual reasoning(반사실 상태 변화 예측)이나 object-centric 3DGS의 변화 추적과 결합해 재구성하는 방향이 누리랩 관점에서 더 가치 있을 것으로 보임.

Uncertainty-Gated Exploration Noise Suppresses Task Collapse in Online RL Fine-Tuning of a Flow-Matching Vision-Language-Action Policy

arXiv PDF alphaXiv
VLA Online RL Fine-tuning relevance 9/10 Robotics (cs.RO)
Mehmet Turan Yardımcı, Yunus Emre Çoğurcu PDF 전문 1차 65점
온라인 RL로 flow-matching VLA를 계속 학습시키면 전체 평균 성공률은 멀쩡해 보여도 개별 task가 완전히 무너지는 task collapse가 흔히 일어남을 보임. RND(random network distillation) novelty와 critic 불확실성으로 task별 noise 크기를 조절하는 controller를 쓰면 LIBERO-10 7-task 세팅에서 3개 seed 모두 collapse 없이 버텼지만, 어떤 arm도 behavior cloning baseline보다 나은 성능은 못 냄.
Core Innovation & Methodology
- task collapse라는 현상을 정의함: online RL fine-tuning 중 aggregate success는 유지되면서 개별 task success가 behavior cloning(BC) 기준값의 절반 아래로 떨어지는 것을 뜻함 - RND(random network distillation) 기반 novelty 신호와 PPO critic value·5-head value ensemble spread 기반 competence 신호를 조합해, task label·episode 경계 없이 4단계 noise scale({0.12, 0.30, 0.36, 0.42}) 중 하나를 매 step마다 선택하는 controller를 제안함 - SmolVLA(450M) + PPO를 LIBERO-10 7-task pool에 적용하고, exploration noise 정책만 다른 세 arm(고정 noise, ReinFlow식 learned noise, uncertainty-gated controller)을 나머지 조건은 모두 고정한 채 비교함 - bfloat16 in-place 파라미터 업데이트에서 action expert 원소의 96.02%가 3 iteration 연속 그대로임을 별도로 측정해, 업데이트 크기와 학습 정체의 관계를 부가 결과로 제시함
Novelty vs. Prior Works
- 가장 가까운 prior work인 ReinFlow는 동일한 learnable noise 아이디어를 쓰지만 소형 state/pixel 기반 policy에서만 검증했고 task collapse 자체를 측정하지 않음 - 이 논문은 같은 메커니즘을 450M VLA·language-conditioned multi-task 환경으로 옮기고 collapse를 4가지 정의로 정량 측정한 것이 본질적 기여임 - controller 자체는 novelty·competence 두 신호를 2x2 lookup table로 매핑하는 규칙 기반 설계라 신호를 학습하는 모듈이 아니며, 방법론적 새로움은 제한적임. novelty의 무게중심은 mechanism보다 문제 정의와 측정 프로토콜에 있다는 점을 저자도 인정함
Benchmark Results
- LIBERO-10 7-task pool, SmolVLA 450M, PPO 200 iteration, 3 seed/arm 기준: controller는 pooled collapse 0/7(3 seed 모두), fixed noise는 2/3 seed에서 collapse(최대 4/7), ReinFlow식 learned noise는 3 seed 모두 collapse(최대 6/7)함 - 어떤 arm도 BC baseline(pooled success 0.648 campaign 기준/0.576 local 기준) 이상으로 aggregate success를 못 올림 — 핵심 주장은 task 보존이지 성능 향상이 아님 - 통계적 유의성은 약함: seed-level Fisher exact test로 fixed vs controller p=0.400이고, seed 3개뿐이라 도달 가능한 최소 p값이 0.100이라 설계상 0.05 유의수준에 못 미침 - controller seed 간 spread(SD 0.013)는 rescoring noise floor(0.0147~0.0375) 안에 들지만, fixed noise seed 간 spread(0.194)는 그 floor의 5배 이상이라 seed 재현성 차이는 신뢰할 만함 - 저자가 직접 수행한 재현 실험(ReinFlow 자체 benchmark, 8 task·2 policy class)에서는 controller 우위가 엄격한 기준으로는 사라짐(양의 분리 없음, 음의 분리 2건). fp32 master copy pilot(단일 seed)에서는 같은 학습률이 controller도 3/7까지 collapse시킴 — 코드·모델 가중치는 anonymized 저장소로 공개 예정(review 단계, ICLR 2027 submission)
누리랩 연구와의 연결
- online RL fine-tuning 중 task collapse를 미리 잡아내는 신호(RND novelty + critic value/ensemble spread)는 실로봇 배포 중 failure detection·recovery 신호로 전용 가능함 — 동일 신호를 test-time policy uncertainty proxy로 재사용하는 아이디어임 - 4가지 pre-registered collapse 정의(pooled/point/sustained/ever)와 dual-ruler(Wilson interval + rescoring SD) 측정 방법론은 우리 lab의 test-time optimization·online learning 실험에서 seed noise와 실제 효과를 구분하는 프로토콜로 차용할 만함 - "task success가 0으로 떨어지면 reward가 다시 안 들어와 복구가 막힌다"는 관찰은 robot memory·failure recovery 연구에서 collapse가 일어나기 전에 개입하는 조기 경보 메커니즘 설계의 근거로 쓸 수 있음

오늘의 핵심 연구 트렌드 종합

  • world model에서 search 구조 자체를 바꾸는 흐름 — Representation World Model은 현재-목표 latent를 선형보간한 경로에 inverse dynamics만 적용해 CEM 같은 rollout search를 통째로 없앰. Aim Short to Reach Far는 frozen world model이 final-goal distance만 채점하면 영원히 못 움직이는 반례를 증명하고, 기록된 경로에서 중간 target을 검색하는 방식으로 우회함.
  • counterfactual 신호를 학습 신호로 직접 쓰는 흐름 — AD-WM은 factual prediction 정확도와 counterfactual action 구별 능력이 별개임을 지적하고 action recovery head로 MPC용 latent를 제약함. ActGaze는 이미지 영역을 지우고 action loss 변화를 재는 counterfactual intervention으로 gaze supervision을 만듦. 둘 다 counterfactual reasoning을 진단이 아니라 학습 신호로 씀.
  • 배포 후 자기 경험만으로 스스로 보정하는 흐름 — PACL은 사람 개입 없이 쌓인 성공·실패 혼합 rollout으로 offline RL 후처리를 함. Self-Adaptive VLA는 하드웨어 오정렬을 자기 실패 rollout으로 감지해 AdaLN(adaptive layer normalization) 주입으로 보정함. human correction 없는 test-time self-improvement가 공통 문제 설정으로 자리잡음.
  • world-action model의 실시간 효율화 흐름 — DeltaWAM은 delta token 압축으로, Streaming-WAM은 committed action을 조건으로 쓰는 방식으로 world-action model의 추론 비용을 줄임. 두 논문 다 성능 향상보다 속도-정확도 trade-off 개선이 핵심임. novelty는 기존 요소의 재조합 수준으로 스스로도 인정함.
  • VLA online RL fine-tuning의 숨은 실패 모드 — Uncertainty-Gated Exploration은 online RL 중 평균 성공률은 멀쩡해 보여도 개별 task가 완전히 무너지는 task collapse를 정의하고 측정 프로토콜을 제시함. 제안한 controller도 behavior cloning baseline을 못 넘었다는 부정적 결과를 그대로 보고함.
  • persistent object-centric memory로 장기 조작을 지원하는 흐름 — OCC4M은 물체별 world-frame 좌표를 유지하는 4D memory를 VLM이 episode당 한 번만 조회하게 해 가려진 물체·뒤섞인 컨테이너 문제를 풂. "과거 위치는 고정, 현재 위치는 live 추적"이라는 분리가 여러 논문의 memory 설계에서 반복적으로 등장함.

유망 연구 방향 및 프로젝트 제안

Elite-regret 기반 world model 평가 지표를 test-time planning 진단에 도입 - Research question: factual prediction error나 전체 순위 상관 대신, planner가 실제로 쓰는 elite 후보군(예: CEM이 매 iteration 추리는 상위 k개 후보) 기준 regret이 closed-loop 성공률을 더 잘 예측하는가. - 접근·novelty: AD-WM의 elite-regret 지표(R_k, R̄_k)를 누리랩의 world model 실험(factual MSE만 보고하던 관행)에 이식하고, 여기에 실패 rollout까지 포함한 elite-regret 분포를 추가해 실패 직전 상태에서 지표가 무너지는지 검증. - 왜 지금·경쟁 prior works: AD-WM은 Franka pick-and-place 하나에서만 검증했고 실패 조기 진단으로는 못 씀 — 이 gap을 채우는 방향. - risk·target venue: 새 지표의 일반화가 다른 world model 아키텍처에서도 성립하는지가 관건. CoRL 또는 RSS 워크숍용 실험으로 먼저 검증 가능.

Counterfactual attribution을 실패 원인 localization으로 확장 - Research question: 실패 직전 프레임에 counterfactual visual intervention을 걸었을 때 action loss가 크게 뛰는 영역이 실제 실패 원인과 일치하는가. - 접근·novelty: ActGaze의 masking/blurring 기반 attribution을 성공 gaze 학습이 아니라 실패 사후 진단에 적용. AD-WM의 action recovery 신호와 결합해 정상 행동과 실패 행동의 counterfactual 차이를 명시적으로 대조. - 왜 지금·경쟁 prior works: ActGaze는 성공 데이터로만 gaze를 학습해 실패 진단에는 안 씀. Embodied Interpretability·AGRA 등 동시기 연구도 사후 분석에 그침 — 진단을 실시간 recovery trigger로 연결하는 논문은 아직 없음. - risk·target venue: 실패 sample 수가 적어 통계적 유의성 확보가 어려울 수 있음. CoRL 또는 실패 detection 전용 워크숍.

Search 없는 world model planning을 VLA policy에 이식 - Research question: latent interpolation + inverse dynamics로 만든 search-free planning이 VLA policy의 test-time replanning에서도 CEM 기반 방법을 대체할 수 있는가. - 접근·novelty: RWM의 encode-construct-decode 구조를 VLA latent space에 붙이고, 재인코딩된 z_t가 애초 경로에서 벗어나는 정도를 실패 조기 감지 신호로 재사용. - 왜 지금·경쟁 prior works: RWM은 sim 4개 task와 LIBERO-Goal에서만 검증했고 replanning 간격이 길어지면 성능이 98.33%→69.17%로 급락함 — 실로봇·긴 horizon에서의 강건성이 미해결. - risk·target venue: interpolation 전제(직선 경로가 실행 가능하다는 가정)가 접촉 많은 조작에서 깨질 수 있음. CoRL 도전, 실패 시 ICRA로 하향.

Persistent 4D memory와 object-centric 3DGS 결합 - Research question: OCC4M 식 world-frame object memory의 containment/motion 관계를 규칙 기반 threshold 대신 3DGS 기반 표현으로 대체하면 관계 추출 정확도와 실패 복구 성능이 함께 오르는가. - 접근·novelty: OCC4M의 "과거 위치 고정, 현재 위치 live 추적" 분리를 유지하되 각 track을 3D Gaussian cluster로 표현해 occlusion 후 재등장 시 identity 보존을 정량 평가. - 왜 지금·경쟁 prior works: OCC4M은 SAM 3 검출 + 12cm gated matching이라는 hand-tuned rule에 의존해 관계 추출이 deterministic함 — object-centric 3DGS 연구가 이 지점을 대체할 수 있는 명확한 진입점. - risk·target venue: 3DGS 갱신 비용이 실시간 조작에 비쌀 수 있음. CVPR(3D representation 축) 또는 CoRL.

하드웨어 shift를 넘어선 self-adaptive VLA 확장 - Research question: Self-Adaptive VLA의 context-token ensemble 보정이 actuation bias·encoder offset을 넘어 조명 변화·object pose shift 같은 시각적 이상에도 적용되는가. - 접근·novelty: shift-조건부 데이터 자동 생성 파이프라인을 시각적 도메인 shift로 확장하고, world model 기반으로 실패 원인을 명시적으로 추론하는 단계를 추가해 무엇이 왜 틀렸는지까지 설명하도록 함. - 왜 지금·경쟁 prior works: Self-Adaptive VLA는 두 종류의 constant-offset shift만 다루고 카메라 캘리브레이션 등은 미해결로 남김 — 저자도 명시한 gap. - risk·target venue: 시각적 이상은 shift가 벡터로 깔끔히 분리되지 않을 수 있어 직교성 가정이 깨질 위험. CoRL.
