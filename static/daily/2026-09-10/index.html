Programmable World Model

arXiv PDF alphaXiv
World Model relevance 6/10 Computer Vision and Pattern Recognition (cs.CV)
Zheng-Hui Huang, Guixu Lin, Jiacheng Lin, Yi-Chuan Huang, Ruihan Yu, Muyao Niu, Siqi Yang, Yu-Lun Liu 외 3명 PDF 전문 1차 60점
비디오 월드모델이 지속적인 world state를 기억하지 못한다는 문제에서 출발해, 자연어 지시를 실행가능한 프로그램으로 변환해 state를 explicit engine으로 관리하고 이를 3D bounding box(OBB) 기반 조건 신호로 압축해 영상 생성기에 넣는 Programmable World Model을 제안함. 자체 제작한 CombatStateBench에서 Count Accuracy 94%, State Accuracy 98%로 기존 interactive video world model들을 크게 앞섬.
Core Innovation & Methodology
- world-state evolution을 explicit engine으로 분리하고 video model은 그 state를 조건으로 받아 렌더링만 담당하도록 문제를 재정의함 - 자연어 지시를 coding agent가 entity state·transition rule을 담은 실행가능한 world program으로 변환하고, lightweight engine이 이를 실행해 canonical state를 관리함 - state-augmented 3D oriented bounding box(OBB)를 world state와 visual generation을 잇는 중간 표현으로 도입, deterministic state compiler가 target camera 궤적에 맞춰 pixel-aligned identity/semantic/direction map으로 컴파일함 - 사전학습된 camera-controlled video model(LingBot-World-v1)에 trainable Structured Spatial ControlNet을 붙이고, chunk-autoregressive 방식과 geometry-aligned spatial memory로 long-horizon rendering을 지원함
Novelty vs. Prior Works
- 비교 대상인 StatePlay는 state 자체를 모델이 예측해 오차가 누적될 수 있는데, 본 논문은 state transition을 학습된 예측이 아니라 프로그램된 규칙으로 결정론적으로 실행해 오차 누적 문제를 구조적으로 피함 - MASS도 authoritative shared state를 두지만 transition은 learned Logic Engine이 담당하는 반면, 본 논문은 transition 자체를 rule engine이 담당해 상태 진화를 검증 가능하게 만든 점이 본질적 차이임 - representation 선택을 training-inference asymmetry로 분석하고 OBB를 중간 지점으로 정당화한 논리는 설득력 있으나, OBB 자체는 기존 3D detection 표현의 재활용이라 표현 방식 자체의 새로움은 제한적임
Benchmark Results
- 자체 제작 CombatStateBench(50 clip)에서 Count Accuracy 94.00%, State Accuracy 98.00%로 LingBot-World-V2(40.75%, 8.00%)와 YUME(32.00%, 58.00%)를 큰 차이로 앞섬 - VBench 기반 Imaging Quality·Subject Consistency·Background Consistency·Temporal Stability 네 지표 모두 최고치를 기록했으나 Imaging Quality는 67.62 vs 67.46으로 baseline과 거의 차이 없음 - 비교 baseline들은 instance-level state interface가 없어 prompt switching으로만 state를 전달했다는 한계가 있어, 비교 자체가 본 논문에 유리하게 설계됐을 가능성이 있음 - Cyberpunk 2077·Forza Horizon 6·GTA V 게임 영상으로만 학습·평가한 sim/게임 전용 설정이며 실로봇 검증은 없음, 코드와 프로젝트 페이지는 공개됨 - 정량적 ablation 표는 없고 Figure 4, 5의 정성적 비교로만 기여도를 제시해 각 구성요소(identity/semantic/direction map)의 개별 효과는 확인 불가
누리랩 연구와의 연결
- world state를 explicit rule engine으로 분리하는 아이디어는 robot manipulation에서 task progress·inventory 같은 symbolic state 관리와 failure detection 시 state mismatch 검증 신호로 응용 가능함 - entity를 persistent OBB와 attribute로 관리하는 방식은 scene graph/semantic mapping의 node 표현과 맞닿아 있어, object-centric 3DGS 연구와 결합해볼 수 있음 - rule engine이 state transition을 결정론적으로 실행한다는 점은 counterfactual reasoning 기반 test-time planning에서 특정 action이 world state에 미치는 영향을 시뮬레이션하는 데 아이디어를 빌릴 수 있음

Show-Harness: Just a VLM Agent Can Play Robots

arXiv PDF alphaXiv
VLA Embodied AI relevance 9/10 Robotics (cs.RO)
Yanzhe Chen, Zechen Bai, Zhijun Cao, Wenzheng Zeng, Kevin Qinghong Lin, Yiqi Lin, Guoqiang Liang, Kevin Yuchen Ma 외 2명 PDF 전문 1차 54점
VLM이 로봇을 직접 제어하도록 방향·회전·grasp 단위의 이산 semantic action 어휘와 embodiment별 결정론적 interpreter로 구성된 Show-Harness를 제안함. 같은 인터페이스로 closed-source VLM은 zero-shot, 2B급 open VLM은 몇 GPU-hour LoRA로 로봇을 조작하며 VLA·agent baseline 대비 일관되게 높은 성공률을 보임.
Core Innovation & Methodology
- VLM에 노출되는 action space를 8개 이산 semantic unit(MV_*, ROTATE_*, GRASP/RELEASE, DONE)으로 제한해 VLM이 native vocabulary로 직접 예측하게 함. ablation상 성능을 견인하는 건 이 이산 convention 자체이고 semantic 이름은 보조적 요인임. - embodiment별 interpreter가 semantic unit을 6-DoF Cartesian pose delta로 결정론적으로 변환해, VLM이 fine-grained 물리 결정에 계속 책임을 지게 함. - perceive-reason-act 3단계 harness에 subtask planning, situated planning, action chunking, adaptive step, failure recovery 등 plugin을 붙여 closed-loop 실행을 구성함. - 같은 semantic action space를 GUI 조작(GUMI)에도 노출해 사람·VLM 모두 teleoperation 하드웨어 없이 시연 데이터를 모으게 함.
Novelty vs. Prior Works
- 기존 VLA는 VLM을 continuous/discretized low-level action에 fine-tuning해 semantic 지식을 opaque mapping으로 무너뜨리고, 기존 agentic 시스템은 VLM이 상위 결정만 하고 실제 물리 실행은 불투명한 하위 컨트롤러에 맡김. - Show-Harness는 VLM이 fine-grained 물리 결정을 직접 내리되 표현은 여전히 이산 semantic 단위라는 점에서 두 극단의 중간을 채움. - action space 표현 ablation에서 성능을 견인하는 건 명시적 convention이고 semantic 이름 자체는 보조적 prior에 가까워, 이름 자체의 의미가 핵심이라는 주장을 스스로 제한함.
Benchmark Results
- 10개 real-robot task 평균 성공률은 ZS 89%, FT 86%로 baseline 최고인 RATS 57.0%, π0.5 39.0%, GR00T 35.0%를 크게 상회함. - cross-environment(배경·조명·시점·방해물·sim-to-real) 평균은 ZS 100%, FT 88%인데, π0.5·GR00T는 sim-to-real에서 20회 모두 실패(0/20)함. - cross-embodiment(Franka·AgileX)에서 ZS 93%, FT 87%로 baseline 최고인 RATS 52%를 상회함. - interpreter step을 2cm에서 1cm로 줄이기만 해도 VLM action interface 변경이나 재훈련 없이 ZS는 60%에서 82%, FT는 40%에서 65%로 오르지만, π0.5는 같은 FT 시연 데이터로는 18%에 그치고 정밀 동작 전용으로 추가 fine-tuning해야 62%까지 오름. - 검증 범위는 Franka·AgileX 두 embodiment, parallel-jaw gripper only, task 10종 중심이며 code·모델·데이터셋은 공개하나 humanoid·dexterous hand로는 미검증임.
누리랩 연구와의 연결
- continuous action regression 대신 이산 semantic unit과 deterministic interpreter로 나누는 설계는 누리랩 VLA formulation 논의에서 action tokenization 대안으로 참고할 수 있음. - Failure Recovery plugin(빈 grasp 감지 후 rollback)은 단순하지만 바로 재현 가능한 실패 복구 baseline으로 쓸 수 있음. - thinking effort와 backbone 선택에 따른 성능-지연 trade-off 분석은 test-time optimization 연구에 직접 참고 가능함.

JEPA Policy: Diffusion-Free Imitation Learning via Paired Action and Future Representation Prediction

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Jie Xu, Kangjin Yu, Ziyi Jin, Junjie Gao, Liqing Chen, Yixian Li, Shuai Tian, Zhongpu Xia PDF 전문 1차 58점
standard behavior cloning이 action만 supervise하고 그 결과 도달하는 미래 상태는 제약하지 않는다는 문제에서 출발해, action chunk와 관찰된 미래 표현을 하나의 shared Transformer에서 함께 예측하는 diffusion-free JEPA Policy를 제안함. 9개 시뮬레이션 task에서 action-only MIP 대비 평균 성공률 5.6점 개선했고 Diffusion Policy 대비로도 전 task에서 앞섰으며, 5-task 630-episode 실로봇 실험에서도 같은 순위를 재현함.
Core Innovation & Methodology
- action chunk와 demonstration에서 관찰된 미래 표현(future representation)을 짝지어 하나의 shared Transformer에 넣고 매 self-attention layer에서 상호작용하게 해 future 예측이 action 표현을 직접 형성하도록 설계함 - minimal iterative policy(MIP)의 coarse-to-refined 2-step 방식을 action과 future representation 예측에 동시에 확장해, diffusion 없이 두 번의 forward pass만으로 추론함 - future target은 pixel 재구성이 아니라 같은 encoder에서 얻은 latent이며 stop-gradient만 적용하고, EMA/frozen target encoder나 variance-covariance regularizer 없이 action loss 자체를 collapse 방지 제약으로 사용함 - 배포 시 예측된 미래 표현과 실제 실행 후 관찰된 미래 표현의 차이(future-consistency error)를 rollout-level 진단 신호로 제공함
Novelty vs. Prior Works
- 가장 가까운 ACT-JEPA는 context encoder는 공유하지만 predictor·decoder가 분리된 두 branch라 attention 상호작용이 없고 EMA target encoder로 collapse를 막는데, 본 논문은 이를 하나의 attention stack으로 합치고 EMA 없이 action loss만으로 collapse를 막는다는 구조적 차이를 Dual-independent·Dual-cross ablation으로 직접 검증함 - VLA-JEPA, JEPA-VLA는 사전학습 VLM·video representation을 활용하는 반면 본 논문은 encoder를 처음부터 task demonstration만으로 학습해 사전학습 표현의 기여를 배제하고 topology 효과만 분리했는데, 그만큼 대규모 VLA 백본 스케일로의 일반화는 검증되지 않음 - future-consistency error를 failure diagnostic으로 쓰는 아이디어는 Sentinel, FAIL-Detect 같은 기존 runtime monitoring 연구와 유사한 문제를 다루지만, 학습 목적함수의 부산물로 얻는다는 실용성이 있는 대신 저자도 task별로 calibrate해야 하는 좁은 범위의 신호라고 인정함
Benchmark Results
- LIBERO·robomimic·MimicGen 9개 task, 3 seed 평균에서 9-task 평균 성공률 83.0%로 action-only MIP(77.4%) 대비 +5.6점, 9개 task 전부 양의 개선이며 sign test p=0.0039 - Diffusion Policy(10-step) 대비 9개 task 전부 우위이나 Tool Hang(75.0% vs 46.7%)이 격차의 상당 부분을 차지해 이 task를 빼면 평균 차이는 +5.4점으로 줄어듦 - shared-attention topology 자체가 기여의 핵심임을 보이는 ablation에서, 같은 future loss를 분리된 branch(Dual-independent 76.3%, Dual-cross 77.6%)로 넣으면 MIP 대비 이득이 거의 사라짐 - 실로봇 5-task 630-episode 실험에서 Diffusion Policy 대비 30개 중 29개 checkpoint-task 조합에서 우위(p≈1.22e-4)이나, MIP 대비는 15개 중 9승 4패 2무로 방향성만 있고 통계적으로 유의하지 않음(p=0.27) - decision latency는 MIP 대비 0.29ms(2.2%) 추가에 그쳐 13.2ms로 Diffusion Policy(439.5ms) 대비 33배 빠르나, 실험 전체가 ResNet-18/DINOv2 기반 소규모 encoder 세팅이고 대규모 VLA 백본에서의 검증은 없음
누리랩 연구와의 연결
- future-consistency error를 이용한 rollout-level 진단 신호는 failure detection/recovery 연구에 바로 붙일 수 있고, task-conditioned threshold를 학습해 실패 예측 성능을 높이는 후속 실험이 가능함 - shared attention을 통해 future 예측이 action 표현을 형성한다는 결과는 world model 예측과 policy를 분리하지 않고 하나의 표현으로 묶는 설계로, test-time optimization에서 future prediction error를 보고 action을 온라인으로 재조정하는 방향에 활용 가능함 - diffusion-free 2-step 구조라 low-latency가 필요한 robot memory·실시간 replanning 세팅에 적합하며, 다른 action을 가정했을 때의 future representation 차이를 보는 counterfactual reasoning 확장도 가능함

Time-Frequency Geometric Cross-Attention for Chunked Vision-Language-Action Models

arXiv PDF alphaXiv
VLA relevance 9/10 Artificial Intelligence (cs.AI)
Shengye Dong, Haochen Niu, Hao Liu, Peiwen Lin, Chuang Wang, Shanmin Pang PDF 전문 1차 70점
action chunk를 시간-주파수로 분해하고 dot product와 wedge product를 함께 쓰는 cross-attention 모듈 TFGCA를 제안함. 기존 VLA(π0.5)에 drop-in으로 붙여 LIBERO·LIBERO-Plus·RoboTwin·실로봇 AgiBot A2에서 일관되게, 특히 분포 밖(OOD) 조건에서 크게 성능을 올림.
Core Innovation & Methodology
- action chunk 안에서 reach·contact·grasp 같은 단계별 움직임이 표현 공간에서 서로 거의 직교(near-orthogonal)한다는 관찰에서 출발함(TO-DoL: 단계별 action의 시간-직교성을 재는 저자 정의 지표). - dot product attention은 정렬(similarity)만 보고 직교 관계에는 둔감하다는 한계를 지적하고, wedge product 크기(∥q∧k∥² = ∥q∥²∥k∥² − (q⊤k)²)를 추가 점수 채널로 씀. - action을 per-dimension learnable stationary wavelet transform(SWT)으로 분해해 시간-주파수 토큰을 만들고, 시간 토큰이 이 토큰들을 dot+wedge 블렌드로 조회함. - 출력 projection을 0으로 초기화해 초기 상태에서는 base 모델과 동일하게 동작하도록 설계, 사전학습된 VLA에 이어 붙여 fine-tune 가능함.
Novelty vs. Prior Works
- frequency decomposition(Autoformer, FEDformer, SimpleTM)과 geometric attention(Geometric Algebra Transformer)은 시계열 예측에서 이미 쓰이던 기법이고, 이를 VLA action chunk에 처음 결합한 응용 성격이 강함. - FAST(DCT 기반 action tokenization)와 달리 frequency를 압축·토큰화가 아니라 연속적 flow-matching attention의 key로 쓴다는 차별점은 있으나, 핵심은 기존 두 아이디어의 재조합임. - wedge product의 근접-직교 민감성은 이론적으로 증명(Proposition 1)했지만, cross-phase 관계가 실제로 wedge 채널이 잡아내는 방향에 놓인다는 인과적 증거(Q/K routing 분석)는 제시하지 못하고 향후 과제로 남김.
Benchmark Results
- LIBERO 4-suite 평균: π0.5 재현 96.7% → TFGCA 98.2% (+1.5pt), 이미 거의 saturate된 벤치마크라 gap이 작음. - LIBERO-Plus(7종 OOD perturbation) Total: 66.7% → 73.0% (+6.3pt), Noise·Robot·Camera에서 개선폭이 큼. - RoboTwin 2.0 domain randomization 6-task 평균: clean +3.7pt, randomized +28.5pt (42.7%, 학습 시 미노출 조건에서 zero-shot 개선). - 실로봇 AgiBot A2 3개 task, 총 60회 시행: 50.00% → 61.67% (+11.67pt), 티슈 뽑기 task에서 +15pt로 가장 큼. - component ablation(w/o SWT, w/o geometry, w/o alignment) 모두 제거 시 성능이 하락함. LIBERO에서는 alignment loss가, LIBERO-Plus에서는 geometry(wedge) 채널이 가장 중요해 역전됨. - 코드·모델 공개 여부는 본문에서 확인 불가.
누리랩 연구와의 연결
- action chunk를 시간-주파수로 나누는 아이디어는 failure detection에도 응용 가능함 — 고주파 correction 성분이 비정상적으로 커지는 순간을 접촉 실패나 재시도 신호로 쓸 수 있음. - chunk 재계획 주기를 frequency 정보로 정하자는 저자들의 future work는 test-time optimization 방향과 직접 연결됨. - wedge product로 근접-직교 관계를 포착하는 설계는 scene graph에서 서로 다른 물체·관계 임베딩 간 상보성을 다루는 attention에도 적용해볼 만함.

Semigroup-JEPA: Latent Dynamics Consistency for Zero-Shot Physics Generalization

arXiv PDF alphaXiv
World Model relevance 7/10 Machine Learning (cs.LG)
Andy Zeyi Liu, Haoran Sun, Lucas Baker, Randall Balestriero, John Sous PDF 전문 1차 62점

Core Innovation & Methodology
- world model(action-conditioned Wan2.2 기반)이 생성한 8프레임 rollout의 신뢰도를 DINOv3 유사도·depth consistency·optical-flow trajectory consistency·MUSIQ 4개 지표의 평균으로 정의한 hallucination target으로 지도학습함(HAM). - HAM은 예측 영상·현재/기준 이미지·action을 fusion transformer로 합쳐 chunk 단위 hallucination score를 0~1로 출력함. - Reward-Soft 기법으로 raw reward R을 (1−α·H)·R로 깎아, hallucination이 심한 action chunk의 보상 영향을 줄이고 GRPO advantage 계산에 반영함. - world model, HAM, reward model, GRPO를 묶은 closed-loop pipeline으로 OpenVLA-OFT를 8개 병렬 imagined environment에서 online 학습시킴.
Novelty vs. Prior Works
- 저자 스스로 WoVR을 baseline으로 삼아 그 world model(Wan2.2 action-conditioned)을 그대로 가져다 쓰고, HAM과 Reward-Soft만 새로 얹은 구조로, world model 자체나 RL 알고리즘(GRPO)은 기존 것을 그대로 씀. - hallucination을 다중 지표 조합의 continuous score로 정의한 점은 WoVR의 keyframe 기반 접근과 달리 명시적 검증(AUROC 0.9375)을 거쳤다는 차별점이 있음. - reward를 hallucination으로 downweight하는 아이디어 자체는 world model RL 문헌에서 이미 논의되던 방향이라, 새로운 problem formulation이라기보다 기존 파이프라인의 구성요소 교체·보강에 가까움.
Benchmark Results

누리랩 연구와의 연결
- hallucination score를 학습해 world model rollout 신뢰도를 정량화하는 방식은 nurilab의 failure detection·recovery 연구에 그대로 가져다 쓸 수 있음 — 실행 전 rollout 신뢰도로 재시도·개입 시점을 판단하는 test-time 안전장치로 응용 가능함. - world model 기반 policy optimization은 test-time optimization/inference-time planning 주제와 직접 연결되며, HAM 같은 신뢰도 모델을 counterfactual reasoning(가상 rollout의 타당성 검증)으로 확장할 수 있음. - 4개 지표(DINOv3, depth, optical flow, MUSIQ) 조합 설계는 world model 평가나 robot memory에 rollout을 저장할 때 품질 필터링 기준으로도 재사용 가능함.

  • Programmable World Model — world state를 explicit rule engine으로 분리해 오차 누적을 구조적으로 피한 설계로, 오늘 최고점을 받음.

  • Time-Frequency Geometric Cross-Attention (TFGCA) — action chunk를 시간-주파수로 분해하는 관점이 failure detection·test-time optimization에 응용 가능함.
  • Semigroup-JEPA — world model이 훈련 분포 밖 물리 조건으로 실제 일반화하는지 검증하는 실험 프로토콜 자체가 평가 설계에 참고할 가치가 있음.

  • DUET-DINO — dual-view cross-attention으로 rotation·gripper까지 포함한 fine-grained latent planning을 처음 다룸.
  • Identifying Habit, Physics, and Nuisance in Robot World Models — teleoperation 데이터의 operator habit을 물리 법칙과 분리하는 causal formulation이 counterfactual reasoning 주제와 정확히 맞물림.
