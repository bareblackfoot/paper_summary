HuRo: Robotizing Human Videos for Scalable VLA Pretraining

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Jinho Jeong, Se June Joo, Jaehyun Kang, Dongyun Kim, Yena Kim, Hanjung Kim, Seon Joo Kim PDF 전문 1차 78점
사람 착용형(egocentric) 비디오를 로봇 관측·행동 데이터로 변환하는 robotization 파이프라인으로 630K episode, 142M frame 규모의 HuRo 데이터셋을 만들어 VLA policy를 사전학습함. 4개 실제 로봇 조작 task에서 사전학습 규모를 키울수록 성능이 꾸준히 오르고, ID 완료율 68.1%에서 88.4%로, OOD 완료율 34.9%에서 72.2%로 개선됨을 보임.
Core Innovation & Methodology
- 사람 비디오를 카메라 추정·손 자세 추정·VLM captioning으로 주석하고, 부족한 중간 신호(카메라 궤적, 손 자세 등)를 추정으로 채워 이종 source를 공통 포맷으로 변환하는 3단계(annotation-action conversion-visual conversion) robotization 파이프라인을 제안함 - action conversion은 PyRoKi로 손 동작을 로봇 관절 궤적에 retargeting하고, visual conversion은 SAM2로 사람 팔을 제거·inpainting한 뒤 Isaac Sim으로 렌더링한 로봇을 overlay함 - Ego4D, EPIC-Kitchens, EgoDex, EgoVerse, Ego10K 5개 source를 통합해 630K episode·142M frame 규모의 HuRo dataset을 구축함 (기존 robotized-video 사전학습보다 한 자릿수 이상 큼) - GR00T-N1.6-3B backbone에 flow-matching 기반 action head를 붙여 robotized observation과 retargeted action으로 end-to-end VLA 사전학습을 수행함
Novelty vs. Prior Works
- H2R·Masquerade는 robotized video를 visual encoder 사전학습이나 보조 예측 목적으로만 쓰고, Phantom·DexUMI·WARPED·RwoR는 task-matched 세팅에서만 observation-action robotization을 검증한 반면, 본 논문은 이종 source 전체에 걸쳐 obs-action을 함께 robotize해 범용 VLA 사전학습 데이터로 스케일업한 것이 차별점임 - VITRA·EgoScale은 사람 중심 관측을 유지한 채 action만 robot에 맞춰 supervision을 만드는데, 본 논문은 관측까지 robot-aligned로 바꿔야 OOD 성능이 크게 좋아짐(no-overlay ablation)을 실증함 - 다만 방법 자체는 SAM2·DROID-SLAM·HAWOR·PyRoKi·Isaac Sim 등 기존 perception/retargeting/rendering 모듈을 조합한 pipeline engineering에 가까워, 새로운 representation이나 learning paradigm은 아님. 기여는 알고리즘보다 대규모 실증(scaling study)에 있음
Benchmark Results
- ALLEX 양팔 dexterous robot의 실제 4개 조작 task(Apple Pick-and-Place, Cup Stacking, Cup-Noodle Handover, Microwave Loading)에서 HuRo 0%에서 100% 사전학습 스케일로 늘릴 때 overall completion이 51.5%에서 80.3%로 상승함. 이는 ID completion 68.1%→88.4%와 OOD completion 34.9%→72.2%의 평균임 - visual robotization 유무 비교에서 no-overlay는 ID는 비슷(89.4% vs 88.4%)하지만 OOD는 크게 낮음(55.7% vs 72.2%)했고, 심지어 10% PT(59.5%)보다도 낮아 visual robotization의 OOD 기여를 확인함 - Diverse Pick-and-Place에서 action까지 포함한 end-to-end 사전학습(PT Visual+Action)은 ID 61.1%·OOD 50.0%를 기록해, visual pathway만 전이한 PT(Visual Only)보다 크게 앞서 action supervision의 별도 기여를 보임(정확한 격차는 원문 확인 필요) - DreamGen 스타일 I2V+IDM baseline과 동일 frame budget(0.7M/3.5M/7M)에서 비교했을 때 HuRo가 전 구간에서 우세했고, HuRo 0.7M이 I2V+IDM 7M보다도 높은 성능을 보여 스케일링 효율이 더 좋음을 시사함 - 실제 배포된 π0.5, GR00T N1.6 fine-tune 대비 full-scale HuRo가 ID·OOD 모두 앞섰으나(overall 80.3 vs 48.2, 52.0), fine-tuning demo가 task당 16~43개로 적고 단일 embodiment(ALLEX)에서만 검증됨
누리랩 연구와의 연결
- VLA 사전학습 데이터 스케일업 문제에서 사람 비디오 robotization이 실제 real-robot task에서 OOD 성능을 크게 올린다는 실증은 누리랩의 VLA/manipulation 연구에 baseline pretraining recipe로 바로 참고할 만함 - visual robotization이 OOD에 크게 기여한다는 결과는 test-time optimization·failure detection 연구에서 관측 domain gap을 줄이는 것이 policy robustness에 미치는 영향을 분석하는 근거로 쓸 수 있음 - 논문이 스스로 밝힌 self-collision·contact 미모델링 한계(288개 궤적 중 55.2%만 non-self-contact)는 robot memory나 failure recovery 관점에서 robotized data의 신뢰도 진단·필터링 방법을 얹는 후속 연구로 확장 가능함

Memory as Plans: World-Action Modeling with Memory-Grounded Planning

arXiv PDF alphaXiv
World Model Robot Memory relevance 9/10 Robotics (cs.RO)
Sizhe Zhao, Haozhe Xie, Weiyu Zhao, Chenchu Zhang, Huan Wang, Chenyang Wang, Qinglin Liu, Shengping Zhang PDF 전문 1차 74점
장기 기억이 필요한 non-Markovian 로봇 조작을 memory-grounded planning과 plan-conditioned execution으로 분리한 MaP-WAM을 제안함. 완료된 segment를 언어+희소 visual context로 압축해 다음 plan을 생성함. World-Action-Progress 모델이 execution progress를 함께 예측해 executor context를 고정한 채 RMBench 83.3%·실로봇 평균 78% 성공률을 달성함.
Core Innovation & Methodology
- Memory-as-Plans 분해: 과거 관측 전체를 executor에 반복 입력하지 않고, 장기 기억 처리(planning)와 고정 길이 실행(execution)을 분리함 - 에피소드 메모리는 segment 단위 record(언어 instruction + 8프레임 희소 visual context)로 저장함. VLM이 다음 언어 plan을, causal world model(CWM)이 시각적 plan을 생성함 - World-Action-Progress(WAP) 모델은 Mixture-of-Transformers로 action chunk와 progress(0~1 정규화)를 함께 예측해, plan 실행 길이가 가변적인 문제를 해결함 - plan-observation alignment는 현재 관측을 visual plan 프레임과 비교해 progress를 보정하고, 이를 기준으로 segment 전환 시점을 결정함
Novelty vs. Prior Works
- 가장 가까운 baseline인 LingBot-VA는 growing prefix 방식 causal world-action-model(WAM)이라 history가 늘수록 latency·GPU memory가 증가함. MaP-WAM은 executor context를 고정해 이 trade-off를 구조적으로 없앰 - MemER/Mem-0/MEM 같은 language memory 방식은 fine-grained visual evidence를 버림. MaP-WAM은 언어 plan과 함께 CWM이 생성한 visual plan을 유지해 이 손실을 줄임 - progress를 post-hoc verifier가 아니라 action과 공동 생성되는 modality로 다룬 점은 실행-계획 결합에 새로운 기여지만, memory-as-plans 분해 자체는 goal/plan-conditioned policy 계열의 확장에 가까워 novelty는 제한적임
Benchmark Results
- RMBench 9개 task 평균 성공률 83.3%로 SOTA. LingBot-VA 77.1%, Mem-0 42.0%, π0.5 10.4%, DP 5.8% 대비 우위임. 단 task당 demo 50개인 소규모 학습 세팅임 - 실로봇 Franka 7-DoF 2개 task에서 Find Button 88%, Press Buttons 68%(각 50 trial) 달성함. baseline π0.5·FastWAM은 Press Buttons에서 0% - executor latency는 history 1,500프레임까지 약 827ms로 거의 일정함. full-context 방식은 같은 조건에서 약 4배 latency, 1,700프레임에서 GPU memory 80GB 초과로 OOM 발생 - ablation: visual plan 제거 시 Observe&Pick/Swap T 성공률이 19%/96%에서 14%/13%로 급락함 - progress modeling을 classification으로 대체하면 3-task 평균 96.7%에서 37.0%로 급락, calibration 제거 시 73.7%로 하락함. calibration 효과는 423 step짜리 최장 task에서 가장 큼
누리랩 연구와의 연결
- progress-gated transition과 plan-observation alignment는 실행 중 관측과 계획을 비교해 상태를 보정하는 구조라, test-time failure detection·recovery 연구에 재사용 가능함 - segment 단위 episodic memory 구조는 robot memory 연구의 강한 비교 baseline임. segment 경계를 benchmark 라벨에 의존한다는 한계는 자동 segment discovery로 이어질 여지가 있음 - CWM이 planning 시점에만 관여하고 execution 시점엔 관여하지 않는 설계는, world model을 쓰면서 실행 latency 부담을 피하는 패턴으로 다른 world-model 기반 정책에도 적용 가능함

UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Wei Li, Rui Shao, Jie He, Lingsen Zhang, Ziwei Liu, Liqiang Nie PDF 전문 1차 63점
VLA policy가 observation을 action으로 바로 매핑할 때 생기는 문제를 transition realizability gap으로 정식화함. future prediction과 bidirectional memory, flow matching을 action-grounded transition 하나로 묶은 UniMPA를 π0.5 backbone에 world expert와 두 개의 memory bank를 더해 구현함. LIBERO, LIBERO-Plus, RoboTwin 2.0 Hard, real-world 전부에서 baseline보다 성능을 올리면서 학습 epoch은 25-50%로 줄임.
Core Innovation & Methodology
- observation-to-action 직접 매핑에서 생기는 transition ambiguity(관측만으론 결과 예측 불가), prediction-execution mismatch(예측과 실제 실행 결과 불일치), experience-realization mismatch(과거 경험과 현재 실행 가능성 불일치) 세 문제를 transition realizability gap으로 정식화함 - VLM, World Expert, Action Expert 세 transformer stream을 cross-attention으로 묶은 three-system architecture를 제안함. World Expert가 zero-initialized query에서 latent transition token을 만들고 이 token이 decoded future image 없이 바로 Action Expert 조건으로 들어감 - Persistent-Selective Future Prediction: latent supervision은 매 step 걸리고, pixel-level future 예측은 Trigger Gate가 latent 변화량과 translation/rotation/gripper 지표를 함께 봐서 접촉·해제 같은 transition-critical 순간에만 활성화함 - Visual-Action, Action-Visual 두 memory bank를 stateful Mamba로 pretrain함. 예측된 transition이 실행 가능한 과거 visual-action 경험을 검색하고, 최근 action history가 다시 visually grounded action prototype을 검색하는 양방향 구조임 - Prototype-Biased Flow: 검색된 action prototype을 그대로 실행하지 않고 flow matching의 초기 Gaussian source 평균을 그 방향으로 옮긴 뒤 policy가 현재 scene에 맞게 refine함
Novelty vs. Prior Works
- Future prediction(Fast-WAM, DreamVLA 등)과 memory retrieval(MemoryVLA 등)은 개별적으로는 이미 존재하나 대부분 appearance 기반 retrieval이거나 future를 auxiliary/cascaded objective로만 씀. UniMPA는 future prediction의 출력을 memory retrieval의 query로 직접 연결해 둘을 transition이라는 공유 인터페이스로 묶은 점이 차별점임 - Prototype-Biased Flow는 retrieved action을 그대로 복사하는 nearest-neighbor 계열과 달리 flow matching의 noise 분포 평균만 이동시켜 generative refinement 여지를 남김. 다만 개념 자체는 diffusion/flow의 initialization biasing과 유사해 학습 paradigm 수준의 도약은 아님 - transition realizability gap이라는 문제 정의는 새롭지만 해결책은 latent+pixel prediction, dual memory bank, flow matching bias라는 기존 구성요소를 정교하게 조합한 것이라 architecture-level novelty에 가까움
Benchmark Results
- LIBERO 4개 suite 평균 98.6%로 X-VLA(98.1%), Motus·GeoVLA(97.7%) 등 최신 baseline을 앞섬. π0.5(96.9%) 대비 학습 epoch은 25%만 썼다고 명시함(Table III) - LIBERO-Plus(7종 perturbation, 총 10,030 rollout, zero-shot) 평균 85.3%로 전체 1위이며 perturbation에 따른 성능 하락폭도 13.3으로 가장 작음. π0.5(73.6%, 하락폭 23.3)와 MemoryVLA(70.2%)를 크게 앞섬 - Abstract 기준 π0.5 대비 LIBERO +1.7pt, LIBERO-Plus +11.7pt, RoboTwin 2.0 Hard +18.5pt, real-world +12.6pt 개선을 보고함. RoboTwin 2.0 Hard와 real-world의 세부 수치 표는 텍스트 추출 과정에서 누락돼 본문에서 직접 확인 불가 - Real-world는 AgileX Cobot Magic과 GALAXEA R1 Lite 두 platform, 7개 suite(semantic rearrangement부터 long-horizon recovery까지)에서 suite당 25 trial로 평가했다고 명시하나 정량 표는 확인 불가 - Memory bank·Trigger Gate·Prototype-Biased Flow 각각의 ablation 결과는 텍스트에서 표와 서술이 모두 누락돼 확인 불가
누리랩 연구와의 연결
- RoboTwin 2.0 Hard와 real-world Suite G(recovery)에서 보이는 controlled disturbance 후 재개 능력은 failure detection/recovery 연구의 test-time 재개 메커니즘 설계에 참고할 만함 - Visual-Action/Action-Visual memory bank의 transition-query 기반 retrieval 구조는 robot memory 연구의 experience 저장·검색 설계에 바로 재사용 가능함 - Prototype-Biased Flow(검색 결과로 flow source를 이동시키는 방식)는 test-time optimization/inference-time planning의 prior 설계에 활용 가능하나, 저자도 single-prototype이라 multimodal한 grasp/approach 선택엔 한계가 있다고 명시함(Future Work 4)

2AM: Grounding Agent-Side Memory as Guidance for Steerable Action Models in Long-Horizon Manipulation

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Yutong Hu, Fengjiao Chen, Xuezhi Cao, Renaud Detry PDF 전문 1차 72점
장기 horizon manipulation에서 task memory를 전부 Agent 쪽에 두고 Action Model은 episodically stateless(에피소드 내내 상태를 유지하지 않는) 실행기로 분리한 2AM을 제안함. LIBERO-Mem에서 language subtask에 2D grasp/place/move hint를 더한 compositional steering으로 completion 76.3%를 달성해, 저자가 직접 재현한 baseline인 aligned π0(70.8%) 대비 completion +5.5점 개선했으나 strict success는 오히려 소폭 하락함.
Core Innovation & Methodology
- Agent가 task memory를 전담하고 Action Model은 매 action chunk마다 현재 RGB·robot state만 보고 동작하도록 두 모델의 역할을 명확히 분리함. - steering command를 language instruction과 2D grasp/place/move hint로 구성한 compositional contract로 정의해 물리적 의도를 시간 스케일별로 전달함. - demonstration의 object box, contact, projected robot trajectory에서 grasp/place/move label을 자동 추출해 VLM teacher 없이 supervision을 만듦. - condition dropout, spatial noise, temporal jitter로 학습해 Agent가 hint를 누락하거나 부정확하게 줘도 Action Model이 견디도록 훈련함.
Novelty vs. Prior Works
- 가장 가까운 prior work인 MemER은 high-level policy가 low-level π0.5에 text instruction만 전달하는 반면, 2AM은 language에 2D grasp/place/move point를 더한 compositional interface를 씀. - hint 종류 자체는 Steerable Policies, HAMSTER 같은 기존 spatial prompting 연구와 유사하며, 2AM의 novelty는 새 representation이 아니라 memory를 Agent에 전담시키고 attribution을 분리하는 실험 설계에 있음. - architecture나 objective는 기존 VLA(Qwen3-VL-4B backbone + flow matching)를 그대로 쓰고 hint dropout/noise 학습 레시피를 얹은 조합이라 방법론적 기여 자체는 제한적임.
Benchmark Results
- LIBERO-Mem 10개 task에서 2AM은 completion 76.3%, relaxed success 63.0%, strict success 11.8%를 기록함. - 논문이 인용한 published 최고 baseline SlotSSM(completion 14.8%) 대비로는 61.5점 개선이나, 이 수치는 저자들이 직접 재현한 것이 아닌 원논문 보고치임. - 저자가 동일 backbone·dual RGB로 재현한 aligned π0(completion 70.8%, strict success 12.25%) 대비로는 completion +5.5점, relaxed success +25.6점 개선이고, strict success는 오히려 12.25%에서 11.83%로 소폭 하락함. - language-only ablation(동일 Agent·Action Model에서 2D hint만 제거, completion 53.7%) 대비 hint 추가는 completion +22.6점, relaxed success +43.6점으로 hint의 기여를 보여줌. - 평가는 LIBERO-Mem 단일 sim benchmark, 10 task에 한정되고 real-robot 검증은 없음.
누리랩 연구와의 연결
- Agent가 재관찰 후 잘못된 subtask나 grasp binding을 다시 steering하는 closed-loop 구조는 우리 lab의 test-time optimization/failure recovery 설계에 참고할 수 있음. - Figure 3의 실패 사례(잘못된 subtask 선택, 잘못된 destination binding)는 failure diagnosis 연구에 실패 유형 분류 데이터로 재활용 가능함. - relaxed 63% 대비 strict 11.8%로 벌어지는 termination 문제는 test-time에서 정지 시점을 별도로 판단하는 inference-time planning 아이디어와 연결할 수 있음.

CAP: Continuously Adaptive Perception-Blind Humanoid Locomotion via Learned Denoising

arXiv PDF alphaXiv
World Model relevance 8/10 Robotics (cs.RO)
Hongjin Chen, Zijun Xu, Shihao Ma, Yi Zhao, Xilai Liu, Ke Ma, Wei Zhang, Chunyang Xie 외 3명 PDF 전문 1차 68점

  • Demonstration bottleneck을 소프트웨어·하드웨어 양쪽에서 우회 — HuRo는 human video를 robotization pipeline으로 변환해 630K episode 규모 VLA 사전학습 데이터를 만듦. SEED-UMI는 사람·로봇이 동일 exoskeleton을 공유해 encoder 값 자체를 paired supervision으로 씀.
  • Embodied reactive safety를 실제 실행까지 시켜 평가하는 benchmark 등장 — ReactHuman은 MLLM이 낸 반응 계획을 시뮬레이터에서 whole-body controller로 실제 실행시켜 물리적 결과까지 채점하는 freeze-and-predict protocol(위험 순간에 상황을 멈추고 반응을 예측·채점하는 절차)을 제시함.

유망 연구 방향 및 프로젝트 제안

World model readout과 policy feature 기반 failure detection의 fusion 검증 - research question: world model의 predictive state(FARM 방식)와 VLA policy feature(SAFE 방식, policy의 내부 feature에 readout을 붙이는 선행 failure-detection 기법) 중 어느 쪽이 언제 더 신뢰할 수 있는 실패 신호를 주는지, 둘을 합친 meta-monitor가 platform 간 zero-shot 불안정성을 줄이는지 - 접근·novelty: 두 readout을 같은 backbone·같은 task에서 동시에 학습해 비교하고, 신뢰도가 낮은 상황을 판단하는 gating 모듈을 추가함. 기존 연구는 두 표현을 독립적으로만 검증함 - 왜 지금·경쟁 prior works: FARM이 SAFE와 직접 비교 없이 world model 표현만으로 실증했고, fixed-readout zero-shot이 platform마다 크게 흔들린다는 한계를 스스로 명시함 - risk·target venue: 두 표현이 서로 상관돼 fusion 이득이 작을 위험. target: CoRL/RSS

Executor-invariant topological gate를 object-centric 3D manipulation으로 확장 - research question: PointMaze·Kitchen 같은 저차원 state에서 검증된 persistent-homology gate(필수 경유 지점) 개념이 3DGS 기반 object-centric scene representation 위에서도 정의·검출 가능한가 - 접근·novelty: contact-rich manipulation demonstration에서 object pose trajectory carrier를 만들고 그 위에서 gate를 검출해, 그리퍼·팔 구조가 다른 로봇 간 재학습 없는 전이를 검증함 - 왜 지금·경쟁 prior works: Topological Necessities는 gate가 특정 executor의 산물이 아니라 task 구조 자체임을 증명했지만 real-robot·고차원 manipulation 검증은 비어 있음 - risk·target venue: 고차원 manipulation에서 shell-measure profile(경유 지점 검출에 쓰는 위상 구조 정량화 값) 계산이 noisy해 gate 검출이 불안정할 위험. target: CoRL

World model test-time evidence injection을 failure recovery anchoring에 적용 - research question: frozen video world model이 실패 후 재개 시점에서 실제 관측 trajectory를 evidence로 주입해 rollout을 현재 상황에 anchoring하면, 재학습 없이 recovery plan 품질이 개선되는가 - 접근·novelty: World in World의 training-free attention 기반 evidence injection을 camera control이 아니라 실패 복구 조건으로 재정의하고, UniMPA의 bidirectional memory retrieval로 검색한 과거 성공 경험을 evidence로 주입함 - 왜 지금·경쟁 prior works: 두 논문 모두 evidence injection과 memory retrieval을 각각 camera control·action generation에만 적용했고 failure recovery로의 결합은 시도되지 않음 - risk·target venue: training-free injection이 policy 학습 분포와 어긋나 recovery 실패를 오히려 늘릴 위험. target: CoRL/ICRA

접촉 기반 risk valuation을 manipulation test-time optimization으로 이식 - research question: hazardous exploration에서 검증된 Prelec weighting(작은 확률은 과대평가, 큰 확률은 과소평가하는 비선형 확률 왜곡 함수) 기반 risk valuation objective가 접촉이 많은 manipulation에서 "이 접촉 시도를 계속할 가치가 있는가"를 판단하는 test-time objective로 쓰일 수 있는가 - 접근·novelty: Behavioral Valuation의 objective를 belief update 대신 contact force·tactile feedback 기반 risk 추정으로 바꾸고, failure-truncated execution 구조를 grasp retry 판단에 적용함 - 왜 지금·경쟁 prior works: 원 논문은 grid-world 탐사에만 적용했고 manipulation·real-robot 검증이 전혀 없어 직접 확장 여지가 큼 - risk·target venue: 탐사와 달리 manipulation은 정보 이득의 정의 자체가 불명확해 objective 설계가 도전 과제임. target: ICRA/IROS

Human video robotization 데이터의 신뢰도 필터링 - research question: HuRo처럼 대규모로 robotize된 human video 데이터에서 self-collision·contact 미모델링으로 물리적으로 부정확한 궤적을 자동 검출·필터링하면 VLA 사전학습 효율과 OOD 성능이 더 오르는가 - 접근·novelty: robotized 궤적의 신뢰도를 world model 기반 physical plausibility 점수로 매겨 low-quality 데이터를 걸러내거나 downweight함 - 왜 지금·경쟁 prior works: HuRo는 630K episode 중 55.2%만 non-self-contact 조건을 충족한다고 스스로 밝혔지만 필터링 없이 그대로 사용함 - risk·target venue: 필터링 기준 설계가 어려워 유효 데이터 손실이 클 위험. target: CoRL
