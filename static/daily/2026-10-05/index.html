EyeRobot 2.0: Active Gaze for Precise Manipulation without Wrist Cameras

arXiv PDF alphaXiv
Manipulation Active Perception relevance 9/10 Robotics (cs.RO)
Kush Hari, Justin Kerr, Nidhya Shivakumar, Samarth Mahapatra, Carmelo Sferrazza, Jiahui Lei, Jitendra Malik, C. Karen Liu 외 2명 PDF 전문 1차 70점
스테레오 카메라 한 대로 두 눈 시점을 3D 지점에 수렴시키는 Active Visual Fixation(AVF, 능동 시선 고정)으로 손목 카메라 없이 정밀 bimanual 조작을 수행하는 프레임워크를 제안함. 실제 로봇 1000회 이상 trial에서 passive stereo 대비 40%p 높은 성공률을 냈고, 잡은 물체가 손목 카메라를 가리는 과제에서는 ego+wrist 대비 2배 성능을 보임.
Core Innovation & Methodology
- 스테레오 카메라 한 대만으로 두 눈 시점을 3D fixation point에 수렴시켜 손목 카메라 없이 정밀 조작을 수행하는 AVF 프레임워크를 제안함 - gaze를 두 단계로 나눠 학습함: 목표 물체에 수렴하는 저수준 gaze servoing 정책(기하학적 reward로 RL 학습)과 과제 진행에 따라 볼 곳을 정하는 고수준 target selector(RL, BC gripper 정책의 예측 오차를 reward로 co-training) - fixation 지점 주변에 더 많은 visual token을 배정하는 foveated multi-resolution crop 표현으로 연산을 과제 관련 영역에 집중시킴 - gripper proprioception과 action chunk를 고정된 월드 좌표가 아니라 회전하는 fixation-relative SE(3) 프레임으로 정준화해 학습할 action 분포의 크기를 줄임
Novelty vs. Prior Works
- 가장 가까운 선행연구는 저자 자신들의 EyeRobot(360도 카메라 기반 gaze 정책)이며, 이 논문은 이를 스테레오 카메라로 옮기고 foveation·fixation-relative action·계층적 target selector를 추가해 더 정밀한 bimanual task에 적용한 체계적 확장에 가까움 - gaze demonstration 없이 BC-RL co-training으로 gaze 시퀀스를 발견하는 핵심 아이디어는 EyeRobot에서 이미 제시됐고, 2.0의 기여는 스테레오 영상을 광학 중심 회전만으로 워핑해 fixation을 합성한 점(3D reconstruction 불필요)과 fixation 프레임 action canonicalization에 있음 - 손목 카메라를 아예 없애고 ego 카메라만으로 손목 카메라 수준 성능을 재현한다는 문제 설정은 실용적으로 새롭고, active vision을 viewpoint selection이 아니라 fine-grained eye movement 자체에 쓴 점에서 기존 active vision 연구와 구분됨
Benchmark Results
- 실제 로봇 7개 과제에서 1000회 이상, 시뮬레이션 6개 과제에서 1800회 trial로 비교함 - passive stereo(No Gaze) 대비 real 평균 +40%p, sim 평균 +20%p 향상시켰고, wrist 카메라 제거 시 No Gaze는 real 성공률이 52%에서 27%로 떨어짐 - wrist 카메라가 가려지지 않는 과제(marker, tea, toaster, wrench)에서는 ego+wrist와 비슷함(69% vs 64%), 잡은 물체가 wrist 카메라를 가리는 과제(boba, pot)에서는 ego+wrist 대비 2배 이상 성능(48% vs 22%) - ablation: foveation 제거 시 real 평균 -20%p 하락 - ablation: action을 world frame으로 바꾸면 sim에서 gaze-free baseline 수준으로 떨어짐(-21%p) - ablation: stereo 대신 mono+깊이 제거 시 real 평균 -18%p 하락 - distractor를 섞은 상황에서 첫 grasp 성공률이 ego-only·ego+wrist보다 높음(wrench 과제 기준 AVF 20/25 vs ego-only 10/25 vs ego+wrist 3/25)
누리랩 연구와의 연결
- active perception 주제와 직결됨: 과제 진행에 따라 볼 곳을 정하는 target selector 구조를 VLA 정책의 subgoal·attention 선택 모듈로 가져올 수 있음 - failure detection/recovery 연구에 연결 가능: fixation point의 3D 추정 오차나 gaze가 머무는 위치를 모니터링해 조작 실패 징후를 조기에 포착하는 신호로 쓸 수 있음 - object-centric 3DGS·scene graph 연구와 접점이 있음: 현재는 스테레오 depth로 fixation point를 추정하는데, 이를 object-centric 3D representation으로 대체하면 더 일반화된 gaze target 선택이 가능할 것으로 보임

Keep the Effect, Drop the Actor: Programmable Effect-to-Execution World-Action Models

arXiv PDF alphaXiv
World Model Manipulation relevance 9/10 Robotics (cs.RO)
Junyi Hu, Zhewen He, Zhenhua Li, Yi Fang PDF 전문 1차 76점
로봇 시연에서 객체에 일어난 변화만 남기고 로봇 팔의 움직임은 버리는 effect program(객체 keypoint 궤적, grasp를 나타내는 contact point 2개, 종료 상태)을 정의해서 world-action model PEWAM을 학습시킴. 이 program을 조건으로 매 4 step마다 재계산(closed loop)하면 한 번의 시연만으로 held-out task를 풂.
Core Innovation & Methodology
- effect program 정의: 객체의 box keypoint 9개, grasp를 나타내는 contact point 2개, 종료 상태(terminal state)로 시연을 로봇 geometry 없이 표현함. - DiT backbone 하나(71.5M)가 effect(E), end-effector execution(R), native action(A), terminal state(G) 네 스트림을 각각 독립된 flow-matching time으로 학습해서, 어느 스트림을 clean으로 고정하느냐에 따라 같은 가중치로 inverse/goal/forward/inverse-dynamics 네 질의에 전부 응답함. - inference를 program(E, G)을 clamp하고 execution(R, A)만 sampling하는 것으로 재정의해 "programming"이라 부르고, 매 4 control step마다 라이브 장면에서 다시 풂. - progress를 로봇이 일으킨 effect로만 인정하는 engagement gate를 둬서, 밀침(push) 같은 외란을 실패가 아니라 program을 다시 풀어야 할 새 observation으로 흡수함. - program은 로봇 팔 4종에 재학습 없이 옮겨 타고, 사람이 program 좌표를 직접 편집할 수 있음.
Novelty vs. Prior Works
- 가장 가까운 선행연구는 Im2Flow2Act(object flow로 task 전달, flow는 별도 모델이 생성하고 flow-conditioned policy로 실행)와 UWM(독립 timestep의 video-action diffusion). PEWAM은 flow를 따로 생성하지 않고 시연 자체에서 읽어내며, contact point와 terminal state를 더해 grasp와 도착 상태까지 하나의 program에 담은 점이 실질적 차이임. - contact를 affine weight가 아니라 좌표 점으로 둬야 편집이 가능하다는 것을 ablation으로 직접 보임(weight로 인코딩하면 회전 명령 부호와 반대로만 실현됨, Table 5·Appendix N). representation 설계 수준의 기여임. - "demonstration에서 actor를 떼고 effect만 남긴다"는 전제 자체는 object-centric manipulation 계열(Track2Act, General Flow, ReKep 등)이 이미 공유하는 아이디어라 problem formulation의 새로움은 제한적이고, 새로움은 주로 four-stream 단일 모델 설계와 contact-as-point 편집 가능성 쪽에 있음.
Benchmark Results
- LIBERO-Goal held-out task 3개(90 episode)에서 program 조건 40/90(44.4%) 완료, 공개된 demonstration-conditioned method는 모두 더 낮음(UWM 21.1%, Instant Policy 5.6%, ATM·Zero-WAM 0%). - 같은 held-out task에서 시연을 그대로 replay하면 96.7% 성공 — program 방식이 demonstrator 동작을 그대로 복사하는 것보다 본질적으로 약하다는 걸 저자가 직접 인정함(§5 limitation). - Meta-World held-out class 중 shelf-place·sweep-into·bin-picking에서는 공개 baseline(DAMI 등)을 모두 상회하지만, 5-class 평균에서는 DAMI보다 낮음(ML10 49.8 vs 56.8, ML45 34.0 vs 37.5). - RLBench 24개 held-out task에서 program은 160/720(22.2%)로 no-program 108/720(15%)보다는 낫지만, 전문 방법 Instant Policy의 575/720(79.9%)에는 크게 못 미침. - push 후 재계산 23/60 성공 vs demo replay 6/60. - 로봇 팔 4종(Panda/KUKA IIWA/Kinova3/UR5e 순서) 재학습 없이 bowl task 27·24·22·16/30. - 실제 Franka 팔(다른 task 156개 real demo로 fine-tune)에서 사람 비디오로 만든 program이 36/40, 동일 backbone에 마지막 프레임을 goal image로 준 경우는 22/40.
누리랩 연구와의 연결
- test-time optimization/failure recovery: program을 매 4 step 재계산하는 구조와 push를 "새 observation"으로 재해석하는 engagement gate는 누리랩의 test-time re-planning·failure recovery 연구와 바로 연결됨. - object-centric 3DGS/scene graph: 현재 entity는 rigid box keypoint로만 표현되는데, 이를 object-centric 3DGS나 scene graph로 교체하면 비강체 객체·다중 객체 상호작용까지 program으로 확장할 여지가 있음. - VLA와의 역할 분리: actor-free program을 VLA의 중간 출력으로 쓰고 PEWAM류 executor가 재계산 실행을 맡는 구조를 누리랩 VLA 연구에서 검토할 만함.

World-Calibrated Proposal-to-Action Flow for Vision-Language-Action Models

arXiv PDF alphaXiv
VLA Manipulation relevance 9/10 Robotics (cs.RO)
Jie He, Wei Li, Junwen Tong, Rui Shao, Wei-Shi Zheng, Liqiang Nie PDF 전문 1차 68점
Flow 기반 VLA가 매번 isotropic Gaussian에서 액션을 생성하느라 최근 동작의 연속성과 미래 예측 정보를 못 쓰는 문제를 지적함. 최근 동작을 proposal로 만들고 world model이 그 proposal을 얼마나·어느 방향으로 고칠지 계산해 source 분포 자체를 바꾸는 ProAct를 제안함. π0.5 대비 denoising step을 50% 줄이면서 성능도 올림.
Core Innovation & Methodology
- propose-calibrate-refine 구조: Gaussian noise 대신 최근 액션을 모션 외삽 후 flow-matching 한 스텝으로 scene-aware proposal을 만들어 생성 시작점을 demonstration 액션 매니폴드 근처로 당김 - World Expert가 frozen V-JEPA 2 latent future를 예측 타깃으로 쓰면서, 동시에 proposal과 실제 demonstration의 residual로부터 교정 정도(extent)와 방향(low-rank geometry)을 추론함 - extent·geometry로 translation/rotation/gripper 차원에 걸친 anisotropic covariance를 구성해 source 분포를 교체하되, 기존 flow 기반 VLA의 transport parameterization 자체는 그대로 둠 - bounded per-step extent와 trace-normalized low-rank에 condition-number budget(S_max)을 걸어 source가 한 방향으로 퇴화하거나 과도하게 좁아지는 것을 막음
Novelty vs. Prior Works
- source를 informative하게 만드는 방향은 Streaming Flow Policy, A2A, VITA 등 선행 연구에도 있음. ProAct의 차별점은 proposal을 그대로 쓰지 않고 world model이 예측한 미래와의 compatibility로 '얼마나·어느 방향으로' 벗어날지를 계산해 covariance 자체를 결정한다는 점임 - DreamVLA·WorldVLA·VLA-JEPA 같은 world model 결합 VLA는 미래 예측을 조건으로만 쓰는데, ProAct는 미래 예측 결과를 source의 extent·geometry라는 구체적 수치로 변환해 생성 과정에 직접 개입시킴 - 다만 flow-matching proposal step, frozen V-JEPA 2 latent target, low-rank covariance는 각각 선행 요소들의 재조합에 가까워서 완전히 새로운 패러다임이라기보다 기존 조각들을 하나의 보정 인터페이스로 엮은 설계에 가까움
Benchmark Results
- LIBERO: 평균 98.4%로 backbone π0.5(96.9%) 대비 +1.5점, Long suite에서는 격차가 3.6점으로 더 커짐 - LIBERO-Plus(재학습 없이 7종 perturbation 평가): 86.8%로 π0.5 대비 +13.2점, 최강 경쟁 baseline 평균 대비 +7.3점, Noise/Camera/Robot shift에서 가장 큰 개선(14.8~18.1점) - RoboTwin 2.0(50 task 학습, zero-shot randomized hard 평가): 평균 60.3%로 π0.5(28.6%) 대비 +31.7점, 최강 baseline(Spatial Forcing 34.6%) 대비 +25.7점 - real-world 2개 플랫폼(Galaxea R1 Lite, AgileX Cobot Magic) 6 task 25회 시행: π0.5 대비 overall TSR/CSR이 Galaxea에서 +8.7/+6.4점, AgileX에서 +10.0/+8.3점 - 효율성: denoising step 50% 감소, latency -25.8%(sim)/-16.3%(real), throughput +34.8%/+19.5%. ablation상 World Expert 제거 시 성능 하락폭이 가장 큼(LIBERO -1.9점, real-world -8.0점)
누리랩 연구와의 연결
- World Expert가 산출하는 extent(U)는 proposal-미래 compatibility 신호라서, 값이 크게 튀는 순간을 failure detection/online anomaly 신호로 재활용하는 실험이 가능함 - 논문이 스스로 한계로 명시한 부분: factual trajectory만으로 학습해 proposal을 바꿨을 때 실제 결과가 어떻게 달라지는지는 보지 않음. 이는 counterfactual reasoning 쪽 연구 공백과 바로 연결됨 - 50% denoising step 감소는 test-time optimization/inference-time efficiency 연구와 바로 이어지는 결과라, world model 기반 source calibration을 다른 test-time 기법과 결합해 보는 방향이 있음

Native Action-Prior Learning from Videos for World Action Models

arXiv PDF alphaXiv
World Model VLA (Manipulation) relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Zhaochong An, Fei Zhang, Menglin Jia, Duncan Frost, Zijian Zhou, Yikai Wang, Xudong Wang, Aditya Patel 외 5명 PDF 전문 1차 72점
Observation-only 비디오로 action policy(Action-DiT)를 직접 사전학습해서 video representation이나 latent-action 같은 중간 인터페이스를 없앤 world action model임. 특히 OOD 세팅(RoboTwin2.0 Random)과 실로봇 Franka FR3에서 기존 joint WAM·latent-action 방법 대비 큰 폭으로 성능이 좋아짐.
Core Innovation & Methodology
- native action-prior learning 제안: 중간 representation이나 latent-action model 없이, observation-only 비디오의 future-video flow-matching objective로 Action-DiT 파라미터를 직접 최적화함 - Mixture-of-Transformers 구조에서 Video-DiT와 Action-DiT가 joint attention으로 상호작용하되, pretraining 때는 Video-DiT를 freeze하고 Action-DiT만 학습함 - transition-structured joint attention으로 clean 과거 state·noised 미래 state·action 토큰을 하나의 segment로 묶어, 명시적 latent action 변수 없이 attention 안에서 inverse-forward dynamics를 암묵적으로 구현함 - post-training 단계에서는 asymmetric attention으로 비디오 스트림을 action 스트림과 분리해 video KV를 캐싱하고, action만 반복 denoising해서 future video를 생성하지 않고도 효율적인 action-only inference를 가능하게 함
Novelty vs. Prior Works

SocialVLA: A Social Perception Gateway for Human-Reaction-Based Failure Detection and Recovery in VLA Manipulation

arXiv PDF alphaXiv
VLA Failure Detection & Recovery (Human-Robot Interaction) relevance 9/10 Robotics (cs.RO)
Sofya Konstantinova, Miguel Altamirano Cabrera, Artem Lykov, Dzmitry Tsetserukou PDF 전문 1차 68점
VLA 조작 실패를 로봇 내부 신호가 아니라 옆에서 지켜보는 사람의 음성·표정·명시적 stop phrase 반응으로 감지해 실행을 멈추는 외부 게이트 SocialVLA를 제안함. Unitree G1 실로봇에서 16명 참가자로 평가했고, 고정(frozen) 시스템 기준 recall 54.6%·precision 69.5%, 미지 참가자 1명 대상 prospective 평가에서는 recall 59.5%·precision 91.7%를 달성함.
Core Innovation & Methodology
- 사람의 음성·표정·명시적 stop phrase 반응을 VLA 실행 중 runtime intervention 신호로 바꾸는 policy-agnostic 외부 게이트를 제안함 — VLA 내부 activation이나 uncertainty 접근 불필요함 - causal fast/extended-context 음성 감지, visual reaction, 명시적 stop phrase(Vosk), robot-relevance 추정을 별도 채널로 두고 asynchronous first-event fusion으로 결합함 — 가장 먼저 확신이 임계값을 넘는 신호가 즉시 VLA hold를 요청함 - robot relevance는 별도 video-only logistic head로 추정해 reaction confidence를 최대 30%만 깎는 contextual cue로만 씀(hard veto 아님). 명시적 stop phrase는 0.85 floor를 둬서 relevance가 불확실해도 항상 threshold를 넘게 설계함 - hold 이후 별도 Vosk 로깅 세션이 verbal correction을 기록해 participant가 이어서 재개·재시작·새 instruction 지시를 할 수 있게 함 — 이 기록을 향후 failure-aware policy learning supervision으로 쓸 수 있다고 제안함
Novelty vs. Prior Works
- 가장 가까운 선행연구는 Stiber et al.(얼굴·음성·명시적 피드백·robot-error context를 결합한 proactive 시스템, arXiv:2501.05723)임. SocialVLA는 VLA 내부 접근 없이 외부 게이트로 붙음. reaction recognition과 robot-relevance를 분리 학습해 cross-modal label leakage를 막고, first-event async fusion으로 멀티모달 합의를 기다리지 않는다는 점도 다름 - SAFE·FAIL-Detect·AHA 같은 VLA 내부 기반 실패탐지와는 정보원 자체가 다른 상호보완 관계고, 저자도 직접 경쟁이 아니라 상호보완 관계라고 명시함 - 분류기 자체는 ExtraTrees 같은 고전적 shallow classifier와 기존 pretrained 모델(wav2vec2 기반 Aniemore, MobileFaceNet, YuNet, Vosk)의 조합이라 알고리즘 novelty는 낮음. novelty는 주로 problem formulation(인간 반응을 VLA의 runtime gate로 쓴다)과 fusion/relevance 분리 아키텍처에 있음
Benchmark Results
- Unitree G1 + GR00T policy, ball pick-and-place 단일 task, 15명 참가자 238개 intervention episode + 1.038h non-intervention 데이터로 offline replay한 결과 frozen cascade recall 54.6%, precision 69.5%, 500ms 이내 timely recall은 45.4%에 그침 - ablation에서 audio-fast 단독 recall 48.3%, video 단독 22.3%, audio+video fusion은 recall 64.3%(+16.0%p)로 올리지만 false stop이 100건 발생함. relevance 모듈 추가로 false stop 100→57(43%감소), precision 60.5%→69.8%, FPR 41.1%→27.8%로 개선되나 true positive도 153→132로 일부 손실됨 - 16번째 unseen 참가자 대상 prospective 배포에서는 recall 59.5%, precision 91.7%, non-intervention FPR 9.5%, false stops/h 20.9를 기록함 — 다만 단 1명 세션 기준이라 표본이 매우 작음 - latency는 detector→fusion 중앙값 47.9ms, VLA gate→physical hold 336ms, reaction onset→physical hold 중앙값 1.021s(매칭 이벤트 n=14)로, 지연 대부분이 detector emission 이전(반응이 확신 있는 신호로 누적되는 구간)에서 발생함 - 평가가 pick-and-place 단일 task·단일 VLA policy(GR00T)·러시아어 stop phrase 기준으로 한정돼 있고, 저자도 language·culture·age·neurodiversity에 대한 일반화는 이 연구로 검증되지 않는다고 명시함
누리랩 연구와의 연결
- failure detection/recovery 연구 라인에 직접 연결됨 — SAFE·FAIL-Detect 같은 robot-internal monitor와 SocialVLA식 external social-reaction 채널을 결합하는 hybrid failure detector로 확장하는 아이디어 검토할 만함 - reaction-centered intervention record(반응 시각, 활성 VLA action, correction transcript)는 robot memory나 test-time optimization 연구에서 '실패로 이어질 뻔한 순간'의 supervision으로 쓸 수 있음 — 실패 직전 상태를 기록해 두는 방식과 연결됨 - object-centric 3DGS나 scene graph와는 직접 연결이 약하지만, robot-relevance 추정(사람이 로봇 어디를 보는지)을 active perception·semantic mapping의 attention 신호로 재활용하는 방향은 고려할 만함

오늘의 핵심 연구 트렌드 종합

  • world-action model(WAM)의 중간 표현 경쟁 — Top 15 중 7편이 미래 시각 상태와 action을 함께 예측하는 WAM 계열임. 표현 방식은 sparse sub-goal 프레임(ProWAM), 객체 keypoint effect program(PEWAM), 3D point trajectory(PointWAM), latent future(IG-VLA, ProAct), subgoal 이미지(ViGAR), spectral latent(WING)로 갈라지는 중임.
  • 사람 영상을 로봇 action prior로 직접 전이 — NAVA-WAM은 observation-only 비디오로 action policy를 중간 표현 없이 직접 사전학습함(위 7편과 달리 WAM 중에서도 중간 표현 자체가 없는 예외임). WING은 카메라 모션을 분리해 interaction만 남기고, KungfuAthleteBot은 영상 복원 결함을 직접 수리함. 셋 다 "영상을 더 모으기"가 아니라 "영상의 결함을 다루는 방식"을 핵심 기여로 삼음.
  • 실패 신호의 다각화 — 실패를 보는 관점이 내부 reward(CriticHack, wrong-object failure 증폭 진단), 외부 사람 반응(SocialVLA), world model latent collapse(JEPA plannability)로 나뉘어 각자 다른 실패 유형을 잡아냄. 세 신호를 한 시스템에서 합치는 연구는 아직 없음.
  • 능동 지각(active perception)의 하드웨어 단순화 — EyeRobot 2.0은 손목 카메라 없이 스테레오 한 대의 시선을 움직여 정밀 조작을 수행함. 카메라를 늘리는 대신 움직이는 방향의 연구로, 오늘 배치에서 가장 실험 증거가 강함(실로봇 1,000회 이상).
  • 데이터 희소 상황의 안정화 기법 — Multi-Fidelity Policy Gradients는 저정밀 시뮬레이터 데이터를 control variate로 써서 PPO 분산을 줄임. 실제 Franka에서는 업데이트당 4 에피소드로 학습이 안정화됨. WAM 열풍과 별개로, real-robot RL의 실질적 비용 문제를 다룸.
  • 장기 과제의 자율 자기개선 — MobiAgent는 고정 sub-task 대신 atomic skill을 매 스텝 재조합하고, 배포 중 rollout을 사람 라벨 없이 clustering해 skill을 계속 재학습함. 개별 요소는 기존 라인의 조합이지만 통합 파이프라인으로서의 실증이 탄탄함.

유망 연구 방향 및 프로젝트 제안

WAM 예측-실제 괴리를 범용 실패 조기 감지 신호로 쓰기 - research question: world-action model이 예측한 미래 표현(sub-goal, point trajectory, latent)과 실제 rollout의 괴리가 조작 실패를 몇 스텝 전에 예고할 수 있는가? - 접근·novelty: ProWAM·PointWAM·ProAct 모두 "예측 대 실제" 신호를 갖고 있지만 failure detection에 쓰지 않음(각 논문의 recommendation에서 공통으로 지적된 공백). 이 괴리를 정량화해 test-time 모니터로 쓰는 게 신규 지점임. - 왜 지금·경쟁 prior works: SAFE·FAIL-Detect 같은 기존 failure detector는 action 자체의 uncertainty만 봄. WAM이 이미 world prediction을 갖고 있으니 추가 모델 없이 공짜로 얻는 신호라는 점이 차별점. - risk·target venue: WAM 종류별로 괴리의 의미(2D sub-goal vs 3D point vs latent)가 달라 일반화가 안 될 위험이 있음. target: CoRL/RSS.

object-centric 3DGS를 WAM의 중간 표현으로 교체 - research question: PointWAM의 point trajectory나 PEWAM의 keypoint effect program을 object-centric 3DGS로 바꾸면 non-rigid object·occlusion 상황에서 더 잘 버티는가? - 접근·novelty: 두 논문 모두 rigid keypoint/point cloud 기반이라 변형체·얇은 물체에 약함(두 deep review의 recommendation에서 공통 지적). 3DGS는 형상·외형을 함께 표현해 이 한계를 메울 후보임. - 왜 지금·경쟁 prior works: PointWAM(scene-actor 분리), PEWAM(effect-centric)이 바로 이번 주 공개돼 아직 3DGS 결합 시도가 없음. 선점 가능. - risk·target venue: 3DGS 렌더링·최적화 비용이 WAM의 실시간 inference 요구와 충돌할 위험이 있음. target: CoRL/RSS, 실로봇 검증 필수.

counterfactual world-action calibration - research question: ProAct는 factual trajectory만 학습해 proposal을 바꿨을 때 결과가 어떻게 달라지는지 모른다는 한계가 있음. counterfactual 학습 신호를 추가하면 (action 생성 시작점 분포를 교정하는 모듈인) World Expert의 교정 정확도가 오르는가? - 접근·novelty: 같은 장면에서 다른 proposal을 가정했을 때의 결과를 world model로 시뮬레이션해 counterfactual pair를 만들고, 이를 World Expert 학습에 추가하는 방향. - 왜 지금·경쟁 prior works: ProAct·DreamVLA·WorldVLA 계열이 모두 factual-only. counterfactual reasoning은 누리랩이 이미 우선순위로 두는 주제와 직결됨. - risk·target venue: counterfactual rollout의 품질이 world model 자체의 한계에 묶여 악순환할 위험이 있음. target: NeurIPS/ICLR.

내부 reward 신호와 외부 사람 반응 신호를 합친 hybrid failure detector - research question: CriticHack이 찾은 wrong-object failure(reward는 오르는데 엉뚱한 물체를 조작)를, SocialVLA의 사람 반응 채널이 몇 초 더 빨리 잡아내는가? - 접근·novelty: 두 신호가 서로 다른 실패 유형(reward 착시 vs 관찰자가 보기에 명백한 오류)을 잡을 가능성이 높아, 단순 병렬 결합만으로도 recall 개선 여지가 큼. - 왜 지금·경쟁 prior works: SocialVLA 저자도 robot-internal monitor와의 결합을 future work로 남겨둠. 경쟁자 없음. - risk·target venue: 사람 관찰자가 상시 배치되는 상황이 제한적이어서 일반적 배포 시나리오에서 활용도가 낮을 위험이 있음. target: IROS/ICRA.

sim-to-real control variate를 VLA test-time 적응에 적용 - research question: Multi-Fidelity Policy Gradients의 control variate 아이디어를, VLA fine-tuning이 아니라 배포 중 test-time replanning의 신뢰도 추정에 쓸 수 있는가? - 접근·novelty: world model의 sim rollout(저정밀)과 실제 관측(고정밀) 간 상관을 모니터링해, 상관이 깨지면 world model 예측에 기반한 replanning을 꺼버리는 fallback 게이트로 응용. - 왜 지금·경쟁 prior works: 원 논문은 RL 학습 단계에만 적용함. test-time 적응 쪽은 미개척. - risk·target venue: 분산 감소 이론이 학습 중 gradient 추정을 전제로 해서 inference-time으로 옮길 때 재유도가 필요함. target: CoRL, 빠른 산출 트랙에 적합.
