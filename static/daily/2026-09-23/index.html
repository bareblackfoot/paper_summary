Dual-Frontier: When Can an Agent Trust Its World Model?

arXiv PDF alphaXiv
World Model relevance 6/10 Artificial Intelligence (cs.AI)
Huatai Zhu, Qiang Chen, Ziqian Kou, Wenhao Li, Fei Wang, Yichao Cao, Xiu Su, Yi Chen PDF 전문 1차 75점
world model이 안내한 결정이 실패했을 때 그 원인이 정책 오류인지 world model 오류인지는 관측만으로 구분 불가능함을 증명함. 이에 예측 이득이 인증된 world model 오차 한계를 넘을 때만 world model 제안을 받아들이는 Dual-Frontier 규칙을 제안함. tool-use agent benchmark 3종에서 baseline 대비 평균 success 11점, accuracy 6점 개선함.
Core Innovation & Methodology
- failure attribution 문제를 counterfactual decomposition(R=A+W, 정책 결핍 A와 world model 효과 W)으로 정식화하고, 유한 horizon planner에서도 passive interaction만으로는 A와 W를 식별 불가능함을 minimax 하한으로 증명함 - Bellman-residual identity로 action-conditioned world model 오차를 decision-specific radius로 변환해, 특정 행동 비교(policy pair)에 대해서만 신뢰 여부를 인증하는 방식을 제시함 - 예측 이득 S(x)가 world model 오차 bound B(x)와 추정 오차 ξ(x)를 넘을 때만 후보 행동을 승격하는 verify-then-promote gating(FW/FA frontier)을 도입함 - conformal calibration과 simultaneous confidence sequence로 여러 요청에 걸쳐 하나의 인증서를 재사용하면서도 familywise false-promotion 오류를 통제하는 adaptive evidence reuse 절차를 제공함
Novelty vs. Prior Works
- WAKER(오차 큰 영역에서 데이터 수집)·AdaWM(dynamics/policy mismatch 분리 후 해당 성분만 재학습) 같은 기존 reliable model-based learning은 global 혹은 shift 단위 진단인데, 본 논문은 policy pair 단위(decision-specific)로 인증 범위를 좁힌 점이 본질적 차이로 보임 - Corollary 2(예측 오차가 작아도 greedy action ranking이 뒤집힐 수 있음)로 global prediction accuracy가 decision trust의 충분조건이 아님을 별도로 증명한 점이 기존 confidence/consistency 기반 gating과 다름 - 다만 이론 장치(Bellman residual bound, conformal 보정, simultaneous confidence sequence)는 policy evaluation·offline RL·conformal prediction 이론에서 표준적인 도구의 조합이라, formulation의 참신함은 강하지만 개별 수학적 기법 자체의 새로움은 제한적으로 보임
Benchmark Results
- BFCL v4/API-Bank/NexusRaven 3개 tool-use benchmark, Llama-3.1-8B-Instruct·Qwen3-8B 두 backbone에서 Dual-Frontier가 모든 benchmark-metric 조합에서 1위를 기록함(Table 1) - 최강 경쟁 규칙(Consistency) 대비 평균 Success +11.57pp(Llama)/+11.07pp(Qwen), Acc. +5.93pp/+5.83pp 개선함 - Always-WM 대비 Net Decision Gain은 BFCL v4에서 +55.81~+58.12pp, API-Bank +31.10~31.89pp, NexusRaven +34.90~35.54pp로 benchmark마다 편차가 큼 - controlled finite-world 실험(sparse/chain/grid, 16 state 4 action)에서 targeted evidence가 attribution accuracy를 50.25%에서 100%로 올리고 harmful use를 5.10%에서 0.30%로 낮춤. margin 대 audit sample 수 log-log slope 2.014로 이론상 n=Theta(gamma^-2)와 일치함 - ablation(Table 2)에서 world model 오차·추정 오차 항을 제거하면 성능이 단계적으로 하락해 각 구성요소 기여를 확인함. 단, 모든 agent 실험이 tool-calling 텍스트 benchmark이고 real-robot이나 manipulation 환경 실험은 본문에서 확인 불가
누리랩 연구와의 연결
- failure detection·recovery 연구에 world model 신뢰 여부를 언제 promote할지 정하는 verify-then-promote gate로 바로 적용 가능함. VLA policy가 학습된 world model의 rollout을 신뢰할지 판단하는 test-time 안전장치로 활용할 수 있음 - counterfactual reasoning 축과 직결됨. 정책 결핍과 world model 오류를 분리하는 A/W decomposition을 조작 실패 원인 진단(policy 문제 vs. dynamics 예측 문제)에 그대로 적용할 수 있음 - test-time optimization/inference-time planning에서 robot manipulation의 model-based planner가 예측 advantage와 인증된 오차 bound를 비교해 개입 여부를 정하는 rule로 확장하면 real-robot 실험으로 이어질 여지가 있음

Minimal Recurrent Behavioral Memory for Imitation under Partial Observability

arXiv PDF alphaXiv
Imitation Learning Robot Memory (정보이론적 formulation) relevance 8/10 Machine Learning (cs.LG)
Xianyao Li, Fang Xu, Rui Min, Ruitong Tian, Jing Du PDF 전문 1차 78점
부분관찰 환경에서 특정 expert를 모방하는 데 필요한 최소 recurrent memory를, 미래 관측을 side information으로 다루는 compatibility relation으로 정의하고 정보이론적으로 정확히 특성화함. Toy manipulation task와 외부 커뮤니티 벤치마크에서 이 요구량을 측정하는 프로토콜과 event-agnostic future-behavior supervision을 제안해 36/40 seed에서 요구 rate에 근접시켰지만, delay가 길어지면 학습 신뢰도가 떨어짐을 보임.
Core Innovation & Methodology
- 부분관찰에서 특정 expert를 모방하는 데 필요한 최소 recurrent memory를 새로운 problem formulation으로 정의함 - 미래 관측을 side information으로 다루는 compatibility relation을 도입해, transitive한 경우 그 등가류(같은 미래를 만드는 상태 묶음)의 조건부 entropy가 정확한 최소 memory량임을 증명함 - non-transitive한 일반 경우는 closed compatible state assignment에 대한 entropy 최소화 문제로 환원하고, 유한 인스턴스에서 exact certificate를 제시함 - sufficiency·minimality·attribution을 분리하는 측정 프로토콜, VQ 기반 sole-carrier 정책 DIACRITIC, future offset의 action을 예측하는 event-agnostic future-behavior supervision을 학습 신호로 제안함
Novelty vs. Prior Works
- predictive state representation(causal state, PSR)은 미래 관측 분포 전체를 보존하지만, 이 논문의 target은 공통으로 도달 가능한 future continuation에서 특정 expert의 action 분포만 맞추면 됨. 더 좁고 expert-specific한 target임 - bisimulation·approximate information state 같은 control-state target은 reward·dynamics 보존이 목표라 특정 expert가 무시하는 구분까지 남길 수 있음. 이 논문은 그 구분을 배제함 - 아키텍처(VQ, information bottleneck, variational discriminator bottleneck)는 기존 요소를 그대로 씀. novelty는 architecture가 아니라 representation target의 정의와 characterization에 있음
Benchmark Results
- Task A(0-bit 요구, hidden mass M=4~512)에서 K=16 carrier가 모든 M에서 8/8 seed sufficient, grasp 중 code rate 0.00~0.10bit, closed-loop success 0.91~0.99를 보임 - readout-2(2-bit 요구, M까지 512)에서 plain training이 7~8/8 seed sufficient, rate 약 2bit, success 0.85~0.96이며, system identification head는 codebook을 128→1024로 늘려도 rate만 2.25→8.71bit로 커짐 - A'의 anticipatory memory(2→1→0bit 요구)에서 matched-side-information + task-informed supervision이 32/32 run sufficient, grasp 전 2.03~2.09bit·grasp 후 1.00bit, success 0.96~1.00을 달성함 - 제안한 event-agnostic future-behavior supervision은 고정 설정에서 36/40 seed sufficient를 얻고, 가장 긴 horizon의 pixel 설정에서 held-out sufficient seed를 0/8→6/8, success를 0.08→0.57로 개선함 - bsuite memory chain·Passive T-maze(수정 없이 사용)에서 192 run 중 87 run이 mid-delay 인증 rate와 일치했으나 delay 100에서는 32 run 전부 실패함. 물리적 weighing task(질량 최대 2.5kg)에서도 grasp-side accuracy는 0.30→0.99로 회복되지만 전체 success는 0.13~0.38에 머무름
누리랩 연구와의 연결
- robot memory 연구에서 아키텍처를 정하기 전에 '얼마나 많은 memory가 필요한가'를 정량화하는 진단 틀로 이 compatibility relation과 SΓ/SG 측정 프로토콜을 그대로 가져다 쓸 수 있음 - anticipatory memory(2→1→0bit) 개념은 failure detection·recovery에서 recovery 시점까지 유지해야 할 과거 정보를 식별하는 데 응용 가능함 - VLA의 long-horizon manipulation에서 context 압축이나 test-time memory 크기 결정에 이 measurement protocol을 적용해 불필요한 recurrent state를 진단하는 실험을 설계할 수 있음

Brain-Inspired Hierarchical Modularity for General Continual Learning

arXiv PDF alphaXiv
Continual Learning (VLA 포함 멀티도메인) relevance 8/10 Machine Learning (cs.LG)
Hongwei Yan, Kanglei Zhou, Qi Cheng, Weiyi Dong, Chunyan Lan, Guanglong Sun, Jun Zhou, Qian Li 외 2명 PDF 전문 1차 65점
Drosophila 후각 학습계의 ORN-PN-KC 구조에서 착안해 sparse random expansion 기반 MoE routing과 spatial-temporal ensemble learning(EL)을 계층적으로 결합한 FlyGCL을 제안함. Pretrained backbone은 고정하고 LoRA/adapter/prompt 같은 경량 모듈만 온라인으로 학습시켜, visual recognition·vision-language·ego-exo video·embodied VLA(LIBERO) 네 도메인에서 replay-free 조건의 online continual learning 성능을 대체로 끌어올림.
Core Innovation & Methodology
- FlyGCL은 Drosophila 후각계의 ORN-PN-KC 계층을 계산적으로 재해석해, sparse random expansion 기반 expert routing(MoE)과 spatial/temporal multi-timescale ensemble(EL)을 하나의 계층 구조로 결합함. - Expert router는 별도 gradient 학습 없이 latent space에서의 closed-form ridge regression으로 instance 단위 routing을 풂. - 각 expert에 fast/medium/slow 세 timescale 예측 head를 둬 short-term부터 long-term까지의 기억을 temporal ensemble로 통합함. - Pretrained backbone을 안정적 표상으로 고정하고 경량 adaptation 모듈만 계속 학습시켜, 여러 backbone·adaptation 방식(prompt/adapter/LoRA)에 이식 가능하게 설계함.
Novelty vs. Prior Works
- MoE와 ensemble learning을 결합한다는 아이디어 자체는 새롭지 않고, 저자들도 일부 구성요소를 이전 conference paper에서 이미 다뤘다고 명시함 — 이번 논문의 핵심 기여는 hierarchical 결합의 생물학적 grounding(FlyWire connectome 통계 반영)과 평가 범위 확장임. - 기존 continual learning 방법(L2P, DualPrompt, CODA-Prompt, MVP, MISA, CLAP4CLIP 등) 대비 본질적 차이는 routing을 gradient-free ridge regression으로 풀고 spatial/temporal 계층을 명시적으로 분리한 점이며, 아키텍처 자체는 경량 모듈의 조합 수준임. - General continual learning(온라인·task 경계 없음·데이터 재출현)이라는 문제 설정은 MVP/MISA 계열에서 이미 정립된 틀을 그대로 채택했고, VLA(LIBERO)로의 확장이 이 논문에서 가장 새로운 실증 기여임.
Benchmark Results
- LIBERO 4개 suite(Spatial/Object/Goal/Long)의 online GCL 세팅에서 FlyGCL Alast는 83.1/86.1/94.5/79.1%로, replay-free 최강 baseline(DualPrompt+ 등) 대비 49.5~58.8%p 높음. - 단 replay를 쓰는 baseline인 ER과 비교하면 LIBERO-Object에서 ER Alast 89.5%가 FlyGCL 86.1%를 오히려 상회함 — FlyGCL 우위는 'replay-free' 조건에서만 성립함. - 연속 시각 인식(CIFAR-100/ImageNet-R/CUB-200)에서 Aauc/Alast가 최강 baseline 대비 각각 3.5%p/6.9%p, 13.8%p/18.7%p, 12.6%p/24.6%p 개선됨. - CLIP 기반 continual vision-language 학습에서 Aauc/Alast 85.2%/79.6%(CIFAR-100), 84.7%/79.3%(ImageNet-R)로 MG-CLIP·CLAP4CLIP을 능가함. - Ablation에서 MoE+EL 결합이 단독 사용보다 항상 우수함(disjoint 세팅 AUC 28.9%→MoE 39.9%→MoE+EL 43.2%). 모든 실험은 시뮬레이션 기반이며 real-robot 검증은 본문에서 확인 불가.
누리랩 연구와의 연결
- FlyGCL의 expert routing + temporal ensemble 구조는 VLA policy의 online continual learning에 바로 적용 가능함 — long-horizon manipulation·skill chaining 연구에서 새 task를 배울 때 기존 skill을 잊지 않는 robot memory 모듈로 활용할 수 있음. - Ridge regression 기반 gradient-free routing은 backprop 없이 즉석으로 expert를 고르는 방식이라, test-time optimization 상황에서 새 상황에 맞는 expert를 빠르게 선택하는 아이디어로 참고할 만함. - 다만 이 논문은 success 신호가 있는 online 학습만 다루고 실패 감지·진단 자체는 다루지 않으므로, failure detection·recovery와 결합하려면 routing 기준을 실패 유형 추정치로 바꾸는 추가 formulation이 필요함.

Skytopia: Monocular Drone Navigation with Action-Conditioned Latent World Models

arXiv PDF alphaXiv
World Model Aerial Navigation relevance 8/10 Robotics (cs.RO)
Yuhang Zhang, Rangya Zhang, Yujing Shang, Zhuoyuan Yu, Weiying Wang, Steven Yang, Qingsong Yan, Chao Yan 외 1명 PDF 전문 1차 62점
단안 카메라 드론 navigation에서 world model이 정책에 줘야 하는 건 예측된 미래 프레임이 아니라 그 예측을 만드는 표현이라는 관찰에서 출발해, forward-inverse dynamics objective로 backbone을 학습시키고 추론 시엔 predictor를 버리는 정책 SKYTOPIA를 제안함. 3DGS로 재구성한 94개 실제 장면 시뮬레이터에서 point-goal·image-goal·goal-free 세 과제 모두 최강 baseline(OmniVLA) 대비 성공률을 15%p 이상 높였고, 추론 FLOPs를 59.4% 줄이면서 fine-tuning 없이 실제 드론 비행에도 전이됨.
Core Innovation & Methodology
- world model의 존재 이유를 재정의함: 정책에 필요한 건 predictor가 만든 미래 예측값이 아니라 그 예측을 만드는 backbone 표현이므로, dynamics objective는 학습에만 쓰고 추론에서 predictor를 통째로 버림. - forward objective는 action token 조건으로 frozen video encoder(V-JEPA2) latent의 다음 시점 표현을 L1으로 예측함. - inverse objective는 예측된 transition에서 실제 실행된 velocity command를 복원해, forward만 쓸 때 생기는 과거 외삽 shortcut을 차단함. - 3DGS + rigid-body physics로 실사 94개 장면(indoor/urban/vegetation)을 재구성한 시뮬레이션 플랫폼을 새로 구축해 32.5M frame을 확보하고, Qwen3-VL-2B backbone과 flow-matching DiT action head로 point-goal/image-goal/goal-free 세 모드를 하나의 정책으로 통합함.
Novelty vs. Prior Works
- 가장 가까운 prior work인 FutureNav(2026)가 이미 dynamics objective를 학습에만 쓰고 추론 시 predictor를 버리는 구조를 제안함. SKYTOPIA는 이를 continuous velocity command·flow-matching action head로 확장하고 단안 드론 도메인에 특화했다는 점에서 formulation 자체의 신규성은 제한적임. - WorldVLN(2026)도 항공 도메인을 다루지만 video backbone을 closed-loop로 계속 돌려 추론 비용 문제를 안고 있고, 저자들도 이 지점을 직접 차별점으로 명시함. - forward+inverse latent 예측과 frozen target encoder로 collapse를 막는 구성은 JEPA류 self-supervised representation learning의 표준 레시피와 유사해, 기여의 무게는 알고리즘적 도약보다 단안 드론이라는 새 도메인 적용과 대규모 실사 3DGS 플랫폼 구축에 있음.
Benchmark Results
