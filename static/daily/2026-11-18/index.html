Body Schema Policy: Body as the Vision-Action Interface for Efficient Robot Loco-Manipulation

arXiv PDF alphaXiv 프로젝트 페이지
Manipulation relevance 9/10 Robotics (cs.RO)
Lechen Zhang, Chenyuan Chen, Muxin Zhou, Zewen He, Yoshihiko Nakamura PDF 전문 1차 68점
로봇의 관절 트리 위에 관절·링크 token을 두고, 각 신체 부위가 이미지에서 필요한 부분을 따로 읽어 자기 행동을 denoising하는 35M 파라미터 imitation learning policy를 만듦. SIMPLE의 Unitree G1 전신 과제 9개에서 2.63B 파라미터 VLA Ψ0와 같은 성공 횟수(270회 중 221회 대 220회)를 냄. visual key·value 캐싱과 CUDA graph를 쓰면 RTX 6000 Ada에서 action chunk 하나를 13.9ms에 냄.
무슨 문제인가
휴머노이드나 모바일 매니퓰레이터의 loco-manipulation에서 가장 잘하는 policy는 수십억 파라미터의 VLA나 world-action model(WAM: 미래 영상과 행동을 함께 모델링하는 모델)이고, 이마저도 과제마다 fine-tuning이 필요함. Diffusion Policy 같은 일반 visuomotor policy는 행동을 좌표의 평평한 벡터로, 이미지를 행동 전체가 공유하는 하나의 feature로 다룸. 그래서 관절들이 어떻게 함께 움직이는지, 이미지의 어느 부분이 어느 신체 부위에 중요한지를 demonstration에서 통째로 배워야 함. 저자들은 MLP나 Transformer가 학습 범위 밖 관절 구성에서 forward kinematics를 제대로 외삽하지 못하는 것을 이 문제의 한 예로 듦.
어떻게 푸나
BSP(Body Schema Policy)는 Diffusion Policy와 같은 DDPM 노이즈 예측 방식의 policy이고, 입력은 egocentric 이미지와 proprioception, 출력은 H스텝 action chunk임. 먼저 현재 noisy action chunk, denoising step, 로봇 상태로부터 관절 token, 링크 token(채널마다 4×4 행렬), 전신용 global token을 만들고, 이를 latent body schema라 부름. Neural Screw Operator는 각 관절 token에서 latent 관절 좌표를 예측하고, 학습된 screw motion(회전축 둘레 회전과 축 방향 이동을 합친 변환)으로 부모 링크 feature를 자식 링크로 옮김. 이는 forward kinematics가 관절 변환을 차례로 곱해 링크 자세를 구하는 구조를 그대로 따름. 중간중간 body-queried vision 단계에서 각 관절 token과 global token이 query가 되어 DINOv2 patch token에 cross-attention을 하고, 각자 필요한 시각 정보를 가져옴. 마지막으로 관절 좌표는 해당 관절 token에서, 이동 속도 같은 트리 밖 명령은 global token에서 condition을 받아 하나의 공유 temporal decoder가 각 행동 좌표의 노이즈를 예측함. 실제 관절 구동은 시뮬레이션에서 GR00T N1.6의 whole-body controller, 실로봇에서 HoloMotion v1.4가 맡음.
결과
- SIMPLE(Unitree G1 휴머노이드 전신 loco-manipulation 시뮬레이션 벤치마크)의 과제 9개에서 과제당 30 episode로 잼. 총 성공 횟수는 BSP 221회, Ψ0 220회, Diffusion Policy 111회, π0.5 121회, DreamZero(WAM) 167회임. Ψ0는 사람 영상 약 800시간과 휴머노이드 데이터 30시간으로 사전학습됐고, BSP는 과제당 demonstration 약 100개만 씀. - 같은 DINOv2 encoder와 비슷한 크기(34.9M)를 쓰는 Patch Policy는 177회임. 물체·로봇 자세를 바꾸는 L2 수준에서는 BSP 71회, Patch Policy 46회, Ψ0 63회로 BSP가 가장 높음. - ManiSkill-HAB(Fetch 모바일 매니퓰레이터의 가정 환경 정리 벤치마크) SetTable 세부 과제 3개에서 seed 3개 평균 성공률을 잼. Open fridge·Close fridge·Place 과제 성공률이 각각 BSP 34.4%·20.6%·16.5%, π0.5 33.4%·11.4%·13.3%, Diffusion Policy 18.7%·13.2%·6.5%임. - 실제 G1에서 과제 2개(카트 밀고 물건 집기, 발로 휴지통 열고 버리기)를 demonstration 15개로 학습하고 과제당 10회 시험함. 총 성공은 BSP 16회, Ψ0 13회, Diffusion Policy 3회이고, chunk 생성 시간은 RTX 5090에서 17.4ms 대 137ms 대 284ms임.
한계
SIMPLE 평가와 ablation은 seed 하나로만 돌렸고, 실로봇은 과제 2개에 과제당 10회라 Ψ0와의 차이(16회 대 13회)는 통계적으로 가르기 어려움. 13.9ms는 visual key·value 캐싱과 CUDA graph를 쓴 결과이고, baseline에도 같은 최적화를 했는지는 본문에서 확인 불가임. 방법은 행동이 관절 공간 명령이라는 가정에 기대며, SONIC처럼 latent 공간으로 명령받는 whole-body controller에서는 효과가 줄었다고 저자들이 밝힘. 코드 공개 여부는 본문에서 확인 불가임.
누리랩 연구와의 연결
- 로봇의 운동학 구조를 policy 내부 표현으로 넣어 작은 모델로 manipulation 성능을 내는 사례임. VLA action head를 관절 단위 token과 body-queried attention으로 바꾸는 실험의 직접 비교 대상이 됨. - 각 관절 명령이 이미지의 어느 patch에 민감한지 관절별로 볼 수 있으므로, 실패 시 어느 신체 부위가 무엇을 잘못 봤는지 진단하는 failure diagnosis 도구로 쓸 여지가 있음.

DreamFAR: Real-Time and Long-Horizon Interaction with Diverse Objects

arXiv PDF alphaXiv 프로젝트 페이지
World Model relevance 9/10 Robotics (cs.RO)
Yiming Dou, Botao He, Antonio Loquercio, Andrew Owens, Jitendra Malik, Sumedh Anand Sontakke, Ruoshi Liu PDF 전문 1차 66점
internet video pretraining 없이 로봇 teleoperation 데이터만으로 처음부터 학습한 action-conditioned world model로, 10 Hz 실시간 조작과 분 단위 rollout을 지원함. 공개 ABC 데이터의 held-out 1,000개 episode에서 60초 rollout 평균 PSNR이 16.4 dB로, 가장 나은 baseline Cosmos-Predict 2.5의 15.8 dB보다 높음.
무슨 문제인가
로봇 world model을 조작 simulator로 쓰려면 수십 초 이상 앞을 예측해도 오차가 쌓이지 않아야 함. 대형 video generator를 robot data로 post-training한 모델은 2B~14B parameter 규모이고, 학습 길이를 넘겨 생성하면 오차가 누적됨. 긴 rollout을 하는 기존 모델(실시간 장기 상호작용 생성을 하는 IWS(Interactive World Simulator) 등)은 다양한 contact-rich 조작 장면으로 일반화하지 못함. 또 짧은 context window만 보면 물체가 시야를 벗어난 뒤 어디에 놓였는지를 잊음.
어떻게 푸나
DreamFAR는 세 view 영상을 latent로 바꾸는 tokenizer와, action을 받아 다음 latent를 예측하는 1.9B parameter causal transformer로 이루어짐. SSDD는 Single-step diffusion decoder라는 기존 image tokenizer임. tokenizer는 SSDD 기반 encoder로 각 256×256 view를 16×16×16 latent로 만들고, 위치마다 unit sphere 위로 정규화해 rollout 중 latent 크기가 흐트러지는 것을 막음. dynamics transformer는 최근 5초(50 frame)의 latent, 14차원 action, 학습된 sink frame 하나(noise를 넣지도 지우지도 않는 고정 attention 대상), memory slot 8개를 입력으로 받음. 출력은 다음 frame latent, 관절 상태, 양팔 각각의 contact 여부(contact bit)임. contact bit가 바뀌는 순간(잡거나 놓는 순간)의 frame을 keyframe bank에 넣고, 현재 end-effector pose와 비슷한 keyframe을 꺼내 memory로 씀(contact-based memory). contact head는 fine-tuning한 VLM이 붙인 label로 학습함. rollout 중에는 모델 자신의 contact 예측만으로 bank를 갱신함. 추론 때는 noise 수준이 서로 다른 16개 frame을 rolling KV cache 위에서 동시에 denoise하는 방식으로 frame을 계속 내보냄.
결과
- ABC(공개 양팔 조작 데이터: 201개 과제, 약 131k episode)로 모든 모델을 학습하고 held-out 1,000개 episode를 15초 실영상으로 시작해 60초 rollout함. 평균 PSNR은 DreamFAR 16.4 dB, Cosmos-Predict 2.5 15.8 dB, WEAVER(robot 데이터로 학습한 causal world model) 14.5 dB, IWS 11.0 dB임. 이 비교에서는 DreamFAR를 1.9B가 아닌 약 0.8B로 줄여 WEAVER와 크기를 맞췄고, IWS는 step 시간을 맞춰 약 0.4B로 둠. - 같은 60초 동안 FID는 DreamFAR가 15에서 32로 오르고, Cosmos-Predict 2.5는 30에서 73, WEAVER는 46에서 87로 오름. IWS는 계속 180 위에 머묾. - policy evaluation: π0 checkpoint 2개와 실제 과제 3개(접시 정리, 병 던져 넣기, 티셔츠 개기)를 world model 안과 실로봇에서 각 32 episode씩 돌림. checkpoint 2개 × 과제 3개 = 6개 조합의 평균 task progress를 world model과 실로봇에서 비교한 Pearson 상관은 r = 0.71이고, 순위는 3개 과제 중 2개에서만 유지됨. world model 쪽 progress가 대체로 더 높게 나옴. - co-training: 과자 봉지 3개를 바구니에 넣는 과제 하나에서 실제 demonstration 75개에 world model 안에서 teleoperation으로 모은 75개를 더해 π0를 학습함. 실로봇 10회 평가에서 task progress가 63%로, 실제 데이터만 쓴 경우의 약 2배임(실제 데이터만의 정확한 값은 본문에서 확인 불가).
한계
policy evaluation은 데이터 점 6개, co-training은 과제 1개와 10회 시행뿐이라 실로봇 근거가 좁음. 주 모델의 학습 데이터는 YAM 양팔 로봇에서 모은 내부 원격조종 데이터이고(baseline 비교만 공개 ABC로 다시 학습함), 저자도 장면 다양성, 단일 embodiment, 다지 손 부재를 한계로 적음. contact-based memory의 효과는 과제 하나(양념병 정리)의 ablation으로만 보였고, PSNR 차이가 0.263 dB로 작음. 저자는 코드와 weight 공개를 밝혔으나 본문에 저장소 주소는 없음.
누리랩 연구와의 연결
- 잡기·놓기 순간을 keyframe으로 저장하고 end-effector pose로 꺼내는 방식은 robot memory와 object-centric 장면 상태 추적에 바로 가져다 쓸 수 있는 설계임. - world model 안에서 VLA policy를 돌려 실로봇 성능 순위를 가늠하는 실험은 failure detection이나 test-time planning용 world model을 평가할 때 비교 기준이 됨. 다만 과대평가 경향이 있어 실로봇 검증이 함께 필요함.

InteractVLA: Turning VLAs into Interactive Tools for Agentic Robotic Manipulation

arXiv PDF alphaXiv 프로젝트 페이지
VLA relevance 9/10 Robotics (cs.RO)
Chen Zhao, Zipeng Ye, Shifeng Bao, Yihan Lin, Haitao Shen, Yining Luo, Yuchen Xie, Jing Zhang PDF 전문 1차 66점
VLA를 언어 지시로만 부르던 agent가 end-effector 목표 자세를 넣어 고정된 VLA의 action 생성을 조종하고, 생성된 action chunk를 돌려받아 고치게 함. LIBERO-Plus에서 같은 agent와 VLA 조합의 전체 성공률이 93.1%에서 98.3%로 오름.
무슨 문제인가
agent가 pretrained VLA를 도구로 쓰는 기존 시스템은 VLA를 언어 지시만 받는 black box로 다룸. 그래서 VLA 호출이 실패하면 agent는 같은 지시로 다시 부르거나 지시 문장을 바꾸는 것밖에 할 수 없음. 다시 부르면 비슷한 관측에서 거의 같은 동작이 나오고, 지시를 바꾸면 VLA가 학습 분포를 벗어나 성공률이 크게 내려감. 결국 agent가 저수준 제어를 직접 떠맡게 되며, 이때 VLA가 가진 접근 궤적과 grasp timing 같은 motor prior를 쓰지 못함.
어떻게 푸나
InteractVLA는 flow-matching 기반 VLA를 고정한 채 test time에만 동작하며, agent가 준 목표 G(end-effector 위치, 자세, gripper 상태)를 입력으로 받음. denoising 각 단계에서 clean action 추정값을 미분 가능한 command-to-pose mapping으로 자세로 바꾸고, 목표와의 자세 오차를 계산함. 이 오차의 gradient를 velocity field에 더해 action chunk를 목표 쪽으로 옮김. confidence는 step 중 최소 자세 오차와 필요한 보정량을 각 허용치로 나눈 값 중 큰 쪽 x에 대해 exp(-x)로 계산함. 첫 guided step 뒤 confidence가 e^-1 아래면 생성을 멈추고 agent에 재계획을 넘김. 목표에 도달하는 step은 미리 정하지 않음: soft-time target alignment는 step별 오차에 log-sum-exp를 씌워 denoising이 진행될수록 가장 잘 맞는 step에 guidance를 모음. 반대 방향인 action-informed agentic refinement는 생성된 chunk, 실행된 부분, 보정된 카메라로 재투영한 예상 자세를 agent에 보여 줌. agent는 이를 관측과 비교해 목표를 고쳐 VLA를 다시 부르거나 궤적 일부만 직접 고침. 평가 장면과 다른 연습 환경에서 이 과정을 반복해 전략을 쌓는 것을 RSI(recursive self-improvement)라 부름.
결과
- LIBERO-Plus(LIBERO 조작 과제에 배경·조명·카메라·로봇 초기 자세 등 7종 교란을 건 benchmark)에서 agent는 GPT-6.1 Sol, VLA는 MR-0으로 고정함. 이 조합의 전체 성공률이 언어 지시만 쓸 때 93.1%, InteractVLA를 붙이면 98.3%임. 배치 교란은 89.5%에서 98.4%로, 카메라 시점 교란은 87.6%에서 98.4%로 오름. - RoboDojo(양팔 과제를 포함한 generalist 조작 policy 평가 benchmark)에서 같은 비교의 전체 성공률이 18.0%에서 26.0%로 오름. RSI까지 더한 최종 값은 48.62%로 leaderboard 최고 baseline HexaShell-Preview(46.85%)보다 1.77퍼센트포인트 높음. 평가 차원 중 memory(63.89% 대 81.00%)와 open-ended 조작(41.67% 대 55.25%) 영역은 HexaShell-Preview보다 낮음. - RoboDojo ablation에서 도달 step을 정하는 방식만 바꾸면 성공률이 모든 step 평균 34.7%, 마지막 step 고정 39.1%, 오차 최소 step 하나 44.2%, soft-time 48.6% 순임. agent에 관측만 줄 때 40.3%이고, action chunk를 더하면 44.8%, 재투영까지 더하면 48.6%임. - 실제 Dexmal 로봇 과제 4개에서 과제당 demonstration 50개로 MR-0를 학습하고 과제당 30회 평가함. 물 붓기 task score(척도는 본문에서 확인 불가)가 언어 지시 기반 Agent + VLA의 38.5에서 79.2로 오름. Move Cube는 86.7에서 97.6으로 오르고 실행 시간은 165.2초에서 67.5초, API 호출은 14.4회에서 4.7회로 줆.
한계
RSI 비교의 baseline 수치는 다른 논문과 leaderboard에서 가져온 값이라 agent 모델과 평가 subset이 다름. LIBERO-Plus의 기존 agent 기반 VLA 시스템 HarnessVLA, RV-ICL 값은 GPT-6 Astra로 120-variant subset에서 잰 값임. 시뮬레이션 성공률과 ablation에 시행 횟수나 분산이 없고, VLA backbone은 MR-0 하나만 실험함. 방법은 agent가 쓸 만한 목표 자세를 낼 수 있고 보정된 카메라와 RGB-D가 있다는 가정에 기대며, 코드 주소는 본문 텍스트에서 확인 불가임.
누리랩 연구와의 연결
- 고정된 flow VLA의 denoising에 자세 목표 gradient를 넣는 test-time guidance와, 생성 chunk를 재투영해 실패를 진단하는 구조가 한 시스템에 묶여 있음. VLA test-time optimization과 failure diagnosis/recovery 연구에서 비교 대상으로 쓸 수 있음. - 도달 시점을 latent로 두는 soft-time alignment는 keypoint나 affordance 같은 sparse 목표로 VLA를 조종하는 다른 manipulation 연구에도 옮겨 쓸 수 있음.

Plausible Videos Can Lead to Poor Decisions: Diagnosing and CURE-ing World Models for Planning

arXiv PDF alphaXiv

ReLAP은 영상에서 시간적으로 이어지는 latent action을 배워 VLA 사전학습에 쓰는 방법이며, 세 단계로 학습함. Stage 1은 영상만 씀. 영상 프레임은 고정된 V-JEPA 2.1(Joint-Embedding Predictive Architecture 계열 영상 self-supervised encoder)로 feature가 됨. 이 feature 위에서 inverse dynamics model이 인접 관측 쌍마다 16차원 연속 latent action을 추론함. forward model(LWM, latent world model)은 각 전이를 따로 복원하는 local 손실과 함께, 첫 feature에서 출발해 자기 예측을 다음 입력으로 4단계(0.4초 간격, 총 1.6초) 굴리는 rollout 손실을 받음. rollout 오차가 앞쪽 latent action까지 역전파되므로 latent 열 전체가 서로 맞게 학습됨. Stage 2는 Qwen3-VL-2B 기반 VLM이 현재 이미지와 지시문만 보고 latent 열 4개를 Q-Former로 한 번에 예측하게 함. 손실은 고정된 inverse model 출력으로의 distillation과, 예측한 latent 열을 고정된 LWM으로 굴려 얻은 미래 JEPA feature 오차임. Stage 3은 LIBERO demonstration으로 flow matching action expert를 붙여 8단계 7차원 action chunk를 출력함. 배포 시에는 latent·world model 가지를 떼고 VLM이 행동을 직접 냄.
결과
- LIBERO(시뮬레이션 조작 과제 40개, 과제당 50회 총 2,000 episode) 평균 성공률이 97.9%임. 가장 높은 RotVLA 98.2%, ALAM 98.1%보다 각각 0.3, 0.2퍼센트포인트 낮음. 사전학습 표본 11M개는 RotVLA·ALAM보다 적고, 학습 parameter 1.06B은 7B UniVLA보다 적다는 것이 저자 주장임. - LIBERO-Plus(LIBERO 과제를 카메라 시점, 초기 상태, 언어, 조명, 배경, 센서 noise, 물체 배치 7축으로 교란한 10,030개 사례) zero-shot 평균은 70.0%임. VLA-JEPA 79.5%보다 9.5퍼센트포인트, LAWA 74.4%보다 4.4퍼센트포인트 낮음. 카메라 시점 교란에서는 20.5%로 내려감. - LARY(latent action을 linear probe로 실제 행동 회귀·분류에 쓸 수 있는지 재는 benchmark)에서 평균 회귀 MSE 0.24, 평균 분류 정확도 65.76%임. RotVLA는 0.20, 70.98%로 두 지표 모두 ReLAP보다 좋음. - latent 4개의 시간 순서가 의미를 갖는지 확인한 probe임. latent 순서를 뒤집으면 rollout 오차가 Bridge(Bridge-v2 로봇 영상의 held-out 구간)에서 4.03%, LIBERO-40에서 2.50% 늘어남. 시간 구간이 맞는 latent로 실제 행동을 선형 예측한 R²는 Bridge 0.360 대 어긋난 쌍 0.225임.
한계
recurrent rollout 손실을 뺀 local 손실만의 ablation이 없어서, 핵심 주장인 rollout 손실의 효과가 policy 성능으로 직접 확인되지 않음. 실험은 모두 시뮬레이션(LIBERO, LIBERO-Plus)과 오프라인 probe이고 실로봇 실험은 없으며, 코드 공개 언급도 없음. 저자는 rollout 앞쪽 latent가 더 강한 학습 신호를 받는 비대칭과 다시점 불변성 부재를 한계로 듦.
누리랩 연구와의 연결
- 예측한 상태를 다시 입력으로 넣어 여러 단계 오차로 행동 표현을 학습하는 방식은, world model 기반 test-time planning에서 compounding error를 줄이는 학습 목표로 비교해 볼 만함. - latent action 4개의 순서를 뒤집거나 그중 하나만 망가뜨려 rollout 오차 변화를 재는 probe는 VLA 사전학습 표현의 시간 구조를 점검하는 평가 도구로 가져다 쓸 수 있음.

Outcome-Balanced PPO and Policy-Induced Flow Rectification for Flow-Based VLA Policies

arXiv PDF alphaXiv
VLA relevance 9/10 ICLR 양식 (추정) Artificial Intelligence (cs.AI)
Yuhan Wang, Ruiyang Wang, Jiaguan Zhu PDF 전문 1차 72점
π0.5 같은 flow 기반 VLA를 PPO로 후학습할 때 과제별·부호별 advantage 크기를 맞추고, 바뀐 velocity field를 주기적으로 다시 맞추는 두 장치를 더함. 시뮬레이션 4개 benchmark 평균 성공률이 flow 기반 VLA RL의 기존 최고 방법 πRL의 86.6%에서 88.9%로 오름.
무슨 문제인가
flow 기반 VLA를 online RL로 학습하려면 ODE sampler를 같은 marginal을 갖는 SDE로 바꿔 transition likelihood를 구해야 함. 이 방식은 Flow-GRPO가 처음 제안함. 이때 SDE에 들어가는 score는 선형 경로를 가정한 closed-form 식으로 근사됨. PPO가 velocity field를 바꾸면 이 가정이 덜 맞게 되어, 학습용 SDE sampler와 평가용 ODE sampler의 분포가 벌어질 수 있음. 또한 sparse reward 다중 과제 학습에서는 성공률이 낮은 과제의 positive 신호가 드물고, positive와 negative advantage의 크기도 서로 다름.
어떻게 푸나
방법은 Outcome-Balanced PPO와 Policy-Induced Flow Rectification 두 부분으로 이루어짐. Outcome-Balanced PPO는 먼저 과제별 성공률의 지수이동평균(EMA)을 구함. DAA(difficulty-aware allocation)는 positive advantage에 0.75~1.25 범위의 과제별 가중치를 주되, 성공률이 낮은 과제일수록 큰 값을 줌. 이어서 paired advantage normalization은 positive와 negative advantage 묶음을 각각 전체 평균 절댓값에 맞춰 rescale하되 부호는 유지함. Flow rectification은 SDE와 ODE marginal 차이가 임계값 γ를 넘을 때 PPO를 멈추고 시작됨. 현재 policy를 고정해 Gaussian noise에서 deterministic ODE로 action 끝점을 만듦. 이 (관측, action, noise) 쌍을 잇는 직선 경로에 flow matching으로 action expert를 다시 맞춤. 이후 다시 맞춘 velocity field로 PPO를 이어 감. VLM은 고정하고 action expert와 critic만 학습함.
결과
- 시뮬레이션 benchmark 4개는 LIBERO(언어 조건 조작 과제 suite 4개), ManiSkill(접촉이 많은 조작), MetaWorld(Sawyer 팔 50종 과제), CALVIN(이어지는 언어 지시 과제)임. 4개 평균 성공률이 πRL의 86.6%에서 88.9%로 오름. ManiSkill이 90.9%에서 95.0%로 가장 크게 오르고, LIBERO는 97.9%에서 98.4%로 오름. 각 benchmark는 10 seed × 1,000 episode로 평가했으나 seed 간 분산은 보고하지 않음. - 같은 PPO baseline에 rectification만 더했을 때 평균 87.6%이고, ReFPO처럼 reflow loss를 PPO loss에 함께 더한 경우는 84.7%임. 부호 유지 rescale을 BAPO(LLM RL에서 positive·negative 기여의 불균형을 clipping 범위 조정으로 맞추는 방법)식 adaptive clipping과 비교하면 평균 88.3% 대 85.9%임. - ablation은 ManiSkill, MetaWorld, CALVIN, LIBERO suite 4개의 7개 항목을 같은 가중치로 평균한 macro 평균으로 잼. 4개 benchmark 평균과 집계 방식이 달라 πRL 값이 91.4%임. 구성 요소를 하나씩 더하면 macro 평균이 91.4%(πRL), 92.0%(+DAA), 92.7%(+paired normalization), 93.0%(+rectification) 순으로 오름. 단계마다 차이는 1퍼센트포인트 이하임. - 실로봇은 Franka FR3로 당근을 접시에 옮기는 과제 1개이며, 시뮬레이션에서 학습한 policy를 실제 로봇에서 100회 평가함. 표준 PPO는 32%, paired normalization과 실패 초기 상태 재사용(failed-state replay)을 더한 경우는 43%임. 이 실험에는 rectification과 DAA가 들어가지 않음.
한계
실로봇 실험은 과제 1개이고, 제안한 전체 framework가 아니라 일부 구성 요소에 논문 본문의 방법에 없는 failed-state replay를 더한 조합만 평가함. 시뮬레이션 개선 폭은 대부분 1~4퍼센트포인트인데 seed 간 표준편차나 유의성 검정이 없어 차이가 잡음보다 큰지 판단하기 어려움. 본문에 코드 공개 주소가 없고, rectification이 실제로 score 근사 오차를 줄여서 성능이 오르는지는 marginal 차이 그림 외에 인과적으로 보이지 않음.
누리랩 연구와의 연결
- π0.5 계열 VLA를 RL로 후학습할 때 SDE 학습 sampler와 ODE 배포 sampler 사이의 차이를 재고 줄이는 절차를 제시함. 누리랩의 VLA RL fine-tuning 실험에서 학습 중 진단 지표로 쓸 수 있음. - 실로봇 실험에서 실패한 초기 상태를 다시 쓰는 failed-state replay는 failure recovery 연구의 단순 baseline으로 비교할 만함. 다만 본문 방법의 일부는 아님.

FailureGen: Scalable Robot Failure Data Generation with World Models

arXiv PDF alphaXiv 프로젝트 페이지
World Model relevance 9/10 CoRL 양식 (추정) Robotics (cs.RO)
Akul Santhosh, Chaitra Sathe, Aastha Jhunjhunwala PDF 전문 1차 68점
실제로 녹화된 실패 궤적의 동작을 성공 녹화 장면에 옮겨 심고, action-conditioned world model로 새 실패 영상을 만들어 failure detector 학습 데이터를 늘림. 산업용 양팔 과제에서 실패 구간 36개 중 탐지한 수가 real 데이터만 쓸 때 28개에서 33개로 오름.
무슨 문제인가
로봇 실패는 로봇 동작, 물체 배치, 접촉 조건이 특정하게 맞물려야 일어나므로 많이 모으기 어려움. 드문 실패 유형은 실제 실행을 반복해도 데이터셋에 적게 남음. 기존 연구 AHA는 시뮬레이션에서 절차적으로 동작을 흔들어 실패를 만들고, Dream2Fix는 world model 위에서 action을 흔든 뒤 여러 verifier로 결과를 거름. 두 방식 모두 실제로 관측된 실패 동작을 다른 장면에서 다시 쓰지는 않음.
어떻게 푸나
FailureGen은 실패 동작을 주는 녹화(donor)와 장면과 정상 동작을 주는 성공 녹화(host)를 짝지어 새 실패 영상을 만드는 4단계 파이프라인임. 첫째, NVIDIA의 사전학습 video world model인 Cosmos3-Nano를 성공·실패 녹화로 fine-tuning함. 학습 샘플마다 동작으로 영상을 생성하는 forward dynamics와 영상에서 동작을 예측하는 inverse dynamics 중 하나를 무작위로 배정함. 둘째, vision-capable LLM 여러 개로 구성한 agentic labeling pipeline이 녹화마다 과제 단계, 실패, 회복 구간의 시작·끝 시각을 붙이고, 같은 과제 단계에서 donor 구간과 host 구간을 짝지음. 셋째, donor의 실패 동작을 host 녹화에서 실패 동작을 끼워 넣을 구간이 시작되는 시점의 로봇 상태에 맞춰 이어 붙이고, 필요하면 공간 offset을 더해 개입 위치를 바꿈. world model은 host 첫 관측, 수정된 동작 열, 텍스트 설명을 입력받아 3.2초 길이의 영상을 출력함. 넷째, 생성 영상을 같은 labeling pipeline으로 다시 라벨링하고 사람이 검토해 시각적 결함이 있는 영상을 걸러 냄. 라벨은 의도한 실패가 아니라 영상에 실제로 보이는 사건을 따름.
결과
- 산업용 양팔 YAM 로봇의 SMT reel 집기·건네기·쌓기 과제(사내 데이터, 실제 녹화 80개)에서 Cosmos3-Edge 기반 failure detector를 학습함. Cosmos3-Edge는 영상 생성에 쓴 Cosmos3-Nano와 다른, visual tower와 language decoder를 갖춘 사전학습 모델임. 별도 녹화 세션의 실패 구간 36개 중 탐지한 수가 real만 쓴 가장 좋은 설정의 28개에서 생성 영상 75개를 더한 설정의 33개로 오름. - 같은 비교에서 timestamp 단위 average precision은 0.41에서 0.51로 오름. 실패 없는 정상 episode 41개 중 경보가 울린 episode 수는 5개에서 0개로 내림. task 전용 fine-tuning 없는 모델은 41개 모두에서 경보를 냄. - ViFailback(실패가 포함된 조작 녹화 데이터셋)의 과제 3개에서 Qwen3-VL-2B와 8B를 episode 단위 성공·실패 분류로 fine-tuning함. 서랍·캔 과제에서 2B 모델의 정확도가 84.4%에서 97.0%로 오름. - ViFailback의 vial/test-tube rack 과제는 2B 모델에서 58.5%로 변화가 없고, 8B 모델도 49.6%에서 54.1%로 오르는 데 그침. 모델·과제 조합 6개 중 5개에서 오르고 1개는 유지됨.
한계
결과는 실제 녹화와 생성 영상으로 학습한 탐지기를 실제 녹화로 평가한 것이며, policy 학습이나 실로봇 closed-loop 실행에는 쓰지 않음. 산업 실험은 평가 세션 하나와 실패 구간 36개뿐이고, 평가 라벨 일부는 false positive를 본 뒤 수정됨. real-only 설정과 augmented 설정은 negative 표본 수와 update 수(real-only 400, augmented 295)도 달라 데이터 효과만 분리되지 않음. 생성 영상 필터링에 사람 검토가 들어가며, ViFailback 평가 episode 수와 코드 공개 여부는 본문에서 확인 불가임.
누리랩 연구와의 연결
- failure detection 데이터를 world model로 늘리는 사례로, 실패 동작을 다른 장면에 옮겨 결과를 상상하는 방식은 counterfactual failure synthesis 연구와 직접 비교할 수 있음. - 생성 결과에 의도가 아니라 관측된 사건으로 라벨을 붙이는 절차는, world model 기반 failure recovery 데이터를 만들 때 라벨 오염을 줄이는 기준으로 참고할 수 있음.

오늘의 흐름

  • world model의 예측이 결정에 실제로 쓰이는지 재는 도구: 영상이 그럴듯해도 결정이 틀릴 수 있다는 진단과, 그 정도를 수치로 재는 방법이 함께 나옴. CURE는 학습 데이터가 그 행동을 얼마나 덮는지(support)와 모델 오차로 계획을 판정하고, RelayWAM은 action 경로가 미래 예측 정보를 실제로 읽는지 층별로 잼.
  • world model에 기억을 붙여 긴 과제를 다룸: 상상 rollout이나 계획 비용에 명시적 기억을 더해 긴 horizon의 실패를 줄임. DreamFAR는 잡기·놓기 keyframe을 저장하고, EPM(executable perceptual memory)은 지각 상태를 상상 안에서 갱신함. EKR(Episodic Kernel Repulsion)은 지나간 latent를 기억해 같은 상태로 되돌아가는 계획에 벌점을 줌.
  • 실패 데이터와 진행도를 world model로 만듦: 실패 감지에 필요한 신호를 world model에서 얻는 연구가 늘어남. FailureGen은 실패 동작을 다른 장면에 옮겨 실패 영상을 생성하고, Progress Predicts Policy는 진행도 함수의 gradient를 명령으로 쓰면서 그 값으로 성공 여부도 가름.
  • VLA의 입력과 후학습 절차를 고침: VLA 가중치를 고정한 채 demonstration 선택은 rollout으로 잰 유용도로 context를 고르고, InteractVLA는 agent가 목표 자세로 action을 조종함. Outcome-Balanced PPO는 flow 기반 VLA의 PPO 후학습에서 과제별 advantage 크기를 맞추고 velocity field를 주기적으로 다시 맞춤.
  • 로봇 몸 구조와 시연 데이터 출처를 policy에 반영함: Body Schema Policy와 cross-robot 조합 일반화는 운동학 구조를 action 표현에 넣음. PriDex는 사람 영상에서 양팔 dexterous 시연을 만들고, ALOHA Lightning은 kinesthetic teaching으로 빠른 시연을 모아 policy 실행 시간을 줄임.

해볼 만한 연구

world model 계획 신뢰도를 실로봇 실패 감지 신호로 쓰기

  • 질문: world model planner가 실행 전에 내는 신뢰 점수가 실로봇 조작의 실제 실패를 얼마나 미리 가려내는지 밝힘.
  • 첫 실험: V-JEPA 2-AC(Meta의 action-conditioned 영상 world model) planner로 실로봇 조작 과제를 돌림. CURE의 계획 신뢰도 점수(certificate), 진행도 함수 값, 영상 예측 오차 세 점수의 실패 예측 AUROC를 비교함.
  • 가장 가까운 연구: CURE는 시뮬레이션과 녹화된 실로봇 영상에서 결정 단위 regret만 봤고 폐루프 실로봇 실행은 없음. Progress Predicts Policy는 rollout이 끝난 뒤의 진행도로 성공을 가름. 이 연구는 실행 전 점수를 실로봇 실패와 직접 맞춰 봄.

world model rollout으로 retrieval 기억의 유용도 추정하기

  • 질문: retrieval-augmented VLA에서 어떤 demonstration을 기억에서 꺼낼지, 시뮬레이터 rollout 대신 world model rollout으로 정해도 되는지 밝힘.
  • 첫 실험: LIBERO에서 같은 후보 pool들의 성공률을 시뮬레이터 rollout과 action-conditioned world model rollout으로 각각 잼. pool 순위의 상관과 각 방식이 고른 pool의 성공률을 비교함.
  • 가장 가까운 연구: demonstration 선택은 유용도를 재는 데 과제마다 시뮬레이터 rollout 600회가 필요함. DreamFAR는 world model 안의 policy 평가가 실로봇과 r = 0.71로 맞지만 순위는 과제 3개 중 2개에서만 유지됨. 이 연구는 그런 순위 오차가 pool 선택에도 생기는지 봄.

관절 단위 action 표현으로 cross-embodiment 실패 진단하기

  • 질문: 관절 token마다 이미지의 어느 부분을 읽는지 보이는 policy가, 다른 로봇으로 옮겼을 때 어느 신체 부위에서 실패가 생기는지 짚어 낼 수 있는지 밝힘.
  • 첫 실험: RoboTwin의 미관측 로봇-과제 조합에서 Body Schema Policy식 관절 token policy와, 공유 좌표에 로봇별 decoder를 붙인 cross-robot 방법을 비교함. 실패 rollout마다 관절별 attention 변화와 forward kinematics로 계산한 tool pose 오차를 같이 기록함.
  • 가장 가까운 연구: Body Schema Policy는 Unitree G1과 Fetch에서 각각 평가했을 뿐 다른 로봇으로 옮기는 실험은 없음. cross-robot 조합 일반화는 성공률과 tool 위치 오차만 보고하고 실패를 신체 부위별로 나누지 않음.

꼭 읽을 논문

  • Plausible Videos Can Lead to Poor Decisions (CURE): world model의 영상 품질과 결정 품질을 떼어 보고, 학습 데이터만으로 계획 신뢰도를 판정하는 기준을 줌.
  • DreamFAR: 로봇 데이터만으로 학습한 world model로 10 Hz 실시간 조작과 60초 rollout을 보이고, keyframe 기억 설계를 제시함.
  • Body Schema Policy: 35M parameter policy가 SIMPLE 시뮬레이션 과제 9개에서 2.63B parameter Ψ0와 거의 같은 성공 횟수(221회 대 220회)를 내서, 운동학 구조를 표현에 넣는 효과를 보여 줌.
  • Making Future-Predictive Representations Actionable (RelayWAM): 미래 예측 loss로 배운 정보를 action 경로가 실제로 읽는지 층별로 재는 절차를 줌. transition layer를 넣어 LIBERO-Plus 성공률을 51.5%에서 72.0%로 올림.
  • Progress Predicts Policy: 진행도 함수 하나로 행동 명령과 실패 감지를 같이 얻는 구조임. LIBERO에서 rollout 끝 진행도로 성공을 가르는 AUROC가 0.84임.
