World Motion Models: Flexible Sequence Modeling of SE(3) Trajectories

arXiv PDF alphaXiv
World Model relevance 9/10 Robotics (cs.RO)
Jiahui Lei, Qianqian Wang, Trevor Darrell, Angjoo Kanazawa PDF 전문 1차 75점
로봇 액션, 인간/손 관절, 물체, 카메라까지 전부 sparse SE(3) pose trajectory라는 하나의 토큰 공간으로 표현하고, 토큰별로 noise level을 따로 주는 flow-matching으로 any-to-any marginal conditioning을 학습함. 같은 네트워크에 마스킹만 바꿔서 미래예측·정책·MPC·motion infilling·cross-embodiment retargeting·inverse dynamics를 전부 수행함.
Core Innovation & Methodology
- 동적 장면을 object·human·hand·robot link·camera를 포함한 sparse SE(3) pose trajectory 집합으로 통일 표현함. 9D (position + 6D rotation) pose token에 semantic/geometric feature를 붙여 엔티티 종류에 상관없이 같은 형식으로 처리함 - Diffusion Forcing 방식을 확장해 토큰(엔티티 x 시간)마다 독립적인 noise level을 샘플링하는 flow-matching objective 하나로 학습함. 추론 시 관측 토큰은 λ=0, 목표 토큰은 λ=1로 고정해 적분하면 future prediction, policy, forward dynamics 등 어떤 조건부 분포든 샘플링됨 - 연속 시간축에 묶이지 않는 context SE(3) token을 도입해 goal state, cross-embodiment 대응 예시처럼 비인과적(non-causal) 앵커를 조건으로 넣음. context token도 일반 trajectory token과 동일하게 학습·생성됨 - 12K 토큰 규모를 감당하기 위해 전역/시간축/엔티티축 self-attention과 register 토큰을 조합한 factored attention 구조와 per-token AdaLN 조건화를 설계함
Novelty vs. Prior Works
- 가장 가까운 선행연구는 Diffusion Forcing(토큰별 noise level, 시간축 위주)과 TraceGen(동일 저자 계열, dense 3D point trajectory)임. WMM은 per-token noise를 시간축뿐 아니라 엔티티축까지 확장하고, dense point track 대신 sparse SE(3) frame을 기본 단위로 써서 human/robot/object/camera를 같은 토큰 공간에 넣은 점이 본질적 차이임 - SE3-Nets, SPOT 등 기존 SE(3) 기반 방법은 single-agent나 고정 물체 설정에 한정되는데, WMM은 context token으로 비인과적 조건(목표 상태, 리타겟팅 대응쌍)까지 같은 네트워크에서 처리함 - 다만 벤치마크별로 별도 WMM 체크포인트를 학습해 하나의 범용 foundation model을 실제로 검증하지는 않았음. 통합 표현의 '보편성'은 제안 단계이고 실증은 benchmark-specific 모델 6개임
Benchmark Results
- Language Table (sim, 5-task family, family당 50 rollout): WMM macro-average success rate 87.2%로 LCB 80.0%, LangTable 원 논문 77.0%, ActionVLA 76.8%를 상회함 - TraceGen (Droid/EpicKitchen, 400 keypoint, 32-step): MSE·MAE·endpoint error 전 항목에서 TraceGen baseline보다 낮음 (EpicKitchen MSE 0.322 vs 0.445). 128개만 보고 400개 전체를 추론해도 baseline을 이김 - OMOMO human-object interaction: CHOIS 대비 대부분 지표에서 동등하거나 우수함 (T_s 0.15 vs 1.71, C_F1 0.76 vs 0.67). 단 T_obj, O_obj 등 일부 지표는 CHOIS가 더 나음 - Humanoid retargeting (SMPL → Unitree G1, TWIST 컨트롤러로 물리 시뮬레이션 검증): throughput 86.97 FPS로 GMR(35.03), PHUMA(2.27)보다 빠름. success rate(SR-seq)도 clean/in-fill/noisy 세 조건 모두에서 GMR·PHUMA를 둘 다 앞섬 - Ablation: per-token noise를 빼면(synced noise) 정책 모드 success rate가 0%로 붕괴함. axis-wise factored attention을 plain DiT로 바꾸면 MAE가 약 15배 악화됨
누리랩 연구와의 연결
- 같은 네트워크가 마스킹만 바꿔 policy와 differentiable world model(MPC)로 동시에 동작하는 구조는 test-time optimization·inference-time planning 연구에 바로 참고할 틀임. gradient 기반 MPC와 샘플링 기반 방법을 혼합한 부분(App B.3)은 실로봇 실패 복구 시 test-time 재계획에 응용 가능함 - context token 메커니즘은 robot memory나 장기 과거 사례를 비인과적 조건으로 주입하는 방식으로 확장할 수 있음. 학생 연구 중 world model/failure recovery 트랙에 이 context-token 설계를 가져와 '과거 실패 사례를 context로 주는 복구 모델'로 변형하는 아이디어 가능함 - SE(3) trajectory를 object-centric 3D representation(3DGS motion basis)과 연결하는 부분은 저자의 이전 DynMF/MoSca 작업과 직접 이어지므로, 3DGS 기반 scene representation 연구와 묶어 비교·인용할 가치가 있음

InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation

arXiv PDF alphaXiv
VLA World Model relevance 9/10 Robotics (cs.RO)
Zhuo Lin, Sirui Xu, Liuyu Bian, Yu-Xiong Wang, Liang-Yan Gui PDF 전문 1차 68점
InterEvolve는 고정된 humanoid whole-body controller(behavioral foundation model)를 재학습 없이 새 task에 쓰는 방법임. LLM 에이전트가 staged reward program을 execution feedback으로 계속 고쳐 쓰고 CMA-ES가 상수를 튜닝해서, 학습 때 본 적 없는 loco-manipulation task(박스 차기, 뒤집기 등)에서 성공률을 fixed reward 대비 크게 끌어올림.
Core Innovation & Methodology
- 문제 설정: controller는 그대로 두고 reward program(stage별 reward + completion condition + 튜닝 가능한 상수)만 test-time에 진화시켜 새 task에 대응하는 "test-time evolution" 프레임을 제안함 - 실행 메커니즘: forward-backward(FB) behavioral foundation model(BFM-Zero 기반)을 써서 reward를 latent prompt로 바로 변환, policy 재학습 없이 매 reward 후보를 즉시 실행·평가함 - object-aware 확장: 기존 FB 모델은 body만 관측해서 object goal이 다른 reward끼리 같은 행동으로 collapse되는 문제가 있어서, frozen body prior 위에 trainable object residual(actor·forward·backward map 전부)을 얹고 OMOMO·GRAB HOI 데이터로 이 residual만 학습함 - 진화 루프를 구조 탐색과 상수 탐색으로 분리함: outer loop에서 LLM 에이전트가 stage·reward term 같은 program 구조를 execution feedback과 skill library를 보고 수정하고, inner loop에서 CMA-ES가 고정된 구조의 상수(가중치·threshold)를 192개 parallel rollout으로 튜닝함 - 검증된 program을 텍스트 형태 skill library에 축적해서 이후 task가 이를 재사용·조합하게 함 (예: carry+place+kick 같은 long-horizon composite task)
Novelty vs. Prior Works
- 개별 요소(FB behavioral foundation model, LLM이 reward 작성, CMA-ES 튜닝)는 전부 기존 기법이고, 저자도 Eureka/DrEureka(LLM reward 설계), ROSETTA(언어 선호로 multi-stage reward program 구성), MotionDisco(LLM+trajectory opt로 동작 발굴)를 직접 선행연구로 인정함 - 본질적 차이는 reward 후보 평가 방식임: Eureka 계열은 reward 후보마다 policy를 새로 학습해야 해서 느린데, 이 논문은 FB 모델의 zero-shot reward-to-latent 성질을 이용해 재학습 없이 각 후보를 바로 실행·비교하므로 test-time에 많은 후보를 빠르게 search할 수 있음 (LLM test-time scaling을 robot reward 설계로 옮긴 아이디어) - object-aware FB 자체는 기존 FB 모델에 object residual을 더한 비교적 직접적인 확장이라 representation 측면 novelty는 제한적임. 핵심 novelty는 "controller는 고정, reward program만 test-time에 진화 + skill library로 경험 축적"이라는 system-level formulation에 있음
Benchmark Results
- Reference tracking(held-out large-box clip): InterEvolve(evolved reward) Eh=19.80cm, Eo=24.92cm, SR=72%로 object-aware FB(미진화) SR=60%보다 높고, 전용 tracker인 ULTRA(SR=66%, Eh=15.68, Eo=21.45)의 SR도 넘어섬. 단 오차 절대값은 ULTRA가 더 낮음. body-only BFM-Zero는 SR=8%로 object 다루는 능력이 거의 없음을 보임 - Goal-conditioned 8개 task family(평균, sim-only): InterEvolve SR=86.5%, Earned=95.6%로, 사람이 쓴 reward(SR=8.0%)나 CMA-ES로 튜닝만 한 agent 초기 program(SR=34.6%, Earned=82.5%)보다 2배 이상 높음. 평가 비용은 GPU-h=2.1, LLM token=0.23M/task - task family별 성공률 편차가 큼: push to mark(100%), lift to support(92.2%), tip onto new face(95.3%)는 쉬움. kicking to mark는 InterEvolve로도 59.4%에 그쳐 가장 어려움(학습 데이터에 kick 동작이 드물어서라고 설명) - ablation(Table 3): multi-stage를 없애고 single reward로 강제하면 SR이 44.7%로 가장 크게 떨어지고, CMA-ES 튜닝 제거 시 51.6%, targeted edit 대신 full-rewrite 시 68.9%, multi-scenario 평가 제거 시 68.4%, scene context 제거는 78.7%로 영향이 가장 작음 - skill library 재사용(composite task, unseen task): full library로 relocate 8/10, stack 4/10, carry-place-kick 5/10 해결, library 없으면 0/10·0/10·1/10으로 거의 실패. 저장된 program을 재탐색 없이 그대로 돌리면 거의 성공 못 해서(carry-place-kick 6.3%), 이득은 library 자체가 아니라 library를 활용한 재탐색(evolution)에서 나옴 - 물리 로봇 검증: Unitree G1 1대에서 egocentric RGB-D + FoundationPose로 박스 위치를 추정해 kick/push task를 자율 실행하는 정성적 데모만 제시함. 실로봇 성공률·시행 횟수 수치는 본문에서 확인 불가
누리랩 연구와의 연결
- test-time optimization 트랙과 직결됨: 학습 단계가 아니라 inference 단계에서 task 표현(reward program)을 반복 개선한다는 점이 우리 lab의 test-time optimization/inference-time planning 관심사와 바로 연결되고, failure feedback(criterion별 실패 원인)을 다음 라운드 prompt에 넣는 구조는 failure detection·recovery 연구에 참고할 만함 - skill library가 text로 쌓이는 방식은 robot memory 연구와 맞닿아 있음. 다만 library reuse 실험이 "contact mode가 겹치는 task만 전이된다"는 negative result를 보여줘서, memory retrieval을 언제·어떻게 매칭할지가 후속 연구 질문이 될 수 있음 - controller를 전혀 업데이트하지 않고 reward program만 진화시키는 구조라, 저자도 "누적 경험으로 controller 자체를 갱신하는 것"을 향후 과제로 남김 — 우리 lab의 world model/VLA policy에도 이 FB-model식 frozen controller + test-time reward search 조합을 적용해볼 여지가 있음

Screw Attention: Rigid-Body Algebra Inside a Transformer

arXiv PDF alphaXiv
Manipulation relevance 9/10 Robotics (cs.RO)
Aly Magassouba PDF 전문 1차 70점
로봇 link와 scene object를 pose를 가진 토큰으로 두고, 토큰 쌍의 관계를 학습된 그래프 edge 대신 상대 pose와 joint screw로 직접 줌. attention score는 frame-invariant한 양만 읽고, message만 받는 쪽 frame으로 transport하는 Screw Attention을 제안함. LIBERO-Spatial에서 16,162개 파라미터로 97.3%를 달성해 27배 큰 flat MLP를 앞섬. link별 frame 표기 관행이 바뀌어도 성능이 거의 그대로인 반면(-0.2~+1.0포인트) 같은 예산의 transformer·graph network·MLP는 0.0~2.3%로 붕괴함.
Core Innovation & Methodology
- 모든 로봇 link와 scene object를 pose를 가진 토큰으로 표현하고, 토큰 쌍(i,j)의 관계를 학습된 그래프 edge가 아니라 상대 pose X_ij와(로봇 joint면) joint screw S_j로 직접 줌. 이 pair term은 학습 대상이 아니라 입력임 - attention score는 Killing form κ와 Klein form λ라는 두 frame-invariant bilinear form으로만 기하 정보를 읽고, message는 X_ij로 받는 쪽 토큰의 frame으로 transport한 뒤에 채널만 학습된 행렬로 섞음. score는 invariant, message만 frame 연산을 담당하는 구조로 설계를 나눔 - gate γ(s_i)가 softmax 정규화로 생기는 1/|A(i)| 배율을 상쇄하도록 설계해서, 단일 layer가 수작업 weight 설정만으로 rigid-body mechanics의 velocity recursion과 Jacobian-transpose control law를 정확히 재현함(수치 검증 오차 10⁻⁹~10⁻¹⁵, Section III-D, Appendix B) - motion/force/twist 세 readout 모두 joint별 고유 파라미터가 없어 자유도 수가 다른 팔에 그대로 적용 가능하고, analytic controller 위에 gated residual(Eq. 15)로 얹을 수 있어 gate를 닫으면 controller를 정확히 복원함
Novelty vs. Prior Works
- 가장 가까운 세 갈래 선행연구와 비교하면: embodiment-aware policy transformer(MetaMorph, Body Transformer, morphology-embedded transformer)는 kinematic tree를 connectivity(그래프)로만 쓰고 두 link 사이 거리·회전축 같은 물리 내용은 네트워크가 추론하게 둠. equivariant policy(Diffusion-EDF, EquAct, SA-VLA, GATr)는 scene object geometry는 보존하지만 로봇은 end-effector pose 하나로만 표현함. kinematics-structured policy(XMoP, Rodrigues Network, ABD-NET)는 pose·transform을 토큰으로 갖지만 학습된 행렬을 좌표에 직접 곱해 frame 변경에 대한 불변성이 깨짐(XMoP는 frame-randomizing augmentation 없이 unseen embodiment 성공률 68.1%p 손실을 자체 보고) - 본질적 차이는 '기하 연산을 attention score가 아니라 message(value path)에만 넣는다'는 설계와, 로봇 link와 scene object를 같은 token space에서 동일하게 typing한다는 점임. 저자도 Appendix C에서 GATr과의 관계를 밝히는데, algebra 측면에서는 GATr의 full geometric algebra 대신 rigid-body mechanics가 쓰는 bivector(screw)만 남긴 축소판이고, symmetry 측면에서는 GATr의 scene 전체 단일 global frame 불변성보다 넓은 '토큰마다 독립적인 frame 변경'에 대한 불변성을 가짐 - novelty의 범위는 제한적임. 검증된 task가 3개의 custom 로봇 task(reorientation, affordance, insertion)와 LIBERO-Spatial 10개 task이고, 전부 ground-truth pose 입력(이미지·언어 미사용)이라 perception·language와 결합했을 때도 이 novelty가 유지되는지는 본문에서 확인 불가함
Benchmark Results
