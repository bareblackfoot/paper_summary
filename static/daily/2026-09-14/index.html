RelateAnything: Real-Time Open-Vocabulary Relation Prediction From Any Inputs

arXiv PDF alphaXiv
Open-Vocabulary Scene Graph Visual Relation Detection relevance 6/10 Computer Vision and Pattern Recognition (cs.CV)
Maëlic Neau PDF 전문 1차 68점
물체 라벨을 아예 입력받지 않고 region과 predicate 문자열만으로 관계를 예측하는 53M 파라미터 모델 RelateAnything을 제안함. 19,103개 predicate에 대한 positive-unlabeled 학습과 antonym을 분리하는 text encoder distillation으로 기존 open-vocabulary scene graph 방법 대비 mean recall 2.3~3.5배를 달성함.
Core Innovation & Methodology
- object class label을 어떤 단계에서도 입력받지 않는 구조임. detector·segmenter 종류와 무관하게 region만 받아 relation head를 재학습 없이 쓸 수 있음 - predicate vocabulary를 학습된 classifier가 아니라 text embedding bank로 취급함. inference 시 vocabulary를 바꾸는 것은 matrix 치환일 뿐임 - 학습에 쓰는 free-text predicate 19,103개 전체에 대해 positive-unlabeled InfoNCE loss를 씀(이 중 RA-4M 코퍼스 자체의 고유 predicate는 10,102개). 미표기 predicate(riding에 대해 unstated인 sitting on 등)를 negative로 벌점 주지 않고 co-annotation 통계로 추정한 확률만큼 discount함 - contrastive text encoder가 above/below를 cosine 0.95로 거의 동일하게 묶는 문제를 antonym-repulsion 항을 추가한 student encoder distillation으로 해결함(inverse cosine 0.92→0.09)
Novelty vs. Prior Works
- 가장 가까운 prior work인 OvSGTR/MegaSG 계열 대비, object label을 아예 배제하고 vocabulary를 text embedding bank로 분리한 interface 설계가 본질적 차이임. label-conditioned relation head라는 기존 scene graph 구조의 전제 자체를 없앤 것으로 보임 - scene-graph recall이 실제로는 corpus agreement(shared triplet mass)를 측정한다는 것을 정량 분석(frequency table이 micro recall에서 학습 모델을 15% 앞서는 것 등)하고, 이를 근거로 cross-dataset 전용 6-axis benchmark(OV-SGG-Bench)를 새로 설계한 것이 formulation 수준 기여로 보임 - 다만 architecture 자체(DINOv3 backbone, box-query cross-attention pooling, pair transformer, text-embedding 매칭)는 open-vocabulary detection/segmentation에서 이미 쓰이던 요소의 조합이라 순수 model design 측면의 novelty는 제한적임
Benchmark Results
- 3개 cross-dataset benchmark와 1개 zero-shot benchmark에서 comparable scale의 최강 open-vocabulary baseline(OvSGTR) 대비 mean recall 2.3~3.5배, rare-predicate recall 5~21배 (abstract·intro에서 확인, 세부 벤치마크별 표는 본문에서 확인 불가) - single GPU에서 20ms/frame으로 동작해 real-time object detector와 함께 쓸 수 있음을 확인함. - 3B-parameter VLM 기반 scene-graph model 대비 파라미터 2% 미만으로 recall·precision 두 지표 모두 앞서지만, free-text matcher로 채점 시 micro recall은 뒤짐(본문 확인) - in-domain 측정이 cross-dataset transfer 성능을 약 5배 과대평가한다고 보고함(§8 결과, 세부 수치는 본문에서 확인 불가) - frequency-table baseline(object category만 쓰고 pixel 미사용)이 micro top-1 accuracy에서 학습 모델을 15.0~15.6% 앞서지만, macro(per-predicate) 지표에서는 28.9~85.7% 뒤짐(VG150/PSG/IndoorVG 3개 벤치마크, Table 1) - RA-4M corpus는 동일 이미지·박스 기준 기존 annotation 대비 밀도 1.7배(9.03 vs 5.29 relations/image), vocabulary는 107배(10,102 predicates)임
누리랩 연구와의 연결
- 누리랩 우선 주제 중 scene graph/semantic mapping, object-centric 3D representation에 직접 연결됨. object label 없이 region만으로 관계를 예측하는 구조는 임의 detector·SAM 계열 segmenter와 조합해 온라인 semantic mapping에 바로 붙일 수 있음 - 20ms/frame real-time 특성상 manipulation 중 scene graph를 실시간 갱신해 failure detection·recovery의 상태 표현으로 활용 가능함 - 3DGS 기반 object-centric 표현과 결합해 3D scene graph로 확장하는 방향이 자연스러운 후속 연구 주제로 보임

UniPart: Towards Zero-shot Language-Grounded 3D Part Segmentation for Embodied Interaction

arXiv PDF alphaXiv
3D Vision Manipulation Perception relevance 8/10 Computer Vision and Pattern Recognition (cs.CV)
Xinqiang Yu, Zekun qi, Jiawei He, Wenyao Zhang, Xuchuan Chen, Guaocai Yao, Li Yi, Zhaoxiang Zhang 외 1명 PDF 전문 1차 68점
UniPart는 자유형 언어 문구로 3D point cloud에서 기능적 부품을 zero-shot 분할하는 feed-forward cross-modal 3D Transformer임. 160K+ Objaverse 객체와 8M text-part pair로 만든 LangPart-1M으로 학습해 open-vocabulary part segmentation benchmark에서 FIND3D를 앞서고 실물 로봇 language-conditioned grasping까지 연결함.
Core Innovation & Methodology
- LangPart-1M 구축 파이프라인: GPT-5.2-Pro로 객체별 부품 리스트를 질의하고, 12개 렌더링 뷰에 SAM+Set-of-Mark로 후보 영역을 뽑은 뒤 GPT-5.2-Pro가 뷰 간 영역을 텍스트 기준으로 merge해 3D로 lifting하는 4단계 자동 라벨링임. - 자동 생성 대규모 데이터(LangPart-1M, 160K+ 객체·8M text-part pair)와 수작업 검증 소규모 데이터(LangPart-4K)를 분리해 스케일과 품질을 함께 확보함. LangPart-4K는 다시 학습용 LangPart-3K와 평가용 LangPart-1K로 나뉨. - UniPart 아키텍처: FPS+kNN으로 point cloud를 토큰화하고, frozen CLIP text embedding을 모든 Transformer layer에 단순 덧셈(additive)으로 주입한 뒤 PointNet 계열 decoder로 point-wise binary mask를 예측함. - 3단계 curriculum(이미지-포인트 cross-modal 정렬 pretrain → LangPart-1M pretrain → LangPart-4K fine-tune)으로 노이즈 있는 대규모 데이터와 고품질 소규모 데이터를 순차 결합함.
Novelty vs. Prior Works
- 가장 가까운 prior work는 concurrent인 FIND3D로, 언어 문구로 임의 3D 부품을 쿼리한다는 문제 설정 자체는 동일함. - 본문 controlled study(표 6)에서 architecture 교체 효과는 상대개선 14.69%(30.75→35.27), data 교체 효과는 상대개선 24.94%(30.75→38.42)로, 성능 향상의 더 큰 축이 architecture보다 data engine(LangPart-1M)에 있음. - cross-modal fusion도 cross-attention·multiplication·concat 대비 additive가 가장 좋다는 ablation 수준이라 새로운 학습 패러다임이라기보다 engineering 선택에 가까워 architecture 자체의 novelty는 제한적임.
Benchmark Results
- Objaverse-General에서 UniPart는 seen/unseen·두 prompt 조건 전부 mIoU 41.46~49.27로, 최강 baseline인 FIND3D의 26.21~34.10보다 높음. - ShapeNetPart(canonical/rotated/V2) 전 조건에서 UniPart 39.56~55.63, FIND3D 23.71~42.15로 UniPart가 앞섬. - PartNet-E에서는 UniPart가 21.72~24.28인데, {part} 단축 prompt 조건에서 PartSLIP++가 32.71(canonical)·23.03(rotated)으로 UniPart(22.90·21.72)를 앞서 완전한 우위는 아님. - 자체 구축한 LangPart-4K의 평가 split인 LangPart-1K benchmark에서 UniPart 27.17~33.56, FIND3D 8.97~17.28이나, 이 benchmark는 저자 자신의 데이터 분포로 만든 것이라 교차 검증 성격이 약함. - 실물 로봇 20개 객체 language-conditioned grasping에서 part segmentation accuracy 90.5%, GraspNet·DexGraspNet2.0과 결합한 grasp success 85.0%를 보고했으나 baseline 비교 없이 자사 파이프라인 단독 수치임.
누리랩 연구와의 연결
- 언어 조건 3D part segmentation을 fine-grained manipulation의 perception primitive로 쓰는 구조는 누리랩의 language feedback 기반 manipulation·scene graph 연구에 전처리 모듈로 바로 붙일 수 있음. - LangPart-1M의 SAM+Set-of-Mark+VLM 기반 multi-view consistent part labeling 파이프라인은 failure detection/recovery에서 "어느 부품이 문제인지"를 짚는 semantic diagnosis 데이터 구축에 참고할 만함. - 다만 UniPart는 정적 point cloud 대상 segmentation이라 test-time optimization이나 world model과 직접 연결되지는 않고, object-centric 3D representation·scene graph 연구의 입력 모듈 정도로 활용 가치가 있음.

Dynin-Robotics: Omnimodal Unified Diffusion Vision-Language-Action Model

arXiv PDF alphaXiv
VLA World Model relevance 10/10 Robotics (cs.RO)
Hoeun Lee, Jaeik Kim, Jusang Oh, Jinhyeok Kim, Geon Choi, Hyeonggeun Kim, Jaeyoung Do PDF 전문 1차 74점
언어·관측·행동·목표상태를 하나의 masked diffusion backbone에서 discrete token으로 통합해, policy·world modeling·goal-state prediction·task understanding을 조건부 masking만 바꿔 한 모델로 학습함. LIBERO 98.1%, zero-shot LIBERO-Plus 73.0%, 실로봇 Franka 78.4% 성공률을 내고 action decoding을 최대 29.2배 가속함.
Core Innovation & Methodology
- 자체 이전 연구인 Dynin-Omni(omnimodal masked diffusion LM)를 확장해 로봇 action을 discrete token으로 quantize하고 sensor token까지 예약 슬롯으로 추가한 shared trajectory representation을 제안함. - objective token으로 visible span과 target span을 바꿔 Policy(행동 생성), World Modeling(행동 조건부 다음 상태 예측), Goal-State Prediction(목표 상태 예측), Task Understanding(trajectory→instruction 복원)을 한 backbone에서 학습함. - inference 단계에서 goal-state guidance, action/world-model joint denoising, world-model 기반 candidate reranking 등 6가지 조합을 지원해 test-time scaling을 가능하게 함. - dInfer 기반 block-parallel decoding으로 action chunk 생성을 병렬화해 model-side decoding throughput을 최대 29.2배 높임.
Novelty vs. Prior Works
- 가장 가까운 prior work인 UD-VLA, MMaDA-VLA는 둘 다 masked diffusion으로 action과 visual state를 joint denoising하지만 world modeling까지만 다루고 goal-state prediction·task understanding·candidate reranking은 없음(논문 Table 1 비교 기준). Dynin-Robotics는 이 네 기능을 한 모델에 다 넣은 점이 차별점임. - 다만 masked diffusion을 로봇 action에 적용하는 아이디어 자체는 Discrete Diffusion VLA, LLaDA-VLA, UD-VLA에서 이미 나왔고, 백본도 자체 사전 논문 Dynin-Omni를 그대로 가져와 action/sensor token만 얹은 구조라 architecture 신규성은 제한적임. - 새로운 학습 패러다임을 제시했다기보다 기존 masked diffusion 통합 모델군에 objective를 조합적으로 완성하고 inference composition을 체계화한 엔지니어링 기여에 가까움.
Benchmark Results
- LIBERO 4개 suite 평균 success rate 98.1%, zero-shot LIBERO-Plus 73.0%를 보고함(baseline 대비 구체적 비교 수치는 본문에서 확인 불가). - Franka Research 3 실로봇에서 4개 manipulation 조건 평균 78.4% 성공률로 sim-to-real 검증을 병행함(조건별 세부 수치는 본문에서 확인 불가). - VLABench 두 task(SelectFruit, InsertFlower) diagnostic은 이 논문의 모델이 아니라 두 개의 기존 baseline policy인 π0.5와 Mimic-Video를 비교한 동기부여용 분석임. SelectFruit는 π0.5가 우세하고 InsertFlower는 Mimic-Video가 특히 간접 지시(Track 4)에서 경쟁력 있음. random-string instruction으로 바꿨을 때 π0.5의 성공률 하락폭이 Mimic-Video보다 큼. - Stage-2에서 robot pretraining(Stage-1 checkpoint)이 동일 step budget 내 적응을 개선하고, full objective mixture가 Policy-only post-training 대비 shifted-instruction 성공률을 높인다고 보고하나 구체적 개선폭 수치는 본문에서 확인 불가. - block-parallel decoding(dInfer 적용)이 base 구현 대비 model-side action decoding throughput을 최대 29.2배 가속함.
누리랩 연구와의 연결
- goal-state prediction과 world-model 기반 candidate reranking을 test-time scaling 방식으로 쓰는 부분은 누리랩의 test-time optimization/inference-time planning 주제와 바로 연결됨. - action/world-model joint denoising으로 실행 전 미래 상태를 같이 예측하는 구조는 predicted next-state와 실제 관측을 비교해 실패를 감지하는 failure detection·recovery 연구로 확장 가능함. - policy·world model·goal·language를 하나의 discrete token space에 넣는 trajectory representation은 unified representation 설계 관점에서 robot memory·semantic representation 연구 참고가 될 수 있음.

Breaking the Vision-Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models

arXiv PDF alphaXiv
VLA relevance 10/10 Robotics (cs.RO)
Jianman Lin, Shailesh Shailesh, Zhongyi Luo, Jiafei Duan PDF 전문 1차 67점
VLA·world-action model이 학습 데이터의 우연한 시각적 상관관계에 의존해 action을 생성하는 vision-action shortcut 문제를 다룸. 이미지 없이 학습한 action prior에 pose로 지도된 latent interface를 유일한 시각 조건화 경로로 붙여, LIBERO-Plus OOD 성능을 4개 아키텍처에서 3.87~10.70%p, 실로봇 OOD에서 13.3~16.7%p 개선함.
Core Innovation & Methodology
- 이 논문은 제안 방법을 LIT(Latent Interface Training)라 부름. Stage 1: 이미지 없이 language·robot state·데모 action chunk의 terminal SE(3) end-effector pose(위치3+axis-angle3+gripper2, 8차원)만으로 action expert를 학습해 spatial-goal-conditioned action prior를 만듦. - Stage 2: 학습 가능한 latent token 100개가 self-attention·semantic cross-attention·visual cross-attention으로 backbone의 시각·의미 표현을 집약해, pretrained action expert에 대한 유일한 시각 조건화 경로 역할을 함. - latent token을 Stage 1과 동일한 terminal pose로 복원하도록 MLP decoder로 지도(pose reconstruction loss, λ=0.3)해 시각 경로가 목표 관련 공간 정보만 담도록 제약함. - backbone·action expert 구조, action representation, 학습 objective를 그대로 두는 framework-agnostic 방법으로, Pi0.5·MolmoAct2(VLA) 및 FAST-WAM·ImageWAM(world-action model) 4개 아키텍처에 동일하게 적용함. - counterfactual intervention: 실행 중 시각 입력이나 목표를 인위적으로 바꿔 action이 얼마나 따라 변하는지 측정해서 policy가 시각 정보에 실제로 반응하는지 진단하는 분석 기법임.
Novelty vs. Prior Works
- 이미지 없는 action prior 학습 자체는 LA4VLA·Qwen-VLA에 이미 있음. LIT는 terminal pose를 Stage1 조건과 Stage2 재구성 타깃으로 공유해 두 단계를 연결하는데, LA4VLA 방식을 재현한 baseline은 OOD 65.46%로 LIT 71.92%보다 6.46%p 낮아 본질적 차이가 있음을 보임. - latent token으로 시각 정보를 병목시키는 구조는 VLA-Adapter류 query 기반 interface와 유사하나, pose 지도 없이 token aggregation만 쓴 ablation은 65.70%에 그쳐 병목 구조 자체보다 pose 지도와의 결합이 핵심임을 보임. - 구성 요소(image-free pretraining, latent bottleneck, 보조 pose loss)는 각각 선행연구에 존재해 새로운 problem formulation이라기보다 기존 아이디어의 통합·재배치에 가까움. novelty는 제한적이나 ablation으로 통합 설계의 필요성을 명확히 입증한 점이 강점임.
Benchmark Results

- diffusion policy가 만든 action chunk를 world model로 사전평가해 선택하는 구조는 VLA의 test-time optimization/inference-time planning에 그대로 옮길 수 있음 — 실패 예측 기반 action reranking 설계에 참고 가능함. - world model이 실제 controller 방문 상태에서 정확도가 크게 떨어지는 distribution shift(radial MAE 0.028→0.576mm)는 우리 lab의 failure detection·recovery 문제와 직접 연결됨. - semantic mask+ResNet만으로 기하를 추정하는 얕은 표현은 확장성이 제한적이라, object-centric 3DGS 표현으로 교체해 더 일반적인 deformable object 조작으로 확장해볼 여지가 있음.

오늘의 핵심 연구 트렌드 종합

  • world model을 실행 전 검증기로 쓰는 흐름 — Dynin-Robotics, RodForesight가 공통적으로 world model rollout을 candidate action 재랭킹이나 goal-state 검증에 씀. Pelican-Sim은 같은 world model을 검증이 아니라 학습 데이터를 늘리는 증강기로 씀. IMPLY는 self-consistency만으로는 object-blind world model을 못 잡아낸다는 것을 실험으로 보여 반례를 제시함.
  • label 없이 open-vocabulary로 3D/관계를 뽑는 흐름 — UniPart는 물체 라벨 없이 3D part를 언어로 분할하고, RelateAnything은 물체 라벨 없이 region만으로 관계를 예측함. 둘 다 label-free perception primitive를 scene graph·manipulation의 앞단으로 두는 설계임.
  • vision-action shortcut·causal confusion 진단 — Breaking the Vision-Action Shortcut이 VLA가 우연한 시각 상관관계로 action을 내는 문제를 counterfactual intervention으로 진단하고 고침. failure detection 연구에서 참고할 진단 기법임.
  • 촉각·기억의 특이성(specificity)을 직접 검증하는 흐름 — STAR는 촉각 신호의 희소성을 구조화해 학습에 쓰고, Does Video Memory Use What It Retrieves?는 memory 모델이 실제로 retrieve된 내용을 쓰는지 개입 실험으로 감사함. 두 논문 모두 "그 신호가 정말 쓰이는가"를 직접 검증한다는 공통점이 있음.
  • gradient 없는 test-time 적응 — CLAW가 hypernetwork로 world model용 LoRA를 즉석 생성해 gradient step 없이 새 환경에 적응함. 다만 사전에 정의된 환경군 밖으로는 일반화가 안 됨.
  • 학습 없이 에이전트를 policy로 쓰는 흐름 — Agent as Policy는 범용 코딩 에이전트를 그대로 로봇 policy로 써서 5개 과제군에서 성공률 80% 이상을 냄. 다만 시행당 20~54분·수십 달러 오버헤드가 있어 실용성보다는 상한선 참고용에 가까움.

유망 연구 방향 및 프로젝트 제안

촉각 기반 실시간 scene graph로 접촉 진단하기 - research question: contact 시점의 sparse tactile 신호로 어느 물체·부품이 접촉했는지를 label 없이 실시간으로 추론할 수 있는가 - 접근·novelty: STAR의 contact gate로 뽑은 active tactile patch를 RelateAnything의 label-free relation predictor에 조건으로 넣어, 접촉 대상-도구 관계를 매 프레임 갱신하는 구조. 기존 tactile learning은 policy 입력으로만 쓰고 scene graph로 연결한 적은 없음 - 왜 지금·경쟁 prior works: STAR는 policy 학습에, RelateAnything은 vision relation에 국한돼 있어 둘을 잇는 시도가 없음. 두 방법 모두 real-time(RelateAnything 20ms/frame) 설계라 결합 가능성이 실제로 있음 - risk·target venue: 촉각 센서 하드웨어(268채널)에 의존적이라 재현성이 낮을 수 있음. real-robot 검증까지 가야 설득력이 생김. target: RSS/ICRA

world model 검증을 dexterous manipulation의 접촉 물성 anchoring으로 확장하기 - research question: IMPLY가 쓰는 물성 anchoring(rollout이 서로 일치하는지가 아니라, 실측한 질량·마찰 값과 일치하는지를 검증 기준으로 삼는 방식)이 단일 box push를 넘어 dexterous in-hand manipulation처럼 복잡한 접촉에서도 self-consistency의 맹점을 잡아낼 수 있는가 - 접근·novelty: calibration probing으로 물성을 추정하는 IMPLY 방식을, 학습된 forward model 기반 anchoring으로 바꿔 ArtManip류 articulated object manipulation에 적용. 시뮬레이터 역산 대신 학습 기반 anchoring이 필요하다는 점이 novelty - 왜 지금·경쟁 prior works: IMPLY 저자도 이 확장을 한계로 명시함. 기존 rollout selection 연구(RodForesight 포함)는 anchoring 없이 rollout 자체의 일치도만 봄 - risk·target venue: anchoring용 forward model 학습이 추가 supervision을 요구해 데이터 비용이 커질 수 있음. target: CoRL

vision-action shortcut 진단을 실행 중(on-line) 신뢰도 신호로 쓰기 - research question: 학습 단계에서 shortcut을 제거하는 것을 넘어, 실행 중에 policy가 shortcut에 의존하는 정도를 실시간으로 스코어링해 실패를 예측할 수 있는가 - 접근·novelty: Breaking the Vision-Action Shortcut의 counterfactual intervention(시각 개입 시 action 변화량 측정)을 학습이 아니라 inference 시점 진단 도구로 재구성 - 왜 지금·경쟁 prior works: 원 논문은 학습 단계 개입만 다룸. 온라인 진단은 별도 문제로 다뤄진 적이 없고, failure detection 연구와 직접 맞닿음 - risk·target venue: 실시간 개입이 제어 주기를 늦출 위험이 있어 latency와 진단 정확도의 trade-off 분석이 필요함. target: ICRA/ICML

gradient-free test-time 적응을 world model에서 VLA policy로 옮기기 - research question: CLAW의 hypernetwork 기반 LoRA 생성을 world model이 아니라 언어 조건 VLA policy 자체에 적용해 domain shift에 즉시 대응할 수 있는가 - 접근·novelty: failure detection 신호(예상 상태와 실제 관측의 괴리)를 hypernetwork 입력으로 써서, 실패가 감지된 순간에만 LoRA를 생성하는 조건부 적응 구조 - 왜 지금·경쟁 prior works: CLAW는 사전에 정의된 locomotion·manipulation 환경군 안에서만 검증돼 open-world 일반화가 빈 자리로 남아 있음 - risk·target venue: distribution 밖 환경에서 hypernetwork가 엉뚱한 adapter를 생성할 위험이 큼. 안전장치 설계가 선행돼야 함. target: NeurIPS/ICLR

memory specificity audit을 robot policy의 long-horizon memory 설계 진단으로 확장하기 - research question: manipulation policy의 memory augmentation이 실제로 특정 과거 episode를 참조하는지, 아니면 generic prior 복구로 성능이 나오는지 구분할 수 있는가 - 접근·novelty: video world model에 적용된 read-time memory substitution(memory를 읽는 시점에 저장된 내용 일부를 다른 값으로 바꿔치기해, 성능 이득이 그 내용 자체에서 오는지를 확인하는 개입 기법)을 long-horizon robot policy에 이식해, memory 의존도를 task별로 정량화 - 왜 지금·경쟁 prior works: 원 연구는 video world model(DINO-WM, SAM 2)에 국한. robot policy의 memory 설계에는 이런 진단 프로토콜이 없어 memory 투자 방향(retrieval 정밀도 vs. representation 안정성)을 결정할 근거가 부족함 - risk·target venue: robot policy는 world model보다 memory 접근 경로가 복잡해 substitution 개입이 어려울 수 있음. target: CoRL

오늘 반드시 읽어야 할 논문

  • RelateAnything — object label 없이 region만으로 관계를 예측해 mean recall을 기존 대비 2.3~3.5배 올린, scene graph 실시간 구축의 새 기준점임.
  • UniPart — 자유형 언어로 3D part를 zero-shot 분할해 실물 로봇 language-conditioned grasping까지 연결한 결과가 확실함.
  • Dynin-Robotics — policy·world model·goal·language를 하나의 discrete token space에 넣고 LIBERO 98.1%, 실로봇 78.4%를 낸 통합 설계임.
  • Breaking the Vision-Action Shortcut — VLA의 causal confusion 문제를 4개 아키텍처에서 재현하고 latent interface로 OOD 성능을 최대 16.7%p 올려 진단·해법을 동시에 제시함.
  • Pelican-Sim 1.0 — world model을 데이터 증강기로 써서 50 demo에 생성 궤적을 더해 성공률을 70%에서 93%로 올린 구체적 수치가 있음.
  • IMPLY — self-consistency가 object-blind world model을 못 잡아낸다는 것(AUROC 0.70)을, 물성을 실측해 검증 기준으로 삼는 anchored 방식(AUROC 1.00)과 대비해 통제 실험으로 명확히 보여 검증 방법론에 경고를 던짐.
  • STAR — 268채널 촉각을 spatial·temporal·informational sparsity로 구조화해 4개 실로봇 task 평균 성공률 61%를 낸 학습 레시피임.
  • Does Video Memory Use What It Retrieves? — memory 모델군마다 실제 memory 의존 양상이 본질적으로 다르다는 것을 개입 실험으로 보여 memory 설계 전반에 시사점을 줌.
