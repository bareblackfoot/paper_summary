DreamLedger: Execution-Settled Credit Files for World-Model Imagination in Robot Decision Loops

arXiv PDF alphaXiv
World Model relevance 9/10 Robotics (cs.RO)
Xianyao Li, Ruitong Tian, Rui Min, Fang Xu, Jing Du PDF 전문 1차 70점
세계모델이 내놓은 예측을 로봇이 실제로 소비할 때마다 claim으로 등록하고, 그 예측이 나중에 실제 관측과 맞았는지를 조건×영역×horizon 단위로 누적 기록하는 credit file을 만듦. 이 기록을 예측 사용 전에 조회해 신뢰도 낮은 예측은 사용 horizon을 줄이거나 추가 관측을 시키는 방식으로, 실패로 끝나는 예측 소비(burned imagination)를 62% 줄임.
Core Innovation & Methodology
- 세계모델 신뢰도를 순간적인 모델 내부 신호(ensemble disagreement, self-report confidence) 대신 실행으로 정산된(execution-settled) 지속적 배포 기록으로 다룸 - 로봇이 실제로 소비한 예측만 claim으로 등록하고 이후 관측과 대조해 redeem/fail로 정산함. 라벨링 비용이 추가로 들지 않음 - attribution 단계(confidence gating, residual decomposition, honest discard 3단계)로 위치추정·센서 오차를 모델 실패로 잘못 기록하는 걸 걸러냄 - 정산 기록이 희박한 cell을 보완하려고 world model 예측 경로는 안 건드리고, latent에서 gradient를 끊은 introspection head를 정산 결과로만 지도학습함
Novelty vs. Prior Works
- 저자도 binning, calibration, confidence head, gating, conformal recalibration, 로깅 등 개별 요소는 기존 방법이라고 명시함. 기여는 이를 condition×region×horizon으로 인덱싱된 지속적 claim 정산 기록이라는 하나의 배포 object로 묶은 것임 - 기존 instantaneous gate(M2AC류 ensemble disagreement, learned verifier, self-report, one-step consistency)와 달리 '지금 이 예측이 맞아 보이나'가 아니라 '비슷한 조건에서 과거에 얼마나 맞았나'를 묻는다는 점이 핵심 차이임 - conformal trust horizon, model-precondition estimator 같은 competence-aware 계열과 비교해도 새 이론적 장치보다는 기존 조각의 재조합에 가까움. formulation 자체의 참신성은 중간 수준으로 판단됨
Benchmark Results
- weak quadrotor에서 credit gating이 blind consumption 대비 burned imagination을 62% 감소시킴(95% CI 43-81%). 성공률은 양쪽 다 0.683으로 동일, 충돌 차이는 유의하지 않음(Δ=-0.8, CI[-19.2,17.6]) - 모델 강도별(weak/medium/strong) burn 감소폭은 각각 62%/56%/44%로 모든 CI가 0을 배제함 - manipulation(Table V)에서 credit gating이 probe 횟수를 1.00/ep에서 0.36/ep로 64% 줄임. 단 success는 0.98[.94,1.0]에서 0.94[.88,.97]로 소폭 낮아짐 — 저자는 verification-efficiency trade-off로 설명함 - instantaneous baseline(ensemble, self-report, adaptive conformal, consistency monitor) 대비, ledger 기반 threshold는 seed 간 0.58-0.66로 안정적인 반면 baseline들은 0.22~1.0으로 요동침(Table IV) - 실제 Franka에서 등록된 spend 1,062건 전부가 감사 로그에서 재구성됨(정산 949건, discard 108건, pending 5건). 다만 hardware의 gated-vs-blind 비교는 순차 진행으로 배치 조건이 달라 인과적 비교가 아니라고 저자가 명시함
누리랩 연구와의 연결
- failure detection·diagnosis·recovery 연구와 직결됨. world model rollout을 test-time planning에 쓰는 VLA policy에 이 credit file을 gate로 붙여, 낮은 신뢰도 구간에서 추가 관측·horizon 단축 같은 recovery behavior를 트리거하는 실험 설계에 바로 참고 가능함 - test-time optimization/inference-time planning 관점에서, 예측 신뢰도를 condition별로 누적 추적하는 이 settlement 메커니즘은 누리랩의 world model 기반 policy에 real-robot 실험으로 이식해볼 수 있음 - attribution 단계(측정 오염 배제) 설계는 실로봇 실패 감지에서 센서 노이즈와 모델 실패를 구분하는 문제에 직접 적용 가능함

GlanceWAM: Sparse Test-Time Imagination for World-Action Models

arXiv PDF alphaXiv
World Model relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Linhan Wang, Zijian An, Mingyuan Zhang, Chen Dai, Yi Xu, Can Cui, Zichong Yang, Yinlin Chen 외 2명 PDF 전문 1차 78점
GlanceWAM은 world-action model에서 test-time visual imagination을 control loop와 분리해, 느린 clock에서 약 3초 앞 lookahead frame 하나만 비동기로 생성하고 빠른 clock에서는 이를 latent 상태 그대로 소비해 action chunk를 디코딩함. RoboCasa kitchen 24-task에서 72.2%로 동기식 Cosmos Policy(67.1%)를 능가하면서 chunk당 48ms로 동기식 baseline 대비 24배 빠른 추론 속도를 달성함.
Core Innovation & Methodology
- 단일 video DiT(SkyReels-V2-DF, 1.3B) 안에서 느린 clock(약 3초 주기)의 비동기 lookahead 생성과 빠른 clock(48ms)의 action decoding을 분리한 dual-timescale 구조를 제안함. - 3-class prefix-LM attention mask로 observation·future target·lookahead 토큰을 서로 격리해, lookahead 조건이 video generation 표현을 오염시키지 않게 함. - staleness-robust training으로 lookahead offset u~U(0,Hf]를 학습 중 무작위 샘플링해, action head가 시간이 지나 낡아가는 lookahead를 그대로 소비하도록 학습시킴. - action head가 4개 DiT layer(5,12,19,26)에서 뽑은 lookahead·observation feature를 cross-attend해 action chunk를 flow matching으로 디코딩함.
Novelty vs. Prior Works
- Cosmos Policy 등 기존 world-action model은 future prediction을 action chunk와 같은 짧은 horizon에 동기적으로 묶어 매 chunk마다 diffusion sampling 비용을 지불함; GlanceWAM은 이 결합을 시간축으로 분리한 것이 핵심 차이임. - Fast-WAM·AHA-WAM처럼 test-time imagination을 아예 버리는 접근과 달리 imagination을 유지하되 비동기로 amortize함 — lookahead를 강제로 지우면 성능이 no-lookahead baseline보다도 낮아진다는 개입 실험으로 imagination 유지의 필요성을 직접 입증함. - 방법을 구성하는 요소(비동기 실행, latent-space 소비, staleness-aware conditioning, diffusion forcing)는 개별적으로는 새로운 개념이 아니라 기존 아이디어의 조합에 가까움 — 저자 스스로도 concurrent work인 DeVA, Flex-π와 문제의식이 겹친다고 명시함.
Benchmark Results
- RoboCasa kitchen 24-task(50 demos/task, held-out scene 1200 episode): GlanceWAM 72.2%, 동일 조건 Cosmos Policy 67.1% 대비 +5.1%p, 동일 backbone·데이터의 imagination-free co-training 64.4% 대비 +7.8%p. - LIBERO 4-suite 평균: 99.0%(Spatial 99.4/Object 100.0/Goal 99.0/Long 97.8)로 Cosmos Policy·LingBot-VA(각 98.5%)보다 근소 우위, benchmark 포화 구간에서의 개선임. - 추론 속도: chunk당 48ms(A100, 실측 47.95ms)로 동기식 baseline(1133~3812ms) 대비 24~80배 빠름. Fast-WAM(A100 재측정 91.5ms, 6B) 대비 약 2배 빠르면서 성공률도 더 높음(99.0% vs 97.6%, 파라미터는 1.6B로 더 작음). - ablation: lookahead 토큰을 학습된 checkpoint에서 강제로 0으로 만들면 71.5%에서 61.6%로 하락해 no-lookahead baseline(64.4%)보다도 낮아짐 — lookahead가 causally load-bearing함을 확인. - 비동기 실행 자체의 성능 손실은 동기 실행 대비 -0.5%p(p=0.72)로 통계적으로 유의하지 않음. concurrent work DeVA는 affordance·depth 라벨을 쓰는데 그 supervision을 제거하면 66.0%로 GlanceWAM보다 6.2%p 낮아져, GlanceWAM이 추가 라벨 없이 비슷하거나 더 나은 결과(72.2 vs 72.0)를 낸다는 점이 저자 주장으로 제시됨.
누리랩 연구와의 연결
- test-time optimization/inference-time planning 우선 주제에 직접 부합함 — 비동기 lookahead amortization은 latency budget 안에서 world model 추론을 끼워 넣는 설계로 참고할 만함. - visual foresight를 latent space에서만 소비하고 pixel decoding을 아예 생략하는 구조는, 예측 latent와 실제 관측 latent의 불일치를 failure detection 신호로 쓰는 방향으로 확장 가능함. - staleness-robust training(다양한 offset에 policy를 노출)은 robot memory나 장기 planning에서 오래된 context를 다루는 학습 방식으로 참고할 만함.

Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning

arXiv PDF alphaXiv
World Model relevance 9/10 Robotics (cs.RO)
Sixiang Chen, Jiaming Liu, Jixian Wu, Yichen Guo, Tinghao Wang, Siyuan Qian, Hao Chen, Jiajun Cao 외 2명 PDF 전문 1차 65점
action-conditioned world model이 expert 궤적만 잘 따르고 off-expert action에서는 시각적 붕괴나 action 무시를 일으킨다는 문제를 WorldEcho 벤치마크로 진단함. 이를 해결하는 학습 레시피 WorldSync를 제안해 RoboTwin과 real-robot에서 policy 개선 성공률을 CtrlWorld 대비 크게 높임.
Core Innovation & Methodology
- expert demonstration만으로 학습·평가하던 기존 AC-WM 관행을 지적하고, action을 정말 따르는지는 expert action에서만 검증됐다는 gap을 문제로 formulate함. - WorldEcho는 demonstrated action 외에 cross-state replay, local perturbation, policy rollout, feasible-space sampling 4개 off-expert query 카테고리를 두고, visual integrity gate(quality·motion·EEF visibility·arm integrity)와 SE(3) end-effector NDTW alignment를 함께 측정하는 integrity-gated error를 정의함. - WorldSync는 세 축으로 개선함: (1) simulation off-expert 궤적과 소량 real-robot 데이터를 공유 action space로 묶는 action coverage expansion, (2) 중간 video representation에서 미래 EEF 궤적을 디코딩해 action-induced dynamics를 강제하는 Action-Forcing Expert(AFE, 추론 시 제거), (3) 같은 observation·noise에서 action만 다른 pair의 예측 변화량을 GT 변화량에 맞추는 Intervention-Effect(IE) supervision. - 세 목적함수(flow matching + AFE + IE)를 Wan DiT 기반 backbone에서 공동 학습함.
Novelty vs. Prior Works
- 가장 가까운 prior work인 MiraBench는 failure-inducing perturbation으로 action-conditioned reliability를 봤지만 image-space motion이나 task-level 판정 위주였다고 본문이 밝힘. 본 논문은 SE(3) 궤적 자체를 GT와 직접 정렬하는 continuous alignment를 쓴다는 점에서 차별화를 주장함. - WorldEcho 자체는 새로운 representation·learning paradigm이라기보다 진단용 benchmark/protocol 설계이고, WorldSync도 architecture적으로는 기존 flow-matching video world model에 두 개의 auxiliary loss(AFE, IE)를 추가하는 형태라 개념적 도약보다는 문제 진단 후 대응이라는 성격이 강함. - IE의 paired-intervention 방식은 counterfactual 개념을 world model 학습 loss로 구체화했다는 점에서 흥미롭지만, ablation 결과(4.5절) 자체가 AFE 단독으로는 action metric을 개선하지 못한다고 보여줘 두 요소 결합의 필요성 근거가 다소 약함.
Benchmark Results
- 50개 RoboTwin task, 6개 baseline(CtrlWorld, Cosmos-Predict2.5, Cosmos3, DreamDojo, Motus, LingBotVA) 대상 진단에서 off-expert query 시 integrity-gated error가 expert 대비 0.029-0.099m 증가, raw NDTW 0.010-0.043m 증가, visual failure rate 6.3-28.1%p 증가함(저자 주장, Figure 5). - 6개 baseline 모두 Expert Demonstrations 대신 Expanded Action Coverage로 학습 시 integrity-gated error와 raw NDTW가 일관되게 낮아짐. visual pass rate는 backbone별로 개선 3개, 거의 무변화 2개, 악화 1개로 혼재함(Table 1). - WorldSync는 integrity-gated error 0.0661로 전체 설정 중 최저(2위 CtrlWorld 0.0670과 근소한 차이), visual pass 84.51%로 최고(2위 Motus 84.34%)를 기록함. 단 raw NDTW는 Cosmos-Predict2.5(0.0127)가 WorldSync(0.0223)보다 낮아 모든 지표에서 절대 우위는 아님(Table 1). - policy improvement: RoboTwin bin-dumping task에서 초기 성공률 51-52%에서 2 round 후 WorldSync 65%(+13%p), CtrlWorld는 Expanded/Expert 조건 모두 56-57%(+5%p)에 그침. real-robot stacking-cups task(단일 task)에서는 48% 초기값에서 WorldSync 68%(+20%p), CtrlWorld 56%(+8%p)임. - component ablation(4개 task, 8 checkpoint 평균, Table 2): coverage 확장만으로 gated error 0.0781→0.0738. IE 추가 시 raw NDTW가 0.0170으로 최저를 찍지만 visual pass는 81.25%로 오히려 하락. AFE 단독은 action metric 개선이 없고 visual pass만 83.04%로 높임. Full(coverage+IE+AFE)이 gated error 0.0695로 최선이나 raw NDTW·visual pass 각각은 IE 단독, AFE 단독보다 낮음.
누리랩 연구와의 연결
- WorldEcho의 off-expert action query 5분류(cross-state replay, local perturbation, policy rollout, feasible-space sampling)는 누리랩의 failure detection/recovery나 test-time optimization 연구에서 policy가 world model rollout을 신뢰해도 되는지 판단하는 진단 도구로 바로 가져다 쓸 수 있음. - Intervention-Effect supervision(같은 observation·noise, 다른 action의 예측 변화량을 GT 변화량에 맞춤)은 counterfactual reasoning 기반 world model 학습에 적용 가능한 일반적 objective로 보임. - action-conditioned world model을 VLA policy의 test-time simulator로 쓸 때 이 논문의 integrity-gated error 프로토콜을 evaluation 축으로 채택해 우리 world model 연구의 신뢰도 진단에 쓸 수 있음.

XP-JEPA: Cross-Predictive Physics Grounding for Forecastable Latent Dynamics

arXiv PDF alphaXiv
World Model relevance 8/10 Machine Learning (cs.LG)
Kehan Wen, Ziming Li, Siyuan Luo, Fan Shi PDF 전문 1차 78점
XP-JEPA는 시각 관측과 물리 상태(privileged state, 학습 때만 쓰고 배포 때 버리는 특권 정보)를 같은 action-conditioned predictor로 굴려 각 예측을 두 modality의 미래 표현 모두에 맞추는 cross-predictive 목적함수를 제안함. multi-task 실험에서 rollout drift를 0.361에서 0.104로 줄이고 control success를 53.6%에서 78.2%로 올림.
Core Innovation & Methodology
- 물리 상태와 시각 관측을 같은 action-conditioned predictor로 진행시키고, 각 예측을 두 modality의 미래 표현 모두에 맞추는 cross-predictive 목적함수(식 1)를 제안함. - self-prediction(같은 modality)과 cross-modal prediction(다른 modality)을 동시에 걸어 시각 latent transition을 물리 궤적에 grounding함. - 물체 geometry(pooled SDF)·pose·end-effector 상태를 6개 object slot 토큰으로 표현하는 unified privileged-state interface를 설계해, task별 라벨 없이 22개 object-task 구성을 하나의 물리 encoder로 처리함. - 물리 branch는 학습 후 폐기하고 시각 encoder-predictor-planner만 배포해, 추론 비용과 구조를 시각 전용 baseline과 동일하게 유지함.
Novelty vs. Prior Works
- 가장 가까운 선행연구(TWIST, PIGDreamer, Pri4R)는 물리 정보를 distillation이나 state regression으로 한 방향만 전달하는데, XP-JEPA는 두 modality를 모두 online encoder로 유지하며 양방향으로 서로의 미래를 예측함. - decodability(스냅샷에서 물리량 복원 가능성)와 forecastability(latent transition 예측 가능성)를 실험적으로 분리해, state regression이 decodability만 올리고 forecastability·control은 못 올린다는 것을 보인 분석 프레임이 핵심 기여임. - 동시기 공개된 Phys-JEPA, PhyLatent도 JEPA에 물리 grounding을 더하는 유사 방향이라 저자도 이를 명시했고, architecture 자체의 novelty는 제한적임.
Benchmark Results

Latent 예측-관측 불일치를 실시간 실패 감지 신호로 쓰기 - research question: world model이 소비하는 latent lookahead(또는 latent action)와 실제 관측 latent 사이의 괴리를 policy 실행 중 실시간으로 측정해, 명시적 실패 라벨 없이 실패를 조기에 예측할 수 있는가. - 접근·novelty: GlanceWAM의 비동기 latent lookahead 소비 구조에 DreamLedger의 execution-settled 신뢰도 정산을 결합하고, WorldSync의 off-expert query(cross-state replay, local perturbation 등)로 괴리-실패 상관관계를 학습 데이터로 확보함. - 왜 지금·경쟁 prior works: 세 논문 모두 이 신호를 recommendation 수준으로만 언급하고 직접 failure detection에 쓰지 않아 gap이 뚜렷함. - risk·target venue: 실제 실패 사례를 실로봇에서 충분히 모아야 검증 가능. CoRL 또는 RSS 타겟.

Test-time optimization amortization을 실패 복구에 특화 - research question: LeFlow의 rectified-flow trajectory prior를 정상 실행이 아니라 실패 이후 재계획(replanning)에 특화하면, 실패 유형별 recovery trajectory를 CEM 없이 빠르게 생성할 수 있는가. - 접근·novelty: normal-execution 데이터뿐 아니라 WorldSync의 off-expert perturbation으로 만든 실패 상태 분포까지 flow prior 학습에 포함시켜, 실패 상태에서 목표까지의 latent path를 직접 생성하게 함. - 왜 지금·경쟁 prior works: 기존 test-time replanning은 매번 CEM full search라 recovery latency가 크고, LeFlow는 정상 실행 상황만 다룸. - risk·target venue: 실패 상태 분포를 충분히 다양하게 커버하지 못하면 일반화가 실패할 위험. CoRL 타겟.

Latent action을 embodiment-agnostic intention 표현으로 써서 cross-embodiment 학습 - research question: LAWA의 action-free egocentric video 기반 latent action tokenizer가 GVLA의 5종 gripper 데이터에서도 gripper-agnostic한 공통 intention 표현을 학습할 수 있는가. - 접근·novelty: LAWA의 latent action tokenizer를 GVLA의 MiGA 데이터셋(132개 gripper-strategy pair)으로 사전학습해, gripper별 soft prompt 없이도 latent action만으로 embodiment 차이를 흡수하는지 검증함. - 왜 지금·경쟁 prior works: GVLA는 gripper 정보를 explicit prompt로 주입하는 반면 LAWA는 action-free video만으로 latent action을 학습해 접근 방식이 대비됨. - risk·target venue: latent action이 gripper 물리적 제약(soft/suction 등)까지 흡수하지 못할 위험이 큼. CoRL 타겟.

World model 신뢰도 정산 프레임워크를 counterfactual 학습 신호로 확장 - research question: DreamLedger의 조건별 신뢰도 정산 기록을, WorldSync의 Intervention-Effect supervision(같은 observation·noise에서 action만 바꾼 예측 변화량을 GT에 맞추는 목적함수) 학습에 가중치로 넣으면 counterfactual world model 학습이 더 효율적인가. - 접근·novelty: 정산 기록이 낮은 조건(cell)에 더 많은 counterfactual perturbation 샘플을 배정하는 active data collection으로 두 방법을 결합함. - 왜 지금·경쟁 prior works: 두 논문 모두 같은 문제의식(world model이 action을 정말 반영하는가)에서 출발했지만 정산 트래킹과 counterfactual objective를 따로 다룸. - risk·target venue: 두 파이프라인을 하나의 학습 루프로 통합하는 엔지니어링 난이도가 높음. NeurIPS 또는 CoRL 타겟.
