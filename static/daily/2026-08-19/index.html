An Omitted Mode Is a Rare Rule: The Sampling-Verification Danger Law in Continuous Code World Models

arXiv PDF alphaXiv
World Model relevance 10/10 Machine Learning (cs.LG)
Javier Aguilar Martín PDF 전문 1차 90점
Code World Model(CWM)에서 sampling-based verification이 continuous control의 희귀 mode를 놓치면 planner가 이를 악용해 큰 위험을 만든다. 저자는 danger = E[play cost of shipped artifact] 분해와 gate-miss 확률 식 (1−r)^N 및 training/acceptance 결합 (1−r)^(Ntr+Ng)을 이론·실험으로 보였다.
Core Innovation & Methodology
- Prop.1·Prop.4로 gate-miss 확률이 연속 상태공간에서 정확히 (1−r)^N이고, 독립인 training·acceptance 샘플에 대해 (1−r)^(Ntr+Ng)로 합성됨을 보였다. - Prop.3으로 shipped cost가 acceptance와 비상관(Cov=0)일 때 위험의 곱형식이 성립함을 명시했다. blind 모델의 상수 비용 경우 항등식이 됨을 제시했다. - Lipschitz localization budget 정리로, 두 Lipschitz 모델 차이 η가 있으면 ε 초과 불일치 집합에 반경 (η−ε)/2L의 sup-ball이 포함됨을 보이고 κ=2^(−(d+m))의 예리한 상수를 도출했다. - freeze semantics와 Prop.7으로 일부 reset-like 불연속(mode)은 관측 불가·반증불가능하여 q_hit=0인 규칙류가 존재함을 보였다.
Novelty vs. Prior Works
- 기존 model-based RL(예: Hafner 2020 등)은 누적 오차·전역적 부정확성에 주목했으나, 본문은 sampling-verified 환경에서 국소 희귀 규칙의 체계적 악용(geometry)을 통계·기하적으로 정식화했다. - Code-as-Policies/Code World Models 계열과 달리, acceptance gate의 통계적 보장 범위를 정확식(Fréchet–Hoeffding 스타일)으로 규정하고 localization budget으로 표현력 한계를 가격화한 점이 본질적 차이다. - 단점으로 실험이 3개 계기·고정 planner·GPT-5.x에 한정돼 있어 외연 일반화는 보수적 해석이 필요하다.
Benchmark Results
- 이론적 핵심: gate-miss = (1−r)^N. training/acceptance 독립이면 중앙 사건 확률은 (1−r)^(Ntr+Ng) (Prop.1,4). - Partition 인증: L≤5.77인 쌍은 wall error 4.2를 통과하지 못했고, deployed gate가 planner 질의의 약 1.9%만 커버했다. - cart-with-wall 실험에서 rarity r은 0.317 → 0.0024로 감소했다 (Table 1 언급). - LLM 합성: GPT-5.x는 1D clamp에서 105/111 정확 합성. 그러나 2D 영역에서는 0/156로 회복 실패했다. - 실험 설정·수치: Ntr=40, Ntr+Ng=80. accepted play cost 평균 0.508, 클러스터 구간 [0.344,0.671]. version-space 식별은 6/20, 18/20 등으로 보고되었다.
누리랩 연구와의 연결
- VLA·test-time optimization: acceptance gate를 coverage-aware 검증으로 확장하고 (1−r)^(Ntr+Ng) 규칙을 이용해 residual risk에 따라 counterexample-guided augmentation을 트리거한다. - Active perception·failure recovery·robot memory: boundary 접촉을 유도해 r을 높이는 data collection 루프를 만들고, 관찰된 boundary contact를 메모리화해 freeze-like unfalsifiable 영역을 안전 필터로 태깅한다. - World model·object-centric/scene graph: Lipschitz budget을 고려해 reset-like 불연속을 코드로 분리하고, 2D 합성 붕괴를 완화하려면 disc/slab 형식 priors 또는 object-centric 3DGS·scene graph 스타일의 region hypothesis를 결합한다.

CompCPZ: Preserving Multi-Modal Intent in Language-Guided Robot Manipulation

arXiv PDF alphaXiv
VLA relevance 10/10 Robotics (cs.RO)
Zhen Zhang, Ahmad Hafez, Peng Xie, Yanliang Huang, Wenyuan Wu, Amr Alanwar PDF 전문 1차 90점
언어 지시의 다중 모드(intent)를 보존하는 CompCPZ를 제안한다. CPZ 기반 two-sided enclosure와 distribution-free split-conformal calibration으로 multi-component 보증을 제공하고, 런타임은 sub-ms 수준이다.
Core Innovation & Methodology
- CompCPZ 컴파일러는 constrained polynomial zonotope(CPZ)로 primitive별 two-sided enclosure(C^- / C^+)를 추출한다. - 언어 파스 트리의 AND/OR/NOT을 집합 연산(∩/∪/·^c)으로 하향식 합성해 연결 성분(topological connectivity)을 보존한다. - split-conformal calibration과 union bound로 분포 가정 없이 per-node coverage를 보장한다. - 실행 시 containment-checked mode switching으로 차단된 모드에서 다음 유효 모드로 실시간 전환한다. 런타임은 <0.25ms(@d=4), <1.1ms(@d=7)이다.
Novelty vs. Prior Works
- 기존 multi-peak decoders(VoxPoser/PhysVLM/RoboPoint)는 mode 구조를 표현하지만 sound한 연결 성분 보증이 없다. 반면 CompCPZ는 k-component 집합 인코딩으로 위상적 보증을 제공한다. - single-action/point output 계열(OpenVLA/RT-2 등)은 고정 차원으로 k-mode 불확실성에 취약하다(논문 Theorem 13). CompCPZ는 representation 수준에서 문제를 재정의한다. - AABB/MVEE 같은 convex enclosure는 union을 convex로 붕괴시켜 다중 성분을 보존하지 못한다(하우스도르프 하한 관련 Theorem 11/12). 다만 본 접근은 wrapper 성격이라 학습적 신기성은 제한적일 수 있다.
Benchmark Results
- ManiSkill3(18 families, 200 seeds each): geometric success 양측 ≥0.99. in-GT-mode는 CompCPZ 1.00 vs convex baseline 0.13. paired sign test 1,900/1,918 wins, p≪1e-30(부록 p≤1e-533). - 대표 과제 예: StackCube red∨blue 1.00 vs 0.00; PokeCube cube∨peg∨goal 1.00 vs 0.00; PickClutterYCB 1.00 vs 0.98; PushT 0.89 vs 0.51. - Ellipsoid avoidance benchmark (n=459): in-GT-mode CompCPZ 1.000, AABB-union(bounding) 0.928, AABB-union(inscribed) 0.715. - Adversarial mode blocking: CompCPZ pooled mean 0.90, heatmap argmax 0.54, sampling decoder 0.52. Hardware Unitree Go2: CompCPZ 12/12 in-GT-mode, AABB 0/12, single-clause 7/12. - 런타임 및 calibration: synthesis <0.25ms@d=4, <1.1ms@d=7; conformal coverage는 다양한 노이즈에서 목표 대비 ±1% 수준. YOLOv8n fine-tune(800 synth)의 detector로 0.73cm @ 0% miss에 도달하여 bench in-GT-mode 1.00을 보고함.
누리랩 연구와의 연결
- VLA 파이프라인에 CompCPZ를 wrapper로 추가해 multi-peak heatmap이나 single-action 디코더의 mode collapse를 방지한다. inference-time planning(mode switching)과 결합하면 실패율을 크게 낮출 수 있다. - Failure recovery·test-time optimization에 활용할 수 있다. in-GT-mode 판별과 mode blocking 감지로 recovery 정책과 online mode-specific optimization을 설계할 수 있다. - World model·robot memory·active perception과 연계할 수 있다. CPZ 기반 집합 표현을 memory에 저장해 장기 과제에서 모드 가용성 히스토리를 반영하고, next-best-view를 모드 분리(η) 기준으로 선택하도록 활용할 수 있다.

GroupForward: Building Referable 3D Scenes via Instance-Grouped Feed-Forward Gaussian Splatting

arXiv PDF alphaXiv
3D Vision relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Qijian Tian, Zimeng Wu, Xuhong Wang, Lizhuang Ma, Xin Tan PDF 전문 1차 85점
GroupForward는 per-Gaussian 고차원 feature 렌더링을 버리고 per-instance 저차원 embedding으로 3D Gaussian Splatting(3DGS)을 재구성해, feed-forward로 referable 3D scene을 만든다. ScanNet/Replica와 referential reasoning에서 Uni3R 등 대비 mIoU·PSNR·SSIM·LPIPS 등 지표가 유의미하게 개선된다.
Core Innovation & Methodology
- GroupForward: per-Gaussian 고차원 semantic feature 대신, pixel-aligned Gaussian에 de=8 차원의 instance embedding을 부여해 per-instance로 집계·전파하는 표현 전환. - Architecture: multi-view encoder(VGGT) + geometry decoder + Gaussian decoder(attribute head + instance head)로 구성하여 cross-view 일관된 3D instance grouping을 학습. - Gauge-aligned self-rendering: self-predicted pose와 재구성된 scene의 gauge(특히 scale)를 정렬하고, 정렬된 pose에서 photometric loss를 추가해 geometry–pose 불일치 완화. - Inference 및 semantics: HDBSCAN으로 context-view embedding을 클러스터링해 3D instance 생성, LSeg 기반 dense feature를 instance-wise로 pooling해 semantic prototype을 만들고 RSRF(3D scene graph + Qwen3-VL-8B 후보 선택)로 referential reasoning 수행.
Novelty vs. Prior Works
- 기존 LSM/Uni3R/Feature 3DGS 계열은 per-Gaussian 고차원 feature를 렌더링한 반면, 본 논문은 representation·학습·추론 단위를 per-Gaussian → per-instance로 근본적으로 전환함. - IGGT 등은 instance cue를 다루지만 novel-view synthesis가 제한적이었음. 본 접근은 rendering-consistent instance loss와 gauge-aligned self-rendering으로 feed-forward 3DGS의 pose-geometry 불일치를 체계적으로 다룸. - Inference에서 HDBSCAN 기반 instance 형성 및 per-instance semantic prototype 저장으로 고차원 feature 저장·렌더링 부담을 줄이는 점이 기존 feature-distillation 방식과 본질적으로 다름.
Benchmark Results
- ScanNet (Source view): mIoU 0.5905, Acc 0.8294, rel 2.14, τ 82.23. (Target view): mIoU 0.5989, Acc 0.8302, PSNR 26.23, SSIM 0.8948, LPIPS 0.1230. - 개선 vs Uni3R (Target view): mIoU +0.0405 (0.5584→0.5989), PSNR +0.70 (25.53→26.23), SSIM +0.0221 (0.8727→0.8948), LPIPS -0.0150 (0.1380→0.1230). - Multi-view 예시: 8 views mIoU 0.6623 vs Uni3R 0.5880, SSIM 0.8740 vs 0.8318; 16 views mIoU 0.6880 vs 0.5813, PSNR 25.71 vs 23.35. - Zero-shot Replica (avg 2/4/6/8 views): mIoU 0.5633, Acc 0.8769, PSNR 27.26, SSIM 0.8790, LPIPS 0.1226 vs Uni3R 0.4754/0.8351/23.03/0.7880/0.1276. - Referential reasoning: novel-view referring segmentation mIoU 0.6496 vs Sa2VA 0.5012 및 Uni3R 0.2538. Ablation: w/o L_render mIoU 0.5772; w/o instance embedding 0.5479; w/o self-rendering PSNR 26.11 / SSIM 0.8917 / LPIPS 0.1267; w/o curriculum mIoU 0.4669, PSNR 18.92. Semantic model: LSeg 0.5905, OpenSeg 0.4536, CLIP 0.1630. 학습 효율: 2-view에서 stage 당 약 50k iters, 총 약 30시간(8×A100 80GB).
누리랩 연구와의 연결
- VLA / policy grounding: GroupForward의 instance-level scene graph를 언어-행동 grounding의 메모리로 사용해 VLA 정책의 candidate grounding 및 후보 축소에 활용 가능. - Failure recovery / test-time optimization / robot memory: gauge-aligned self-rendering의 일관성 신호를 실패 검출 신뢰도로 전환하고, per-instance prototype을 time-aggregated memory로 누적해 변경 감지·failure recovery와 TTO 초기화에 활용. - Active perception / manipulation / world model: scene graph 기반 불확실성으로 next-best-view를 계획하고, 선택된 3D 인스턴스의 g3D 속성(크기·중심·가시성)을 grasp 후보 생성·충돌 제약에 바로 연결하며, per-instance prototype을 4D world model의 구성 단위로 통합할 것을 권장.

Hydra-0: Action Flow for Generalist World Modeling and Control

arXiv PDF alphaXiv
World Model relevance 10/10 Robotics (cs.RO)
Hongyu Li, Bowen Wen, Xinghao Zhu, Yixuan Wang, Yilun Du, Yunzhu Li, George Konidaris, Stan Birchfield 외 3명 PDF 전문 1차 88점
Hydra-0은 robot action을 image-plane pixel trajectory로 정규화한 action flow를 제안한다. 이를 통해 Cosmos 2.5 대비 robot-motion error 90.40% 감소, object-motion error 60.16% 감소 등 시각적 world model과 inverse control 성능이 크게 향상된다.
Core Innovation & Methodology
- action flow: robot action을 camera image-plane의 pixel trajectory로 표준화해 embodiment-agnostic 시각 조건을 만든다. - Bidirectional use: Forward 모드로 kinematically grounded visual condition을 생성해 future observation을 예측하고, Inverse 모드로 desired object flow→compatible robot motion→action decoding을 수행한다. - Lightweight action head: LoRA rank-32 어댑터 + 두 계층 GELU MLP로 embodiment-specific executable action을 복원한다. - Backbone portability 및 training trick: Cosmos 2.5, Wan2.2 등 다양한 video-generation backbone에 동일 인터페이스를 장착하고, β=220, TopK=2, LoRA(rank-64) mid-training, autoregressive→few-step distillation로 긴 horizon을 가속화한다.
Novelty vs. Prior Works
- 기존 action-conditioned models는 joint-space나 6D end-effector 명령에 의존해 embodiment-specific coupling을 피하기 어려웠다. Hydra-0은 image-plane action flow로 kinematic grounding을 제공해 이 모호성을 줄인다 (대조: Cosmos 2.5, ATI, Wan-Move). - ATI/Wan-Move 등은 trajectory-conditioned video generation을 보였으나, 실행가능한 robot command와의 정합성(kinematic grounding)과 inverse control까지 통합하지 못했다. Hydra-0은 그 둘을 하나의 인터페이스로 연결한 점이 핵심 차별점이다. - 다만 Gaussian propagation/first-frame feature transport 등 motion-feature 전파 메커니즘은 ATI/Wan-Move의 연장선에 있으므로 기초 메커니즘 자체의 완전한 새로움은 제한적이다.
Benchmark Results
- 최고 구성에서 Cosmos 2.5 대비 robot-motion error 90.40% 감소, object-motion error 60.16% 감소를 보고한다. - Table 2(average block): PSNR 15.62→21.84, SSIM 0.668→0.830, Obj EPE 13.23→5.27, Gripper EPE 34.28→3.29, FID 39.1→18.7, FVD 405.8→155.9으로 개선. - 데이터셋별 개선: XVLA-Soft-Fold Gripper EPE 35.78→3.20, Deform360 Obj EPE 20.02→6.86, DROID Gripper EPE 28.45→3.13, ABC-130k Obj EPE 14.00→5.53. - Open-loop policy evaluation: 300 replay 집계에서 Pearson r=0.96, Spearman ρ=0.93, MAE 5.7%p를 보고하며 태스크 평균 순위를 재현. - Inference/속도: 81프레임 기준 single H100에서 bidirectional 20.92s→autoregressive 12.48s→few-step student 1.31s로 최대 16.0× generation-only 가속 달성. Real-robot inverse 제어는 정성적 성공 사례만 제시됨.
누리랩 연구와의 연결
- VLA / high-level planning: LLM/VLM에서 나온 high-level plan을 Isaac Lab rollout→action flow로 변환해 Hydra-0에 conditioning하면 언어-유도 제어로 확장 가능하다. - Failure recovery & test-time optimization: 실제 vs 예측 flow의 EPE를 failure score로 쓰고, desired object flow를 변수로 두어 autoregressive+few-step rollouts로 빠르게 탐색·replan 하면 replanning과 counterfactual reasoning에 유리하다. - World model / robot memory / 3DGS 결합: chunked causal caching과 multi-view 통합으로 장기 horizon과 3D 일관성을 강화하고, object-centric 3DGS 또는 scene graph로 flow를 node-edge 동역학으로 투영해 의미적 planning·manipulation(도구 사용·접촉 강화) 연구로 확장할 수 있다.

UniReflex: Plug-and-Play Force Control for Pretrained Generative Policies via Fast-Slow Reflex

arXiv PDF alphaXiv
Manipulation relevance 10/10 Robotics (cs.RO)
Yan Huang, Shoujie Li, Ziwu Song, Wenbo Ding PDF 전문 1차 84점
프리트레인된 generative policy의 decoder latent를 read-only hook으로 가로채 fast reflex만 학습해 VIC 기반 active force control을 추가한다. Contact 안정성과 Phase II 성공률을 크게 올리면서 per-step backward latency를 25–66배 낮춘다.
Core Innovation & Methodology
- UniReflex는 frozen generative backbone의 action-head latent z를 read-only forward hook으로 추출해 slow intent로 사용한다. - Fast reflex는 GRU 기반 causal 모델로 proprioception, wrist F T, phase embedding과 slow intent를 결합해 x_reflex, F_ref, ΦK를 생성한다. - F_ref와 anisotropic stiffness ΦK를 Cartesian VIC에 연결해 능동적 force tracking과 방향성 stiffness 배분을 수행한다. - Phase gating으로 contact 전에는 position-dominant, 접촉 후에는 force-dominant로 전환해 chunk drift를 억제한다.
Novelty vs. Prior Works
- 기존 ForceVLA/TA-VLA/FoAR 계열은 보통 force를 관측으로 융합하거나 백본 재학습을 요구하지만, UniReflex는 frozen backbone의 내부 latent를 non-invasive하게 훅해 plug-and-play로 force output(F_ref, ΦK)을 능동 생성한다. - RoboDual/fast-slow prior는 종종 공동 학습이나 리아키텍처를 필요로 하나, UniReflex는 fast-only 학습만으로 slow intent를 보존해 foundation model 재활용에 적합하다. - 다만 VIC, fast-slow 분해, gating 아이디어 자체는 선행이 풍부하므로 본 기여는 구성의 정교한 통합 및 실용적 인터페이싱에 중점이며 완전한 패러다임 전환은 아님.
Benchmark Results
- Phase II 개선: UniReflex+DP에서 Wipe Curve/Incline/Peel Note/Flip Chip Box 각각 40/40/60/40 포인트 개선, Plug Charger 동률(50). UniReflex+π0는 각 50 포인트 개선(Plug Charger 50). UniReflex+DreamZero는 30/30/20/30 포인트 개선(Plug Charger 30). - Phase I 보존성: DP 대비 UniReflex+DP에서 최대 10포인트 이내 변화 보고. Repetition as Reinforcement: Enhancing Sample Efficiency via Instant Episode Repetition in Reinforcement Learning

arXiv PDF alphaXiv
RL relevance 8/10 Machine Learning (cs.LG)
Hoda Yamani, Yuning Xing, Koen van Rijnsoever, Bruce A. MacDonald, Henry Williams PDF 전문 1차 82점
새로운 Instant Episode Repetition(IER)은 high-reward episode의 action sequence를 즉시 여러 에피소드 동안 반복 실행해 sample efficiency를 높인다. 시뮬(8개 MuJoCo/DMC)과 실로봇 실험에서 SAC/TD3 대비 더 빠른 수렴과 높은 성능을 보였다.
Core Innovation & Methodology
- Instant Episode Repetition(IER): 새 최고 보상 episode의 전체 action sequence를 RN 에피소드 동안 강제로 재실행한다. - Interaction-level intervention: 데이터 수집 분포를 바꿔 episode-level로 성공 행동열을 능동적으로 재방문한다. - Off-policy 호환성: SAC/TD3에 네트워크·loss·optimizer 변경 없이 적용되고, 수집된 transition은 replay buffer로 학습된다. - RN 하나로 반복 강도를 제어하며, 적정 값(RN2–RN4)이 권장된다.
Novelty vs. Prior Works
- 기존 PER/SIL은 replay-buffer에서의 passive 중요도 조정 방식인 반면, IER는 환경 상호작용 단계에서 행동 선택을 episode 단위로 대체하는 active 개입이다. - IER는 데모나 목표조건 없이 범용 off-policy 연속제어에 적용된다는 점에서 차별화된다. - 그러나 이론적 분석·representation 변화·최적성 보장은 제시되지 않아 근본적 혁신보다는 실용적 개선에 가깝다.
Benchmark Results
- IER-SAC: 8개 과제 중 6개에서 SAC보다 우수, 나머지 2개는 유사하다고 보고됨. - IER-TD3: 8개 과제 중 6개에서 TD3보다 우수; SIL-TD3 대비 5/8 과제에서 앞섬. - RN 민감도: RN∈{0..7} 비교에서 SAC+TD3 합산 평균 ΔAUC%가 RN3에서 피크 10.66% 보고. - 실험 설정: 시뮬 training step 1e6, exploration 1e3, episode horizon(시뮬) 1000(일부 조기 종료), real-robot episode 20 step 및 총 20,000 interaction step. - 통계: 시뮬 5 seeds 평균(표준편차 음영), real-robot 5 seeds, RN ablation은 10 seeds 사용.
누리랩 연구와의 연결
- VLA/generalist policy: language-conditioned 성공 trajectory를 즉시 반복해 빠른 skill consolidation에 활용 가능하다 (IER as control-loop hook). - failure recovery / test-time optimization: 반복 중 성능 저하를 failure signal로 RN을 조절하거나, 성공 episode를 inference-time plan reuse로 활용해 빠른 회복을 달성할 수 있다. - world model / robot memory / manipulation: 모델 기반 예측으로 반복 후보를 선별하고 top-k 성공 episode 라이브러리와 다양성 제약을 결합해 반복의 과도한 exploitation을 방지하며, 접촉 중심 조작에서 데이터 밀도를 높이는 데 유용하다.
