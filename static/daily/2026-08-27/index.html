$R^3$: Training Robots to Reason in Natural Language via Reinforcement Learning

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Lehong Wu, Yuxiao Qu, Zheyuan Hu, Ivan Zhang, Limin Wei, Zackory Erickson, Aviral Kumar PDF 전문 1차 63점
R^3는 오프더셸프 VLM을 저수준 policy를 언어로 steering하는 'robotic reasoner'로 바꾸는 2단계 post-training 레시피임. expert reasoning trace로 mid-train한 뒤 offline action 데이터에 rubric 기반 RL(Dr.GRPO)을 적용해, Language Table과 시뮬레이션 bimanual grocery packing에서 instruction-only imitation보다 특히 미학습 task에 대한 일반화가 크게 좋아짐.
Core Innovation & Methodology
- 고수준 VLM이 자유형식 언어로 추론(reasoning trace z_t)한 뒤 저수준 instruction u_t를 내고, 고정된 저수준 policy가 이를 실행하는 계층 구조를 씀. 기존 ECoT 등은 bounding box 같은 구조화된 중간 표현을 학습 신호로만 쓰는데, R^3는 free-form language reasoning 자체를 test-time steering 신호로 학습시킴 - Stage I mid-training: Gemini 3 Flash를 expert로 써서 부분 진행·실수·복구가 담긴 multi-turn trajectory와 reasoning trace를 수집하고, 성공·실패 무관하게 next-token prediction으로 VLM에 reasoning style을 주입함 - Stage II single-step RL: expert reasoning trace 없이 expert instruction만 있는 더 넓은 offline 데이터에 대해, VLM이 생성한 instruction이 expert instruction과 의미적으로 일치하면 보상하는 rubric 기반 VLM-judge 보상으로 RL 알고리즘 Dr.GRPO(GRPO 변형)를 적용함. multi-turn rollout이나 최종 task success 없이 단일 스텝만으로 credit assignment 문제를 피함 - interaction history(직전 스텝의 full response)를 context로 넣어 진행상황·계획을 이어가게 함. history 유무 ablation에서 expert pass@1이 44.9→51.0%(line task), 52.3→57.6%(V task)로 오름
Novelty vs. Prior Works
- 가장 가까운 선행연구(ECoT, Chen et al.)는 구조화된 reasoning을 학습 시점 보조 supervision으로만 쓰고 추론 시 reasoning을 꺼도 성능이 안 떨어진다고 보고했는데, R^3는 반대로 test-time reasoning이 causal하게 성능에 기여함을 truncation 개입 실험으로 직접 보임(reasoning budget을 줄이면 성능이 하락함) - IL(pretrain·co-train으로 reasoning supervision을 흡수)과 비교해도 OOD task에서 R^3가 일관되게 더 나아, 'reasoning 이득이 표현학습으로 환원된다'는 기존 결론에 반례를 제공함 - 다만 검증 환경이 Language Table(2D 블록 배치)과 시뮬레이션 grocery packing 두 개뿐이고 real-robot 실험이 없어, free-form reasoning의 이득이 저수준 policy가 이미 다양한 instruction을 신뢰성 있게 따르는 통제된 testbed에 의존할 가능성이 있음
Benchmark Results
- 14개 Language Table 장기 task를 mid-training(6개) / RL(3개) / OOD held-out(5개)으로 분리 평가. OOD 5개 task 전부에서 R^3가 instruction-only IL을 능가함(diag_line +14.2%p, iL +9.9%p, mid +8.7%p, clear_half +4.8%p, rect +3.9%p) - 절대 성공률은 과제별로 낮은 경우가 많음(T task 9.9%, rect 6.0%)으로, 어려운 기하학적 task에서는 여전히 개선 여지가 큼 - 추론 예산 개입 실험(동일 체크포인트에서 reasoning 토큰을 0/50/100/전체로 조절): 전체 reasoning 대비 truncate@50에서 V task가 69.2→26.6%로 급락해, test-time reasoning이 실제로 성능에 기여함을 정량적으로 확인함 - 시뮬레이션 bimanual grocery packing에서도 RL만으로 instruction-only IL을 능가한다고 abstract에 보고되나, 본문에서 확인 불가 - ECoT류 구조화 reasoning과의 비교(4.4절)에서는 R^3가 held-out task 다수에서 근소하게 우세하나, 표 일부는 본문에서 확인 불가
누리랩 연구와의 연결
- test-time에 언어로 추론해 policy를 steering하는 방식은 누리랩의 test-time optimization·inference-time planning 및 failure detection·recovery 연구와 직결됨. 논문이 관찰한 '재검토→재계획' self-correction 패턴은 실패 복구 로직 설계에 참고할 만함 - mid-training 없이 RL만으로는 reasoning style이 불안정하다는 결과는, VLM을 robot reasoner로 전환할 때 순서(behavior prior 확보 후 RL)가 중요하다는 실무적 시사점을 줌 - rubric 기반 VLM-judge 보상은 사람이 정답 reasoning을 라벨링하지 않고도 instruction-level 보상을 얻는 방법이라, 누리랩에서 language feedback 기반 학습이나 counterfactual reasoning 데이터 구축의 저비용 보상 설계에 응용 가능함

LM-X: Explainable Action Modeling with Progress, Event, and Uncertainty Prediction for Generalist Robot Manipulation

arXiv PDF alphaXiv
VLA relevance 9/10 Robotics (cs.RO)
Jin Lou, Jingxuan Zhu, Andong Chen, Xupeng Wang, Yuan Xu, Yuexuan Li, Xingdong Zhu, Zhijie Zhu 외 9명 PDF 전문 1차 68점
장기 과제를 하나의 short-horizon action target으로만 학습하는 VLA의 한계를 지적하고, task-scale 진행도(RTG)·event-scale 다음 전이(ETG)·동작 신뢰도(heteroscedastic variance)를 명시적으로 예측해 action 생성에 직접 조건화하는 LM-X를 제안함. 2만 시간 넘는 실물 로봇 데이터(실패 rollout 1000시간 포함)로 학습해 RoboTwin2.0에서 GR00T N1.7 대비 74.1% vs 55.4%, 실물 7개 task에서 68.6% vs 50.7%를 기록함.
Core Innovation & Methodology
- RTG는 128-bin ordered classification으로 학습되는 task-scale scalar로, 성공 시 종료 시점에서 0에 가까워지고 실패 시 별도의 음의 margin을 받도록 설계해 dense progress signal을 성공·실패 rollout 모두에서 얻음 - ETG는 다음 검증된 semantic event까지의 action chunk(horizon 60, fine action head horizon 30보다 김) 자체를 flow matching으로 예측해, 별도 이미지 생성기나 symbolic skill vocabulary 없이 subgoal을 action space 안에서 표현함 - action expert는 mean flow velocity와 log-variance를 동시에 예측하고 forward Euler 적분으로 variance를 최종 action까지 전파해(Hutchinson estimator로 covariance 근사) 매 스텝 local reliability를 노출함 - RTG→ETG→action 순서로 조건화하는 정보 흐름(causal information flow)을 구성해 세 신호가 post-hoc 설명이 아니라 control 계산 자체에 내재되도록 함 - 20일·64 B200 GPU급 본 pretraining 전에 5-task RoboTwin2.0로 pretraining gate를 돌려 신호의 유효성을 확인한 뒤에만 전체 파이프라인을 실행하는 비용 인식적 연구 프로세스를 씀
Novelty vs. Prior Works
- Decision Transformer의 RTG 개념을 가져오지만 optimal value function이 아니라 성공·실패 trajectory에서 관측된 empirical progress-quality signal로 재정의했고, π*0.6의 ReCAP과 달리 실제 policy 실패 rollout(1000시간+)을 학습에 포함해 regression을 구분함 - π0.5·π0.7의 textual subtask/keyframe 예측이나 CoT-VLA의 keyframe CoT와 달리, ETG는 별도 생성기·discrete space 없이 event를 native action space의 chunk로 정의해 짧은 horizon 행동과 embodiment normalization·dynamics를 공유함 - variance를 flow velocity에서 propagate해 최종 action 분산으로 전달하는 방식(Hutchinson estimator 이용)은 πRL 등 기존 uncertainty-aware flow 연구와 유사한 원리를 쓰지만, RTG·ETG와 결합해 hesitation·oscillation을 잡아내는 해석까지 이어간다는 점에서 응용이 새로움 - 다만 개별 아키텍처 요소(RTG head, event chunk, heteroscedastic flow)는 각각 선행연구가 존재해, novelty는 explicit multi-timescale predictive state를 하나의 causal 인터페이스로 묶었다는 시스템 통합에 있음
Benchmark Results
- pretraining gate(RoboTwin2.0 held-out 5-task)에서 backbone 63.6%→LM-X 79.6%(+16.0%p), RTG·ETG·uncertainty 단독은 각각 +5.2/+0.4/+1.6%p에 그쳐 세 요소의 결합 효과가 개별 합보다 큼(block ranking task에서 RTG·uncertainty 단독은 backbone보다 낮은데 결합 시 90%로 +42%p) - RoboTwin2.0 전체 50-task(randomized-hard, 100 trial/task)에서 평균 55.4%(GR00T N1.7)→74.1%(LM-X, +18.7%p), stamp_seal task에서 22%→74%로 가장 크게 개선되었으나 beat_block_hammer에서는 40%→25%로 오히려 후퇴함 - 실물 로봇 4 embodiment·7 task에서 평균 50.7%→68.6%(+17.9%p), 5개 task 개선·1개 동률·1개 후퇴(tape-roll pick-and-place, -10%p)로 개선이 보편적이지 않음 - RTG·variance의 정성 분석(그립 실패·target 전환 시 RTG 급락, 망설임·oscillation 시 variance 급등)은 저자도 temporal correspondence이지 calibrated failure-detection 성능이 아니라고 명시해, 실제 recovery trigger로 쓰려면 threshold 검증이 추가로 필요함 - 학습 비용이 20일·64 NVIDIA B200 GPU로 매우 큰 산업 규모이고, 20,000시간 이상 비공개 사내 데이터에 의존해 재현성은 낮음
누리랩 연구와의 연결
- RTG의 dense progress signal과 variance propagation은 누리랩의 failure detection·diagnosis·recovery 연구에서 threshold 기반 recovery trigger로 발전시킬 직접적인 출발점이 됨 - ETG가 subgoal을 action space 안에서 표현하는 방식은 skill chaining·long-horizon planning 연구에서 별도 symbolic skill vocabulary 없이 event 경계를 정의하는 대안으로 활용 가능함 - RTG head가 proprioception 없이 관측만으로 progress를 평가하도록 설계된 점은 robot memory·counterfactual reasoning 연구에서 state 품질 평가와 동작 실행을 분리하는 구조로 참고할 만함

Zero-WAM: In-Context World-Action Modeling from Human Videos for Open-Ended Task Generalization

arXiv PDF alphaXiv
World Model relevance 9/10 Robotics (cs.RO)
Jiaming Zhou, Qihang Zhang, Gangwei Xu, Cunxin Fan, Yujie Zhao, Ruilin Wang, Yiming Luo, Shuai Yang 외 4명 PDF 전문 1차 62점
Zero-WAM은 사람이 시연하는 동영상을 in-context 예시로 줘서 로봇이 한 번도 학습하지 않은 task를 수행하게 하는 causal video-action model임. robot trajectory를 사람 영상으로 자동 변환하는 파이프라인으로 74.2K pair·8.6K task 규모의 HumanGen 데이터셋을 만들고, shortcut 학습을 막는 in-context future chunk prediction(IFP) objective를 더해, RoboTwin 2.0 미학습 7-task에서 가장 강한 video-action baseline 대비 성공률을 29.5%p 끌어올림.
Core Innovation & Methodology
- 로봇 조작의 task specification으로 언어 대신 사람 시연 영상을 쓰는 in-context learning 패러다임을 제안함. 동일 causal 모델이 언어 instruction과 human video 두 형태의 task 지정을 모두 지원함 - VLM(Gemini 3.1 Pro/Qwen3.6-Plus)으로 로봇 영상에서 task 정보를 추출하고, 이미지 편집 모델로 첫 프레임을 사람 시점 영상으로 바꾼 뒤 비디오 생성 모델(Wan 2.7/Kling AI 3.0)로 사람 시연 영상을 자동 합성하는 파이프라인을 구축함 - 이 파이프라인으로 task-sampled robot trajectory를 대량의 사람 영상과 자동으로 짝지어 HumanGen 데이터셋(74.2K pair·8.6K task)을 만듦 - Wan-2.2-TI2V-5B를 causal video-action model로 변환한 Mixture-of-Transformers 구조를 씀. video branch가 다음 로봇 영상 chunk를 예측하고, action branch가 그 예측 영상으로부터 inverse dynamics로 action을 디코딩함 - 학습 중 최근 로봇 history만으로 다음 영상을 예측하는 shortcut을 막기 위해, 현재 표현에서 여러 개의 미래 chunk를 동시에 strided 예측하는 in-context future chunk prediction(IFP)을 보조 목표로 추가함. IFP 모듈은 human video에 직접 접근하지 못하고 main branch를 거친 표현만 보게 해, main branch가 human video 정보를 반드시 encode하도록 강제함
Novelty vs. Prior Works
- 로봇 조작에 human video를 언어보다 풍부한 in-context prompt로 쓴다는 아이디어 자체는 기존 one-shot·few-shot imitation(BC-Z, RH20T 등)에서도 있었지만, 이들은 사람이 직접 사람-로봇 페어를 촬영해야 해 task 다양성이 100~350개 수준에 그침. Zero-WAM은 이를 완전 자동 생성 파이프라인으로 8.6K task까지 확장한 것이 데이터 측면의 실질적 novelty임 - IFP는 'shortcut learning으로 in-context 신호를 무시한다'는 문제를 정확히 짚고, ablation으로 그 효과(28.55%→46.95%)를 명확히 검증한 점에서 단순 engineering을 넘는 기여로 볼 수 있음 - 다만 기반 아키텍처(causal video-action model, MoT)는 LingBot-VA를 그대로 계승하고, HumanGen 데이터와 IFP objective를 추가 학습해 LingBot-VA 대비 +29.5%p 성능 차를 냄. world model이라는 명칭에도 불구하고 video generation을 명시적인 planning이나 counterfactual reasoning에 쓰지는 않아 world model로서의 활용은 다음 chunk 예측에 그치는 제한적인 수준임
Benchmark Results
- RoboTwin 2.0 미학습 7-task 평균 성공률: Zero-WAM 46.95%, LingBot-VA 17.45%, WAN-Action 10.98%로 각각 +29.5%p, +35.97%p 개선. 7개 task 전부에서 두 baseline을 능가함(seed 3개 평균) - place empty cup에서 84.87%로 두 baseline(38.33%, 42.33%) 대비 2배 이상, stack blocks three는 유일하게 non-zero(9.00%)지만 여전히 가장 어려운 task로 남음 - real-world Franka: object-to-container placement 53.3% vs LingBot-VA 43.3%(30 trial), three-object sequential manipulation 33.3% vs 10.0%, two-table-leg insertion(정밀 삽입) 16.7% vs 0.0%로 절대 성공률은 낮지만 fine-grained task에서 baseline은 아예 실패함 - ablation: ICL human video 자체의 효과만 분리(43개 seen task로만 학습) 시 WAN-Action이 10.98%에서 36.36%로 상승해 ICL이 대규모 pretraining 없이도 효과 있음을 보임. IFP 추가 시 28.55%→46.95%, task-balanced pretraining만 분리한 text-only 버전도 LingBot-VA 대비 +21.99%p(39.44% vs 17.45%)로 두 구성요소가 독립적으로 기여함 - stack blocks three 같은 unseen long-horizon task는 소규모 ICL 학습만으로는 0%에 머물러, 대규모 task-diverse ICL pretraining이 필수적임을 저자가 명시함. 코드·모델 공개 여부는 본문에서 확인 불가
누리랩 연구와의 연결
- human video를 in-context task specification으로 쓰는 방식은 누리랩의 robot memory·counterfactual reasoning 연구에서, 실패 이후 사람이 보여준 복구 시범 영상을 in-context guidance로 삼는 failure recovery 파이프라인에 응용 가능함 - robot trajectory를 human video로 자동 변환하는 파이프라인은 데이터가 부족한 새 task·embodiment에 저비용으로 in-context 예시를 늘리는 방법으로, VLA test-time adaptation 연구(RA-VLA류)의 buffer 구축에도 쓸 수 있음 - IFP처럼 '가까운 미래만 보면 shortcut이 생긴다'는 문제의식은 world model 학습에서 causal shortcut을 막는 보조 objective 설계 일반에 적용 가능함

V-Link: Recovering Lost Visual Representations in Action DiT for Vision-Language-Action Models

arXiv PDF alphaXiv
VLA relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Yehao Lu, Jiarui Yang, Yuning Su, Yufeng Xie, Yu Zhong, Yazhou Zhang, Haiyu Lan, Kaixiang Lu 외 5명 PDF 전문 1차 72점

Beyond Pairwise Feedback: Listwise Vision-Language Supervision for Preference-Based Reward Learning

arXiv PDF alphaXiv
RL relevance 8/10 Machine Learning (cs.LG)
Srivalli Katkuri, Maxwell Kawada, Juan Wachs PDF 전문 1차 62점
VLM이 매긴 K개 후보의 listwise ranking을 Plackett-Luce(순위 K개를 한 번에 학습하는 선호 모델) reward model로 학습하는 첫 프레임워크를 제안함. Meta-World 3개 태스크에서 pairwise Bradley-Terry, K-wise BT, RL-VLM-F와 비슷한 수준을 냈지만 대부분의 짝지은 비교에서 통계적으로 유의한 우위는 없었음.
Core Innovation & Methodology
- VLM이 생성한 listwise ranking(K=3,4,5)을 Plackett-Luce reward model로 학습하는 첫 프레임워크를 제안함 - Bradley-Terry pairwise, K-wise BT rank-breaking, RL-VLM-F를 baseline으로 삼아 SAC 정책 학습 루프에 통합함(PEBBLE류 entropy warm-up 후 VLM 질의 시작) - ranking size K와 iteration당 query 수 M을 독립 변수로 두고 Meta-World Drawer Open·Door Close·Button Press에서 비교함 - feedback budget ablation(M=1 vs M=4)으로 VLM 질의 비용 대비 성능 트레이드오프를 분석함
Novelty vs. Prior Works
- Plackett-Luce reward model 자체는 Zhu et al.(2023)의 기존 이론이고 VLM pairwise preference는 RL-VLM-F의 기존 방법임. 이 논문은 두 요소를 처음 결합한 조합 연구로, 새 objective나 architecture를 제시하지 않음 - PL이 pairwise보다 통계적으로 효율적이라는 주장은 선행 연구(Lee, Yi, Oh 2025)에서 이미 이론적으로 제시됐고, 본 논문은 이를 VLM 세팅에서 실증만 함 - novelty가 제한적임. 저자 스스로도 "to our knowledge, first framework combining..."으로만 기여를 규정하고 있음
Benchmark Results
- Drawer Open에서 PL(K=4) 86% 성공률로 oracle(86%)과 동률이나, RL-VLM-F가 92%로 가장 높은 성공률을 기록함 - Door Close에서 PL(K=5) 54%로 최고였고 RL-VLM-F·BT-Pairwise는 둘 다 39%에 그침. 단 oracle은 100%임 - Button Press에서 PL(K=5)이 BT-Kwise(K=5) 대비 26% vs 7%로 유일하게 명목상 유의(t=2.881, p=0.045)했으나 Holm 보정 후에는 유의성이 사라짐(p=0.405) - 같은 K에서 PL과 BT-Kwise를 짝지은 9개 통계 검정 중 8개는 유의한 차이가 없어, PL이 rank-breaking보다 우월하다는 주장은 통계적으로 뒷받침되지 않음 - 검증은 Meta-World 시뮬레이션 3개 태스크·5 seed에 한정됨. feedback budget을 M=1로 줄이면 PL 성공률이 49%로 떨어지고 5개 seed 중 최소 1개는 완전 실패(0%)함. 코드는 공개 예정이라고만 밝혀 현재 공개 여부는 본문에서 확인 불가
누리랩 연구와의 연결
- VLM listwise ranking을 test-time reward 신호로 쓰는 아이디어는 우리 lab의 language feedback 기반 learning 흐름과 연결됨. 특히 K를 조절해 VLM에 제시하는 candidate 수를 바꿀 수 있다는 점은 미세한 진행 차이를 구분해야 하는 태스크에 유용함 - world model rollout에서 여러 candidate trajectory를 한 번에 ranking해 counterfactual 비교에 쓰는 방향으로 확장 가능함(현재는 단일 이미지 프레임 비교에 그침) - 다만 통계적 근거가 약해 그대로 채택하기보다, K를 조절 가능한 listwise query 구조만 참고하고 실제 적용은 더 많은 task·seed에서 재검증이 필요함

오늘의 핵심 연구 트렌드 종합

  • VLM이 가진 3D/semantic 정보가 action expert에 실제로 전달되는지 진단하는 흐름 — V-Link는 probing으로 Action DiT의 depth/segmentation 접근성이 VLM 대비 크게 떨어짐을 정량화하고, GaussVLA는 Gaussian opacity를 depth confidence의 간접 신호로 씀. VLA 성능 개선을 새 아키텍처가 아니라 정보 흐름의 병목 진단에서 찾는 방향이 여럿 등장함.
  • World model 표현을 학습에만 쓰고 추론에서 제거하는 asymmetric 설계 — GaussianDream++는 3D Gaussian 디코더·렌더러를 학습 때만 감독 신호로 쓰고 추론 시 20개 토큰만 남김. 무거운 world model 계산을 추론 비용 없이 정책에 내재화하려는 실용적 타협이 반복됨.
  • test-time reasoning·progress 신호가 학습 보조가 아니라 실제로 causal하게 기여한다는 재검증 — R³는 reasoning budget을 truncation으로 줄이는 개입 실험으로 test-time free-form reasoning의 인과적 기여를 보이고, LM-X는 progress·event·불확실성을 action 생성에 직접 조건화함. 기존엔 "reasoning은 학습 시 표현학습으로 환원된다"던 통념(ECoT, Embodied Chain-of-Thought)에 반례를 제공함.
  • 파라미터 추가 없이 메모리·적응 능력을 얻는 경량 설계 — StreamPI는 attention mask 재설계만으로 streaming memory를 얻고, RA-VLA는 학습 없이 retrieval로 새 task에 적응함. 대형 backbone을 다시 학습하지 않고 추론 시점 구조만 바꿔 능력을 늘리는 쪽으로 무게가 실림.
  • 서로 다른 embodiment·에이전트를 하나의 공유 표현으로 통일 — UCAG-P는 카메라 좌표계 anchor motion으로 로봇팔·휴머노이드·사람 손을 통일하고, MA-VLA는 arm-specific atomic prompt와 Arm Shuffle로 협업 팔 역할을 비고정 학습함. 사람 영상이나 다른 팔의 데이터를 retargeting 없이 바로 섞어 쓰려는 시도가 늘고 있음.
