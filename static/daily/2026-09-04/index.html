Puffin-World: Scaling a Unified Multimodal Model with Native 3D World States

arXiv PDF alphaXiv
World Model Unified Multimodal 3D Perception relevance 7/10 Computer Vision and Pattern Recognition (cs.CV)
Kang Liao, Yihang Luo, Xiao-Ming Wu, Linyi Jin, Size Wu, Chunyu Lin, Yao Zhao, Fei Wang 외 2명 PDF 전문 1차 72점
Puffin-World는 물리(중력·위도)·기하(depth)·외형(RGB)을 native world state로 명시해 하나의 멀티모달 프레임워크에서 카메라 이해·생성·재구성을 동시에 수행하는 world model임. 참조 프레임의 절대 중력 방향을 미래 프레임까지 전파하는 physics propagation으로 방향 drift를 줄이는 것을 목표로 하며, 생성 품질의 정량 결과는 본문에서 확인 불가함.
Core Innovation & Methodology
- physics(중력장·위도)·geometry(depth)·appearance(RGB)를 native 3D world state로 분리해 하나의 프레임워크에서 perception·generation·reconstruction을 통합함. - Omni-Camera representation: gravity-anchored absolute field(up-vector, latitude)와 relative ray field를 9채널로 결합해 single-view·cross-view 조건을 하나로 통일함. - physics propagation: reference view에서 추정한 절대 중력 방향을 relative rotation으로 미래 프레임에 전파해 trajectory 전체가 하나의 절대 좌표계를 공유하게 함. - depth를 3D Hilbert curve 기반 invertible color mapping으로 RGB화해 동일 frozen VAE로 appearance와 함께 flow-matching으로 동시 생성함(asymmetric attention과 zero-init geometry embedding으로 appearance 성능 보존).
Novelty vs. Prior Works
- 가장 가까운 prior work인 Puffin 대비 본질적 차이는 persistent world frame의 유무임. Puffin은 isolated single-view 카메라 이해·생성만 다루지만 Puffin-World는 physics propagation으로 trajectory 전체에 절대 좌표계를 부여하고 reconstruction까지 통합함. - camera representation 자체(절대+상대 결합)는 Perspective Field와 Plücker ray 계열 표현을 조합한 것이라 표현 방식의 novelty는 제한적임. 새로움은 이를 diffusion latent에 pixel-aligned additive injection으로 넣고 trajectory에 전파한 시스템 설계에 있음. - depth를 Hilbert curve 매핑으로 RGB화해 별도 encoder 없이 기존 VAE로 처리하는 방식은 기존 아이디어(Vision Banana)를 world model 맥락에 적용한 것이라 응용 novelty에 가까움.
Benchmark Results
- camera-to-world understanding에서 Stanford2D3D 기준 roll error 0.29도, pitch error 0.53도로 GeoCalib(0.40도/0.93도)·UVP(0.52도/0.95도) 대비 개선되고 AUC@5도가 roll 97.4%, pitch 88.8%로 비교 방법 중 최고임. - 비교 baseline은 DeepCalib, CTRL-C, ParamNet, GeoCalib, AnyCalib 등 카메라 calibration 전용 모델임. 본문에서 확인 가능한 정량 수치는 Stanford2D3D 결과뿐이고 MegaDepth·TartanAir·LaMAR 결과는 표 후반부가 텍스트 추출 과정에서 생략되어 확인 불가. - 학습 데이터 Puffin-16M은 vision-language-camera triplet 1500만 개와 challenging-motion trajectory 100만 개로 구성되며 기존 Puffin-4M(400만) 대비 규모가 크고, 공개 데이터셋 28개(약 4450만 이미지)에 절대 카메라 파라미터 주석을 추가로 공개함. - physics propagation의 효과를 보여주는 ablation(Fig. 12)이 존재하나 정량 수치는 본문에서 확인 불가하고 정성적 예시만 제시됨. - free-viewpoint 생성 품질, 3D world modeling의 reconstruction 정확도, multi-task synergy(mimic·self-calibrated exploration) 관련 정량 결과와 limitation 절은 텍스트 추출이 5.2 후반부터 결론까지 생략되어 본문에서 확인 불가. real-robot 실험은 없음(실내·파노라마 이미지 기반 world model).
누리랩 연구와의 연결
- self-calibrated world exploration(중력 오정렬을 예측 action과 imagined observation으로 자동 감지·보정)은 failure detection·recovery 우선주제와 맥락이 닿음. VLA policy의 test-time self-correction 설계에 참고할 만함. - physics propagation의 절대 좌표계 anchoring 아이디어는 robot manipulation에서 world model 기반 test-time planning 시 long-horizon 상태 drift를 줄이는 데 응용 가능함. - appearance-geometry joint latent 생성은 object-centric 3DGS/scene reconstruction 파이프라인의 pretraining 신호로 쓸 수 있으나, real-robot 검증이 없고 실내·파노라마 이미지 도메인 중심이라 manipulation task로의 전이는 별도 검증이 필요함.

RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning

arXiv PDF alphaXiv
Manipulation Robot Data Retrieval relevance 9/10 Computer Vision and Pattern Recognition (cs.CV)
Howard Qian, Yiting Chen, Yunfei Xie, Kejia Ren, Podshara Chanrungmaneekul, Gaotian Wang, Bowen Wen, Chen Wei 외 1명 PDF 전문 1차 72점
인터넷 동영상 속 사람의 손 움직임을 actor 중심 3D trajectory로 변환해, query 시연과 비슷한 조작 동작을 검색하는 RoboTok을 제안함. 이 검색 결과로 dexterous manipulation policy를 학습시키면 STRAP·HAND 등 기존 retrieval 방법보다 시뮬레이션 성공률이 크게 올라감.
Core Innovation & Methodology
- internet-scale retrieval 프레임워크 RoboTok을 제안, human manipulation video를 query로 웹 비디오에서 유사 조작 시연을 non-parametric하게 검색함 - 핵심 표현은 actor-centered 3D hand trajectory임. camera 좌표계의 hand pose를 hand wrist frame만으로 추정한 torso frame 기준으로 정규화해 viewpoint 변화·occlusion에 무관하게 만듦 - 정규화된 trajectory 쌍의 DTW(dynamic time warping) alignment cost를 pseudo-GT 유사도로 삼아 lightweight encoder를 학습함. set loss(top-K 이웃 판별)와 rank loss(순서 보존)를 결합 - offline으로 100K clip을 한 번씩 인코딩해 inner-product index를 구축하고, query 시 cosine similarity로 top-K를 검색해 전체 corpus와 DTW를 다시 계산하지 않고도 확장 가능하게 설계함
Novelty vs. Prior Works
- 가장 가까운 prior work은 STRAP(ICLR 2025, visual foundation feature+DTW로 고정 robot corpus 내부 검색), HAND(ICRA 2026, 2D hand-robot path 매칭, self-collected robot play 대상), FlowRetrieval(optical flow 기반)임. 이들은 fixed robot corpus 혹은 2D/이미지 공간 motion에 한정됨 - RoboTok의 본질적 차이는 query와 검색 대상이 모두 internet human video라는 점, 그리고 3D actor-relative hand trajectory라는 명시적 motion representation을 쓴다는 점임. camera coordinate가 아니라 추정된 torso frame 기준이라 occlusion과 viewpoint 변화에 강함 - 다만 구성 요소(WiLoR hand pose 추정, MoGe-2 metric depth, HaWoR infill, torso frame estimator, DTW 기반 metric learning)는 대부분 기존 방법의 조합임. novelty는 architecture가 아니라 representation·retrieval formulation에 있고, 이 formulation 자체는 STRAP·HAND의 자연스러운 확장으로 볼 여지도 있음
Benchmark Results
- RoboTok evaluation corpus(Action100M 기반 N=100K, 10K held-out query)에서 mAP@20=0.353, Recall@20=0.996, Kendall τ=0.487로, 최강 baseline STRAP(mAP@20=0.007, Recall@20=0.12)을 크게 앞섬 - 외부 corpus AssemblyHands(N=831, cross-dataset domain shift)에서도 mAP@5=0.261 vs STRAP 0.133으로 우위가 유지돼 순위가 바뀌지 않음 - VTDexManip sim benchmark(6 task, PPO reward guidance만 사용, robot action label 미사용)의 원 formulation에서 6개 중 5개 task에서 최고 pretrained baseline(VT-JointPretrain)을 능가, 평균 seen +7.45%p / unseen +5.83%p - 저자가 dense reward를 제거하고 3D hand control을 복원한 harder formulation(3 task)에서 BottleCap Turning 77.3%(HAND 대비 +17.8%p), Faucet Screwing 44.8%(+38.0%p), Lever Sliding 79.3%(+59.8%p)로 격차가 더 커짐. 다만 이 harder task는 논문이 자체 정의한 변형이라 외부 검증이 없음 - 모든 downstream 실험이 simulation이며 real-robot 실험은 없음. policy 학습도 imitation이 아니라 retrieved clip을 reward shaping(potential-based)으로만 사용하는 PPO 방식임
누리랩 연구와의 연결
- test-time에 유사 조작 시연을 검색해 policy guidance로 쓰는 방식은 failure recovery 시 참조 시연을 검색해 복구 전략을 세우는 test-time retrieval/adaptation 아이디어로 확장 가능함 - actor-centric 대신 object-centric 3D reference frame(3DGS·scene graph 연구와 결합)으로 retrieval하면 object-relative manipulation motion을 더 정확히 잡을 수 있어 우리 연구와 연결 여지가 있음 - VLA post-training용 dexterous manipulation 데이터 확보 파이프라인 참고용으로 유용함. real robot에 이식 시 reward-shaping이 아니라 imitation 학습으로 바꿨을 때도 효과가 유지되는지 검증할 필요가 있음

WISE: World-model-guided Imagination Scheduling for Efficient Post-training of Vision-Language-Action Models

arXiv PDF alphaXiv
VLA World Model relevance 9/10 Robotics (cs.RO)
Chenhao Zhang, Hanyu Zhao, Hang Cheng, Tengfei Pan, Long Zeng PDF 전문 1차 78점
VLA post-training에서 world model 상상(imagination)을 아무 상태에나 쓰지 않고 interaction-relevant 상태에서만 선택적으로 짧게 굴려 GRPO 스타일로 policy를 업데이트하는 WISE를 제안함. π0/π0.5에서 MimicGen 5개 task 평균 성공률을 각각 9.8/7.9%p 올리면서 world model 연산은 full imagination 대비 약 77% 줄였고 real robot에서도 개선을 확인함.
Core Innovation & Methodology
- DINOv2 기반 lightweight scheduler로 현재 시점이 imagination이 필요한 interaction-relevant 상태인지 판단해 world model 호출을 선택적으로 트리거함 - 선택된 상태에서만 action-conditioned multi-view world model(Open-Sora 기반)로 L-chunk bounded rollout을 굴려 긴 horizon에서 누적되는 예측 오류를 제한함 - 별도 학습된 reward model이 progress/confidence/completion 신호를 결합해 imagined trajectory를 평가하고, imagined state-action을 직접 supervision으로 쓰지 않고 후보 간 상대적 advantage로만 GRPO 업데이트에 반영함 - reliability filter(ranking consistency, reward uncertainty, reward separation 기준)로 신뢰도 낮은 imagination 그룹을 걸러내고 real interaction context에서 나온 첫 action chunk만 실제로 학습에 씀
Novelty vs. Prior Works
- world model로 VLA를 post-training하는 흐름 자체는 WMPO, World4RL, VLA-RFT, AtomVLA, RISE 등 이미 여러 편 있고 이 논문도 그 계열에 속함. 본질적 차이는 imagination을 '언제·어디서' 쓸지 스케줄링하는 것을 명시적 학습 대상으로 만든 점임 - bounded rollout + 상대적 advantage(GRPO 스타일)로 imagined trajectory를 direct supervision이 아닌 counterfactual 평가로만 쓰는 설계는 world model prediction error 누적 문제에 대한 실용적 해법으로 타당함 - 다만 본문 baseline은 GRPO/DSRL/DPO(비-world model 계열)뿐이고, 가장 가까운 prior work인 WMPO·World4RL·VLA-RFT·AtomVLA·RISE와 직접 성능 비교가 없어 '스케줄링이 기존 world-model 기반 post-training보다 낫다'는 핵심 주장의 실험적 근거는 약함
Benchmark Results
- MimicGen 5개 task 시뮬레이션: π0 49.7%→59.5%(+9.8%p), π0.5 52.3%→60.2%(+7.9%p), 가장 강한 baseline인 π0+DPO(53.8%) 대비 +5.7%p - imagination scheduling ablation(Stack/Threading/Mug Cleanup 평균): full imagination 60.4%(138 states, 11.45 GPU h) 대비 WISE 68.3%(28 states, 2.61 GPU h)로 성공률은 높이고 GPU 시간은 약 77% 절감함. uniform(61.1%)·random(59.1%) scheduling보다도 우수함 - reward model ablation: progress-only/completion-only 각각 57.3%로 full reward(68.3%) 대비 낮아 progress+completion+confidence+backward penalty 조합이 유효함을 보임 - real robot(Galaxea R1 Lite, 4 task, standard/generalization 각 20 trial): π0 기준 표준 60.0%→77.5%(+17.5%p), generalization 42.5%→68.8%(+26.3%p); π0.5 기준 표준 61.3%→77.5%, generalization 50.0%→71.3%로 distribution shift 상황에서 개선폭이 더 큼 - reward model 최종 discrimination은 AUROC 0.938~1.000(5개 task)로 sim 데이터 기준 수치이며 real-world reward model 정확도는 별도 보고 없음
누리랩 연구와의 연결
- imagination scheduling(언제 world model을 불러올지 판단하는 lightweight visual classifier) 아이디어는 test-time optimization/inference-time planning에서 연산 예산을 실패 위험이 높은 지점에 집중시키는 방식으로 failure detection 연구에 바로 연결 가능함 - bounded rollout + reliability filter(ranking consistency, reward uncertainty)는 world model 예측이 신뢰 가능한 horizon을 정량적으로 판정하는 방법론이라 counterfactual reasoning 기반 실패 예측/recovery 연구에 참고할 틀임 - reward model이 progress/confidence/completion을 분리해 학습하는 구조는 robot memory나 object-centric representation과 결합해 장기 task의 stage-aware 평가로 확장할 여지가 있음

Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies

arXiv PDF alphaXiv
VLA Multimodal Robustness relevance 10/10 Robotics (cs.RO)
Yue Yang, Diego Romeres, Chiori Hori, Gedas Bertasius, Daniel Szafir, Siddarth Jain PDF 전문 1차 68점
여러 센서를 쓰는 VLA 정책이 적은 로봇 시연 데이터 때문에 센서 간 가짜 상관관계를 학습하는 문제를 modality entanglement로 정의함. 프레임·센서별 evidence score로 무관한 센서엔 invariance를, 유효한 센서엔 single-sensor sufficiency를 강제하는 EGR을 제안해 시뮬레이션과 실로봇 두 플랫폼에서 성공률을 개선함.
Core Innovation & Methodology
- modality entanglement를 nuisance sensitivity(무관한 센서 왜곡에도 행동이 변함)와 single-modality insufficiency(유효 센서 하나만 남아도 실패함) 두 실패 모드로 formalize함 - task 구조(focal/interaction object의 픽셀 면적, tactile contact 여부)로부터 프레임·센서별 evidence score E_{t,m}을 계산함. end-to-end 학습이 아니라 heuristic으로 부여함 - evidence를 hinge weight로 게이팅해 낮은 evidence 센서엔 invariance loss, 높은 evidence 센서엔 single-sensor sufficiency loss를 적용하고 base policy(π0.5) 구조는 그대로 둠 - 2|M|번 필요한 추가 forward pass를 importance sampling으로 스텝당 2회로 줄이고 unbiased 추정임을 증명함
Novelty vs. Prior Works
- 가장 가까운 prior work인 modality dropout(Liu et al. 2017)과 adversarial multi-sensor consistency(Guo et al. 2025)는 센서·시점을 균일하게 다뤄 state-dependent 선택을 못하는데, EGR은 task-grounded evidence로 프레임마다 다르게 게이팅한다는 점이 차별점임 - TacVLA의 contact gate는 tactile·binary contact에 특화된 반면, EGR은 동일 프레임워크를 vision·tactile에 공통 적용 가능하게 일반화함 - evidence score 자체는 instance segmentation, focal/interaction object 라벨, tactile reference pattern 같은 사전 정의된 task 구조에 의존함 - 저자도 in-hand reorientation처럼 evidence를 미리 정의할 수 없는 경우엔 적용 불가능하다고 명시해 novelty가 학습 목적함수 설계에 국한됨
Benchmark Results
- BEHAVIOR-1K 기반 47개 skill(NAV 11 + MAN 36) 시뮬레이션에서 π0.5 대비 SR을 Full 12.5%→16.4%(+31%), NoUseless 9.4%→16.5%(+75%), UsefulOnly 2.8%→6.1%(+118%)로 개선함 - 절대 성공률은 최고 16.5%로 낮음 - BEHAVIOR-1K challenge task 자체의 baseline 성능이 낮은 상태에서의 상대 개선폭임 - 실로봇 bi-manual(Kinova 2팔 + RGB 3대) 4개 task에서 RealDistractor SR 30%→85%(+183%, Fisher's exact p<0.001, N=40)로 가장 큰 개선을 보임 - 실로봇 vision-tactile(MELFA ASSISTA + GelSight 2개) 2개 task에서 SingleUseful SR 40%→90%(+125%, p=0.0022)는 유의하지만 RealDistractor 55%→70%는 유의하지 않음(p=0.51, N=20) - ModDrop baseline과 비교해 Suite1 action-deviation ratio·Suite2 SR 대부분에서 EGR이 우세하나, Suite2 NAV Full(p=0.875)과 MAN Full(vanilla 대비 p=0.065)은 통계적으로 유의하지 않음
누리랩 연구와의 연결
- evidence-gated invariance/sufficiency 개념은 누리랩 failure detection/recovery 연구에서 실패 감지 후 어떤 센서를 신뢰해 fallback할지 판단하는 test-time 모듈로 확장 가능함 - vision evidence 계산에 쓰는 instance segmentation·focal/interaction object 라벨을 object-centric 3DGS나 scene graph로 대체하면 evidence score를 3D 표현에서 직접 얻어 사전 라벨링 의존을 줄일 수 있음 - evidence가 사전 정의된 task 구조에만 의존하는 한계는 world model 기반 counterfactual reasoning(센서를 가상으로 perturb했을 때 예측 변화 측정)으로 evidence를 학습하는 방향으로 이어질 수 있음

FailBench: How Reliable are VLMs at Judging Robot Task Success?

Core Innovation & Methodology
- action horizon을 통째로 미분 가능한 변수로 취급해 frozen LeWM의 autoregressive rollout을 통해 L-BFGS로 직접 backprop하는 gradient 기반 planner를 제안함. Novelty vs. Prior Works
- gradient 기반 trajectory optimization 자체는 Differentiable MPC(Amos et al.)나 learned model을 통한 planning에서 이미 쓰이던 방식이라 sampling에서 gradient로 planner를 바꾼 것 자체의 novelty는 제한적임. - 본질적 기여는 latent 목적함수 단독 최적화가 offline data 분포 밖 action을 선호할 수 있다는 문제를 decoder 기반 보조 energy로 보정한 것임. test-time에서 latent objective hacking을 막는 정규화 기법에 가까움. - 가장 가까운 prior work인 LeWM+CEM·DINO-WM 대비 world model·표현은 그대로 두고 planner만 바꿨다는 점은 실용적이지만, decoder가 시뮬레이터 state descriptor로 학습돼 있어 실제로는 privileged information에 의존하는 구조임(논문도 한계로 인정).

누리랩 연구와의 연결
- terminal energy로 latent objective만으로는 못 잡는 실패(목표 미도달인데 latent cost는 낮은 경우)를 planning 단계에서 걸러내는 아이디어는 누리랩의 failure detection/recovery, test-time optimization 주제와 직접 연결됨. - decoder 기반 terminal descriptor 대신 object-centric 3DGS나 scene graph 기반 geometry-aware descriptor를 goal 표현으로 쓰면(논문이 스스로 future work로 제안) privileged state 의존을 줄이면서 real-robot에 적용 가능한 확장이 될 수 있음. - world model은 그대로 두고 test-time에서 planner objective만 바꿔 성능을 크게 올린 사례라, 우리 VLA·world model 파이프라인에서도 frozen policy 위에 test-time energy를 추가하는 방식을 재현성 있게 시도해볼 만함.

Object-centric 3D 검색 기반 test-time failure recovery - research question: 실패 직후 유사한 성공 시연을 3D 표현으로 검색해 recovery 궤적을 즉시 생성할 수 있는가 - 접근·novelty: RoboTok의 actor-centric 3D trajectory retrieval을 object-centric 좌표계로 바꾸고, GraFT의 3D scene graph를 검색 인덱스로 결합. RoboTok은 학습 데이터 확보용으로만 검색을 쓰고 test-time recovery에는 쓰지 않음 - 왜 지금·경쟁 prior works: retrieval augmented policy는 있으나 실패 발생 이후 실시간 recovery로 쓴 사례는 아직 드묾. RoboTok의 검색 정확도(mAP@20 0.353)가 이미 실증됨 - risk·target venue: 검색 latency가 실시간 recovery에 맞는지가 관건. CoRL 겨냥, 실로봇 실패 시나리오 데이터셋 구축이 선행되어야 함

Evidence-gated 센서 신뢰도를 counterfactual로 학습 - research question: 사전 정의된 task 구조 없이, 센서를 가상으로 perturb했을 때 예측이 얼마나 바뀌는지로 evidence 신뢰도를 학습할 수 있는가 - 접근·novelty: Sensing Which Modality Matters의 evidence-gated invariance/sufficiency가 현재는 사전 정의된 라벨에 의존하는 한계를, VeriPhy의 typed evidence record(measured/abstained/errored) 구조로 보완하고, 여기에 world model 기반 counterfactual perturbation을 새로 추가해 대체 - 왜 지금·경쟁 prior works: 두 논문 모두 evidence 개념을 다루지만 각각 라벨 의존과 미실행 closed-loop라는 한계를 스스로 명시함. 둘을 잇는 후속 연구가 명시적 gap으로 열려 있음 - risk·target venue: counterfactual perturbation을 실로봇에서 안전하게 수행하는 절차가 필요. CoRL/RSS

과거-압축·미래-정밀 비대칭 표현을 manipulation에 이식 - research question: 자율주행에서 검증된 "과거는 discrete로 압축, 미래는 continuous로 정밀 생성"하는 비대칭 표현이 manipulation VLA의 action tokenizer에도 유효한가 - 접근·novelty: LaPla의 frozen residual VQ-VAE decoder + continuous latent projection 구조를 FAST 등 기존 manipulation action tokenizer와 비교 실험 - 왜 지금·경쟁 prior works: LaPla는 자율주행 궤적에서만 검증됨. manipulation은 접촉·힘 등 자율주행에 없는 불연속성이 있어 같은 설계가 통할지가 열린 질문 - risk·target venue: 자율주행과 manipulation의 action space 성격이 달라 이식이 실패할 위험이 있음.
